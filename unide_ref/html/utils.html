Утилиты

Started Util

Меню Started Util перечисляет открытые окна утилит (все видимые окна, кроме главного); щелчок поднимает окно, свёрнутое разворачивает. Те же окна показаны оранжевыми плашками справа в строке меню: имя окна, полный заголовок — в подсказке, щелчок поднимает окно.

Find inc file

Utils → Find inc file... (только в проектах Basic): поиск include-файла на дисках по имени (маски допускаются), галка «Все локальные диски», список найденных копий, кнопки «Копировать в папку inc проекта» и «Открыть в редакторе». Окно предлагается само, когда rc.exe не находит $INCLUDE.

INC Manager

Utils → IncManager... (только в проектах Basic): проверка своих include-файлов RapidQ против эталона, защитный $IFNDEF, демо-программа, сборка нескольких файлов в один.

Недостающие файлы и строгая проверка

Окна, которые открываются перед сборкой RapidQ: «Недостающие файлы программы» и «Строгая проверка» (RapidQ).

Tidy editor.ini

Projects → Manage Projects → Tidy editor.ini...: поиск файлов editor*.ini и *.prj в выбранной папке (Scan), перенос отмеченных проектов (Add to editor.ini), разбор настроек (Tidy and restart). Tidy пишет рядом editorNew.ini, копии для других компьютеров (editorN.ini) и editorOLD.ini; при перезапуске editorNew.ini становится editor.ini, прежний сохраняется как editor_prev.ini. Add to editor.ini дописывает отмеченные проекты прямо в editor.ini.

Build Release, Release files

Только для проектов Delphi. unIDE находит файлы, которые нужны exe (по файловым операциям в исходниках), показывает их списком с галками и кладёт выбранное вместе с exe в папку Release рядом с .dpr (прежняя папка Release удаляется).

Palette Icons

View → Palette Icons... или правая кнопка на кнопке палитры → Edit Icon...: свои значки компонентов палитры. Хранятся в palette_icons.txt рядом с программой.

Окна и закладки

  • Windows → Del WinList... — отметить несколько окон галками и закрыть разом.
  • Bookmarks → Clear List... — удалить отмеченные закладки.
  • Hot Bookmarks → Закрепить... — закрепить закладки.
