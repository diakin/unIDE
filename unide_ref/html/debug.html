Отладка

Отладчики есть для Delphi и для RapidQ (сборка rc.exe). Для FreeBASIC и для RapidQ через FreeBASIC отладчика пока нет.

Клавиши

КлавишаДействие
F9Compile & Run; на остановке — продолжить.
Ctrl+F2Program reset — остановить программу.
F5Поставить или снять точку останова на строке с кареткой.
Ctrl+F5Add watch — имя или выделение под кареткой в окно Watch.
F7Trace into — шаг с заходом в подпрограммы.
F8Step over — шаг без захода.
F4Run to cursor — до строки с кареткой.

F7, F8 и F4 работают на остановке; если программа не запущена, она собирается и запускается с остановкой. Кнопка Pause (остановить программу там, где она сейчас) есть только у отладчика Delphi.

Точки останова

  • F5, щелчок по номеру строки или двойной щелчок по полосе меток.
  • Красный кружок — точка, стрелка — строка остановки.
  • Правый щелчок по номеру строки или полосе меток, либо пункт «Breakpoint condition...» в меню редактора, задаёт условие (только RapidQ).

Окно Watch

Столбцы: Выражение, Значение, Условие, Тип. Меню окна: Добавить... (Ins), Изменить... (Enter), Условие..., Удалить (Del), Удалить все, Добавить переменные процедуры (параметры и локальные текущей процедуры). Двойной щелчок по столбцу Условие открывает условие, по остальным — правку выражения. Над списком пишется, где стоит программа.

Значение под мышью: на остановке при наведении на имя появляется «Имя = значение» (Editor Options → Code Insight → Tooltip expression evaluation).

Отладка RapidQ

Exe RapidQ не содержит адресов строк, поэтому unIDE отлаживает копию программы <имя>_rqdbg.bas, в которой перед каждым оператором вставлена проверка точки останова. Копия собирается, когда в программе есть точки или запуск идёт по F7, F8, F4. Exe получается тот же <имя>.exe.

  • На остановке программа стоит целиком: её окна не перерисовываются, как под отладчиком Delphi.
  • Точки, поставленные или снятые на ходу, начинают действовать после следующей остановки.
  • Точка не ставится на строки без кода: пустые, комментарии, объявления (DIM, CONST, DECLARE), блоки CREATE и TYPE, директивы, ELSE, CASE, LOOP, NEXT, END IF, заголовки и концы SUB.
  • В копию попадают и отлаживаются include-файлы, в которых есть точки, и те, что открыты во вкладках этого главного файла.
  • Ошибки компиляции копии показываются по строкам исходника.

Условия точек

Условие — выражение RapidQ, например SumIdx = 2 или Count > 10 AND Name$ = "abc" (без : и ' вне кавычек). Оно вписывается в копию, поэтому новое условие действует после пересборки (Ctrl+F2, затем F9). F7 и F8 на условия не смотрят.

Переменные и выражения

  • Показываются объявленные переменные простых типов и параметры SUB; локальные — только в своей SUB.
  • Не показываются массивы целиком, объекты, VARIANT, свои TYPE, переменные без DIM.
  • Выражения Watch (a(3), Form.Caption, a+b) вставляются в копию при сборке; новое выражение получает значение после пересборки. Объект.Свойство простого типа (например Tab.TabIndex) показывается с типом свойства из описания компонентов.
  • Условие Watch (столбец Условие, например =10, <5, <> 0): точка, где выражение вычисляется, срабатывает только при выполнении всех таких условий. Действует после пересборки.

Лог сборки и сеанса сохраняется в <имя>_rqdbg.log.

Отладка Delphi

  • Программа запускается под отладчиком Win32. Адреса строк берутся из .map, значения — из отладочной информации exe (ключ -V).
  • Точки можно ставить в работающую программу.
  • F7 заходит в процедуры с номерами строк; F8 проходит вызовы целиком. Код без номеров строк (RTL, VCL, DLL) проходится свободно. F7/F8 до запуска останавливают на begin главного блока.
  • Pause останавливает программу; если все потоки стоят в чужом коде, по стеку ищется строка вызова.
  • Исключения программа обрабатывает сама; в лог пишутся код, класс, сообщение и строка.
  • Watch: имя или цепочка через точку (Self.FCount, Rec.Field, Form1.Edit1). Типы: числа, символы, Boolean, строки, указатели, объекты (класс и адрес), записи и массивы, перечисления, множества. Для статического массива справа открывается панель с индексами и таблицей значений.

Строка вывода значения

Пункт меню редактора «Debug (RuntimeLog)» вставляет под строкой вызов AddClrString(...), который выводит значение переменной в Runtime log.
