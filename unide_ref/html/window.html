Главное окно

Сверху вниз: строка меню, панель инструментов (файлы, поиск и замена, рамка Project со сборкой), вкладки открытых файлов, панель объявления, редактор с полосой номеров и полосой меток, логи. Справа — правая панель со списками и инспектором.

Отдельных меню поиска и сборки нет: поиск — на панели инструментов, сборка и запуск — кнопками рамки Project и клавишами F9, F7, F8, F4.

Вкладки файлов

  • Одноимённые .pas и .dfm стоят рядом: модуль слева, форма справа.
  • Include-файл RapidQ, открытый из дерева Includes или остановкой отладчика, помнит свой главный .bas: его имя показано на вкладке после имени файла, а сборка и запуск с этой вкладки идут по главному файлу.
  • Меню вкладки (правый щелчок): Перечитать файл с диска, Подсветка, Закрыть вкладку, Закрыть остальные вкладки.
  • Файл перевода RapidQ в папке _rqfb открывается только для чтения (Перевод _rqfb).

Правая панель

ВкладкаЧто показывает
SubListПодпрограммы файла: Name, Begin, End. Над списком — фильтр (Esc — очистить, Enter — к первой найденной, стрелка вниз — в список). Двойной щелчок переходит к подпрограмме.
ObjectsИнспектор объектов: дерево объектов формы, свойства и события (Инспектор).
CodeТолько Delphi: все компоненты, которые создаёт код модуля, с номером строки создания; щелчок — к строке.
IncludesТолько RapidQ и FreeBASIC: дерево подключённых файлов с путями и номерами строк. Ненайденный файл помечен; двойной щелчок открывает строку подключения. Для файлов C/C++ вкладка называется Headers; при сборщике Arduino она скрыта.

Какие вкладки видны, зависит от режима среды: для Basic видны Includes и страницы палитры RQ, для Delphi — Code, Build Release и «Перенести в .dfm».

Логи

ВкладкаЧто в ней
Compilation logВесь вывод сборки. Ошибки красные, подозрения тёмно-оранжевые.
Error logТолько ошибки; открывается сам при неудачной сборке.
HiLite logСлужебные сообщения среды (выбор сборщика, замеры, разбор).
Runtime logВывод программы и отладочные строки AddClrString.

Двойной щелчок по строке ошибки открывает файл на этой строке. Понимаются форматы dcc32, fbc, gcc и сообщения перевода RqToFb.

Строка состояния

Номер строки и позиция каретки, код символа под кареткой, кодировка файла (UTF-8 BOM, UTF-8 или ANSI), замеры отрисовки. Над ней — строка с полным путём файла, размером и датой.
