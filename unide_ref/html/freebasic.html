FreeBASIC

Сборка программы FreeBASIC

  • Главный файл: вкладка, открытая из Includes, собирается по своему главному файлу; .bas, подключённый через #include в цель проекта, — по цели; иначе файл вкладки (он же становится целью проекта).
  • Вид и разрядность — списки GUI / Console / DLL и 32 / 64 в рамке Project; запоминаются для главного файла. По умолчанию Console, 32 бит (если есть только 64-битный компилятор — 64).
  • Компилятор — IDE Options → Compilers → FreeBASIC: FB compiler 32 (ищется fbc32.exe, затем fbc.exe) и FB compiler 64 (fbc64.exe, затем fbc.exe; пустое поле — fbc64.exe ищется в папке FB compiler 32).
  • Include и Library передаются ключами -i и -p. Пустые поля — ключи не передаются, и fbc берёт свои папки inc и lib; в лог пишется, какая папка взята. Кнопка «...» у пустого поля открывает папку inc или lib компилятора.
  • Результат (exe или dll) — рядом с главным файлом.

RapidQ через FreeBASIC (FB Smart, FB Compat)

Программа RapidQ переводится в FreeBASIC препроцессором RqToFb и собирается fbc вместе с библиотекой компонентов RqLcl (классы RapidQ поверх LCL, rqlcl32.dll / rqlcl64.dll).

  • FB Smart — программа не падает там, где можно продолжить работу; ошибки выполнения показываются с файлом и строкой исходника RapidQ, пишутся в <программа>_error.log.
  • FB Compat — поведение как в RapidQ.

Этапы видны в окне хода сборки: проверка настроек, перевод, компиляция fbc, разбор вывода, копирование библиотеки компонентов.

  1. Папка RqLcl — поле RqLcl folder (Compilers → RapidQ Basic), иначе RqLcl\ рядом с unIDE. В ней должны быть inc\rqrt.bi и inc\rqlcl.bi.
  2. Каждый файл программы переводится в папку _rqfb рядом с главным .bas. Строки переводятся один к одному, с директивами #line, поэтому ошибки fbc указывают на строки исходника RapidQ.
  3. В лог выводятся итог перевода и список подозрений на ошибки в программе.
  4. fbc собирает exe рядом с главным .bas, ресурсы $RESOURCE — через .rc-файл перевода.
  5. Рядом с exe копируется rqlcl32.dll или rqlcl64.dll, если её там нет или она старее.
  6. Переведённый главный файл открывается во вкладке.

Окна ошибок библиотеки RqLcl и ошибки классов называют файл и строку исходника RapidQ, на которой был вызов: «Строка исходника: Файл.bas(N)».

Вкладка перевода _rqfb

Файлы в _rqfb пересоздаются при каждой сборке, поэтому во вкладке они только для чтения. При первой попытке их править появляется вопрос «Перевод RapidQ -> FreeBASIC»:

КнопкаЧто дальше
Связь с RapidQИсходником остаётся RapidQ. Перевод только для чтения; в инспекторе и конструкторе правятся свойства, которые можно перенести в исходник RapidQ. Правка пишется в исходник (строка ищется по #line) и сразу повторяется в переводе. Если в исходнике у свойства выражение, которое перевод переписал, правка отклоняется. Обработчики событий создаются в исходнике RapidQ.
Перейти на FreeBASICПапка _rqfb копируется в <главный>_fb рядом с исходником; строки #line удаляются, пути исправляются. Копия открывается и дальше правится как обычный FreeBASIC; исходник RapidQ с ней больше не связан. Exe собирается в папке _fb.
CancelНичего не делать.

Выбор запоминается для главного файла RapidQ в editor.ini, раздел [RqFbMode]. Чтобы выбрать заново, удалите строку файла из этого раздела.

Файл из _rqfb можно собрать и прямо со своей вкладки: unIDE распознаёт перевод по заголовку и собирает его с теми же ключами, что FB Smart, а exe кладёт рядом с исходником RapidQ.
