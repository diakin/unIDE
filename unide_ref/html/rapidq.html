RapidQ

Программу RapidQ unIDE собирает одним из трёх способов, выбранным в рамке Project для главного .bas:

  • rc.exe — компилятор RapidQ;
  • FB Smart и FB Compat — перевод в FreeBASIC и сборка fbc (RapidQ через FreeBASIC).

Выбор запоминается для главного файла. Режим можно задать и в самом исходнике строкой '$RQFB SMART или '$RQFB COMPAT (для rc.exe это комментарий).

Сборка rc.exe

  1. Определяется главный .bas проекта.
  2. Препроцессор проверяет, что все файлы программы на месте (ниже).
  3. Если стоит галка «FB smart» — строгая проверка (ниже).
  4. rc.exe вызывается с ключами -I (папка include), -L (Library), -G (значок). Exe появляется рядом с .bas; занятый старый exe переименовывается в .exe.old.
  5. Ошибки разбираются, каретка переходит к первой. Если rc.exe не нашёл файл $INCLUDE, unIDE предлагает найти его копии на дисках (окно Find inc file).

Настройки — IDE Options → Compilers → RapidQ Basic: папка rc.exe (Compiler), Include UnIde, Include User, Library, App icon, Components, RqLcl folder.

Папки include

  • Include UnIde — набор include-файлов, который поставляется с unIDE (rapidq_ref\RQInc); пустое поле — эта папка рядом с программой.
  • Include User — своя общая папка include.
  • Проект выбирает одну из них (или свою папку) в Project Properties или в рамке Project. Файл без проекта использует Include UnIde.

Препроцессор: недостающие файлы

Перед каждой сборкой rc.exe unIDE читает главный .bas и все его include-файлы, в том числе вложенные, и проверяет, что на месте:

  • файлы $INCLUDE и $RESOURCE — в папке программы и папке include;
  • DLL из DECLARE ... LIB "x.dll" — рядом с exe, в системных папках и в PATH.

Условные директивы $IFDEF/$IFNDEF/$ELSE/$ENDIF, $DEFINE, перенос строк и комментарии учитываются.

Если чего-то не хватает, открывается немодальное окно «Недостающие файлы программы»:

  • список: имя, вид (inc / resource / DLL), где используется, сколько копий найдено;
  • под ним — найденные копии, текст выбранной копии и поле «Куда»;
  • кнопки: Искать (поиск на дисках; «...» — папки поиска), Скопировать, Копировать отмеченные и собрать, Собрать без копирования, Отмена;
  • галка «Не спрашивать про неотмеченные» запоминает исключения;
  • для $INCLUDE с несуществующей подпапкой предлагается исправить путь в исходнике или создать подпапку в Include UnIde.

Include-файлы и ресурсы копируются в папку include, DLL — в папку программы.

Строгая проверка

Галка FB smart в рамке Project (при rc.exe) включает проверку программы переводом в FreeBASIC без компиляции. Она находит:

  • ошибки программы — GOTO в чужую SUB, объект без DIM/CREATE, CASE > 5 вместо CASE IS > 5, незакрытый блок, BIND на несуществующую SUB, TYPE объявлен дважды и т. п.;
  • подозрения — места, которые скорее всего работают не так, как задумано;
  • ограничения перевода — только для сведения.

С галкой Info only всё уходит в лог, и rc.exe собирает программу. Без неё открывается немодальное окно «Строгая проверка» со списком: двойной щелчок открывает строку; кнопки Найти определение, Заменить на ..., Вставить IS, Подключить ..., Открыть строку, Собрать rc.exe как есть. Снятая галка у строки пропускает её при следующих проверках.

Снимок программы

Чтобы показать настоящие значения свойств (выражения вроде Width = Panel.ClientWidth*2\3), unIDE собирает и запускает копию программы _rqprobe.bas, которая выписывает значения всех объектов и завершается. Подробно — в разделе Инспектор: снимок RapidQ.

Отладка

Программа, собранная rc.exe, отлаживается своим отладчиком unIDE: точки останова, условия, шаги, окно Watch (Отладка RapidQ). Для сборки через FreeBASIC отладчика пока нет.
