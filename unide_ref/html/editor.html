Редактор

Подсветка синтаксиса

Цвета и слова берутся из схемы schemes\<расширение>.clr. Если своей схемы у расширения нет, используется соответствие (pp, dpr, inc → pas; lfm → dfm и др., см. Схемы подсветки). Для отдельного файла схему можно выбрать вручную: View → Highlighting или «Подсветка» в меню вкладки. Пункт «Авто (по расширению)» возвращает выбор по расширению.

Линии отступа

Слева от текста блоки отмечены вертикальными полосами; цвета чередуются по пяти уровням. Уровни считаются по блокам языка (begin/end, SUB/END SUB, скобки и т. п.), а не по числу пробелов. Включаются галкой HiLight и настраиваются на вкладке Editor Options (там же бледность полос в процентах).

Если начало или конец блока ушли за край окна, у края появляется метка. Щелчок по ней показывает строку начала или конца блока в панели объявления.

Скобки

  • Когда каретка стоит на скобке ( ) [ ] { } или сразу за ней, подсвечивается она и её пара (в HTML — парный тег). Скобки в строках и комментариях не считаются.
  • Одновременно все скобки этой строки окрашиваются цветом линии отступа своего уровня вложенности: пара получает один цвет.
  • Цвет пары задаётся строкой Pair Mark (bracket under caret) в таблице схемы. Если цвет текста в ней None, текст пары берёт цвет своего уровня.

Закладки

Полоса меток между номерами строк и текстом показывает закладки (квадратик с номером), точки останова (красный кружок) и строку остановки отладчика (стрелка).

  • Щелчок по полосе меток ставит или снимает закладку; двойной щелчок ставит точку останова.
  • Меню Bookmarks: Add BookMark, Delete BookMark, Set BookMark (переставить последнюю закладку на текущую строку), Sort BookMark, Delete Missing BookMarks, Clear List... и список закладок текущего окна. Закладки, строк которых нет, показаны серыми.
  • LastBM — вернуться к предыдущей закладке; повторные нажатия идут по истории по кругу.
  • Hot Bookmarks — закреплённые закладки и 8 последних посещённых со всех вкладок. Ctrl+щелчок закрепляет или открепляет.

Переход к закладке ищет строку по её тексту от прежнего места, поэтому закладка не теряется после правок выше неё. Закладки хранятся в проекте.

Панель объявления

Панель над редактором после щелчка в тексте показывает объявление идентификатора под кареткой, в том числе из других модулей и include-файлов. Щелчок по панели переходит к объявлению, повторный щелчок возвращает назад. Справа на панели — имя подпрограммы, в которой стоит каретка. Для RapidQ свой разбор: DIM, CONST, CREATE, SUB/FUNCTION, TYPE, $DEFINE, метки, include-файлы.

Format text

Меню Format text заново расставляет отступы в активном файле; меняются только пробелы в начале и конце строк. Глубина считается по словам блоков схемы. Строки внутри незакрытых скобок выравниваются по скобке. Чем делать отступ (пробелы, табуляции, без отступа) и его размер задаются в Editor Options, группа Indent hilight (строка Indent).

  • RapidQ: блоки CREATE ... END CREATE, записанные в одну строку, разворачиваются.
  • RapidQ: объекты DIM X AS Qкласс с X.Parent = Родитель встают деревом: строка DIM ребёнка на уровень правее DIM родителя, строки свойств X.Свойство = ... — правее своего DIM. Линии отступа тогда показывают, где чьи дети. Объект без родителя и детей в файле не сдвигается.
  • Для Паскаля и C строки, код которых кончается точкой, помечаются как подозрительные.
  • Откат — Edit → Отменить массовую замену.

Набор текста

  • Enter ставит отступ уровня блока.
  • Двойной щелчок выделяет слово без пробелов после него.
  • Show spaces (Editor Options) показывает пробелы точками «·» и табуляции знаком «»».
  • Меню редактора (правый щелчок): Search {выделение} — перенести выделение в поле поиска; Debug (RuntimeLog) — вставить строку вывода значения переменной; Run to cursor, Add watch, Breakpoint condition...; правка; Clear; To UpperCase, To LowerCase.

Кодировки

При открытии определяется UTF-8 (с BOM и без); иначе файл считается ANSI (кодовая страница Windows). При сохранении восстанавливается исходная кодировка. Символы, которых нет в кодовой странице Windows, при сохранении теряются. Кодировка видна в строке состояния.

Просмотр по формату

Вкладку с файлом .md, .html/.htm, .mht, .rtf или .rvf можно показать не текстом, а так, как файл выглядит: F12, кнопка Txt/Fmt у левого края вкладки, View → Просмотр по формату или пункт «По формату» в меню правой кнопки; повторное F12 или «Как текст» в меню правой кнопки возвращает текст. Просмотр закрывает текст, номера строк и полосы прокрутки; редактор под ним на это время только для чтения. Вид запоминается для каждой вкладки отдельно, место прокрутки — для каждого файла.

Если текст во вкладке не менялся, просмотр строится по файлу на диске — символы вне кодовой страницы Windows (стрелки и т.п.) видны, у HTML и MHT работают картинки и стили по относительным путям. Правленый текст берётся из редактора (у HTML относительные пути по-прежнему считаются от папки файла). RVF всегда показывается с диска.

Ссылки на странице: метка (#раздел) — переход по странице; файл, который открывается в unIDE (.md, .html, исходник и т.п.), — вкладкой, у файлов с просмотром по формату сразу в этом виде; адрес в интернете, PDF, картинка, папка — программой Windows.

Режим Internet Explorer выбирается по объявлению <!DOCTYPE> страницы, как в самом браузере: с полным объявлением — режим установленной версии IE, без него или с неполным — режим совместимости (IE 5). Для этого при первом показе страницы unIDE записывает для своего exe значение FEATURE_BROWSER_EMULATION в HKEY_CURRENT_USER\Software\Microsoft\Internet Explorer\Main\FeatureControl (11000 для IE 11); уже записанное значение не меняется. Без этой записи встроенный IE показывал бы все страницы в режиме IE 7.

Меню правой кнопки на просмотре: «Как текст» / «По формату», «Копировать» (Ctrl+C), «Выделить всё» (Ctrl+A).

Вторая панель

View → Разделить по вертикали (панели слева и справа) или по горизонтали (сверху и снизу); View → Без разделения или кнопка x в заголовке панели убирает её. Граница между панелями перетаскивается мышью.

Редактор с подсветкой один, править можно в одной панели. Вторая показывает любую открытую вкладку только для чтения: текст с подсветкой по схеме файла или, кнопкой Txt/Fmt в заголовке, вид по формату (.md, .html, .mht, .rtf, .rvf). Вкладка выбирается щелчком по заголовку панели или пунктом «Во второй панели» в меню правой кнопки на вкладке; на полосе вкладок она отмечена чертой снизу.

У обеих панелей сверху строка с именем файла (щелчок по ней — другая вкладка в этой панели) и кнопкой Txt/Fmt; строка панели, в которой работают, подсвечена цветом активной вкладки. F12 переключает вид активной панели. Вид каждой панели свой и при переходе из панели в панель не меняется: например, в одной панели правится код HTML, в другой видна та же страница в браузере и обновляется после паузы в наборе. Щелчок по странице (виду по формату) только делает эту панель активной.

Щелчок по тексту второй панели — править в ней: панели меняются местами, редактор открывает её вкладку с кареткой в месте щелчка, а прежняя вкладка редактора остаётся рядом текстом только для чтения, на том же месте прокрутки. В обеих панелях может быть одна и та же вкладка: тогда вторая показывает другое место того же текста или его вид по формату и обновляется после паузы в наборе (текст с подсветкой больше 1 000 000 символов — только при смене панелей).

В меню правой кнопки на второй панели — «Копировать» (Ctrl+C) и «Выделить всё» (Ctrl+A).

Изменения файла на диске

Файлы открытых вкладок проверяются при возврате в программу и раз в 2 секунды. Если файл изменили снаружи:

  • в окне нет правок — файл перечитывается без вопроса;
  • правки есть и тексты различаются — вопрос: Перечитать, Слить (трёхстороннее слияние; при конфликте вставляются метки <<<<<<< / ======= / >>>>>>>), открыть версию с диска в новой вкладке или оставить текст окна. Галка «то же для остальных» применяет ответ ко всем файлам.

Перед сборкой проверка выполняется обязательно; если после ответа остались конфликты, сборка не начинается.
