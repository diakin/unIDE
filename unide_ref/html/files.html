Файлы и папки unIDE

Рядом с программой

Файл / папкаЧто в нём
editor.iniВсе настройки и проекты. Разделы, например: [Editor], [Themes], [IdeFonts], [CodeInsight], [Preferences], [Designer], [EnvironmentVariables], [Compiler.*], [Projects], [Project.<имя>], [Recent], [HotFolders], [FindInFiles], [FileSchemes], [RqFbMode].
editor1.ini, editor2.ini...Настройки для других компьютеров: при запуске unIDE выбирает файл, папка которого совпадает с папкой программы.
IDE.clrЦвета самой среды (Light, Dark, свои темы).
schemes\Схемы подсветки <ext>.clr, общая •default•.clr, соответствия alias.ini.
rapidq_ref\Справка RapidQ (help\rapidq.chm, help\keywords.txt), HTML-страницы, набор include RQInc, эталон incOld, описание компонентов Component*.data.
fb_ref\Руководство FreeBASIC help\freebasic.chm и слова для F1 help\fbkeywords.txt.
unide_ref\Это руководство: help\unide.chm.
RqLcl\Библиотека компонентов RapidQ для FreeBASIC (inc, bin).
palette_icons.txtСвои значки палитры.
startup.logЭтапы последнего запуска (по ним идёт полоса окна загрузки).
hang.log, crash.logСведения о зависании или сбое среды.

Папки rapidq_ref, fb_ref и unide_ref ищутся рядом с программой, уровнем выше и в projects\*\.

Рядом с программой пользователя

ФайлЧто в нём
<имя>_compile.batКомандная строка последней сборки.
<имя>_compile.logЛог сборки с ошибками.
_rqfb\Перевод RapidQ в FreeBASIC (FB Smart/Compat).
<имя>_fb\Отделённая копия перевода после «Перейти на FreeBASIC».
<имя>_rqdbg.bas, .cmd, .state, .logКопия для отладчика RapidQ и файлы связи с ним.
_rqprobe.bas, _rqprobe.txtСнимок значений объектов RapidQ.
<программа>_error.logОшибки выполнения программы, собранной через FB Smart.
dsgcache\Кэш разбора форм и снимков инспектора.
