Проекты

Проект запоминает набор открытых файлов, вкладки, закладки, главный файл сборки и тип. Все проекты описаны в editor.ini: раздел [Projects] со строками Имя=папка проекта и раздел [Project.<Имя>] с типом (Type=), целью сборки (Target=; \ в начале — путь от папки проекта) и состоянием окон.

Файлы .prj — прежний формат (общий с RQdebugger). При запуске и через Open Project их описание переносится в editor.ini; сами .prj на диске не меняются.

Ниже пунктов — список всех проектов в виде «Имя • Тип»; текущий отмечен. Последний проект открывается при следующем запуске.

Окно New Project / Project Properties

  • Имя проекта, папка проекта, тип проекта, «На базе существующего проекта».
  • Типы: RapidQ Basic, Delphi, Lazarus, FreeBASIC, Visual Basic, Arduino, C project, CPP project, Go, Python, Rust, WebSite.
  • Для приложения Delphi создаются .dpr, Unit1.pas, Unit1.dfm и пустой .res; для DLL и консольной программы — .dpr и .res; для остальных типов — папка и описание.
  • Рамка «Папка inc (RapidQ)»: проект RapidQ берёт include-файлы из Include UnIde, Include User или своей папки.
  • У проекта Delphi есть страница Project options (как в Delphi 7: Forms, Application, Compiler, Compiler Messages, Linker, Directories/Conditionals, Version Info, Packages). Настройки пишутся в .dof, .dpr и .res.

Окно Delete Projects

Список с галками и выбор: удалить только описание проекта или папку проекта целиком в корзину. Проект без описания на диске просто убирается из списка.

Главный файл (цель сборки)

У проекта есть цель — файл, который собирается: .dpr для Delphi, главный .bas для RapidQ и FreeBASIC. Если собрать вкладку с файлом, который цель не подключает, этот файл сам становится целью. Include-файл собирается по главному файлу, который его подключает. Текущая цель видна в рамке Project под переключателем сборщика.
