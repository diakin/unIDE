Сборка и запуск

Как выбирается сборщик

Сборщиков четыре: Delphi, RapidQ, FreeBASIC, Arduino. Выбирается по файлу активной вкладки:

  1. Если для файла сборщик выбран вручную в рамке Project — он.
  2. По расширению:
    • .pas .dpr .dfm .dpk — Delphi; .ino .pde — Arduino; .rqb .rq — RapidQ; .prj — по типу проекта;
    • .bas — по главному файлу, если он подключён в другой; иначе по тексту файла (первые 64 КБ: строки с директивами $..., AS QFORM, CREATE ... AS Q... считаются за RapidQ, с директивами #... — за FreeBASIC, побеждает большинство); признаков нет — по типу проекта, иначе RapidQ;
    • .inc .bi — по главному файлу; без него .bi — FreeBASIC, .inc — Delphi, если в папке есть .dpr, иначе по проекту;
    • .c .cpp .h .hpp в папке скетча — Arduino.

Почему выбран сборщик, пишется первой строкой лога сборки: «Сборщик: RapidQ (по тексту файла)».

Рамка Project

  • Переключатель сборщика: Delphi, RapidQ, FreeBASIC, Arduino, Auto. Выбор запоминается для файла; Auto возвращает выбор по файлу.
  • Цель — файл, который будет собран, или «цель не найдена».
  • RapidQ: компилятор главного файла (rc.exe, FB Smart, FB Compat), папка include проекта, галки «FB smart» (строгая проверка) и «Info only».
  • FreeBASIC (и FB Smart/Compat): вид результата (GUI, Console, DLL) и разрядность (32 / 64).
  • Arduino: список плат на USB, кнопки Verify и Upload.

Сборка и запуск

  • Compile & Run (кнопка, F9) — сохранить файлы, собрать и, если ошибок нет, запустить. На остановке отладчика F9 продолжает программу. У скетча Arduino F9 выполняет Upload.
  • Program reset (Ctrl+F2) — остановить запущенную программу (у Arduino — снять arduino-cli).
  • Перед сборкой несохранённые файлы сохраняются, а изменения файлов на диске проверяются.
  • Exe запускается из своей папки. Консольная программа запускается в окне, которое после конца программы ждёт нажатия клавиши.
  • Preferences: Minimize on run (свернуть среду на время работы программы), Hide designers on run (спрятать конструкторы форм).

Ошибки

Ошибки компилятора выводятся красным в Compilation log и повторяются в Error log, который открывается сам. Каретка переходит к первой ошибке. Двойной щелчок по строке ошибки открывает файл на этой строке. При ошибках лог сохраняется в <главный>_compile.log.

Командная строка компилятора при каждой сборке сохраняется в <главный>_compile.bat: её можно запустить вручную.

Окно хода сборки

Окно «Ход сборки» показывает этапы (ждёт / идёт / готово / ошибка / пропущен) с временем, текущую строку лога, полосу, счётчики ошибок и предупреждений. Кнопки: Стоп (снять компилятор), Скрыть / Закрыть. Галка «Закрывать окно после удачной сборки».

Сборка RapidQ через FreeBASIC показывает это окно всегда; Delphi, FreeBASIC и RapidQ (rc.exe) — если включено Preferences → Show compiler progress. У Arduino окна хода сборки нет.
