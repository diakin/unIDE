Настройки (IDE Options)

Меню Options открывает окно IDE Options. Вкладки: Color Scheme, Editor Options, IDE colors and Fonts, Compilers, Arduino, Preferences, Designer, Environment Variables, File Types. Почти все значения записываются сразу при изменении.

Color Scheme — схемы подсветки

Таблица показывает разделы схемы активной вкладки: Syntax Element, Font Color, Background Color. Под таблицей — данные раздела (слова, маркеры). Двойной щелчок по цвету открывает выбор цвета.

  • Темы редактора (список сверху, Add, Delete): одна схема хранит цвета для всех тем. Основную тему Classic Windows удалить нельзя.
  • Режим IDE: IDE Light, IDE Dark, Custom (свои темы, Add, Del).
  • Add Group / Delete Group — группы Keywords, Operators, Block Comment, Line Mark.
  • Restore Defaults — вернуть цвета к умолчаниям.
  • Edit Default — править общую схему schemes\•default•.clr (кнопка становится Edit Current).
  • Open clr file — открыть файл схемы во вкладке; Select scheme — взять другую схему как заготовку.
  • Save записывает схему, Exit закрывает окно.

File Types — какая схема у расширения

Порядок: своя схема schemes\<ext>.clr; соответствие в schemes\alias.ini (раздел [Alias], строки вида pp=pas); для .inc в проекте RapidQ — bas; встроенные соответствия (dpr, dpk, pp, p, lpr, inc → pas; lfm → dfm; lpi, lps, lpk, fpd → xml; toml → ini). Вкладка File Types показывает и правит эти соответствия (Add..., Edit..., Delete).

Editor Options

  • Syntax HiLight, Show spaces, Tab (ширина табуляции), Show line numbers, Font Change (шрифт редактора, один на все языки).
  • Indent hilight: строка Indent — чем делать отступ (spaces, tab, none) и сколько; HiLight — линии отступа и их бледность.
  • Editor colors: цвета текста и полосы номеров.
  • Margin and gutter: правое поле, полоса номеров, её ширина (Auto — по числу цифр номера последней строки, не меньше пяти), отступ текста от полосы (Text indent, в точках).
  • Code Insight: Code completion, Code parameters, Tooltip expression evaluation, Tooltip symbol insight, задержка; цвета списка.

IDE colors and Fonts

Цвета элементов самой среды (вкладки, меню, выделение, деревья, кнопки, полосы прокрутки, полоса номеров, отладчик и т. д.) и шрифты групп: окна и панели, меню, вкладки файлов, правая панель, логи, строка состояния (размер 8–14). Двойной щелчок — выбор цвета или шрифта. Цвета хранятся в IDE.clr (свои для Light, Dark и своих тем), шрифты — в editor.ini. «Вернуть умолчания» сбрасывает всё.

Preferences, Designer, Environment Variables

  • Preferences: автосохранение файлов редактора и рабочего стола проекта; Show compiler progress, Minimize on run, Hide designers on run.
  • Designer: Display grid, Snap to grid, Grid size, Auto create forms & data modules, Show component captions, Show designer hints, Show extended control hints.
  • Environment Variables: системные переменные и свои подмены (New..., Edit..., Delete). Подмены видны в путях как $(VAR) и %VAR% и во всех запускаемых программах.
