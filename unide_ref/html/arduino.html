Arduino

Скетчи собираются и загружаются утилитой arduino-cli. Путь к ней и папки задаются в IDE Options → Compilers → Arduino; параметры сборки — на вкладке Arduino.

Сборка и загрузка

  • Кнопки рамки Project: Verify — собрать скетч (arduino-cli compile), Upload — собрать и загрузить в плату. F9 на скетче выполняет Upload.
  • Скетч — папка <имя>\<имя>.ino.
  • Плата — меню Arduino → Board; порт — Arduino → Port или список плат на USB в рамке Project (выбор платы ставит её порт и тип).
  • Если платформа платы не установлена, unIDE предлагает установить её и собрать снова.
  • Вывод arduino-cli идёт в Compilation log; ошибки компилятора — и в Error log, двойной щелчок открывает строку.
  • Program reset (Ctrl+F2) снимает arduino-cli.

Меню Arduino

ПунктЧто делает
Sketchbook, Examples, Include LibraryСкетчи, примеры, подключение библиотеки.
Board, Port, Get Board InfoВыбор платы и порта, сведения о плате.
Serial Monitor (Ctrl+Shift+M)Монитор порта: Send, Autoscroll, Show timestamp, Clear output; окончание строки (No line ending, Newline, Carriage return, Both NL & CR). На время загрузки монитор закрывает порт и потом открывает снова.
Board Manager...Платформы и платы: Core list и Board list, установка ядра, выбор платы, Additional URLs.
Library Manager...Каталог библиотек с фильтрами Type, Topic и поиском, установка.
Arduino CLI Help...Команды arduino-cli и их справка; запуск команды.

Настройки

Вкладка Arduino в IDE Options: Warnings, Log level, подробный вывод при компиляции и загрузке, Verify code after upload, Export compiled binary, Save sketch..., Additional Boards Manager URLs; вкладка Network — прокси; вкладка Cli config file. Кнопка «Импорт из RQdb.ini» берёт пути из настроек RQdebugger.
