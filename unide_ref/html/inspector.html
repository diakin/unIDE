Инспектор объектов и конструктор форм

Инспектор — вкладка Objects правой панели. Сверху — кнопки (снимок, Design form, Hide form, «Перенести в .dfm»), ниже — дерево объектов, страницы Properties (Свойство, Значение, Строка кода) и Events.

Правка свойств

  • Двойной щелчок, Enter или F2 начинают правку. Enter или уход из поля записывают, Esc отменяет.
  • Перечисления выбираются из списка, множества — галками, цвета — из списка констант.
  • Свойства, не заданные в файле, показаны серым со значением по умолчанию; правка серого свойства добавляет строку.
  • Колонка «Строка кода» — строка, которая задаёт значение; щелчок открывает её.

Формы Delphi

  • Дерево строится из .dfm и из кода модуля (компоненты, созданные в коде).
  • Правка меняет одну строку .dfm: во вкладке .dfm, если она открыта, иначе в файле на диске. У компонента, созданного в коде, значение пишется в .pas.
  • Не правятся значения снимка, многострочные значения, двоичный .dfm.
  • Группа (Shift+щелчок в конструкторе): видны общие свойства, правка пишется всем.
  • Events: двойной щелчок переходит к обработчику; у пустого события создаётся обработчик (при открытом конструкторе формы).
  • Снимок — кнопка Show snapshot values / Show .dfm values only: настоящие значения живой формы. Своя форма редактора снимается с живого окна, чужой проект — пробным запуском копии (конструкторы форм и OnCreate выполняются, Application.Run — нет). Ctrl+щелчок делает новый снимок; щелчок по подписи внизу инспектора убирает снимки.
  • Перенести в .dfm — разбирает, какие компоненты, созданные кодом, можно перенести в .dfm; перенос можно откатить.

Программы RapidQ

  • Дерево строится из блоков CREATE ... END CREATE (вложенный CREATE — потомок) и объектов DIM [SHARED] Имя AS Qкласс, свойства которых заданы строками Имя.Свойство = значение. Имя.Parent = Родитель переносит узел под родителя. Разбирается текст редактора вместе с несохранёнными правками; объекты из include-файлов пока не показываются.
  • Не заданные свойства показаны серым по цепочке классов (TYPE ... EXTENDS) и описанию компонентов ComponentAll.data (поле Components в Compilers → RapidQ Basic).
  • Правка заданного свойства меняет значение в той же строке; не заданного — добавляет строку в блок CREATE (у объекта DIM — Имя.Свойство = ... после его свойств). Если значение было выражением, строка с ним остаётся комментарием, под ней пишется новое значение.
  • Events: двойной щелчок переходит к SUB обработчика. У неназначенного события создаётся обработчик Имя+Событие без On (например BtnClick): SUB в конце файла, DECLARE SUB перед объектом, назначение события. Параметры берутся из описания компонентов.

Снимок RapidQ

Кнопка Show snapshot values собирает копию программы _rqprobe.bas рядом с .bas: перед первым CREATE в неё вставлен таймер, который после создания всех объектов выписывает значения их свойств в _rqprobe.txt и завершает программу. Значения показываются в инспекторе и конструкторе. Подпись Update snapshot (отдельным цветом) значит, что текст менялся после снимка; щелчок снимает заново. Свойства, которые компилятор читать не даёт, исключаются и запоминаются.

Перевод _rqfb

Для вкладки перевода FreeBASIC инспектор показывает те же объекты; правка свойств идёт в исходник RapidQ (Вкладка перевода _rqfb).

Конструктор форм Delphi

  • Открывается кнопкой Design form, меню View → Конструктор формы или кнопкой New Form.
  • Форма строится из текста .dfm настоящими контролами VCL в отдельном окне. Изменения пишутся в текст вкладки .dfm, на диск — при Save. У конструктора свой откат (Ctrl+Z).
  • Сетка, привязка к сетке и шаг (2–128) — IDE Options → Designer.
  • Выделение щелчком, группа — Shift+щелчок, перенос мышью, 8 маркеров размера.
  • Двойной щелчок по компоненту создаёт обработчик или переходит к нему.
  • Меню по правому щелчку: Edit (Undo, Cut, Copy, Paste, Delete; буфер совместим с Delphi), Control (Bring to Front, Send to Back), Rename Component..., Replace Components..., Copy Component Names, Align (края, размеры, равные промежутки), Menu (Insert, Delete, Create Submenu, шаблоны меню), Clipboard history..., Layout to log.
  • Палитра: страницы Delphi 7 (Standard, Additional, Win32, System, Dialogs, Win 3.1, Samples) и страницы сторонних компонентов. Значки можно заменить: View → Palette Icons... или правая кнопка на кнопке палитры → Edit Icon....
  • Мастер меню (Insert From Template...) — готовые наборы пунктов и свои шаблоны *.mnu.
  • View → Просмотр модулей / Просмотр форм: при наведении на строку справа показывается картинка формы из .dfm.

Конструктор форм RapidQ

  • Design form у файла RapidQ открывает форму выбранного узла или первую форму файла.
  • Значение свойства: число или строка из кода; если там выражение или свойства нет — из снимка; без снимка — умолчание класса.
  • Перенос и изменение размера пишутся в код (блок CREATE или строки Имя.Свойство). Место, заданное выражением, закомментируется, под ним пишется число. Место самой формы не трогается.
  • Дерево и конструктор синхронизированы; двойной щелчок переходит к строке объекта.
  • Палитра RQ: RQ Standard, RQ Additional, RQ System, RQ Dialogs и свои компоненты. Щелчок по форме вставляет блок CREATE.
  • New Form спрашивает: добавить форму в этот файл или создать отдельную программу.
