Delphi

Цель сборки

Собирается .dpr из папки активной вкладки. Если .dpr в папке несколько, unIDE показывает список; невыбранные переименовываются в .dpr1, .dpr2..., чтобы вопрос больше не возникал. Если .dpr нет — цель проекта.

Перед сборкой

  • Проверяются повторы имён компонентов в .dfm; при повторах сборка останавливается.
  • Имя в строке program исправляется по имени .dpr.
  • В .res записывается информация о версии (с автоувеличением номера сборки, если оно включено в Project options).

Компилятор и ключи

  • Компилятор — <Delphi path>\Bin\dcc32.exe (IDE Options → Compilers → Delphi). Если по пути компилятора нет, установка Delphi ищется в реестре; кнопка Find installed делает то же вручную.
  • Ключи берутся из .dof проекта. Пути проекта, Library path и папка компонентов Ui передаются ключами -U -I -O -R; Browsing path компилятору не передаётся.
  • Папка exe: OutputDir проекта, иначе Output (exe) из настроек, иначе папка .dpr. Папка .dcu — Output (dcu), иначе рядом с проектом.
  • Если в программе есть точки останова или запуск идёт по F7/F8/F4, добавляются ключи отладочной сборки -$D+ -$L+ -$O- -$W+ -GD -V.

Project options

Project Properties проекта Delphi содержат страницу Project options с вкладками, как в Delphi 7: Forms, Application, Compiler, Compiler Messages, Linker, Directories/Conditionals, Version Info, Packages. Настройки пишутся в .dof, .dpr и .res.

Формы

Формы .dfm открываются в инспекторе объектов и визуальном конструкторе (Инспектор и конструктор). Кнопка «Перенести в .dfm» переносит компоненты, созданные в коде, в .dfm.

Отладка

Программа Delphi отлаживается отладчиком Win32 unIDE (Отладка Delphi).
