Поиск и замена

Поиск и замена находятся на панели инструментов: поле Find, поле Replace (оба с историей), кнопки <-Find, Find->, Replace, All, Undo, список режима и список области. Ctrl+F ставит фокус в поле Find.

Режим

  • Normal — поиск подстроки;
  • WholeWord — только целое слово;
  • Go to line — в поле Find вводится номер строки.

Галка Case учитывает регистр. F3 и Shift+F3 — следующее и предыдущее вхождение. Если выделен фрагмент в пределах одной строки, он сначала становится образцом поиска.

Замена All

All заменяет во всех файлах выбранной области. Закрытые файлы перезаписываются в своей кодировке. Undo (или Edit → Отменить массовую замену) возвращает и окна, и файлы на диске.

Find In Files

Немодальное окно поиска по файлам на диске:

  • Папки — несколько через «;», кнопка «...» выбирает папки в дереве;
  • Файлы — расширения с галками, кнопки Все и Снять; Маски — свои маски;
  • Во вложенных папках;
  • Найти (во время поиска — Стоп), Закрыть.

Открытые файлы берутся из памяти, с несохранёнными правками. Файлы больше 32 МБ и двоичные пропускаются. Закрытые файлы читаются как есть, в кодировке Windows: русский образец в файлах UTF-8 не находится. Результаты попадают в окно Match list: группы по файлам сворачиваются, двойной щелчок открывает строку. Галка «Disable comments» скрывает совпадения в комментариях.

Потерянные файлы и папки поиска

Если файл открытой вкладки или проекта не найден на прежнем месте (папку перенесли), его можно найти:

  • Windows → Search folders... — задать папки поиска («горячие папки»): слева дерево дисков, справа список; галка у папки включает её в поиск;
  • Windows → Find lost files... — искать рядом с программой и в этих папках;
  • Windows → Remove missing files from list — убрать из списка окна без файлов;
  • Windows → Check wrong file names — сверить пути открытых файлов с диском.
