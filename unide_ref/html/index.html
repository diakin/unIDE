Руководство unIDE

unIDE — среда разработки для Windows, написанная на Delphi 7. В одном окне она открывает, подсвечивает, собирает и отлаживает программы на четырёх языках:

  • RapidQ Basic — сборка компилятором RapidQ (rc.exe) или через FreeBASIC (перевод RqToFb и библиотека компонентов RqLcl), свой отладчик, инспектор объектов, конструктор форм, проверка недостающих include-файлов;
  • FreeBASIC — сборка fbc 32 и 64 бит, GUI, Console или DLL;
  • Delphi 7 — сборка dcc32, отладчик, инспектор объектов и конструктор форм .dfm;
  • Arduino — сборка и загрузка скетчей через arduino-cli, менеджеры плат и библиотек, монитор порта.

Любой другой текстовый файл открывается как в обычном редакторе: подсветка для него берётся из схемы по расширению (схемы подсветки).

Разделы руководства

  • Главное окно — меню, панель инструментов, правая панель, логи.
  • Редактор — подсветка, отступы, скобки, закладки, Code Insight, форматирование, кодировки.
  • Поиск и замена — поиск в окне, во вкладках, в проекте и на диске.
  • Проекты — создание, открытие, свойства, перенос.
  • Сборка и запуск — как выбирается сборщик, рамка Project, логи, окно хода сборки.
  • RapidQ, FreeBASIC, Delphi, Arduino — особенности каждого сборщика.
  • Отладка — точки останова, шаги, окно Watch.
  • Инспектор объектов и конструктор форм.
  • Настройки (IDE Options).
  • Утилиты — окна-помощники.
  • Файлы и папки unIDE — где что хранится.
  • Клавиши — сводная таблица.
  • Справка — RapidQ, FreeBASIC, это руководство, F1.

Как устроена работа

Всё, что делает unIDE, определяется файлом активной вкладки. По нему выбирается сборщик (Delphi, RapidQ, FreeBASIC или Arduino), схема подсветки, видимые вкладки правой панели и кнопки отладчика. Проект нужен, чтобы помнить набор открытых файлов, закладки и главный файл сборки; одиночный файл можно собрать и без проекта.

Настройки хранятся в файле editor.ini рядом с программой и в основном пишутся сразу при изменении. Цвета среды хранятся в IDE.clr, схемы подсветки — в schemes\*.clr (их записывает кнопка Save на вкладке Color Scheme).
