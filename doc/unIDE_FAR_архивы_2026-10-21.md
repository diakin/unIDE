# unIDE FAR — архивы: что распаковывается и как (21.10.2026)

Запрос: Shift+F1 — упаковать выбранное в zip или 7z; Enter на архиве — FAR на две панели, содержимое архива — в другой панели, копирование оттуда в другую панель; распаковка — всех возможных архивов.

## Чем распаковывать

Своими силами Windows 7 почти ничего не умеет: ZIP — через объект оболочки (Shell.Application, CopyHere, асинхронно, с окном хода), CAB — `expand.exe`. `tar.exe` в Windows появился только в Windows 10 (1803). На этом основы для «всех архивов» нет.

Практически единственный вариант с широким набором форматов, который работает на Windows 7 и бесплатен, — **7-Zip**:
- последняя версия на сайте — 7-Zip 26.04 (5.10.2026); заявленные системы — Windows 11, 10, 8, **7**, Vista, **XP**, Server 2000–2022;
- лицензия: GNU LGPL (`7z.exe` и большая часть `7z.dll`), часть `7z.dll` — BSD 3-clause (LZFSE), декодер RAR — LGPL с ограничением unRAR (нельзя использовать его код для создания RAR-совместимого упаковщика). Бесплатно и для коммерческого использования; при распространении бинарников — приложить лицензию (`License.txt`).
- RAR 7-Zip **только распаковывает** (RAR5 — с версии 15.06). Создавать умеет только 7z, ZIP, TAR, GZIP, BZIP2, XZ, WIM.

Два способа подключить 7-Zip:
1. **`7z.exe` (+ `7z.dll`) командной строкой** — как командная строка FAR (b.17): процесс без окна, вывод через трубу. Список — `7z l -slt -sccUTF-8 архив`, распаковка — `7z x`, упаковка — `7z a -tzip|-t7z архив @список -scsUTF-8`. Просто, все форматы `7z.dll`, ход операции и ошибки — текстом.
2. **`7z.dll` напрямую** (интерфейсы IInArchive / IOutArchive) — без процесса, свой ход операции, распаковка сразу нужного пути без промежуточной папки. Обёртку под Delphi 7 придётся писать или переносить; работы заметно больше.

Предложение: начать с `7z.exe`, при необходимости позже перейти на `7z.dll`.

Где брать `7z.exe`: установленный 7-Zip (реестр `HKLM\Software\7-Zip` / `HKCU\Software\7-Zip`, значение `Path` / `Path64`; или `Program Files\7-Zip`), иначе копия рядом с unIDE (например `tools\7zip\7z.exe`, `7z.dll`, `License.txt`), путь — в IDE Options.

## Какие форматы распаковываются (7-Zip, официальный список и `7z i`)

Упаковка и распаковка: **7z** (.7z), **ZIP** (.zip .zipx .jar .xpi .apk .ipa .appx .epub .docx .xlsx .odt .ods, тома .z01), **TAR** (.tar .ova), **GZIP** (.gz .gzip .tgz .tpz), **BZIP2** (.bz2 .bzip2 .tbz2 .tbz), **XZ** (.xz .txz), **WIM** (.wim .swm .esd .ppkg).

Только распаковка:
- архивы: **RAR / RAR5** (.rar, тома .r00 / .part1.rar), **ARJ** (.arj), **CAB** (.cab), **LZH** (.lzh .lha), **Z** (.z .taz), **LZMA** (.lzma .lzma86), **ZSTD** (.zst — с версии 24.01), **CPIO** (.cpio), **AR** (.ar .a .deb .lib), **RPM** (.rpm), **XAR** (.xar .pkg .xip), **NSIS** (установщики NSIS), **PPMD**, **SPLIT** (.001 .002 …);
- образы дисков: **ISO**, **UDF** (.iso .udf .img), **VHD**, **VHDX**, **VMDK**, **VDI**, **QCOW2**, **DMG**, **HFS**, **APFS**, **NTFS**, **FAT**, **EXT2/3/4**, **GPT / MBR / APM**, **SquashFS**, **CramFS**;
- прочее: **CHM / HXS / LIT** (справка), **COMPOUND** (.msi .msp .doc .xls .ppt — старые Office и MSI), **UEFI** (.scap .uefif), **IHEX**, исполняемые (**PE** .exe .dll .sys, ELF, Mach-O, COFF — секции и ресурсы; SFX-архивы внутри .exe), SWF, FLV, Base64.

Набор зависит от версии 7-Zip: unIDE может узнавать его у самого `7z.exe` командой `7z i` (раздел Formats — имена форматов и расширения), а не держать свой список.

Особые случаи:
- **зашифрованные архивы** (ZIP AES, 7z, RAR): нужен пароль (`-p`); у RAR и 7z с шифрованием имён без пароля нельзя даже посмотреть список; признак — `Encrypted = +` в списке или ошибка «Wrong password»;
- **многотомные** (.001, .part1.rar, .z01): открывать первый том, остальные тома — рядом;
- **SFX и .exe**: архив внутри .exe 7-Zip открывает, но обычный .exe он покажет как набор секций PE — поэтому Enter на .exe должен запускать, а не открывать как архив.

## Проверено (7-Zip 23.01 в Linux-среде; вывод у Windows-версии тот же, разделитель путей — `\`)

- `7z l -slt -sccUTF-8` — по записи на файл: `Path = …`, `Folder = +/-`, `Size`, `Packed Size`, `Modified = ГГГГ-ММ-ДД ЧЧ:ММ:СС`, `Attributes`, `Encrypted = +/-`, `Method` …; русские имена и пробелы — без искажений. Папки в архиве могут не иметь своей записи — их нужно выводить из путей файлов.
- `7z x архив -oПАПКА "Папка с пробелом\файл.txt"` — файл ложится с **полным путём из архива** (`ПАПКА\Папка с пробелом\файл.txt`). Значит, копирование из подпапки архива: распаковать во временную папку и перенести нужную часть на место (или `7z.dll` напрямую).
- `7z a -tzip архив -scsUTF-8 @список` в папке панели, список — относительные имена (UTF-8): папки из списка упаковываются со всем содержимым.

## Предлагаемая работа в unIDE FAR

- **Shift+F1** — окно «Add to archive»: имя архива (по умолчанию — имя выделенного файла / папки или текущей папки), формат ZIP / 7z, уровень сжатия, пароль (необязательно); архив — в папку панели; ход — в вывод под панелями.
- **Enter на архиве** — для «чистых» архивов (zip 7z rar arj cab lzh lha tar gz tgz bz2 tbz xz txz zst z taz iso wim cpio rpm deb 001 …); **Ctrl+PgDn** — открыть как архив любой файл (exe/SFX, msi, docx, jar, img, vhd …). Содержимое — в другой панели (одна панель в режиме F4 — FAR снова на две), по архиву — как по папкам, `..` в корне — выход из архива.
- **F5 из панели архива** — распаковать выбранное в папку другой панели (с переносом из временной папки); F3/F4 на файле в архиве — распаковать во временную папку и открыть (позже); запись в архив (F5 в архив, F8 в архиве) — позже.
