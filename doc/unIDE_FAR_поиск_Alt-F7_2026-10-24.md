# unIDE FAR b.29 — поиск файлов Alt+F7 (24.10.2026, mainTest 001d090)

Дополнение к `unIDE_FAR_план_2026-10-20.md` и `unIDE_FAR_буфер_b25_2026-10-22.md`. Как Find file в FAR Manager.

## Окно Find file (Alt+F7)

| Поле | Что |
|---|---|
| Masks | маски через `,` или `;` (`*.pas;*.dfm`), `*` и `?`, без учёта регистра; `*.*` — любое имя, и без точки (как в FAR); маску можно в кавычках |
| Text | текст внутри файла; пусто — только по именам |
| Code page | All (cp1251, cp866, UTF-8, UTF-16LE сразу), ANSI, OEM, UTF-8, UTF-16 |
| [ ] Case sensitive | учитывать регистр |
| [ ] Whole words | по краям совпадения не буква, не цифра и не `_` |
| [x] Search for folders | папки тоже (только если текст не задан) |
| Area | With subfolders (папка панели и подпапки), This folder (только она), Whole drive (корень диска панели) |

- Кнопки Find, Cancel. Клавиши — как в окне Shift+F1 (Tab / стрелки, Пробел — флажок и выбор; щелчок мышью по флажку — переключить).
- Значения запоминаются: editor.ini `[Far]` `FindMask`, `FindText` (как пути, `utf8:` для символов вне cp1251), `FindCodePage` (0..4), `FindCase`, `FindWhole`, `FindFolders`, `FindArea` (0..2).
- В панели архива — сообщение: поиск в архиве пока не делается.

## Окно найденного

- Поверх панелей, во всю высоту панелей: заголовок `Find file: <маски> containing "<текст>"`; список — путь папки строкой, под ним файлы: дата и время, размер (у папки `<Folder>`), имя; строка хода: `Found files: N, folders: M. Searching in: <папка>`, по окончании — `Search done. Found files: N, folders: M`; кнопки `[ New search ] [ Go to ] [ Edit ] [ Stop ]` (после окончания — `[ Cancel ]`).
- Курсор — только на файлах (строки папок пропускаются): стрелки, PgUp / PgDn, Home / End, колесо мыши, щелчок.
- Enter / Go to / двойной щелчок — панель в папку найденного, курсор на него, окно закрывается.
- F4 / Edit — файл в редактор, как F4 в панели (FAR — одной панелью, редактор рядом); окно найденного остаётся (Ctrl+Tab — обратно в FAR).
- Esc / Stop / Ctrl+Break — остановить поиск; Esc / Cancel после окончания — закрыть.
- New search / Alt+F7 — снова окно Find file поверх списка.
- Tab, ← / → — фокус: список → кнопки по кругу.
- Кейбар, слой Alt: F7 — Find.

## Устройство (FarFind.pas)

- `TFarFindThread`: обход папок рекурсивно (папки после файлов своей папки — в списке папка одним блоком), `FindFirstFileW`; папки-ссылки (reparse point) не обходятся. Найденное — в очередь под критической секцией; окно забирает его по таймеру 150 мс (`TakeFound`). `Cancel` — остановить, `CurrentDir` — где сейчас.
- Текст: `FarBuildPatterns` — образец для каждой кодировки, у каждого символа два варианта байтов (строчный и прописной, `CharLowerW` / `CharUpperW`); символ, которого нет в кодировке, — кодировка пропускается. `FarPatternIn` — поиск в буфере с быстрым отсевом по первому байту; Whole words — таблица букв однобайтовой кодировки, у UTF-16 — `IsCharAlphaNumericW`, у UTF-8 байты от `$80` — часть буквы.
- Файл читается кусками по 1 МБ, хвост прошлого куска (длина образца + 4 байта) — в начало следующего: совпадение на стыке не теряется, край слова проверяется. Первое совпадение — файл найден.
- Файлы открываются с `FILE_SHARE_READ|WRITE|DELETE`; не открылся — пропускается.

## Проверено

- FPC: маски (`*.pas;*.DFM`, `"a b.txt"`, `*.*` и имя без точки, `rq?.bat`, `a*x*f`), поиск текста: UTF-8 без учёта регистра и с учётом, cp1251, cp866, UTF-16LE, Whole words (латиница и кириллица UTF-8), начало поиска не с нуля; поиск в файлах 3 МБ с совпадением на стыке первого и второго куска 1 МБ (и с Whole words на стыке). Перекодировки — заглушками на iconv.
- UnFar.pas — FPC (синтаксис и типы). В Delphi 7 не компилировалось, на Windows не запускалось.

## Чего нет (есть в FAR)

- Поиск в архивах, поиск hex, фильтр, View (F3), Panel (найденное во временную панель), поиск на нескольких дисках.
