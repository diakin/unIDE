# Ревью Alex313031/rufus-win7 v4.6.2208 (2026-10-22)

Исходники: тег v4.6.2208 (fc25e5b5, 2024-10-29). База — upstream pbatard/rufus v4.6 (7488e446). Своих коммитов 7, разница 33 файла, +255/−218. Двоичные файлы: Rufus_4.6.2208_x64.zip (2722702, sha256 23a12bd8847163963174b490ed6590adf47faf2f48365a63b3322735088b49a2), x32.zip (2677952, sha256 743dbe6e3b2083bd7a15d708194f0b53dd90d02e667e2c7f1f351fc9cb68c81d).

## Ошибки в коде
1. stdlg.c:1460 SetUpdateCheck — при каждом запуске записывает UpdateInterval=-1, VerboseUpdates=2, AdvancedMode*=1 и `return FALSE`; `SetFidoCheck(); return TRUE;` недостижимы. Загрузка ISO (Fido) и загрузка свежего sbat_level.txt отключены на всех Windows; проверка `< WINDOWS_8` в SetFidoCheck (стр. 1449) — мёртвый код. Настройки пользователя перезаписываются при каждом старте. Неиспользуемые filename, exename.
2. ui.c:1025–1128 — массивы кнопок уменьшены до 3 элементов, а ветка `appstore_version` читает и пишет `buttons_list[3]`/`bitmaps_list[3]` — выход за границу. В Windows 7 эта ветка не выполняется (нет Store).
3. winio.h:174 GetSizeAsync — убрана обработка ERROR_SECTOR_NOT_FOUND (upstream: так VHD/VHDX сообщает о конце диска). Возможна «Read error» в конце записи/хеширования образа VHD/VHDX (format.c:1378, hash.c:1991). Не проверено запуском. Условие `>= WINDOWS_XP` всегда истинно. Потеря таймаута GetOverlappedResultEx на практике не влияет: оба вызова предваряются WaitFileAsync(DRIVE_ACCESS_TIMEOUT).
4. rufus.c:3619–3631 — порог версии снижен до XP; аргументы MSG_294 сравниваются с WINDOWS_XP (сообщение бессмысленно). PE-заголовок subsystem 6.0, на XP exe не загрузится; Vista формально пропускается, не проверялась.

## Исправления под Windows 7 (корректны)
- DeviceIoControl: NULL в lpBytesReturned заменён на &size (drive.c, drive.h, format.c). Сканирование всех вызовов в src: NULL больше не осталось.
- dev.c: IOCTL_USB_GET_NODE_CONNECTION_INFORMATION_EX_V2 только для Win8+.
- GetOverlappedResultEx (Win8+) заменён на GetOverlappedResult.
- Коммит «restore MAX_PARTITIONS» возвращает upstream-код, итоговой разницы нет.
