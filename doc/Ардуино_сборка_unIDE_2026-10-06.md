# Arduino в unIDE, часть 2: сборка и загрузка скетча

Коммиты 375298d (сборка и загрузка) и 4efcdcd (кнопки Verify / Upload), ветка RapidQ. Продолжение claude/Ардуино_разбор_и_план_unIDE_2026-10-05.md (этап 1) и claude/Передача_в_новый_чат_unIDE_2026-10-06.md.

**Проверено у пользователя (2026-10-06):** скетч компилируется и загружается в плату из unIDE.

## Что сделано

- **CompileArduino(AUpload, AKeepLog)** (Unit1, после CompileProject). Compile → Verify; Compile & Run и Run → сборка с загрузкой (`compile ... -u -p <порт>`, как Upload в Arduino IDE). Скетч — `BuildTargetOf(bkArduino)`; имя .ino должно совпадать с папкой, иначе строка в логе и выход.
- **Кнопки Verify и Upload** (`btnArdVerify`, `btnArdUpload` в Unit1.dfm, обработчики `ArdVerifyClick`, `ArdUploadClick`). В режиме Arduino ряд Project: Verify, Upload, Program reset (на местах View Unit, View Form, New Form); Compile & Run, View Unit, View Form, New Form, Pause и шаги отладчика спрятаны (ApplyLangMode). Пока идёт arduino-cli, Verify и Upload недоступны, Program reset доступен (`ArdBuildButtons`). Значки — Ok_07 и Arrow_05 из Lazarus general_purpose, номера 15 и 16 ленты (`IconArdVerify`, `IconArdUpload`), лента пересобрана icons/make_icons.py.
- Командная строка — `ArdCompileArgs` (ArduinoCli): `compile -b <FQBN> [--build-path <BuildPath>\<скетч>] [--libraries <LibPath>] --warnings <W> [-v] [-e] [--log-file <LogFile> --log-level <L>] [-u -p <порт> [-t]] <папка скетча>`, `--config-file` добавляет ArdCommandLine. Полная строка пишется в лог.
- Ключи `[Compiler.Arduino]` — `ArdLoadBuildOptions`: Warnings, LogLevel, CompileVerbose, UploadVerbose, VerifyAfterUpload, SaveBeforeBuild, ExportBinaries (галка «Export compiled binary» в IDE Options - Arduino).
- Запуск — `ArdRunCli` (канал, UTF-8). Program reset во время сборки — флаг `FArdCancel`, `ArdBuildIdle` прерывает, arduino-cli снимается TerminateProcess.
- Несохранённые файлы папки скетча: SaveBeforeBuild=1 — сохраняются; иначе строка «Не сохранён: ... — собирается версия с диска». Autosave editor files тоже работает.
- **Ошибки**: `ArdParseGccLine` — `файл:строка[:столбец]: ...`, приставки `In file included from` / `from`, буква диска не путается, `/` → `\`. В `ParseCompilerLine` проверяется первой, затем формат Borland. `ArdIsGccError` (`: error:`, `: fatal error:`, `undefined reference to`) — строка красная и в окне ошибок. FLastBuildDir = папка скетча.
- **Platform not found** (`ArdIsPlatformMissing`): вопрос → `core install <packager:arch>` (`ArdPlatformOfFqbn`, с `--additional-urls` из настроек) → сборка снова без очистки лога.
- **Порты во время загрузки**: `FArdUploading` — ArdPortsChanged только пишет в HiLite log, выбор порта и монитор не трогает. После загрузки — `FArdPorts.Refresh`. Serial Monitor на этом порту закрывается `PauseForUpload` (DlgArdSerial) и открывается после загрузки, когда порт есть.
- **Плата**: `ArdReadBoard` / `ArdSetBoard`. Папка скетча — папка проекта из `[Projects]` → `[Project.<имя>]` Fqbn, BoardName; иначе `[Compiler.Arduino]` Fqbn, BoardName. Выбор платы пишется в оба места.
- **Рамка Project**: у скетча после имени .ino — порт; в подсказке — плата (FQBN) и порт.

## Ещё не проверено

1. Verify на скетче с ошибкой: формат строк ошибок arduino-cli 0.18.1 для .ino (путь исходного .ino или копии в папке сборки), переход двойным щелчком.
2. Upload на Leonardo или Due (переподключение порта при загрузке), Serial Monitor во время загрузки.
3. Флаги `-t` и `-e` в 0.18.1 — включаются только галками.
4. Program reset во время долгой сборки.
5. Platform not found — текст сообщения arduino-cli и установка.
