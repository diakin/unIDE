## Правила исходников
- `.pas/.dfm/.dpr/.inc/.bas/.ini/.clr`: кодировка CP1251, концы строк CRLF (`.gitattributes`: working-tree-encoding=windows-1251).
- Как править: `iconv -f cp1251 -t utf-8 | sed 's/\r$//'` → правка → `sed 's/$/\r/' | iconv -f utf-8 -t cp1251`.
- Delphi 7:
  - обработчик из .dfm должен быть published, иначе EReadError;
  - строковый литерал не длиннее 255 символов;
  - в классе поля идут до методов.
- `RichEdit1.SelText` не читать: RichEdit 4.1 пишет UTF-16, это порча памяти. Читать через `SelTextA` / `TextRange`.
- Имена переменных осмысленные, не короче трёх букв, кроме счётчиков. Тон ответов спокойный.

## Где что лежит
- `Unit1.pas` — главная форма: редактор, проекты, отладчик, Watch, конструктор.
- `Unit2.pas` — настройки.
- `DbgEngine` / `DbgSymbols` — отладчик Delphi (TD32).
- `FormDesigner` / `Dsg*` — конструктор форм.
- `ObjParse` — разбор формы для инспектора.
- `UiLib` / `Ui*.pas` — свои элементы управления с темами.
- Типы проектов:
  - список в `DlgNewPrj.dfm`, первым идёт RapidQ Basic;
  - главный файл типа — `MainMasksFor`;
  - маски файлов проекта RapidQ: `*.bas;*.inc;*.bi`.
- Сборка сейчас только у Delphi: `CompileDelphi` для других типов пишет «Сборка проектов … здесь пока не поддерживается».
- `editor.ini`: есть секция `[Compiler.RapidQ Basic]` с ключами IdePath, CompPath, IncPath, LibPath, PrjPath, TplPath, IcoFile. В коде она пока не используется.
