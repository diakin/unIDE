# unIDE FAR b.30 — меню дисков с Том # (24.10.2026, mainTest 8871207)

Дополнение к `unIDE_FAR_план_2026-10-20.md`. Меню Alt+F1 / Alt+F2.

## Что в меню

- Первая строка (недоступна для выбора) — заголовок колонок: `Том  Тип  ФС  Метка  Размер  Свободно`, справа — `Сведения`.
- Диски с буквой: `C:`, номер тома (Том #), тип (fixed, removable, network, CD-ROM, RAM disk), файловая система, метка, размер и свободное место в виде FAR (`476,14 G`, `1,82 T`); справа — состояние и сведения diskpart (`Исправен Загрузочный`, `Скрытый`, `Системный`).
- Метка, ФС и размер читаются у жёстких, RAM-дисков и сменных, кроме A: и B: (у дисководов, CD и сетевых чтение может ждать устройство или сеть).
- Под разделителем — тома без буквы (системный раздел, скрытые разделы): только для сведений; том, подключённый в папку, выбирается (переход в эту папку).
- Последняя строка — откуда номера томов: «запрос к diskpart...», «нужен запуск unIDE от имени администратора», «diskpart не вернул список томов» или ошибка запуска.

## Откуда данные (FarVolumes.pas)

- Том #, состояние, сведения, тома без буквы с номерами — `diskpart /s <скрипт>` со скриптом `list volume` / `exit` (`%TEMP%\unide_diskpart_<pid>.txt`), в своём потоке `TFarDiskpartThread`, один раз за время жизни окна FAR; вывод — OEM → Unicode. Ответ diskpart приходит через секунду-две; поток проверяется в `WatchTick` (`DiskpartCheck`), открытое меню дисков перестраивается, курсор остаётся на том же пункте. Больше минуты — diskpart прерывается.
- diskpart требует прав администратора: unIDE без них — `CreateProcess` возвращает 740 (`ERROR_ELEVATION_REQUIRED`), окна UAC нет, номеров томов нет, в меню — пояснение.
- Разбор `FarParseDiskpart`: колонки — по строке из дефисов под заголовком (от языка не зависит), номер тома — число в конце первой колонки, буква — вторая колонка, дальше метка, ФС, тип, размер, состояние; последняя колонка (сведения) — до конца строки. Строки без номера (папки подключения под томом) пропускаются. Проверено на выводе из сообщения пользователя (Windows 7, русский).
- Метка, ФС, размер дисков с буквой — `GetVolumeInformationW`, `GetDiskFreeSpaceExW` (как и раньше, с `SetErrorMode` — без окон «диск не готов»).
- Тома без буквы без diskpart — `FindFirstVolumeW` / `FindNextVolumeW` / `GetVolumePathNamesForVolumeNameW` (загружаются по имени; Windows XP и новее): тома, у которых нет пути вида `X:\`; без файловой системы — не показываются.
- Номер тома — тот, что показывает diskpart; своей нумерации нет.

## Проверено

- FPC: разбор вывода diskpart (номера 0–7 с пропуском, буквы, метка «Восстановит», FAT32 без буквы, сведения), `FarSizeShort`.
- UnFar.pas, FarVolumes.pas — FPC (синтаксис и типы). В Delphi 7 не компилировалось, на Windows не запускалось.
