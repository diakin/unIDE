# unIDE FAR b.31 — меню дисков без diskpart (2026-10-24)

Коммит fd0b3f7 в mainTest. Файлы: FarVolumes.pas (переписан), UnFar.pas.

## Что изменилось
- Колонка «Том #» (diskpart) заменена на «Диск»: `0:2` — диск 0, раздел 2; `CD0` — CD-привод 0; пусто — сеть, A:/B:, составной том.
- Новая колонка «Модель» — модель физического диска, на котором том (у CD — модель привода). Ширина по самой длинной, не больше 28.
- Тома без буквы — те же колонки, номер диска/раздела через `\\?\Volume{...}`.
- В конце меню — физические диски: `Диск N`, модель, шина (SATA/USB/...), размер или «нет носителя», буквы томов на диске.
- Если ни один `\\.\PhysicalDriveN` не открылся — строка с текстом ошибки Windows.
- Поток diskpart, FVol*-поля, StartDiskpart/DiskpartCheck удалены. Колонки «Состояние/Сведения» (загрузочный, системный, скрытый) больше нет.

## Как получаются данные (FarVolumes)
- `FarDeviceNumber(path)` — IOCTL_STORAGE_GET_DEVICE_NUMBER ($2D1080).
- `FarDeviceInfo(path, withSize)` — IOCTL_STORAGE_QUERY_PROPERTY ($2D1400, StorageDeviceProperty): vendor+product (vendor 'ATA' опускается), BusType, RemovableMedia; размер — IOCTL_DISK_GET_DRIVE_GEOMETRY_EX ($700A0). У CD размер не запрашивается.
- `FarPhysicalDisks` — перебор PhysicalDrive0..31 (номера бывают с пропусками).
- CreateFileW с dwDesiredAccess = 0, share read/write — документированный режим запроса свойств устройства.

## Не проверено
- Работа без прав администратора на Windows 7 — проверить на машине пользователя.
- Серийный номер не выводится (на Win7 у ATA-дисков он бывает в hex с переставленными байтами).
- SMART/температура требуют полного доступа к устройству — не делалось.

## Проверка
- FPC 3.2.2: UnFar и FarVolumes компилируются со стабами.
- Мок DeviceIoControl/CreateFileW: разбор дескриптора, пропуск номера диска, CD, том по GUID — результаты верные.
