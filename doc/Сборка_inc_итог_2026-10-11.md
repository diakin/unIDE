# Сборка rapidqAllProc.inc и rapidqComponents.inc — итог 2026-10-11

Ветка RQFreeBasic, коммит fcd61cb.

## Что есть

- `rapidq_ref/tools/build_inc.py` — собирает `rapidq_ref/inc_sys/rapidqAllProc.inc`, `rapidqComponents.inc` и `build_report.md` из `rapidq_ref/inc_good` по `rapidq_ref/inc_merge_plan.md`. Исходные файлы не меняются. Запуск: `python3 rapidq_ref/tools/build_inc.py`.
- Состав: rapidqAllProc.inc — rapidq2.inc без разделов компонентов, rapidq.inc и 113 файлов; rapidqComponents.inc — разделы компонентов rapidq2.inc и 98 файлов, подключает rapidqAllProc.inc. Не вошли 79 файлов; причина каждого — в build_report.md («Не вошли»).
- Повторы (CONST, $DEFINE, DECLARE, TYPE, SUB/FUNCTION, DIM) закомментированы как `'~dup … ' повтор, первое: файл(строка)`.

## Что сборка делает сверх снятия повторов

- `$UNDEF` имени, которое объявил другой файл, закомментирован. Пример: WIN32API.INC в конце делает `$UNDEF TRUE, FALSE`, и в общей сборке True/False пропадали для всех следующих файлов.
- Процедура и `DECLARE … LIB` с одним именем в разных файлах (LoadString в Files.inc и WIN32API.INC, Weekday, UpdateColors): остаётся первое, второе — `'~conflict`.
- `$DEFINE` имени типом, если ниже это имя переменной, получает `$UNDEF` в конце своего файла. Так сделано для createWind.inc `$DEFINE HWND INTEGER`, API_RichEdid.inc и keys.inc `$DEFINE CHAR BYTE`.
- В CMD5.inc внутренние F, G, H, FF, GG, HH, II переименованы в MD5_*. Они совпадали с `DIM F AS QFileStream` в QXLS.INC и с `FOR ii` в eml.inc.
- В плане можно взять часть файла (`да, строки 1-228`), если дальше идёт пример программы (QDrawMenu.inc, QSavePlus.inc).
- Исключены:
  - фрагменты программ: AllProps, stdObjMnu, RapidFRM_Mods, Splash, SplashForm;
  - `$RESOURCE` на отсутствующие файлы: CodeSense, QDirListView1, QMarker, Resources2;
  - ресурсы, которые должна дать программа: XPSkinMetallic, QTButton_AddOns;
  - WebCam.inc — вызывает DLL при подключении;
  - ftiQuery.inc — FUNCTION внутри FUNCTION.

## Палитра

Страницы RQ Comp (визуальные, 55 классов) и RQ Comp System (прочие) строятся из rapidqComponents.inc папки SysIncPath. Наследники QFORM и свои версии классов палитры (QCOLORDIALOG) в палитру не идут. Если поставить такой класс на форму, в программу добавляется `$INCLUDE "rapidqComponents.inc"`. Если проект собирается с другой папкой inc, путь добавляется полный.

## Переводчик RqToFb (найдено на общих файлах)

- Неявная переменная SUB при `DIM` того же имени ниже по тексту остаётся локальной (tests/laterdim.bas).
- Локальная переменная с именем процедуры модуля получает `_v` (tests/procvar.bas).
- Суффиксы чисел `?`, `??`, `???` отбрасываются. После INC перед ELSE сохраняется пробел (tests/numsuffix.bas).
- На корпусе inc_good вывод изменился только в файлах с этими случаями.

## Проверка переводом и fbc (здесь, без rc.exe)

- Перевод: rapidqAllProc.inc — 2 ошибки, rapidqComponents.inc — 109. Все совпадают с ошибками тех же файлов по отдельности или меньше.
- fbc: около 540 строк ошибок. Это ошибки перевода файлов, которые не собираются и по отдельности: QXLS, Memory, keys (`define` без `$`), CM_*, Math, CommCtrl и др. Открытые блоки в QXLS.INC и Memory.inc тянут ошибки в следующие файлы.
- Сверх отдельной сборки осталось немного: SysUtils, TRM_RQDeclares (LoWord), objectToolbox, QFormSkin и ODMenuXP. У последних двух — разные DECLARE одной функции Windows, оставлен первый.
- rc.exe с общими файлами не проверялся.
