# uniFAR: отдельная программа (Free Pascal) и просмотр F3 — FAR b.39

Коммит `75f91f7` в `mainTest`.

## Что сделано

**uniFAR** — FAR из unIDE отдельной программой, Free Pascal / Lazarus, без LCL. Папка `uniFAR` в репозитории unIDE; общие модули берутся из корня (`..\`).

| Файл | Назначение |
|---|---|
| `uniFAR/uniFAR.lpr`, `uniFAR.lpi` | программа и проект Lazarus (режим Delphi, пути `vcl;..`, GUI) |
| `uniFAR/FarApp.pas` | главное окно (WinAPI), цикл сообщений, настройки, схемы |
| `uniFAR/vcl/Graphics.pas` | TColor и имена цветов, TCanvas поверх HDC, TBitmap в памяти |
| `uniFAR/vcl/Controls.pas` | TCustomControl как окно Unicode: Dispatch, мышь, Paint, ParentWindow |
| `uniFAR/vcl/ExtCtrls.pas` | TTimer на SetTimer без окна |

- Главное окно: внутри TFarView на всю клиентскую область. F10 или закрытие окна — выход; если текст в редакторе F4 изменён, программа спрашивает. Положение и размер окна сохраняются в `[uniFAR]`.
- Цикл сообщений: клавиши окна FAR сначала идут в `TFarView.KeyMessage`, как `AppMessage` в unIDE. Одиночные Alt и F10 не переводят окно в режим меню.
- `uniFAR.ini` лежит рядом с exe. При первом запуске он создаётся из `editor.ini` unIDE, который ищется в папке программы и до трёх папок выше. Переносятся разделы `Far`, `FarHistory`, `FarCmdHistory`, `FarColors`, `FarPalette`, `FarFtp`, `[Themes] Current` и `[Editor] TabChars / FontColor / BGColor` (с вариантами `@Тема`). Дальше настройки у каждой программы свои.
- Схемы подсветки берутся из папки `schemes\`; она ищется так же, как `editor.ini`.

**Изменения в UnFar (общие с unIDE)**

- `FarProduct` — имя программы в сообщениях: `'unIDE FAR'`, в uniFAR `'uniFAR'`.
- `MessageLine` — своя строка сообщений над командной строкой. Туда же идёт `Status`, если `OnStatus` не задан. Сообщение держится до следующей клавиши.
- `UnicodeChars` — WM_CHAR приходит в UTF-16 (окно uniFAR). В unIDE остаётся байт кодировки Windows.
- Модули Forms и Clipbrd больше не используются: буфер обмена работает через WinAPI, окно-владелец берётся через `GetAncestor`. Вставка в диалоги и командную строку теперь в Unicode.
- F9 → Colors / Files highlighting без окон unIDE: выводится сообщение.
- Связка с основным редактором unIDE (`OnEditFile`, `OnLeave`, `OnHalfResize`, `OnShowPanels`) осталась: в unIDE она нужна для двойного щелчка по вкладке. uniFAR эти события не задаёт.

**SchemeFiles.pas** — выбор схемы по расширению (своя `.clr`, `alias.ini`, встроенные соответствия, `.inc` по тексту) и чтение схемы с темой. Модуль общий для Unit1 и uniFAR.

## Просмотр F3 (FarViewer.pas), в unIDE и в uniFAR

- Просмотр открывается на месте редактора, в другой панели; F5 разворачивает его на всю ширину. Вместе с редактором просмотр не открывается: F6 переключает в редактор на том же месте, F4 в панели заменяет просмотр редактором.
- Файл целиком не читается. Позиция — смещение в байтах, чтение идёт блоками по 64 КБ (кэш на 32 блока). Строка ограничена 16 КБ, дальше — следующая строка экрана.
- Клавиши:
  - стрелки, PgUp/PgDn, Home/End — листание;
  - Left/Right — сдвиг на 1 колонку (без переноса), Ctrl+Left/Right — на 20 колонок;
  - F2 — перенос строк вкл./выкл.;
  - F4 — hex / текст;
  - F8 — кодировка по кругу: ANSI → OEM → UTF-8 → UTF-16;
  - F7 — поиск, с учётом регистра или без; Shift+F7 — следующее;
  - Alt+F8 — к позиции (число, `0x…`, `…h`, `N%`);
  - Ctrl+R — перечитать;
  - Esc, F10, F3 — закрыть.
- Кодировка при открытии определяется по BOM. Без BOM — по первым 64 КБ: UTF-16 по нулевым байтам, иначе UTF-8, если файл корректный UTF-8 с многобайтными символами, иначе ANSI.

## Проверки

- Сборка uniFAR под win64 кросс-компилятором FPC 3.2.2 с настоящей RTL Windows — без ошибок.
- UnFar с заглушками в духе Delphi 7 собирается.
- FarViewer:
  - построчная разбивка сверена с эталоном на Python: ANSI, UTF-8, UTF-16 с BOM, двоичный файл без LF, пустой файл, табуляции, ширина 3/7/20, с переносом и без;
  - путь вниз и обратно вверх совпадает построчно;
  - поиск без учёта регистра найден;
  - скорость: файл 52 МБ — End и листание мгновенно, поиск по всему файлу 0,4 с; двоичный файл 20 МБ без LF — PageUp около 5 мс.
- uniFAR проверен под Wine:
  - запуск, импорт из `editor.ini`;
  - редактор F4 с подсветкой (тема Dark), ввод Unicode;
  - F3: перенос, hex, кодировки, поиск, F6, F5;
  - F10 — запись `uniFAR.ini`.

## Сборка

- Lazarus: открыть `uniFAR\uniFAR.lpi`, собрать. Или `lazbuild uniFAR.lpi`.
- Без Lazarus: в папке `uniFAR` выполнить `fpc -Mdelphi -Fuvcl -Fu.. -Fi.. uniFAR.lpr`.
- В unIDE добавлены модули `SchemeFiles.pas` и `FarViewer.pas` (`SyntaxHLClaude.dpr`).

## Ограничения и что дальше

- Строки сообщений хранятся в исходниках в cp1251. На Windows с другой кодовой страницей они будут нечитаемы — так же, как в unIDE.
- Нет значка программы и манифеста DPI.
- Окна Colors и Files highlighting в стиле FAR (пункт 5 плана) пока не сделаны. Параметры командной строки тоже.
