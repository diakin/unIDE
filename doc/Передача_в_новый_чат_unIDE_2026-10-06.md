# Передача в новый чат: unIDE, 2026-10-06

Репозиторий github.com/diakin/unIDE, ветка RapidQ (коммитить и пушить прямо в неё; перед push — fetch + rebase, пользователь пушит и сам). Исходники — CP1251 + CRLF. Пользователь на Windows 7, Delphi 7.

Редактор теперь собирается и запускается из `projects\SyntaxHLClaude\Output\` (правило в DelphiOutputDir: .dpr с именем exe редактора → Output; остальные проекты Delphi → папка своего .dpr).

## Что сделано 6 октября (важное для дальнейшей работы)

- **Сборщик по файлу активной вкладки** (`CurBuildKind`, коммит 662e765): bkDelphi / bkRapidQ / bkFreeBasic / bkArduino.
  - .pas/.dpr/.dfm/.dpk → Delphi; .ino/.pde → Arduino; .bas → по тексту ($-директивы → RapidQ, #-директивы → FreeBASIC); .inc/.bi → по главному файлу; .h/.c/.cpp → Arduino в папке скетча; иначе — тип проекта.
  - Ручной выбор в переключателе `cmbBuildKind` (рамка Project, `pnlBuildKind`, коммит bd97c31), хранится в editor.ini `[BuildKind]`; пункт Auto — снова по файлу. Подпись `lblBuildTarget` — что будет собрано.
  - `CompileProject`: Delphi → CompileDelphi, RapidQ → CompileRapidQ; **FreeBASIC и Arduino пока пишут в лог «сборка не подключена»** — место для `CompileArduino`.
  - `ApplyLangMode`: FLangMode = номер сборщика; для FreeBASIC/Arduino спрятаны кнопки шагов отладчика и вкладка Includes.
  - `BuildTargetOf(bkArduino)` = `<папка>\<папка>.ino`.
- **Delphi**: собирается .dpr из папки вкладки; несколько .dpr — список, остальные переименовываются в .dpr1, .dpr2…
- **Проекты — в editor.ini** (коммит 772c16c, модуль `PrjStore.pas`): `[Projects]` имя = папка проекта; раздел `[Project.<имя>]` — Type, Target (`\Имя.dpr` от папки проекта), OutputDir, Toolchain, Windows_*, Tabs_*, Bookmarks_*, HotBookmarks_*, Release_*. Доступ — `TProjectIni` (как TIniFile). `.prj` перенесены автоматически, больше не используются. `[Path]` — папка exe; при несовпадении editor.ini меняется местами с editorN.ini (флешка на разных компьютерах). Пользователь проверил — всё перенеслось.
- IDE Options → Compilers → RapidQ: галка Use IDE path (коммит 7b824cc).
- Сборка Delphi: в лог пишутся «Цель:» и «Папка exe:» (коммит 52aba38).

## Arduino — что уже есть (подробно: claude/Ардуино_разбор_и_план_unIDE_2026-10-05.md, разделы 7–8)

- ArduinoCli.pas (запуск arduino-cli через канал, UTF-8, ARDUINO_LOCALE=en, --config-file), ArduinoHw.pas (платформы/платы/библиотеки по файлам), ArduinoPorts.pas (SetupAPI + WM_DEVICECHANGE).
- Окна: DlgArdBoards (Board Manager), DlgArdLibs (Library Manager), DlgArdCli (CLI Help), DlgArdSerial (Serial Monitor).
- Меню Arduino как в Arduino IDE 1.8: Sketchbook, Examples, Include Library, Board, Port, Get Board Info, Serial Monitor.
- Плата: [Compiler.Arduino] Fqbn, BoardName (по плану — перенести в раздел проекта). Порт не хранится, выбирается по подключению.
- Всё это не проверено у пользователя на настоящем arduino-cli 0.18.1 и платах.

## Чего не хватает для Arduino (этап 1 плана)

1. `CompileArduino` в `CompileProject`: Verify = `compile -b <FQBN> --build-path … --libraries … --warnings … --config-file … <папка скетча>`; Compile & Run → Verify + `--upload --port <порт>`.
2. Разбор ошибок gcc `файл:строка:столбец: error:` в `ParseCompilerLine` (как arduino-cli указывает строки .ino — проверить на реальном выводе).
3. Кнопки для режима Arduino в ряду Project (Verify, Upload, плата, порт) — `ApplyLangMode` / pnlBuildKind.
4. «Platform not found» → `core install <packager:arch>`.
5. Program reset в режиме Arduino — остановить arduino-cli.
6. Плата (FQBN) — в раздел проекта `[Project.<имя>]`.

## Отложено

- Сборка FreeBASIC (GUI / Console / DLL, главный файл по #include, ошибки fbc).
- Неправильный вид grpCompiler при первом Design form — нужны записи «Layout to log» (меню конструктора) до и после исправления.
- Ключ `Compiler=` в разделе проекта (путь к компилятору проекта) — пользователь предлагал, не сделан.
