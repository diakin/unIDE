# Git в unIDE — панель Git, меню Repository и Branch, Commit, History, Discard, Stash, Ignore (23.10.2026, mainTest a9f388e, 4e12e27, 7c0f180, 3c3a98a)

Цель: работать с репозиторием GitHub из unIDE вместо GitHub Desktop. Всё — через консольный git (системный Git for Windows или свой PortableGit 2.46.2 из `tools\git`, `GitTool`).

## Модули

- `GitRun.pas` — `GitExec`: git без окна консоли (`CreateProcessW`, `CREATE_NO_WINDOW`), stdout+stderr в одну трубу, вывод UTF-8 → Unicode, строки — в журнал по мере прихода. Окружение unIDE + `GIT_TERMINAL_PROMPT=0` (git не ждёт ввода пароля в консоли, которой нет; окно входа Git Credential Manager показывается). Ключи ко всем командам: `-c core.quotepath=false -c color.ui=false`. Разбор: `GitParseStatus` (`status --porcelain=v1 -z`, переименования — две записи), `GitParseCounts` (`rev-list --left-right --count`), `GitParseLog` (`GitLogFormat`: поля через #$1F, записи через #$1E, `--date=iso`), `GitParseNameStatus` (`--name-status -z`, у R/C — старое, новое), `GitHubWebUrl` (https / git@ / ssh:// → `https://github.com/владелец/имя`), `GitValidBranchName`, `GitQuote`, `GitRecycleFiles` (корзина: `SHFileOperationW`, `FOF_ALLOWUNDO`, отсутствующие файлы пропускаются).
- `DlgGitCommit.pas` — окно Commit, строится в коде (без .dfm): список изменений с флажками (`TUiListView`, MultiSelect), разница выбранного файла (`OnDiff` → `TForm1.GitDiffOf`), Summary (обязательно), Description, кнопки Commit / Commit and Push / Cancel, вверху справа — Ignore... (`OnIgnore` → `TForm1.GitDlgIgnore`) и Discard Selected... Места кнопок и полей — в `OnResize` панелей (`LayoutTop`, `LayoutMsg`): до первого показа окна `Align` не выполняется, якоря от ширины по умолчанию уводили кнопку за край (6b57203).
- `DlgGitHistory.pas` — окно History, строится в коде: git запускает Unit1 (`OnQuery` → `TForm1.GitHistQuery`).
- `UiCaptionTabs.pas` — вкладки на месте подписи рамки (`TUiGroupBox`): текст вкладок, выбранная — цветом `Group.Text` в рамке `Group.Border`, остальные — `OffText`; щелчок — `TabIndex`, `OnChange`; ширина по текстам (замер на холсте `TBitmap`).

## Панель Git

- Кнопки: Fetch (`fetch --all --prune`), Pull (`-c pull.rebase=false pull --no-edit` — слияние, как в GitHub Desktop), Push (нет upstream — `push -u origin <ветка>`), Commit..., History..., Refresh, Git Bash.
- Строки: Repository — имя, путь, адрес origin; Branch — список локальных веток (выбор другой — `checkout`), `origin/<ветка>: ahead N (не отправлено), behind M (не забрано)` или «нет ветки на сервере — Push опубликует её»; Build — `git describe --tags --always`, Changes — число изменённых файлов, Stash — число записей (если есть).
- Сведения обновляются через 300 мс после показа панели (таймер `FGitTimer`), после каждой команды и по Refresh. Запросы панели — тихие, без журнала.

## Какой репозиторий

- Выбранный вручную (Add Local / Clone / New Repository) — editor.ini `[Git] Repository`; Repository → Use Repository of Current Project снимает выбор.
- Иначе: исходники открытого проекта ReactOS (`SourceDir`), папка проекта, папка файла вкладки → `git rev-parse --show-toplevel`.

## Меню

- **Repository** (File + Repository GitHub Desktop): New Repository (`init`), Add Local Repository, Clone Repository (адрес → папка рядом, имя из адреса), Use Repository of Current Project, Fetch, Pull, Push, Commit..., History..., View on GitHub, Open in Git Bash, Show in Explorer, Repository Settings (адрес origin: `remote set-url` или `remote add`).
- **Branch**: New Branch (`checkout -b`, проверка имени), Switch Branch, Rename Branch (`branch -m`), Delete Branch (`branch -d`; не влита — вопрос и `branch -D`); Discard All Changes..., Stash All Changes, Restore Stash..., Drop Stash..., Hidden Local Changes...; Update from Default Branch (`merge --no-edit origin/<основная>`: origin/HEAD, иначе origin/main или origin/master), Merge into Current Branch (локальные и origin/…); View Branch on GitHub (`/tree/<ветка>`), Create Pull Request (`/compare/<ветка>?expand=1`).
- Меню вставлены после ReactOS (`GitBuildMenus` в FormCreate после `RosBuildMenu`).

## Commit

- Список — `status --porcelain=v1 -z -uall` (каждый новый файл отдельно). Разница: новый файл — `diff --no-index -- /dev/null <файл>`, остальные — `diff HEAD -- <файл> [прежнее имя]`, без коммитов — `diff --cached`; больше 300 000 символов — обрезается.
- В коммит идёт ровно отмеченное (как GitHub Desktop): неотмеченные, уже добавленные в индекс, — `reset -q --pathspec-from-file=… --pathspec-file-nul` (у переименования — оба имени); отмеченные — `add -A --pathspec-from-file=… --pathspec-file-nul` (у переименования — оба имени); `commit -F <файл UTF-8>` (заголовок, пустая строка, описание). Временные файлы — `%TEMP%\unide_commit*.txt`, удаляются.
- Commit and Push — после коммита Push.
- Discard Selected... / Ignore... — по выделенным строкам (не флажкам; выделение — щелчок, Ctrl/Shift+щелчок); после них список перечитывается, снятые флажки сохраняются, список опустел — окно закрывается.
- Нет имени автора (`user.name`, `user.email`) — git откажет, причина в журнале.

## Ignore (окно Commit, 3c3a98a)

- Кнопка **Ignore...** — слева от Discard Selected...; то же — правый щелчок по строке (меню Discard Changes... / Ignore...). Выбор способа — списком (`ChooseFromList`).
- Новые файлы (`??`): игнорировать файл(ы) / все `*.<расширение>` / папку — в `.gitignore` корня репозитория (общий; сам `.gitignore` появится в списке изменений) или только у себя — в `.git/info/exclude` (путь — `rev-parse --git-path info/exclude`). Шаблон файла — `/путь` от корня, `* ? [ ] \ ! #` — через `\`, пробел в конце — `\ `; папка — `/папка/`. Уже записанные строки не повторяются (`GitAppendIgnore`, UTF-8, `\n`).
- Отслеживаемые (git их не игнорирует): «Перестать отслеживать и игнорировать» — `rm --cached -q -- пути` + шаблоны в `.gitignore` (файл остаётся на диске, удаление из репозитория — в следующем коммите); «Скрыть свои изменения» — `reset -q -- пути`, затем `update-index --skip-worktree -- пути` (удалённый файл скрыть нельзя — сообщение). Вернуть — Branch → Hidden Local Changes... (`ls-files -v -z`, тег `S`; `update-index --no-skip-worktree`).
- Выделены и новые, и отслеживаемые — сообщение 9824: выделить по отдельности.

## History (4e12e27)

- Слева — коммиты текущей ветки: заголовок, автор, дата (`yyyy-mm-dd hh:nn`), короткий SHA; `log GitLogFormat -n <N> HEAD`, N = 500, Load More — ещё 500.
- Справа: сведения (`show -s --format=commit %H / Author / Date / полный текст`), изменённые файлы (против первого родителя: `diff -M --name-status -z <h>^ <h>`; первый коммит — `diff-tree -r -M --root --no-commit-id --name-status -z`), разница выбранного файла (`diff -M <h>^ <h> -- файл [старое имя]`; первый коммит — `show --format= <h> -- файл`), длинная — обрезается.
- Кнопки: Copy SHA (полный SHA в буфер), View on GitHub (`<страница>/commit/<SHA>`, если origin на GitHub), New Branch from Commit... (после закрытия — имя, `checkout -b <имя> <SHA>`), Revert Commit (вопрос, `revert --no-edit <SHA>`; конфликт — подсказка `git revert --abort`), Close.

## Discard

- Как Discard в GitHub Desktop: изменённые и удалённые файлы — как в последнем коммите (`checkout HEAD --pathspec-from-file`, и индекс, и файл); новые (`??`, `A` в индексе, новое имя переименования, или коммитов ещё нет) — убрать из индекса (`reset -q --pathspec-from-file`; без коммитов — `rm --cached -q -f`) и в корзину Windows (можно вернуть). Прежнее имя переименования возвращается из последнего коммита.
- Всегда с вопросом (сообщение 9822). Branch → Discard All Changes... — все изменения (`status -uall`).
- Пустые папки после новых файлов остаются.

## Stash

- Stash All Changes — `stash push --include-untracked -m "unIDE <ветка> <дата>"` (нет изменений — сообщение).
- Restore Stash... — выбор записи (`stash list --format=%gd␟%gs␟%cr`), `stash pop <stash@{N}>`; конфликт — запись остаётся.
- Drop Stash... — выбор, вопрос (9823), `stash drop <stash@{N}>`.

## Журнал и прерывание

- Fetch, Pull, Push, Clone, Commit, Checkout, Merge, Revert, Discard, Stash, Ignore и др. — команда и вывод в Compilation log; строка состояния «git … (Esc — прервать)»; окно не замирает (`Application.ProcessMessages`), Esc прерывает git (`TerminateProcess`). Пока команда идёт, другие команды Git не запускаются (`FGitBusy`).
