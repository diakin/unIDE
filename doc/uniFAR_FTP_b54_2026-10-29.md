# FAR b.54 — FTP: операции с файлами (2026-10-29)

Коммит c073ee7 в mainTest. Файлы: FarFtp.pas, UnFar.pas. Продолжение `unIDE_FAR_FTP_b33_2026-10-25.md` (там — вход и переход по папкам).

## Клавиши
**В панели FTP (папка сервера):**
- F3 / Enter на файле — просмотр. Файл скачивается во временную папку `%TEMP%\unIDE_ftp\<метка>\`.
- F4 — правка; F2 в редакторе записывает файл и отправляет его обратно на сервер.
- F5 — скачать в папку другой панели; путь в окне можно изменить.
- F6 — скачать и удалить на сервере. Если ввести имя без пути на диске — переименовать или перенести на сервере. Имя папки этой же панели — перенос внутрь неё.
- Shift+F6 — переименовать.
- F7 — новая папка.
- F8 / Del — удалить, с вопросом; папки — с подпапками.

**С обычной панели на панель FTP:**
- F5 — закачать в текущую папку сервера или в указанную (путь от корня `/...` или от текущей папки).
- F6 — закачать и удалить на диске.

**Общее:**
- Если на верхнем уровне файлы уже есть — окно Overwrite / Skip / Cancel.
- Ход операции — окно Windows (IProgressDialog). «Отмена» в нём или Esc — прервать.
- После операции панели перечитываются, курсор встаёт на новое имя.

## Устройство
- `TFarFtpJob` (FarFtp.pas) — поток.
  - Сначала строит план: все файлы и папки с полными путями, подпапки — обходом.
  - Затем переносит файлы блоками по 64 КБ: FtpOpenFile, InternetReadFile / InternetWriteFile. Ход считается по байтам.
  - На диске — W-функции, имена в Unicode.
  - Перенос: после копирования удаляются исходные, вложенные раньше папок.
  - Прервать — закрыть соединение. Недокачанный файл удаляется: на диске при скачивании, на сервере при закачке.
  - Перед работой проверяет соединение (PWD). Если оно разорвано — соединяется заново.
- `FtpConnectConn` — общее соединение для `TFarFtpThread` (список папки) и `TFarFtpJob`.
- UnFar.pas:
  - запуск — `FtpRunJob`;
  - соединение панели на время операции передаётся потоку;
  - итог забирает `FtpCheck` → `FtpJobDone`;
  - отправка файла после F2 — `FtpUploadEdited`, по `FEditFtp*`.

## Проверка
- Wine + локальный FTP-сервер (pyftpdlib, пассивный режим). Проверены все операции выше, кириллические имена (UTF-8), прерывание на середине (сервер с ограничением скорости), повторное соединение после прерывания.
- Под Wine кириллица в именах на диске работает только при `LANG=C.UTF-8`. Это особенность Wine, на Windows такого ограничения нет.
- Компиляция в стиле Delphi 7 (FPC со стабами) проходит. Настоящий Delphi 7 и настоящий FTP-сервер под Windows не проверялись.

## Не сделано
- Копирование между двумя панелями FTP.
- Shift+F1 (архив) и Alt+F7 (поиск) на FTP.
- Вопрос «файл уже есть» задаётся только для верхнего уровня; вложенные файлы перезаписываются.
- Временные файлы F3/F4 остаются в `%TEMP%\unIDE_ftp\`.
