# FAR b.41 — темы и выбор цвета окном Windows (28.10.2026)

Коммит `dc3a17c` в `mainTest`. Файл: `UnFar.pas`. Работает и в unIDE, и в uniFAR.

## Темы — F9 → Options → Themes
- Встроенных тем три:
  - **Classic** — синяя палитра FAR (`FarPalDefaults`);
  - **FarDark 2026**;
  - **FarLight 2026**.
- Палитры FarDark и FarLight взяты из github.com/diakin/theming-far (файлы `.farconfig`). Ключи FAR сопоставлены с 40 элементами палитры (`FarThemeKeys`, `FarThemeBackKey`).
- Отличия от оригинала:
  - курсор панели заметнее: тёмная — `#094771`, светлая — `#CCE4F7`;
  - у светлой курсор меню `#CCE4F7`, рамка панели `#B0B0B0`;
  - цвета текста и фона редактора берутся из схемы.
- **Import .farconfig...** — любая тема FAR Manager 3:
  - truecolor `AARRGGBB` переносится как есть;
  - `fgindex` / `bgindex` — номер цвета консоли (0..15);
  - `0x80` (цвет по умолчанию хоста) — элемент не меняется.
  - Имя темы — имя файла.
- Тема применяется сразу: палитра пишется в `[FarPalette]`, имя темы — в `[FarTheme] Name`.

## Выбор цвета — окно Windows ChooseColorW
- Сетки из 16 цветов убраны.
- Colors: в меню элементов Enter открывает окно выбора цвета Windows (любой RGB), Del ставит стандартный цвет.
- Окно Files highlighting:
  - расширение;
  - Foreground и Background: Enter или щелчок открывает окно выбора цвета;
  - `[x] Panel background`;
  - образец.
- Окно выбора цвета окрашено цветами диалогов текущей темы:
  - перехват `CC_ENABLEHOOK`: `WM_CTLCOLORDLG` / `STATIC` / `BTN` / `EDIT`;
  - кнопки переведены в `BS_OWNERDRAW` и рисуются в `WM_DRAWITEM`.
  - На тёмной теме окно тёмное. Заголовок окна (рамка Windows) остаётся системным.
- 16 своих цветов окна сохраняются в `[FarTheme] CustomColors`. По умолчанию это 16 цветов консоли.

## Читаемость правил раскраски
- `FarReadable`: правило на фоне панели, у которого цвет мало отличается от фона по яркости (меньше 90 из 255), рисуется на светлом фоне темнее, на тёмном — светлее.
- Так стандартные правила, подобранные под синий фон, читаются на светлой и тёмной теме — и в панели, и в списке правил. В ini цвета не меняются.
