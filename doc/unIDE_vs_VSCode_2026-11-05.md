# Функции VS Code, которых нет в unIDE

Дата: 2026-11-05. Проверено по коду unIDE, ветка mainTest (7981c0b): меню Unit1.dfm, пункты, создаваемые в Unit1.pas, модули EdEditor/EdView, CodeInsight, Git*, FileSearch. Наличие функции определялось по коду, в работе на Windows не проверялось. «Нет» означает, что в коде не нашлось ни реализации, ни заготовки.

Обозначения: **нет** — отсутствует; **частично** — есть похожее, но уже, чем в VS Code.

## Что в unIDE уже есть (для ориентира)

Подсветка по .clr для многих языков, темы Light/Dark/Custom, вкладки с цветом рамки по проекту, разделение окна (верт./гориз.) со второй панелью-редактором, сравнение файлов (отдельное окно и Diff во второй панели), слияние при изменении файла на диске, поиск/замена (регистр, слово целиком), Find in Files (вкладки, проект, папка), закладки (LastBM, Hot Bookmarks), дерево процедур SubList, панель объявления, Code completion (Ctrl+Space) и подсказка параметров (Ctrl+Shift+Space) для Pascal, подсказка объявления под мышью, направляющие отступов, подсветка парной скобки/тега, показ пробелов, отступ блока Tab/Shift+Tab, автоотступ, форматирование Pascal, смена регистра, автосохранение файлов и desktop проекта, просмотр .md/.html (в т.ч. WebView2), Git (fetch/pull/push, commit с выбором файлов, ветки, stash, merge, сравнение веток, история, pull request), сборка Delphi и Arduino, отладчик Delphi (TD32) и отладчик эмулятора ArdSim, конструктор форм, uniFAR.

## Что, на мой взгляд, даёт больше пользы при небольших затратах

1. Комментирование строк Ctrl+/ — комментарий уже известен схеме (.clr), нужен только обработчик клавиши.
2. Перемещение и дублирование строк, автозакрытие скобок — изменения в EdEditor.
3. Регулярные выражения в поиске и Find in Files.
4. Quick Open (файл проекта по части имени) и палитра команд по пунктам меню.
5. Метки изменённых строк на полях — git diff уже вызывается для окна Commit.
6. Свёртка блоков — SubList и уровни вложенности для направляющих уже считаются, но изменение отображения строк в EdView затратное.

Это моя оценка по структуре кода, не замер.
