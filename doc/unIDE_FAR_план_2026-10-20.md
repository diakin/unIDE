# unIDE FAR — план (20.10.2026)

Двухпанельный файловый менеджер в духе FAR Manager внутри unIDE: меню **Utils → unIDE FAR**.
Код: `UnFar.pas` (класс `TFarView`, правила раскраски, командная строка, архивы через `tools\7zip\7z.exe`), `DlgFarColors.pas` / `.dfm` (окно раскраски), подключение — `Unit1.pas` (`FarMenuClick`, `FarLayout`, `FarClose`, `FarEditFile`, `FarHalfOn` / `FarHalfOff`, `FarCollapse`, `FarBtnClick`, `FarSplitterMoved`, `FarBeginUpdate` / `FarEndUpdate`, `FarEditorEsc`, `FarColorsClick`, перехват клавиш в `AppMessage`, `TabsMouseDown`).
Справочник по поведению FAR — форк https://github.com/diakin/FarManager (C++, FAR 3): `far/filelist.cpp` (клавиши панелей, сортировка), `far/palette.cpp` (цвета), `far/config.cpp` (меню Options), `far/cmdline.cpp` (командная строка, история папок), `far/farlang.templ.m4` (тексты диалогов, меню и кейбара).

## Решения

- Окно FAR закрывает область редактора: от строки вкладок (`FTabs`) до лога (`Splitter1`, `pnlLog`, `Panel2`), на всю ширину `pnlMain`. Тулбар, вкладки, лог, инспектор и строки состояния остаются видны. Редактор не прячется и не меняет родителя (RichEdit не пересоздаётся).
- Выход — только F10.
- Режим вида — только Brief (две колонки имён). Режима Full пока нет.
- Цвета панелей — палитра FAR по умолчанию (синие).
- Шрифт — Terminus Bold 10×18, cp1251 (SIL OFL 1.1). Файл `fonts/ter-c18b.fnt` собран инструментами самого Terminus 4.49.1, в exe — ресурс `farfont.res` (`fonts/make_farfont.py`). При открытии пишется во временную папку и подключается `AddFontResourceEx(FR_PRIVATE)`. Файл `ter-c18b.fnt` рядом с exe важнее ресурса. Нет Terminus — Lucida Console. Символы вне cp1251 рисует Lucida Console в ту же клетку. Рамки — линиями (в cp1251 нет псевдографики).
- Имена файлов — Unicode: `WideString`, `FindFirstFileW` и другие W-функции. Ввод в диалогах и командной строке — символы cp1251 (окна VCL в Delphi 7 ANSI). Редактору (ANSI) путь передаётся в кодировке Windows или коротким именем 8.3 (`FarToAnsiPath`).
- Клавиши FAR перехватываются в `TForm1.AppMessage` до отладчика, ярлыков меню и полосы меню. F10 и Alt+F… приходят как `WM_SYSKEYDOWN`; отпускание Alt после Alt+F… и F10 после закрытия гасится, чтобы не открывалось меню IDE. `WM_CHAR` окна FAR — тоже ему (поле ввода диалогов, командная строка).
- Состояние — `editor.ini`. Раздел `[Far]`: `LeftPath`, `RightPath`, `LeftFile`, `RightFile`, `Active`; сортировка `LeftSort`/`RightSort` (0..6), `…SortReverse`, `…DirsFirst`, `…SelFirst`; последние папки дисков `DriveA`..`DriveZ` (общие для обеих панелей); `HalfWidth` — ширина окна FAR в режиме F4; `PanelCut` — на сколько строк панели короче окна. Раздел `[FarHistory]`: `Count`, `Folder1`..`FolderN`. Раздел `[FarCmdHistory]`: `Count`, `Cmd1`..`CmdN`. Раздел `[FarColors]` — раскраска (см. ниже). Путь вне кодировки Windows пишется как `utf8:` + UTF-8.
- Диалоги F5–F8 и Shift+F4 — свои, в духе FAR, поверх панелей (тексты FAR на английском, как кейбар). Операции — `SHFileOperationW`: ход операции и вопросы о замене файлов показывает Windows. Удаление подтверждает только свой диалог.
- Меню (диски, сортировка, история, Options) — свои, в духе FAR VMenu: белым по бирюзовому, курсор белым по чёрному, буква быстрого выбора жёлтая, недоступное — тёмно-серым и пропускается.
- Строки снизу вверх: кейбар (одна строка, а меньше 8 клеток на клавишу — две: F1..F6 и F7..F12), командная строка, вывод команд (если панели укорочены Ctrl+Up), панели.
- Панели следят за своими папками (`FindFirstChangeNotificationW`, опрос таймером 250 мс) и перечитываются, когда сигналы затихли на 300 мс, но не реже чем раз в 2 с. Окно спрятано (или свёрнуто в режиме F4) — слежение снято (handle папки мешал бы её удалить). Пока открыт диалог или меню, панели не перечитываются.
- Смена диска (решено): другая панель на выбранном диске — в её папку; эта панель уже на этом диске — папка не меняется; иначе — последняя папка на диске, нет её — корень. Активная панель не меняется. Метка читается только у жёстких и RAM-дисков (у сменных, CD и сетевых чтение может ждать устройство или сеть). Диск не готов — сообщение в строке состояния, без окна Windows (`SetErrorMode`).

## Командная строка (b.17)

- Над кейбаром: приглашение (путь активной панели и `>`) и текст; каретка — подчёркиванием.
- Буквы и другие символы при панелях идут в неё. Пока строка не пуста, Enter, Shift+Enter, Esc, Backspace и Del — её (Del не удаляет файлы).
- Enter — выполнить. Свои команды: `cd`, `chdir`, `cd..`, `cd\`, `cd /d`, `X:` (смена диска по правилам Alt+F1), `cls`. Остальные — `cmd.exe /C` (`ComSpec`) в папке активной панели, без окна консоли; stdout и stderr — через трубу, ввода нет (программа, ждущая ввода, получит конец файла). Кодировка вывода — OEM (cp866) → Unicode.
- Вывод — в чёрной области под панелями (Ctrl+Up укорачивает панели), последние строки внизу, длинные переносятся, колесо мыши — прокрутка. Ctrl+O — спрятать / показать панели (виден весь вывод; пока спрятаны, работают только командная строка и F10). Вывода не видно — подсказка «Ctrl+O или Ctrl+Up» в строке состояния. Держится до 2000 строк.
- Ctrl+Break — прервать команду (завершается сам cmd.exe; запущенная им программа может остаться). Ненулевой код выхода — в строке состояния. Пока команда выполняется, новая не запускается.
- Esc / Ctrl+Y — очистить; Ctrl+S / Ctrl+D — каретка влево / вправо; Ctrl+V / Shift+Ins — вставить; Ctrl+Enter — имя файла под курсором; Ctrl+[ / Ctrl+] — путь левой / правой панели; Ctrl+E / Ctrl+X — история (до 50, в editor.ini).

## Запуск файлов (b.19)

- Enter и двойной щелчок на файле: `exe`, `com`, `bat`, `cmd` — выполнить, как команду из командной строки (`cmd.exe /C ""имя""` в папке панели, вывод — под панелями, имя — в историю команд); GUI-программу cmd.exe не ждёт. Остальные файлы — открыть программой по ассоциации (`ShellExecuteW`); ассоциации нет — окно «Открыть с помощью» (`openas`).
- Shift+Enter — открыть в своём окне через `ShellExecuteW`: exe — отдельным окном (консольная программа — со своей консолью), папку — в Проводнике.
- Пока выполняется прежняя команда, Enter на exe не запускает его (подсказка: Shift+Enter).

## Архивы (b.20)

- Работу с архивами делает 7-Zip из папки `tools\7zip` рядом с exe (7z.exe, 7z.dll; 7-Zip 26.04 x86, работает в Windows 7 и XP; лицензия LGPL с ограничением unRAR — `tools\7zip\License.txt`, источник и SHA-256 — `tools\7zip\readme.txt`). Установленный в системе 7-Zip не используется. Нет `tools\7zip\7z.exe` — предложение скачать (b.21, ниже).
- Enter (и двойной щелчок) на архиве — содержимое в этой же панели, она остаётся активной. Архив узнаётся по расширению: 7z zip zipx rar arj cab lzh lha tar gz gzip tgz tpz bz2 bzip2 tbz2 tbz xz txz zst lzma z taz cpio rpm deb xar wim swm esd iso udf img vhd vhdx vmdk vdi qcow qcow2 dmg squashfs cramfs 001 r00 chm msi jar apk xpi war ear. Ctrl+PgDn — открыть как архив любой файл (exe с SFX, docx и т. п.).
- Список — `7z l -slt -sccUTF-8` (асинхронно, как команда; Ctrl+Break — прервать). Папки, которых нет в архиве отдельными записями, строятся по путям файлов. Заголовок панели — `путь\архив.zip\папка`.
- В архиве: Enter / Ctrl+PgDn на папке — войти; `..`, Ctrl+PgUp — выше, из корня — обратно в папку с архивом (курсор на архиве); Ctrl+\ — корень архива, из корня — корень диска. Сортировка, выделение (Ins, Shift+…), Tab — как в обычной папке.
- Enter на файле в архиве — распаковать во временную папку `%TEMP%\unIDE_far\<метка>\` и открыть, как обычный файл (exe — выполнить, остальное — по ассоциации). Файл-архив (gz → tar и т. п.) открывается вложенно, `..` возвращает во внешний. Временная папка удаляется при закрытии FAR (F10).
- F5 в архиве — окно Extract: выделенное (или под курсором) — в папку другой панели (путь можно поменять, недостающие папки создаются). 7-Zip распаковывает с полными внутренними путями, поэтому распаковка идёт во временную папку `~unIDE_7z_<метка>` в папке назначения, а оттуда выбранные файлы и папки переносятся на место (`SHFileOperationW`: вопросы о замене — окна Windows). Список имён для 7-Zip — файлом в UTF-8 (`@list`, `-scsUTF-8`).
- Пароль: 7-Zip сообщил, что нужен пароль или пароль неверный, — окно Password (ввод звёздочками), повтор с ним. Пароль держится, пока архив открыт в панели. Esc — отмена.
- Пока нельзя: F4, Shift+F4, F6, Shift+F5, Shift+F6, F7, F8, Del, Shift+F1 в архиве; F5 из обычной панели в панель с архивом; распаковка в панель с другим архивом. Сообщение в строке состояния.
- Коды выхода 7-Zip: 0 — готово, 1 — с предупреждениями (сообщение), 2 и больше — ошибка (первая строка ERROR / Wrong из вывода — в строке состояния).

### Свой 7-Zip unIDE — поиск и установка (b.21, общий с ReactOS с b.23, `SzSetup.pas`)

- Один 7-Zip на весь unIDE: unIDE FAR (архивы) и меню ReactOS (Install RosBE распаковывает им установщик RosBE; Install 7-Zip) берут его из `SzSetup`. Установленный в системе 7-Zip не используется и не меняется (`RosFind7Zip` и установка 7-Zip 24.09 в Program Files убраны в b.23).
- Где ищется (`SzLocalExe`, нужны 7z.exe и 7z.dll): `<папка exe>\tools\7zip\`, затем `%LOCALAPPDATA%\unIDE\tools\7zip\` (`SHGetFolderPathW`, есть и в XP). Куда ставится (`SzChooseTargetDir`): где уже есть свой 7-Zip, иначе у exe, если туда пишется (пробный файл), иначе в профиль.
- Нет своего 7-Zip при открытии архива в FAR — окно «нужен свой 7-Zip unIDE… системный не используется и не меняется»: система, сборка, размер, папка, [Скачать] [Отмена]; после установки открытие архива продолжается само. В ReactOS — вопрос перед Install RosBE и Install 7-Zip; Install 7-Zip при своём 7-Zip той же версии или новее только пишет в журнал путь и версию (`SzFileVersion` — версия файла 7z.exe), при старой — предлагает обновить.
- Сборка по Windows (`SzGetOsInfo`: `RtlGetVersion` — настоящая версия и в Windows 8.1+, `IsWow64Process2` / `IsWow64Process` — разрядность): 64-битная Windows x64 (XP x64 и новее) — 7-Zip 26.04 x64; 32-битная (2000 и новее) и ARM64 — x86; 9x и NT 4 — сообщение «7-Zip работает в Windows 2000 и новее». Таблица сборок — `SzPackages`. Импорт 7z.exe / 7z.dll 26.04 проверен: x86 — без функций новее XP, x64 — `GetLargePageMinimum` (есть с XP x64 / Server 2003).
- Установка — поток `TSzInstall`: качает 7zr.exe (602 624 байта) и установщик (7z2604-x64.exe 1 664 082 или 7z2604.exe 1 361 691 байт) в `<папка>\~download\` — WinINet, таймаут 30 с, адреса: релиз 26.04 на github.com/ip7z/7zip, запасной — downloads.sourceforge.net/project/sevenzip/7-Zip/26.04/ (файлы обоих совпали по SHA-256), проверка размера и SHA-256 (своя SHA-256: в CryptoAPI Windows 2000 / XP до SP3 её нет); затем 7zr.exe (`CreateProcessW` без окна, вывод — в 7zr.log) достаёт `7z.exe`, `7z.dll`, `License.txt`, они переносятся в папку (7z.exe — последним), рядом — `unide_7zip.txt`; `~download` удаляется. Установщик не запускается, в системе ничего не регистрируется, права администратора не нужны.
- FAR читает ход потока по таймеру (окно: файл, полоса, КБ; распаковка — строкой; Отмена / Esc); ReactOS — `SzInstallSync` с событием хода окна установки (КБ для файлов меньше 10 МБ). Две установки сразу не идут (`SzInstallRunning`).
- Не вышло — причина (ошибка WinINet текстом Windows; 12157 — включить «Использовать TLS 1.2» в свойствах браузера; ошибки сертификата — обновить корневые сертификаты); в FAR — окно с ручным способом и кнопкой «Сайт 7-Zip», в ReactOS — в журнале.
- Скачать с github.com и sourceforge.net можно только по TLS 1.2: в Windows 7 он включается в свойствах браузера (в IE 11 включён сам), в XP и 2000 штатно его нет — там, скорее всего, останется ручная установка.

### Упаковка — Shift+F1 (b.22)

- Shift+F1 — окно **Add to archive** для выделенного (или файла под курсором) в обычной папке; в панели архива — пока нельзя (сообщение).
- Поля: **Archive** — имя архива (по умолчанию — имя элемента, у файла без расширения, при нескольких — имя папки панели, в корне диска — `archive`; плюс `.zip` / `.7z`); **Format** — ZIP / 7z; **Level** — Store, Fastest, Fast, Normal, Maximum, Ultra (`-mx` 0, 1, 3, 5, 7, 9); **Password** и **Confirm** — звёздочками. Смена формата меняет расширение в имени, если оно было прежним. Без расширения в имени — добавляется по формату.
- Клавиши окна: Tab / Shift+Tab, стрелки вверх / вниз — поля и кнопки по кругу; на выборе — стрелки влево / вправо, Home / End, Пробел (по кругу); в полях ввода — как в других окнах (Ctrl+V, Shift+Ins, Ctrl+Y). Мышь: щелчок по значению — выбрать, по полю — каретка. Enter — Add.
- Проверки (окно не закрывается, курсор — на поле, причина — в строке состояния): пустое имя; пароль и повтор не совпадают; кавычка `"` в пароле (в командную строку 7-Zip её не передать); ZIP с паролем не из ASCII (7-Zip отвечает E_INVALIDARG — проверено; кириллица — в 7z); имя — папка.
- Архив — в папку активной панели (или по пути из имени). Есть такой архив — 7-Zip дополняет его (`a`: одноимённые файлы заменяются).
- Команда: `7z a -tzip|-t7z -mx=N -sccUTF-8 -scsUTF-8 -bso0 -bsp1 [-p"пароль" -mhe=on (7z) | -mem=AES256 (ZIP)] "архив" @список`; список имён (UTF-8) — во `%TEMP%\unIDE_far\add_<метка>\`, рабочая папка — папка панели, папки упаковываются целиком. Имена в ZIP — по правилам 7-Zip по умолчанию (OEM, если имя в нём представимо, иначе UTF-8).
- С паролем: 7z шифрует и имена файлов (список без пароля не открыть — при открытии unIDE FAR спросит пароль); ZIP — AES-256: встроенный ZIP Проводника Windows 7 такой архив не откроет, 7-Zip — откроет.
- Ход — проценты из вывода `-bsp1` в строке состояния; Ctrl+Break — прервать (новый недописанный архив удаляется). Код 1 (предупреждения: файл занят и т. п.) — сообщение, архив остаётся; 2 и больше — ошибка, новый архив удаляется.
- После: в панели, откуда паковали, с упакованного снимается выделение, панели с папкой архива перечитываются, курсор — на архив; в строке состояния — имя и размер.
- Формат и уровень запоминаются: editor.ini `[Far]` `ArcFormat` (0 — ZIP, 1 — 7z), `ArcLevel` (0..5, по умолчанию 3 — Normal).

### Какие архивы распаковывает 7-Zip 26.04

- Упаковка и распаковка: 7z, XZ, BZIP2, GZIP, TAR, ZIP, WIM.
- Только распаковка: APFS, AR, ARJ, Base64, CAB, CHM, CPIO, CramFS, DMG, EXT, FAT, GPT, HFS, IHEX, ISO, LZH, LZMA, MBR, MSI, NSIS, NTFS, QCOW2, RAR, RPM, SquashFS, UDF, UEFI, VDI, VHD, VHDX, VMDK, XAR, Z, ZSTD (список — из `readme.txt` дистрибутива 7-Zip 26.04).
- Средствами самой Windows 7 — только ZIP (Проводник, без командной строки) и CAB (expand.exe); поэтому выбран 7-Zip.

## Раскраска файлов (b.15)

- Правило: расширение, включено ли, цвет текста, цвет фона (или фон панели). Цвета — любые RGB, выбор — `TUiColorDialog` (по теме IDE).
- Применяется только к файлам (не к папкам). Выделенный файл — жёлтым текстом на фоне правила; курсор — чёрным по бирюзовому, как раньше.
- Стандартный набор — 17 групп: программы, библиотеки, архивы, документы, PDF, таблицы, Delphi, формы, Basic, C/C++/Arduino, веб, текст, картинки, звук/видео, ресурсы, промежуточные файлы, mnb/spl.
- editor.ini `[FarColors]`: `_Set=1` и строки `ext=1,#RRGGBB,#RRGGBB` (вкл, текст, фон; `-` — фон панели). Раздела или `_Set` нет — стандартный набор.
- Окно `DlgFarColors`: флажок | расширение (образец цветами правила на фоне панели) | цвет текста | цвет фона. Щелчок по флажку — вкл/выкл, по цвету — выбор цвета, правый щелчок по фону — фон панели; Пробел, Enter (текст), Shift+Enter (фон), Del. Внизу — поле нового расширения (`ext`, `.ext`, `*.ext`), Добавить, Удалить; OK / Отмена.
- Вызов: в FAR — F9 → Options → Files highlighting; в меню IDE — Options → unIDE FAR - Files highlighting... (подменю Options → Highlighting — это схемы подсветки редактора, его не трогали).

## Клавиши

| Клавиша | Действие |
|---|---|
| F1, F2, F3, F12 | заглушки |
| Shift+F1 | упаковать выделенное в ZIP / 7z (окно Add to archive) |
| Enter (строка пуста) | папка — войти; архив — раскрыть в этой панели; файл: exe/com/bat/cmd — выполнить, остальные — открыть по ассоциации |
| Enter в архиве | папка — войти; файл — распаковать во временную папку и открыть (архив — вложенно) |
| Shift+Enter (строка пуста) | открыть в своём окне (exe — отдельным окном, папка — в Проводнике) |
| F4 | файл под курсором — в редактор: FAR с одной (активной) панелью, редактор рядом; на папке F4 ничего не делает |

Щелчок по вкладке редактора, когда FAR открыт (на всю область или в режиме F4): в активной панели FAR курсор встаёт на файл этой вкладки (другая папка — переход в неё). На всю область — фокус остаётся у FAR. Щелчок по крестику закрытия вкладки курсор не трогает.

Двойной щелчок по вкладке, когда FAR на всю область, — как F4: FAR на половину с одной панелью, файл вкладки — в редакторе. Вкладка была открыта и до этого, поэтому по Esc она остаётся. Двойной щелчок считается по времени двойного щелчка Windows (та же вкладка), не по `WM_LBUTTONDBLCLK`.

### Вкладка при Esc (решено)

- вкладка, которую открыл F4, по Esc закрывается;
- вкладка, открытая до F4, остаётся (без вопроса — правки остаются в ней);
- если файл изменён — запрос «Сохранить / Не сохранять / Отмена», как в FAR («Отмена» — редактор остаётся открытым);
- пустой файл, созданный Shift+F4 и не сохранённый (F2 / Shift+F2), удаляется.

## Режим F4

В `pnlMain` добавляется распорка `FFarSpacer` (`alLeft` / `alRight`, крайняя) со стороны активной панели, за ней — сплиттер `FFarSplitter` (TSplitter, линия-след, ширина ставится при отпускании). FAR рисуется поверх распорки с одной панелью (`SetSingle`), редактор (`FLeftHost`, alClient) занимает остальное. Ширина окна FAR — `HalfWidth` (по умолчанию половина), не уже 200 px, редактору — не меньше 150 px; `FarLayout` ширину только держит в пределах, `HalfWidth` применяется при входе в режим и при развороте (`FarApplyHalfWidth`). Кнопки `_` и `[]` (TUiButton) — в правом верхнем углу окна FAR:
- `_` — свернуть FAR до полоски с кнопкой `[]` (фокус — редактору);
- `[]` у свёрнутого — развернуть до прежней ширины; Utils → unIDE FAR тоже разворачивает;
- `[]` у развёрнутого — FAR на всю ширину с обеими панелями: режим F4 кончается, файл остаётся обычной вкладкой (без вопроса о сохранении).

Смена ширины, свернуть / развернуть, вход и выход из режима — как у правой панели: перерисовка на время раскладки выключена, потом `FormResizeEvent` и перерисовка всего окна (`FarBeginUpdate` / `FarEndUpdate`). Когда фокус в редакторе — клавиши IDE как обычно; Esc сначала закрывает подсказки Code Insight (`CiCompletionShown`, `FCiParamShown`). F4 на другом файле: прежний файл F4 без изменений закрывается, изменённый остаётся вкладкой.
