# unIDE FAR b.33 — FTP, первый этап (2026-10-25)

Коммит 9f11c64 в mainTest. Файлы: FarFtp.pas (новый), UnFar.pas, SyntaxHLClaude.dpr.

## Что сделано
- **Меню дисков.** Пункт FTP под белой линией, после томов без буквы и перед списком физических дисков; справа — «адресов: N».
- **Список адресов** (панель в режиме FTP, заголовок `FTP:`):
  - колонки Host | Home | User, первая строка `..` — обратно в папку, где была панель;
  - Shift+F4 — новый адрес, F4 — изменить, F8 / Del — удалить (с вопросом);
  - строка внизу — комментарий или адрес целиком.
- **Окно адреса.** Поля: Address (host, host:port или `ftp://user:password@host:port/dir` — части URL заменяют поля), Home, User, Password, Comment. Флажки Ask for password every time и Passive mode. Кнопки Save / Connect / Cancel.
- **Хранение адресов.** editor.ini, раздел `[FarFtp]`: Count, HostN, PortN, HomeN, UserN, PassN, DescrN, FlagsN (1 — спрашивать пароль, 2 — пассивный режим).
  - Пароль хранится зашифрованным DPAPI (CryptProtectData). На другой учётной записи или машине он не расшифруется — нужно ввести заново.
  - При «спрашивать пароль» пароль не хранится, перед входом открывается окно пароля.
- **Сервер.** Enter на адресе — вход, заголовок `ftp://user@host/dir`:
  - Enter на папке — войти, `..` / Ctrl+PgUp — выше, из корня — к списку адресов;
  - Ctrl+R — перечитать, Ctrl+\ — в `/`, Esc — прервать запрос;
  - двойной щелчок работает как Enter.
- **Сеть.** WinInet (*A-функции, INTERNET_OPEN_TYPE_DIRECT, тайм-ауты 20 с) в потоке `TFarFtpThread`, ответ забирает `WatchTick` → `FtpCheck`.
  - Соединение `TFarFtpConn` переиспользуется. Если запрос не прошёл не из-за ответа сервера (разрыв), поток один раз соединяется заново.
  - `FFtpSession` отбрасывает ответ, если панель ушла с FTP, пока ждали.
- **Имена файлов** хранятся байтами сервера (`TFarItem.FtpRaw`) для команд серверу. Для показа — UTF-8, если байты верный UTF-8, иначе cp1251. Путь, набранный человеком (Home): ASCII — как есть, иначе UTF-8.
- **Ещё не сделано** (в строке состояния — «следующим шагом»): F3 / F4 / F5 / F6 / F7 / F8 на сервере, копирование на FTP из другой панели, Shift+F1, Alt+F7.
