# INC Manager (View > IncManager...), 2026-10-11

Окно Unit3/Form3, проверки в IncCheck.pas (без VCL, проверены FPC на rapidq_ref).

1. Папки со своими inc: диск и дерево слева, «Добавить» / «Удалить из списка», галка — папка участвует, флажок «Искать и в подпапках». editor.ini [IncManager]: Count, FolderN=путь|1/0, SubDirs, RefPath.
2. Справа — все .inc отмеченных папок (без повторов).
3. Сравнение с эталоном (по умолчанию incOld рядом с SysIncPath, иначе rapidq_ref\incOld у exe; кнопка «...» — своя папка). Текст сравнивается без пустых строк, пробелов по краям, регистра и строк защиты (inc2026 / IncManager). Значок: зелёный — совпадает, жёлтый — эталон с тем же именем отличается, белый — в эталоне нет.
4. «Защитный $IFNDEF» — в отмеченные файлы без защиты: $IFNDEF/$DEFINE в начало, $ENDIF в конец; имя — как у эталона (свой файл и общие inc исключают друг друга), иначе __ИМЯ_INC. Прежний текст — <файл>.bak (существующий .bak не перезаписывается). Комментарий латиницей (файлы бывают UTF-8 и 1251).
5. Ошибки по файлу (слева внизу, двойной щелчок — строка в редакторе; красное число у файла):
   - исправления эталона (строки «inc2026:»), которых нет в файле на том же месте;
   - директива без $; числа 880U / 10L и 0x; CONST без =; «;» вне строки (кроме PRINT);
   - $DEFINE/$UNDEF встроенного класса; TYPE с именем встроенного класса (Component.data без QCOLORDIALOG, плюс QTHREAD);
   - блоки SUB/FUNCTION/TYPE/CREATE/WITH/SELECT/CONSTRUCTOR/EVENT/PROPERTY SET/$IF по операторам через «:»; TYPE X AS Y — без блока;
   - $INCLUDE не найден (предупреждение); $OPTION INKEY$ TRAPALL (предупреждение);
   - имена, которые есть в общих inc: для файла без эталона — по строкам, для остальных — итог с советом про защиту.
   Проверка на rapidq_ref/inc_bad: 169 совпадают, 72 отличаются, 5 нет в эталоне; найдены все «END SUB вместо END FUNCTION» и подобные, исправленные в inc2026.
6. «Демо»: .bas из папок списка, где есть $INCLUDE этого файла (несколько — выбор из списка); нет — новая <имя>_demo.bas рядом: форма, метка, по объекту каждого класса TYPE X EXTENDS, список процедур в комментарии.

Окно открывается сразу, чтение эталона и проверка — с ходом и Стоп (кнопка «Сканировать»). Кнопки — TUiButton (цвета темы), разделители без AutoSnap.

## Поиск inc-файла (View > Find inc file..., DlgFindInc.pas), 2026-10-12

- Имя файла → все копии на локальных дисках (DRIVE_FIXED) или в выбранной папке; пропускаются Windows, $Recycle.Bin, System Volume Information, RECYCLER, WinSxS. Ход и Стоп.
- Каждая копия: значок статуса относительно эталона, число ошибок, дата; замечания — ниже, двойной щелчок — строка в редакторе.
- «Копировать в папку inc проекта»: папка — RapidQIncDir текущего проекта (её читает rc.exe), без неё — SysIncPath; «...» — другая. Такой же файл уже есть — ничего не делается; другой — вопрос, прежний в .bak. Нет защиты — ставится в копию (исходный файл не меняется).
- Сборка RapidQ: сообщение rc.exe «$INCLUDE file X does not exist» — строка в логе и вопрос «найти копии на дисках?», окно открывается с поиском X.

Попутно в эти дни:
- Проверка перед сборкой Delphi: повторы имён в .dfm и обработчики OnXxx не из published (EComponentError / EReadError при запуске).
- Find «В файлах проекта»: окно сразу, у сбора списка файлов ход и Стоп, список не собирается дважды.
- Пробная сборка редактора становится рабочей в FormCloseQuery (не в FormDestroy); полный путь exe в заголовке; пробной сборке копируется <exe>.manifest (внешний манифест Windows ищет по имени exe).
- Конструктор: перенос рамкой (XOR в DC формы), выделение рамкой, правый щелчок не сбрасывает группу, сетка — кистью-узором, маркеры и уголки при замороженной форме; строка замера 3804 после каждого переноса; журнал переноса — [Designer] DragTrace=1.
