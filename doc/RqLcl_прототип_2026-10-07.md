## Решения пользователя
- Компоненты RapidQ для FreeBASIC — на основе LCL (Lazarus), не VCL Delphi 7 (лицензия Delphi могла запрещать распространение VCL-библиотеки для других разработчиков; LCL — LGPL с исключением для компоновки).
- Подход: LCL в DLL с плоским API + обёртка на FreeBASIC. RapidQ-исходник перед fbc нормализует препроцессор (не форк fbc).
- Режимы Compat (как RapidQ) и Smart (по умолчанию: без падений, подробные ошибки). Подробно — `RqLcl/RAPIDQ_RULES.md`.
- Порядок работ: препроцессор в unIDE; функции и классы для rapidq.inc; QSTRINGLIST, QSTRINGGRID, QREGISTRY, QDIRTREE; события с параметрами и CREATE; классы, которые RQdebugger создаёт через CREATE (меню, QPANEL, QCOOLBTN, QCOMBOBOX, QCHECKBOX, QLISTBOX, QSPLITTER); остальные классы из CREATE RQdebugger (QGAUGE, QTABCONTROL, QRADIOBUTTON, QGROUPBOX, QTREEVIEW, QFILELISTBOX, QSTATUSBAR); TYPE … EXTENDS (QBUTTONXP, QMAXEDIT и др.); Align/Tag/TabOrder/Transparent у всех элементов и SUBI; диалоги, QTIMER, Application, Screen, Clipboard, FileRec; $RESOURCE, QIMAGE, QIMAGELIST; QCANVAS, QBITMAP, QSCROLLBAR, QTRACKBAR, QSCROLLBOX, QOVALBTN, QOUTLINE, QHEADER, QPRINTER, QSOCKET, QNOTIFYICONDATA — всё сделано.
- QRICHEDIT — на пакете RichMemo (выбор пользователя 2026-10-07).
- Ошибки в самом RQdebugger (необъявленные TabBAr, Combo2, ReplCheckBox, SubDirCheckbox, ComPortNmb, ChBoxPlainTxt, StartIndent…) пользователь решил оставить.

## Ответы пользователя
- 2026-10-08: Boolean-свойства в RapidQ читаются как 1 / 0 (у RqLcl так и было). TRUE/FALSE — не слова RapidQ: TRUE = 1 даёт `$define True 1` в rapidq.inc; без include тест RapidQ: TRUE → 0, NOT TRUE → -1, FALSE → 0, NOT FALSE → -1; сравнение `(2 > 1)` → -1 (как у FreeBASIC). Препроцессор: без определения TRUE/FALSE — неявная переменная TRUE_v (0) с предупреждением; с $define — подстановка 1/0. Коммиты b1f2837 (TRUE → 1, заменён), 930485c, 08a6434, a82567f.
- 2026-10-08: s$[N] — с 1, вне строки ""; запись s[5] = "x" — ошибка RapidQ; CASE = 0 срабатывает, CASE > 5 — нет (по документации CASE IS > 5); `$define False 0` + `CONST False = 0` → 0.
