Отмена изменений

Отмена записанного (коммитов) — через revert, если коммит уже на сервере, и через reset, если только у вас. Перед reset --hard и clean проверьте, что теряете: эти команды удаляют правки без возврата.

Правки в файлах, ещё не записанные

git restore Unit1.pas            # вернуть файл как в последнем коммите (правки пропадут)
git restore .                    # все файлы в текущей папке и ниже
git restore --staged Unit1.pas   # убрать из индекса, правки в файле остаются
git restore --source=c0fbd74 Unit1.pas   # файл как в коммите c0fbd74

Последний коммит

git commit --amend -m "Новый текст"   # исправить сообщение
git add забытый.pas
git commit --amend --no-edit          # добавить забытый файл в тот же коммит

--amend заменяет коммит новым. Если он уже на сервере, push потребует --force — для отправленных коммитов лучше revert.

Отменить коммит: revert

git revert c0fbd74

Создаёт новый коммит, обратный указанному. История не переписывается — безопасно для коммитов, уже отправленных на сервер.

Вернуть ветку назад: reset

КомандаКоммиты после указанногоПравки этих коммитов
git reset --soft HEAD~1убираются из веткиостаются в индексе
git reset HEAD~1убираются из веткиостаются в файлах (не в индексе)
git reset --hard HEAD~1убираются из веткипропадают, как и все незаписанные правки

git reset --hard origin/mainTest — сделать ветку точно такой, как на сервере (свои незаписанные правки и неотправленные коммиты пропадут).

Отложить правки: stash

git stash                # спрятать незаписанные правки, файлы как в коммите
git stash -u             # и новые файлы
git stash list           # что отложено
git stash pop            # вернуть последнее отложенное и убрать из списка
git stash apply          # вернуть, оставив в списке
git stash drop           # выбросить последнее отложенное

Новые файлы, которых Git не знает

git clean -n             # показать, что будет удалено
git clean -fd            # удалить неотслеживаемые файлы и папки

Файлы из .gitignore clean не трогает (их удаляет -x).

Если что-то потерялось: reflog

git reflog               # куда указывал HEAD: каждое переключение, коммит, reset
git reset --hard HEAD@{3}   # вернуться в то состояние

Коммиты после reset или удаления ветки хранятся ещё какое-то время (записи reflog по умолчанию — 90 дней, для коммитов вне веток — 30) и находятся через reflog.
