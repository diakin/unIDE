Основные понятия

Репозиторий

Папка проекта, в которой есть скрытая папка .git: в ней вся история. Остальные файлы — рабочая копия: файлы той версии, с которой вы сейчас работаете.

Три состояния файла

Коммит

Снимок всех файлов проекта с сообщением, автором и датой. У каждого коммита есть хеш — строка вида c0fbd74 (первые 7 знаков полного 40-значного хеша обычно достаточно). Коммиты связаны в цепочку: каждый знает своего предшественника.

Ветка и HEAD

Ветка — имя, указывающее на последний коммит линии работы (main, mainTest). Новый коммит сдвигает текущую ветку вперёд. HEAD — то, на чём вы сейчас стоите: обычно текущая ветка. HEAD~1 — коммит перед ним, HEAD~2 — ещё раньше.

Удалённый репозиторий

Копия репозитория на сервере (GitHub). Обычно называется origin. Ветки сервера у вас видны как origin/main, origin/mainTest — это запомненное состояние сервера на момент последнего git fetch.

  • git fetch — узнать новое на сервере, ничего не меняя в ваших файлах.
  • git pull — fetch и сразу влить изменения сервера в текущую ветку.
  • git push — отправить свои коммиты на сервер.
