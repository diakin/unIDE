Шпаргалка

Настройка и начало

КомандаЧто делает
git config --global user.name "Имя"Имя автора коммитов
git config --global user.email "почта"Почта автора
git clone <адрес>Скачать репозиторий
git initНовый репозиторий в текущей папке

Изменения

КомандаЧто делает
git statusЧто изменено, текущая ветка
git diff / git diff --stagedИзменения не в индексе / в индексе
git add <файлы>, git add -AВ индекс
git commit -m "текст"Записать коммит
git commit --amendИсправить последний коммит
git rm, git mvУдалить, переименовать

Ветки

КомандаЧто делает
git branch, git branch -aСписок веток
git switch <ветка>Перейти
git switch -c <новая>Создать и перейти
git merge <ветка>Влить ветку в текущую
git branch -d <ветка>Удалить слитую

Сервер

КомандаЧто делает
git fetchУзнать новое на сервере
git pullПолучить и влить в текущую ветку
git pushОтправить коммиты
git push -u origin <ветка>Отправить новую ветку
git remote -vАдреса серверов

Отмена

КомандаЧто делает
git restore <файл>Выбросить незаписанные правки файла
git restore --staged <файл>Убрать из индекса
git revert <коммит>Обратный коммит (безопасно)
git reset --hard <коммит>Вернуть ветку и файлы (правки пропадут)
git stash / git stash popОтложить правки / вернуть
git reflogНайти потерянное
git merge --abortОтменить слияние с конфликтами

История

КомандаЧто делает
git log --oneline --graph --allИстория деревом
git log -p <файл>История файла
git show <коммит>Что в коммите
git blame <файл>Кто менял строки
git grep "текст"Поиск по файлам
git tag -a v1 -m "..."Тег версии

Справка по любой команде: git help <команда> или git <команда> -h (кратко, прямо в терминале).
