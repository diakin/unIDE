История и поиск

log

КомандаЧто показывает
git log --oneline -20Последние 20 коммитов, по строке.
git log --oneline --graph --allВсе ветки деревом.
git log --stat -5С изменёнными файлами.
git log -p Unit1.pasИстория одного файла с изменениями.
git log --follow -- UnFar.pasФайла и до переименования.
git log --since=2026-10-01 --until=2026-10-15За период.
git log --author="Имя"Коммиты автора.
git log --grep="QEMU"По тексту сообщения.
git log -S"RosRunImage"Коммиты, где строка появилась или исчезла в коде.
git log main..mainTest --onelineЧто есть в mainTest и нет в main.

show

git show c0fbd74                 # коммит: сообщение и изменения
git show c0fbd74 --stat          # только список файлов
git show c0fbd74:Unit1.pas       # файл целиком, как в том коммите

git show коммит:файл выводит файл так, как он хранится в репозитории: для *.pas и других файлов с правилом working-tree-encoding это UTF-8 с концами строк LF (см. .gitattributes). Чтобы получить файл из другой ветки или коммита на диск в рабочей кодировке (Windows-1251, CRLF), используйте git restore --source=main GitTool.pas — файл в рабочей копии будет заменён.

Кто изменил строку: blame

git blame Unit1.pas              # для каждой строки - коммит, автор, дата
git blame -L 100,140 Unit1.pas   # только строки 100-140

Поиск по файлам: grep

git grep "SzLocalExe"            # в файлах рабочей копии, которые знает Git
git grep -n "SzLocalExe" main    # в ветке main, с номерами строк

Теги

Тег — постоянное имя коммита, например номер версии.

git tag                          # список
git tag -a v0.2 -m "unIDE 0.2"   # тег на текущем коммите
git tag -a v0.2 c0fbd74 -m "..." # на указанном коммите
git push origin v0.2             # отправить тег на сервер
git switch --detach v0.2         # посмотреть версию (не на ветке)
