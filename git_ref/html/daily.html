Каждый день

Что изменилось: status

git status

Показывает текущую ветку, отстаёт ли она от сервера или опережает его, изменённые файлы (красным — не в индексе, зелёным — в индексе) и новые файлы, которых Git ещё не знает (Untracked).

Чем отличаются: diff

КомандаЧто показывает
git diffИзменения рабочей копии, ещё не добавленные в индекс.
git diff --stagedЧто уйдёт в следующий коммит.
git diff Unit1.pasТолько один файл.
git diff --statТолько список файлов и число строк.
git diff main mainTestРазница между ветками.

Записать: add и commit

git add Unit1.pas UnFar.pas      # отобрать файлы
git add -A                       # отобрать всё: изменённые, новые, удалённые
git commit -m "Что сделано"      # записать отобранное
git commit -am "Что сделано"     # add всех уже известных Git файлов + commit

Сообщение коммита — первая строка кратко (до 70 знаков), что сделано; подробности — после пустой строки. Несколько -m дают несколько абзацев: git commit -m "Заголовок" -m "Подробности".

Убрать файл из индекса, оставив правки в файле: git restore --staged Unit1.pas.

Удалить и переименовать

git rm Old.pas                   # удалить файл и записать удаление в индекс
git rm --cached big.log          # перестать хранить файл, оставив его на диске
git mv Old.pas New.pas           # переименовать

Посмотреть историю: log

git log --oneline -10            # последние 10 коммитов одной строкой
git log --oneline --graph --all  # все ветки деревом
git show c0fbd74                 # что изменено в коммите

Обычный порядок работы

  1. git pull — взять новое с сервера.
  2. Правки в unIDE.
  3. git status, git diff — проверить, что изменено.
  4. git add ... и git commit -m "...".
  5. git push — отправить на сервер.
