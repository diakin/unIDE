Git: справка

Git — система контроля версий: она хранит историю всех изменений файлов проекта, позволяет вернуться к любой прежней версии, вести работу в нескольких ветках и обмениваться изменениями с репозиторием на GitHub. Здесь — как работать с Git из unIDE и основные команды с примерами.

Git в unIDE

ПунктЧто делает
ReactOS → Git Terminal (Git Bash)Открывает терминал Git Bash в папке открытого проекта (нет проекта — в папке файла активной вкладки, нет и его — в папке unIDE). Git нигде не найден — предлагает скачать свой.
ReactOS → Find or Install Git 2.46.2 (tools\git)...Ищет Git for Windows, установленный в системе (реестр, PATH, Program Files\Git, %LOCALAPPDATA%\Programs\Git), и пишет в Compilation log, где нашёл. Не нашёл — скачивает свой PortableGit 2.46.2 в tools\git (около 59 МБ, распакованный — около 400 МБ).
Help → GitЭта справка (git_ref\help\git.chm).

Свой Git unIDE — переносная версия Git for Windows: в реестр и PATH ничего не пишется, права администратора не нужны. 2.46.2 — последняя версия Git for Windows для Windows 7. Поэтому git из обычной командной строки Windows (cmd.exe) свой Git не видит — команды вводятся в Git Bash.

Git и GitHub Desktop

GitHub Desktop и терминал работают с одной и той же папкой репозитория: то, что сделано в терминале, сразу видно в GitHub Desktop, и наоборот. Кнопки GitHub Desktop соответствуют командам:

GitHub DesktopКоманда
Fetch origingit fetch
Pull origingit pull
Push origingit push
Current branch → выбрать веткуgit switch <ветка>
Commit to <ветка>git add отмеченных файлов + git commit -m "..."
Historygit log

Разделы

  • Терминал Git Bash — как вводить команды, пути, копирование.
  • Основные понятия — репозиторий, индекс, коммит, ветка.
  • Первая настройка — имя, почта, редактор, клонирование.
  • Каждый день — status, add, commit, diff, log.
  • Ветки — создание, переключение, слияние; схема main / mainTest.
  • GitHub и удалённый репозиторий — fetch, pull, push.
  • Отмена изменений — restore, revert, reset, stash.
  • Конфликты слияния.
  • История и поиск — log, show, blame, теги.
  • .gitignore и .gitattributes — что не хранить, кодировки.
  • Шпаргалка — все команды таблицей.
