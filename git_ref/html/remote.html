GitHub и удалённый репозиторий

Какие серверы подключены

git remote -v

Показывает адреса origin для получения (fetch) и отправки (push). Сменить адрес: git remote set-url origin https://github.com/diakin/unIDE.git.

fetch — узнать новое

git fetch             # все ветки origin
git status            # "Your branch is behind 'origin/mainTest' by 3 commits"
git log --oneline HEAD..origin/mainTest    # что пришло с сервера

fetch не трогает ваши файлы и ветки: он только обновляет origin/....

pull — получить и влить

git pull              # fetch + merge в текущую ветку
git pull --ff-only    # влить, только если у вас нет своих новых коммитов

Если и у вас, и на сервере есть новые коммиты, а настройка pull.rebase не задана, git pull останавливается и просит выбрать способ (см. Первая настройка): git pull --no-rebase — слияние, git pull --rebase — ваши коммиты переносятся поверх полученных.

push — отправить

git push                          # текущую ветку в связанную ветку сервера
git push -u origin try-feature    # новую ветку: отправить и связать
git push origin --tags            # отправить теги

Сервер отказал (rejected ... fetch first) — на сервере есть коммиты, которых у вас нет: сначала git pull, потом снова git push.

Осторожно: git push --force заменяет историю ветки на сервере вашей; чужие коммиты, которых у вас нет, пропадут с сервера. Если без него не обойтись, git push --force-with-lease откажет, если на сервере появилось что-то, чего вы ещё не видели.

Ветка сервера появилась, а у вас её нет

git fetch
git switch mainTest    # создаётся своя mainTest, связанная с origin/mainTest
