Терминал Git Bash

Git Bash — окно терминала (mintty) с оболочкой bash и набором программ Unix из состава Git for Windows. Команды Git вводятся в строке после $, Enter — выполнить.

Строка приглашения

Пример: user@PC MINGW64 /d/_F/balan/_SyntaxHLClaude (mainTest) — пользователь и компьютер, текущая папка, в скобках — текущая ветка Git. Знак |MERGING или |REBASE после ветки значит, что слияние или перебазирование не закончено (см. Конфликты).

Пути

  • Диск пишется как папка: D:\_F\balan → /d/_F/balan.
  • Разделитель — /. Путь с пробелами — в кавычках: cd "/d/My Projects".
  • ~ — домашняя папка пользователя (C:\Users\<имя>).

Полезные команды оболочки

КомандаЧто делает
pwdПоказать текущую папку.
cd <папка>, cd ..Перейти в папку, на уровень выше.
ls, ls -laСписок файлов (с -la — со скрытыми и подробно).
clearОчистить экран (или Ctrl+L).
start .Открыть текущую папку в Проводнике.
exitЗакрыть терминал.

Клавиши

  • Tab — дописать имя файла, ветки или команды Git.
  • ↑ / ↓ — прежние команды.
  • Ctrl+C — прервать выполняющуюся команду.
  • Копировать — выделить мышью (текст копируется сам); вставить — Shift+Ins или правая кнопка мыши → Paste.

Длинный вывод и редактор

  • Длинный вывод (git log, git diff) показывается постранично программой less: Пробел — дальше, b — назад, / — поиск, q — выход.
  • Если сообщение коммита не указано через -m, Git открывает текстовый редактор (по умолчанию в Git Bash — vim). Выйти из vim с сохранением: Esc, затем :wq и Enter; без сохранения — Esc, :q!. Проще всегда писать git commit -m "текст" или назначить Блокнот: git config --global core.editor notepad.
