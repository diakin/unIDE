QSAVEPLUS Component

Extends QSAVEDIALOG · source: inc/QSavePlus.inc, line 46 · author: Suchart Chokphichitchai

A save file dialog extended with file name checks: missing path, invalid name, missing extension and overwrite confirmation.

QSaveplus extends QSaveDialog and adds the method Execute2, which runs the normal Execute in a loop until the user cancels or picks an acceptable name. If the directory of FileName does not exist, a warning is shown and the dialog reopens. If the name contains ">", it is reported as invalid. If the name has no extension, or an extension that is not in the selected filter, the user is asked whether to add the first extension of the selected filter. If the file already exists, the user must confirm replacing it.

The extension logic reads the Filter string: item i is field i*2 of the "|"-separated filter and its extensions are separated by ";". Per the comments, filter 1 must be "All Files |*.*|" (no extension check is done for it), each entry must end with "|" and no blanks or tabs may follow an extension. The file also defines a helper function delMark$ and the constants dot, Quo$, false and true.

QSAVEPLUS inherits the properties, methods and events of QSAVEDIALOG; the tables below list only what the component adds or redefines (public members).

QSaveplus Methods

MethodTypeDescription
Execute2FUNCTION AS INTEGERShows the save dialog repeatedly until the user cancels or gives a valid, confirmed file name; returns the result of the last Execute (1 when a file was accepted, 0 on Cancel). The final name is in FileName.

Notes

  • The source says it was tested only on Windows 98.
  • The file contains a complete demo program after the TYPE (a form, a QRichEdit, a QSaveplus instance and form.ShowModal at the end); it runs if the file is included as is.
  • It defines global constants false = 0 and true = 1 and turns $ESCAPECHARS ON, which can conflict with other code.
  • The name check only rejects ">"; other invalid file name characters are not checked.
  • Filter index 1 is always treated as "All Files", so the first filter entry must be *.* for the extension logic to work.

QSaveplus Examples

Example from the comments in the source file.

CREATE saveDlg AS QSaveplus
  Filter = "All Files (*.*)|*.*|JavaScript (*.js)|*.js|Text (*.txt)|*.txt|"
END CREATE

IF saveDlg.Execute2 = 1 THEN
  ShowMessage "Save File.. " + saveDlg.FileName
ELSE
  ShowMessage "No Save"
END IF
