QPAGESETUP Component

Extends QOBJECT · source: inc/QPageSetup.inc, line 70 · version: 1.2

A page setup dialog object based on the Windows PageSetupDlg common dialog that returns paper size, orientation and margins.

QPageSetup extends QOBJECT and wraps PageSetupDlgA from COMDLG32. Execute shows the dialog with the PSD_MARGINS and PSD_MINMARGINS flags, using the margins already set as initial values. The DisablePrinter, DisablePaper, DisableOrient and DisableMargins switches add the matching PSD_DISABLE flags.

After OK, PageWidth and PageHeight receive the paper size and the four Margin properties receive the margins, each as the dialog value divided by 100; Orientation becomes True when the page is wider than high (landscape). No unit flag (PSD_INHUNDREDTHSOFMILLIMETERS or PSD_INTHOUSANDTHSOFINCHES) is set, so the unit follows the system measurement setting. When Caption is not empty, a hook centers the dialog and sets its title. Comments in the source are in French.

QPAGESETUP inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QPageSetup Methods

MethodTypeDescription
ExecuteFUNCTION AS BOOLEANShows the page setup dialog; returns True and updates the size, orientation and margin properties if the user pressed OK, otherwise returns False.

Notes

  • The unit of sizes and margins is not fixed by the code: values are the dialog's own units divided by 100, and those units depend on the system measurement setting.
  • Orientation, PageWidth and PageHeight have empty setters (read only); SetPageWidth and SetPageHeight are declared with a boolean parameter although the properties are long.
  • The margin values written by the setters stay in the structure between calls; there is no way to reset them other than assigning new values.
