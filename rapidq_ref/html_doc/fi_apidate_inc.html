lastdayM

FUNCTION · rapidqAllProc.inc, line 6387

Function lastdayM(datum$ as string)as string

Returns the last day of the month for a date given as month-day-year (separated by -), as a string "m-d-y". Finds it by calling GetDateFormat for day 28 and up until the day is invalid.

weekday

FUNCTION · rapidqAllProc.inc, line 6388

Function weekday(datum$ as string)as integer

Returns the day of week (1 to 7) of a date given as month-day-year (separated by -). Compares the short day name from GetDateFormat with the locale names from GetLocaleInfo (LOCALE_SABBREVDAYNAME1..7), so 1 is Monday.
