FUNCTION HtmCodeToChar(CodeNum AS LONG) AS STRING

Converts a Unicode code point to a Windows-1251 character string. Tab, CR and LF become a space, other control codes and the soft hyphen (173) become empty, Cyrillic and a table of common symbols are mapped; codes not in cp1251 return "?".

HtmDecodeEntities

FUNCTION · rapidqAllProc.inc, line 11393

FUNCTION HtmDecodeEntities(TextRun AS STRING) AS STRING

Replaces HTML entities in a string (named ones like &amp; &nbsp; &mdash;, decimal &#1040; and hex &#x410;) with Windows-1251 characters using HtmCodeToChar. Unknown entities and a lone & are left unchanged; returns the decoded string.

FUNCTION HtmTableValue(TableText AS STRING, KeyText AS STRING) AS LONG

Looks up KeyText in a table string of the form "|name=number|name=number|" and returns the number for that name, or -1 if the name is not found. Helper for the HTML entity decoder.
