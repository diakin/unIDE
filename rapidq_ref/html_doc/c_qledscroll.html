QLEDSCROLL Component

Extends QCANVAS · source: inc/QLedScroll.inc, line 1

A scrolling text banner on a QCanvas, with an optional grid overlay that gives an LED display look.

QLEDSCROLL extends QCanvas. Paint fills the canvas with BgColor and draws Text at position X, Y in TextColor; when Raster is non-zero it then draws vertical and horizontal lines in BgColor every RasterLen pixels, so the text looks made of dots.

The component does not move by itself: call Move from a timer to shift the text left, then Repaint, and call Rewind when the text has left the area. SetString sets new text and rewinds. Default size is 200x32 with RasterLen 2.

QLEDSCROLL inherits the properties, methods and events of QCANVAS; the tables below list only what the component adds or redefines (public members).

QLEDSCROLL Properties

FieldTypeR/WDefaultDescription
TextColorLONGRWColor of the text.
BgColorLONGRWBackground color, also used for the raster lines.
XSINGLERWCurrent horizontal position of the text (SINGLE); Move decreases it and Rewind resets it.
YINTEGERRWVertical position of the text.
TextSTRINGRWText to display.
RasterINTEGERRWWhen non-zero, a grid of lines in BgColor is drawn over the text.
RasterLenINTEGERRW2Spacing of the raster lines in pixels (default 2).
FontQFONTRWA QFONT field; SetColor sets its Color, but the component code does not otherwise use it.

QLEDSCROLL Methods

MethodTypeDescription
RewindSUBSets X to Width + TextWidth(Text) + 1, which places the text to the right of the visible area.
PaintSUBDraws the background, the text at X, Y and, if Raster is set, the grid. Also called from OnPaint.
RepaintSUBCalls Paint.
MoveSUB(p AS SINGLE)Move(p) moves the text p pixels to the left (decreases X); it does not repaint.
SetStringSUB(s$)SetString(s$) sets Text and calls Rewind.
SetColorSUB(c AS LONG)SetColor(c) sets TextColor and Font.Color.

The component handles these events itself (EVENT blocks in the TYPE): OnPaint.

Notes

  • Rewind starts the text TextWidth(Text)+1 pixels beyond the right edge, so there is a delay before it appears.
  • Move does not repaint and nothing rewinds the text automatically when it has scrolled out.
  • The Font field is separate from what TextOut uses; text color comes from TextColor.

QLEDSCROLL Examples

Example written for this page from the members above; not run.

$INCLUDE "QLedScroll.inc"
DECLARE SUB TmrTimer
CREATE Form AS QFORM
  Caption = "LED"
  CREATE Led AS QLEDSCROLL
    Left = 10: Top = 10
    TextColor = &H00FF00
    BgColor = &H000000
    Raster = 1
  END CREATE
  CREATE Tmr AS QTIMER
    Interval = 30
    OnTimer = TmrTimer
  END CREATE
END CREATE
SUB TmrTimer
  Led.Move 2
  IF Led.X < -Led.TextWidth(Led.Text) THEN Led.Rewind
  Led.Repaint
END SUB
Led.SetString "Hello from RapidQ"
Form.ShowModal
