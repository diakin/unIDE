QMAXSPLITTER Component

Extends QPANEL · source: inc/QMaxSplitter.inc, line 75 · author: Psyclops

Splitter control based on QPANEL that emulates the Delphi 6 splitter styles: dragging it resizes the neighboring aligned control.

QMAXSPLITTER is a thin aligned panel (default 5 x 5, Align = 1, cursor -15). Shortly after it becomes visible, an internal timer finds its parent window (Owner) and the control just outside it on its aligned side (Mover) with ChildWindowFromPoint. While the mouse is dragged, an 8 x 8 pattern brush bar is drawn on the screen with PatBlt and PATINVERT; when the button is released, the Mover is resized with MoveWindow and the parent receives WM_SIZE. With Style = 3 the Mover is resized continuously during the drag.

Place it after the control to resize, with the same Align (1 top, 2 bottom, 3 left, 4 right). The author's header notes that it is based on a QPanel rather than a QCanvas to get a window handle and better drawing and aligning. Style constants: rsNone (0), rsSolid (1), rsPattern (2), rsUpdate (3).

QMAXSPLITTER inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

Notes

  • Known issue from the header: if the mouse moves too fast it leaves the splitter behind; SetCapture did not solve it.
  • Known issue from the header: setting MinSize to 0 sometimes causes resizing problems.
  • Known issue from the header: the creation order of aligned controls and the order in which properties are assigned to sibling windows matter; in the author's demo (Rich3 and Split3, not included) the problem goes away when Rich3 is created after Split3.
  • Canvas.OnMouseMove calls GetClientRect(.Owner, R) with an undeclared R, while the limits and MoveChild use the global Rect1, which is never filled.
  • Moving, SplitPos, OldSplitPos, OldWhere, Org and Rect1 are global variables shared by all splitters.
  • The global variables of type POINTAPI are declared before the POINTAPI type, which is defined only inside $IFNDEF __WIN32API.
  • The header apologizes for the lack of comments.

QMAXSPLITTER Examples

Example written for this page from the members above; not run.

$INCLUDE "QMaxSplitter.inc"
CREATE Form AS QFORM
  Width = 500
  Height = 350
  CREATE LeftPanel AS QPANEL
    Align = 3
    Width = 150
  END CREATE
END CREATE
DIM Split AS QMAXSPLITTER
Split.Parent = Form
Split.Align = 3
Split.Style = 1
Split.Beveled = 1
Split.MinSize = 50
Form.ShowModal
