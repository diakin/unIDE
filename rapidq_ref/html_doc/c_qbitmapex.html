QBITMAPEX Component

Extends QBITMAP · source: inc/QBitmapEx.inc, line 88 · version: 1.4

An extended QBITMAP with GDI drawing methods, clipboard support and JPEG/GIF loading and JPEG saving through NViewLib.dll.

QBitmapEx extends QBITMAP with drawing methods that call GDI directly on the bitmap handle: outlined and filled circles, rectangles and rounded rectangles, lines, flood fill, color inversion, horizontal mirror and vertical flip. Outlines use the PenStyle (PS_SOLID_BMP ... PS_INSIDEFRAME_BMP) and PenSize fields.

It can copy the bitmap to the clipboard as CF_BITMAP, paste a clipboard bitmap at a position, and report the clipboard bitmap size. DrawIco draws an icon handle with DrawIconEx.

LoadOtherImage and SaveAsJpg use the external NViewLib.dll to load other image formats and to save the bitmap as a JPEG file.

QBITMAPEX inherits the properties, methods and events of QBITMAP; the tables below list only what the component adds or redefines (public members).

Requires

  • NViewLib.dll (for LoadOtherImage and SaveAsJpg)

Notes

  • SaveAsJpg does nothing unless FileName contains a path to an existing folder; it writes temp.bmp into that folder and deletes it afterwards.
  • CopyToClipboard puts the handle of a local temporary QBitmap on the clipboard.
  • Load_JPGBmp and Load_GIFBmp are declared from NViewLib.dll but never used.

QBitmapEx Examples

Example written for this page from the members above; not run.

$INCLUDE "QBitmapEx.inc"
DIM Bmp AS QBitmapEx
Bmp.Width = 200
Bmp.Height = 100
Bmp.PenSize = 2
Bmp.RectangleFilled(10, 10, 190, 90, &H000000, &HFFFFFF)
Bmp.Circle(50, 20, 110, 80, &HFF0000)
Bmp.Line(10, 50, 190, 50, &H0000FF)
Bmp.CopyToClipboard
Bmp.SaveAsJpg("C:\Temp\picture.jpg", 80)
