QFLASHLABEL Component

Extends QLABEL · source: inc/QFlashLabel.inc, line 17 · version: 1.0

QLabel that can flash its text by switching the font color between a dark and a light color on a timer.

QFlashLabel uses an internal QTimer. While Flash is True, each timer tick toggles State and sets the font color to LightColor or DarkColor. Speed sets the timer interval in milliseconds. The label is transparent and auto-sized by default.

Set LightColor and DarkColor (both default to black, &h0), then set Flash = True.

QFLASHLABEL inherits the properties, methods and events of QLABEL; the tables below list only what the component adds or redefines (public members).

QFlashLabel Properties

FieldTypeR/WDefaultDescription
LightColorLONGRW&h0Font color used in the 'on' state (default &h0).
DarkColorLONGRW&h0Font color used in the 'off' state; assigning it also sets the current font color (default &h0).
FlashBOOLEANRWAssigning True starts flashing; assigning False stops it, sets State to 0 and restores DarkColor.
StateSHORTRW0Current color state; assigning 1 shows LightColor, any other value shows DarkColor.
SpeedLONGRW1000Flash interval in milliseconds; assigning it sets the timer interval (default 1000).

The component handles these events itself (EVENT blocks in the TYPE): Timer.OnTimer.

Notes

  • LightColor and DarkColor both default to black, so flashing is not visible until LightColor is changed.

QFlashLabel Examples

Example written for this page from the members above; not run.

DIM Form AS QFORM
DIM Lbl AS QFlashLabel
Lbl.Parent = Form
Lbl.Caption = "Alarm!"
Lbl.LightColor = &HFF
Lbl.DarkColor = &H0
Lbl.Speed = 500
Lbl.Flash = True
Form.ShowModal
