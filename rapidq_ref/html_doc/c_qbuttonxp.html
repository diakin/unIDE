QBUTTONXP Component

Extends QBUTTON · source: inc/QButtonXP.INC, line 13 · author: Nicolas Tillet, modified by Nastase Eodor · date: 10/2003, modified 6/2005

A QButton that resets its window style so it can be drawn with Windows XP visual styles when used together with QXPTheme.inc.

Assigning Xp calls SetWindowLongA with GWL_STYLE (-16) and the style &H54010010 plus the button's Default value, then hides and shows the button to repaint it. The constructor sets Xp = 3, so the style is applied when the button is created. SetFocus gives the keyboard focus to the button with the SetFocus API.

The header note says to use it together with QXPTheme.inc for the effect.

QBUTTONXP inherits the properties, methods and events of QBUTTON; the tables below list only what the component adds or redefines (public members).

Requires

  • QXPTheme.inc (named in the header note as required for the effect)

QButtonXP Properties

FieldTypeR/WDefaultDescription
XpINTEGERRW3Assigning any value stores it and resets the button window style to &H54010010 + Default, then repaints the button; the stored value is not used otherwise.

QButtonXP Methods

MethodTypeDescription
SetFocusSUBGives the keyboard focus to the button (SetFocus API).

Notes

  • The check that skips the update when the value has not changed is commented out, so every assignment resets the style and repaints.
  • The constructor contains commented-out settings (BevelWidth, BorderColor, CaptionColor, LunaDetect, Canvas) that do nothing.

QButtonXP Examples

Example written for this page from the members above; not run.

$INCLUDE "QXPTheme.inc"
$INCLUDE "QButtonXP.INC"

CREATE Form AS QFORM
  CREATE Btn AS QBUTTONXP
    Left = 10
    Top = 10
    Caption = "OK"
  END CREATE
END CREATE
Btn.SetFocus
Form.ShowModal
