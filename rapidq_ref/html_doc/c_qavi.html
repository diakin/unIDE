QAVI Component

Extends QOBJECT · source: inc/QAVI.inc, line 326 · author: JohnK (John Kelly); code contributions by Ray Mercer · version: 1.0

Non-visual component that reads frames from AVI video files into bitmaps and writes bitmaps as frames into new AVI files, using the Video for Windows AVIFile API.

QAVI wraps functions of avifil32.dll (AVIFileOpen, AVIFileGetStream, AVIStreamGetFrame, AVIFileCreateStream, AVIStreamWrite, AVIMakeCompressedStream, AVISaveOptions and others). GetAVIFileInfo opens a file and fills the frame count, size, frame rate and stream rectangle. AVItoBMP extracts one frame into a QBITMAP: 24 bits per pixel for uncompressed "DIB " streams, otherwise 8 bits, letting the API choose the decompressor. The pixel data is copied straight into the bitmap memory, whose address is found with GetCurrentObject and GetObject.

To write a video, call CreateAVIFile with the file name, size, bit depth (8 or 24) and frame rate, then call BMPtoAVIFile once per frame with a QBITMAP of that size, and finish with CloseAVIFile. Setting UseCompression makes an RLE compressed stream, and ShowDialog shows the Windows compression options dialog.

Errors returned by the AVI functions are turned into text in Error (and shown with ShowMessage when ShowError is set); on error the streams and the library are released. The file defines its own TBITMAP and BITMAPINFOHEADER types and constants unless RapidQ2.inc or Windows.inc have already been loaded.

QAVI inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QAVI Methods

MethodTypeDescription
CloseAVIFileFUNCTION AS LONGReleases the streams and the file, calls AVIFileExit and clears the internal pointers. Returns 1. Call it when you have finished reading or writing.
CreateAVIFileFUNCTION(szFile As STRING, TheWidth AS INTEGER, TheHeight AS INTEGER, Bpp AS INTEGER, fps AS INTEGER) AS LONGCreateAVIFile(FileName, Width, Height, Bpp, Fps): opens the AVIFile library, creates the file for writing and a "DIB " video stream with the given format. Returns 1 on success and 0 on error.
GetAVIFileInfoFUNCTION(szFile As STRING) AS LONGGetAVIFileInfo(FileName): opens the file and its first video stream and fills NumFrames, FirstFrame, Width, Height, FileType, FPS, Quality, the stream rectangle and SampleSize. Returns 1 on success and 0 on error; the file stays open.
AVItoBMPFUNCTION(szFile AS STRING, TheBMP AS QBITMAP, FrameNum AS INTEGER) AS LONGAVItoBMP(FileName, Bitmap, FrameNum): reads frame FrameNum of the file into the QBITMAP, setting its size and PixelFormat (24 or 8 bit). Opens the file first if needed.
BMPtoAVIFileFUNCTION(TheBmp As QBITMAP) AS LONGBMPtoAVIFile(Bitmap): writes the QBITMAP as the next key frame of the stream created by CreateAVIFile. The bitmap should have the Width, Height and Bpp given to CreateAVIFile. Returns 1 on success and 0 on error.
NewSUBResets the internal pointers and the public properties to their defaults (Quality 10000, Bpp 24, everything else 0 or empty). The constructor calls it.

Notes

  • The compression part of CreateAVIFile is marked "this part is tricky, work in progress", and the line after AVIMakeCompressedStream carries the comment "crashes".
  • CreateAVIFile limits the FPS property to 60, but the stream uses the fps parameter, so the limit has no effect.
  • The comments give two ranges for Quality: 0 - 100000 (with 10000 = best) and 0 - 10000.
  • If the user cancels the compression dialog, the error handler releases the file and streams, but CreateAVIFile continues and can still return 1.
  • AVItoBMP opens the file again when a file is already open, without releasing the earlier handles, and it never calls AVIStreamGetFrameClose.
  • AVItoBMP accepts FrameNum from 0 to NumFrames inclusive (one past the last frame) and does not add FirstFrame. It returns 1 even after reporting a bad frame number.
  • AVItoBMP copies Height * Width * Bpp / 8 bytes, without the DWORD row padding it computes for biSizeImage. For 8-bit frames the 1024-byte palette is skipped and not copied to the bitmap.
  • CheckAVIError, CreateAVIFile, GetAVIFileInfo and AVItoBMP start with FUNCTION but end with END SUB.

QAVI Examples

Example written for this page from the members above; not run.

$INCLUDE "QAVI.inc"
DIM Avi AS QAVI
DIM Bmp AS QBITMAP
Avi.ShowError = 1
' read the first frame of a video
IF Avi.GetAVIFileInfo("clip.avi") THEN
  ShowMessage "Frames: " & STR$(Avi.NumFrames) & "  Size: " & STR$(Avi.Width) & " x " & STR$(Avi.Height)
  Avi.AVItoBMP("clip.avi", Bmp, 0)
  Bmp.SaveToFile("frame0.bmp")
  Avi.CloseAVIFile
END IF
' write 30 frames of 320 x 240, 24 bits, 15 frames per second
DIM i AS INTEGER
Bmp.PixelFormat = 6   ' 24 bit
Bmp.Width = 320
Bmp.Height = 240
IF Avi.CreateAVIFile("out.avi", 320, 240, 24, 15) THEN
  FOR i = 1 TO 30
    Bmp.FillRect(0, 0, 320, 240, &HFFFFFF)
    Bmp.Circle(i * 8, 100, i * 8 + 40, 140, &HFF0000, &HFF0000)
    Avi.BMPtoAVIFile(Bmp)
  NEXT
  Avi.CloseAVIFile
END IF
