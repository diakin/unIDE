QPROGRESSBAR Component

Extends QOBJECT · source: inc/QProgressBar.inc, line 95 · author: Johnk (derived from code by Benjamin Maggi and David Burkley)

Progress bar component that creates a real Windows progress bar control (msctls_progress32) with colors, smooth, vertical and marquee styles and a state setting.

QProgressBar creates a msctls_progress32 window with CreateWindowEx as a child of the window whose handle is assigned to Parent. Most property setters store the value and call ReDraw, which creates the window if needed, sets the range (PBM_SETRANGE), step, bar and background colors and position, or starts the marquee animation with the update Interval for the marquee style.

Kind selects the style: PBS_OLD (0), PBS_SMOOTH (1), PBS_VERTICAL (4) or PBS_MARQUEE (8). Changing it destroys the window and creates a new one. Setting Visible to False destroys the window, and setting it to True creates it again. The header says it replaces QProgress.inc and uses the real Windows progress bar from comctl32.dll.

Assign Parent (for example Form.Handle), then set Min, Max and Position.

QPROGRESSBAR inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QProgressBar Methods

MethodTypeDescription
CreateSUBCreates the progress bar window with the current Kind, position and size.
CloseSUBStops the marquee, destroys the control window and sets Visible to False.
SetRangeSUBSends Min and Max to the control (PBM_SETRANGE) if Max is greater than Min.
ReDrawSUBCreates the window if needed and applies the range, step, colors and position (or marquee), then moves the window to Left, Top.
SetParentSUB(TheParent AS INTEGER)Internal: setter for Parent.
SetMaxSUB(TheValue)Internal: setter for Max.
SetMinSUB(TheValue)Internal: setter for Min.
SetPositionSUB(TheValue AS INTEGER)Internal: setter for Position.

Notes

  • Create passes Top and Left to CreateWindowEx in the x, y order swapped (x = Top, y = Left).
  • ReDraw calls SetWindowPos with SWP_NOSIZE, so Width and Height changes are not applied to an existing control.
  • The range is limited to 16 bits (Max is cut to 65535).
  • A source comment says the PBM_* messages are available only with comctl32.dll newer than 4.70 (IE3 and later).

QProgressBar Examples

Example written for this page from the members above; not run.

$INCLUDE "QProgressBar.inc"
DIM Form AS QFORM
DIM PB AS QProgressBar
PB.Left = 10
PB.Top = 10
PB.Width = 200
PB.Kind = PBS_SMOOTH
PB.Parent = Form.Handle
PB.Max = 100
PB.Position = 50
Form.ShowModal
PB.Close
