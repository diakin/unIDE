QREDEX Component

Extends QRICHEDIT · source: inc/QRedEx.Inc, line 57 · author: Jacques (2002-2005), [W]arriant (2006) · version: 1.2.1 · date: July 2006

An extended QRichEdit with a built-in edit popup menu, Search and Replace dialogs, scroll position save/restore, text size limit and font/color dialogs.

QRedEx extends QRichEdit. Its constructor builds a popup menu with Undo, Cut, Copy, Paste, Delete, Select All, Search and Replace; when the control is ReadOnly the editing items are hidden. Undo and the Undo check use EM_UNDO/EM_CANUNDO messages, and Delete sends a WM_KEYDOWN with VK_DELETE.

Search and Replace use two QForm windows created by the component (frmSearch, frmReplace) and the rich edit EM_FINDTEXTEX message (1103) with match-case and whole-word options; Replace All locks window updates with LockWindowUpdate while it works. SavePosition/RestorePosition, TopLineIndex and BottomLineIndex use EM_GETRECT, EM_CHARFROMPOS and EM_LINEFROMCHAR. ChangeFont uses a QFontDialog, and ChangeFontColor/ChangeBgColor call ChooseColorA from comdlg32.dll with 16 preset custom colors.

After the TYPE, the file redefines QRICHEDIT as QREDEX, so code included later that creates a QRICHEDIT gets a QRedEx.

QREDEX inherits the properties, methods and events of QRICHEDIT; the tables below list only what the component adds or redefines (public members).

Requires

  • A SendMessage declaration from elsewhere (SavePosition, TopLineIndex and BottomLineIndex call SendMessage, which this file does not declare)

QRedEx Methods

MethodTypeDescription
ExtendSizeLimitSUBSends message &HC5 (EM_LIMITTEXT) with RichTextSizeLimit to raise the maximum text size.

SavePositionSUBStores the visible character range and the caret position in SavedTopLeft, SavedBottomRight and SavedCaretPosition.

ChangeFontSUBOpens a font dialog preset with the current font and applies the chosen font to the control.
ChangeFontColorSUBOpens the Windows color dialog (ChooseColorA) and sets Font.Color to the chosen color.
ChangeBgColorSUBOpens the Windows color dialog (ChooseColorA) and sets the background Color to the chosen color.

The component handles these events itself (EVENT blocks in the TYPE): QRED_PopUpMenu.OnPopUp.

Notes

  • SavePosition, TopLineIndex and BottomLineIndex call SendMessage, which this file does not declare (it declares QRDX_SendMessage).
  • SavePosition and BottomLineIndex pass the buffer address plus 2 to EM_CHARFROMPOS for the bottom-right point, while in a RECT the right/bottom pair starts at byte offset 8, so the bottom-right value may be wrong.
  • The Search and Replace menu handlers test len(.seltext) <> "", comparing a number with a string.
  • The comment on frmSearch.BorderStyle = 3 says bsNone.
  • The header comment lists BOTTOLINEINDEX; the method is BottomLineIndex.
  • Version 1.2.1 removed all sounds and beeps, cancelling the Windows-version-based sound handling added in 1.2.0.
  • The search/replace window opening subs are private; to open the forms from code use frmSearch.Show or frmReplace.Show.
  • The file redefines QRICHEDIT as QREDEX after the TYPE, which affects every later QRICHEDIT in the program.

QRedEx Examples

Example written for this page from the members above; not run.

$INCLUDE "QRedEx.Inc"
CREATE Form AS QFORM
  Caption = "Editor"
  Width = 500: Height = 400
  CREATE Editor AS QRedEx
    Align = 5
  END CREATE
END CREATE
Editor.ExtendSizeLimit
Editor.UsePopup = 1
Form.ShowModal
