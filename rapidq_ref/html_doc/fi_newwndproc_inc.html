SetNewWndProc

FUNCTION · rapidqAllProc.inc, line 6829

FUNCTION SetNewWndProc (ObjectHandle AS LONG, hFunction AS LONG) AS LONG

Subclasses a window: builds a 14-byte code thunk on the process heap that forwards messages to the RapidQ function hFunction (via lpCallBack_4, four-argument dispatcher) and installs it with SetWindowLong(GWL_WNDPROC). Returns the previous window procedure; the thunk is never freed.
