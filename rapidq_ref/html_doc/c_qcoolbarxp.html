QCOOLBARXP Component

Extends QPANEL · source: inc/QCoolBarXPv1d.inc, line 705 · author: D-evolution · version: QCoolBarXPv1 · date: 2003 - 2005

A toolbar panel that imitates the Windows XP toolbar (rebar) look, with image buttons, separators, a grip, a caption, drop-down menus, embedded edit/combo boxes and an overflow chevron menu.

QCoolBarXP extends QPanel. Buttons are added with AddItems (a "-" string makes a separator) and get their pictures from the imgLA image list. The whole bar is drawn off-screen into bitmaps (BMPCache, BMPCache2) and copied to internal QImage/QCanvas objects with BitBlt and TransparentBlt, which the author says reduces flicker while resizing. On Windows XP (detected with GetVersionEx as version 5.1) buttons, grip and background are drawn with the uxtheme.dll API (OpenThemeData, DrawThemeBackground with the "Toolbar" and "ReBar" classes); otherwise classic edges are drawn with DrawEdge. Disabled button images are faded with AlphaBlend from msimg32.dll.

Hover and pressed states are drawn on a separate image (ImageLH) while the mouse is captured with SetCapture. Clicking an enabled button fires OnChange with the item index. When the bar is narrower than its buttons, a 12-pixel chevron button appears on the right (bottom when vertical) and opens a popup menu listing the hidden items. Dragging the grip sends WM_NCLBUTTONDOWN/HTCAPTION to move the panel, and a timer re-applies Align when the mouse button is released.

Optional global bitmaps custBG and custGrip (declared at file level) can hold a custom background and grip image; DisableBG turns them off. The source refers to a separate documentation file, QCoolBarXP.html.

QCOOLBARXP inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

Requires

  • uxtheme.dll (XP theme API, called only when Windows XP is detected)
  • msimg32.dll (TransparentBlt and AlphaBlend)
  • Optional: BMPMenu and CreateMenuBitmap from another add-on when _AMIB is defined (menu icons in the overflow menu)

QCoolBarXP Methods

MethodTypeDescription
RePaintSUBRedraws the cached image of the grip, caption and all buttons. It does nothing until the bar has been painted once, unless a repaint is forced internally.
AddItemsSUBI(...)AddItems(caption1, caption2, ...) adds buttons; "-" adds a separator. Each item is also added to the overflow popup menu, and all items start enabled, not grouped and not pressed.
AsignPopupToItemSUB(Me As QPopupMenu, iIndex As Integer)AsignPopupToItem(Popup AS QPopupMenu, Index) attaches a popup menu to a button, which then gets a drop-down arrow area on its right side; clicking the arrow shows the menu with TrackPopupMenuEx. Assigning to a separator shows a warning message.
InsertED_CtrlSUB(iAfter As Integer, Me As QEdit)InsertED_Ctrl(iAfter, Edit AS QEdit) places a QEdit on the bar after item iAfter (-1 puts it before the first item) and shifts the following buttons. Not supported when Orientation is True.
InsertCB_CtrlSUB(iAfter As Integer, Me As QComboBox)InsertCB_Ctrl(iAfter, Combo AS QComboBox) places a QComboBox on the bar after item iAfter (-1 puts it before the first item). Not supported when Orientation is True.
ItemsGroupSUBI(...)ItemsGroup(GroupIndex, item1, item2, ...) assigns items to a group; with only the group index all non-separator items are grouped. Grouped items toggle their pressed state on each click.
DefineGroupAllowAllUpSUBI(...)Does nothing except repaint the bar; the group 'allow all up' setting is not implemented.
ItemsDownSUBI(...)ItemsDown(State, item1, item2, ...) sets the pressed state of the listed items, or of all items when only State is given. Only grouped items are changed.
ItemsEnabledSUBI(...)ItemsEnabled(State, item1, item2, ...) enables or disables the listed items, or all items when only State is given. Disabled items are drawn grayed with a faded image and do not react to clicks.
ItemsCaptionVisibleSUBI(...)ItemsCaptionVisible(State, item1, item2, ...) shows or hides the caption text next to the image of the listed items (or all items when only State is given), then recalculates positions and repaints. Captions are shown only on a horizontal bar.

Notes

  • XP theming is used only when GetVersionEx reports exactly version 5.1 (Windows XP); on Windows 2000, Vista, 7 and later the classic drawing is used.
  • The source comments say TransparentBlt (msimg32) needs Windows 98 or later, and that on Win9x the caption text can be invisible.
  • Item() has a fixed size of 30 entries (0..29); a comment says redimensioning it crashed the compiler.
  • AddItems always writes the new captions starting at index 0 and resets the per-item arrays; comments in the code say it should start at the previous ItemCount, so calling it more than once overwrites earlier items.
  • AddItems redimensions ItemLeft to ItemCount-1 but then writes ItemLeft(ItemCount).
  • InsertCB_Ctrl redimensions CB_AfterIndex with ED_Count and positions the combo box with CB_Left(ED_Count-1), copy-paste mistakes from InsertED_Ctrl.
  • ItemsCaptionVisible with a single argument always sets the internal ShowBtnCaptAll flag to True, even when the argument is 0, so captions stay visible.
  • Grouped items only toggle their own pressed state; GroupAllowAllUp is set but never used, so groups do not behave like radio buttons, and DefineGroupAllowAllUp is empty.
  • OnChange is called in OnMouseUp outside the separator check, so clicking a separator can also fire it.
  • Popup menus attached with AsignPopupToItem are shown with TrackPopupMenuEx and the TPM_RETURNCMD flag, and the returned command is discarded.
  • The constructor assigns OnChange to CBarOnChange_EventTemplate, a SUB that is only DECLAREd in the file; the comment calls this a temporary address.
  • Warning and error messages are in French (for example "Orientation = True n'est pas supporte !").
  • The file sets $Option Explicit and declares global objects (custBG, custGrip, BMPCache, mnuItemExceed) shared by all bars.

QCoolBarXP Examples

Example written for this page from the members above; not run.

$INCLUDE "QCoolBarXPv1d.inc"
DECLARE SUB BarChange(ItemIndex AS INTEGER, Me AS QPanel)

CREATE Form AS QFORM
  Caption = "Toolbar demo"
  Width = 400
  CREATE Bar AS QCoolBarXP
    Align = 1
    Height = 42
    Caption = "Tools"
  END CREATE
END CREATE

SUB BarChange(ItemIndex AS INTEGER, Me AS QPanel)
  ShowMessage "Clicked item " + STR$(ItemIndex)
END SUB

Bar.AddItems "New", "Open", "-", "Save"
Bar.ItemsCaptionVisible 1
Bar.ItemsGroup 1, 3
Bar.OnChange = BarChange
Form.ShowModal
