QGROUPBOXUX Component

Extends QGROUPBOX · source: inc/XPThemes.inc, line 391

A QGROUPBOX that repaints its frame and caption with Windows XP visual styles after Subclass is called.

QGroupBoxUx extends QGROUPBOX with a window procedure hook. After Subclass is called, on every WM_PAINT and WM_NCPAINT it lets the original procedure paint, then opens the BUTTON theme of uxtheme.dll, erases the old background with DrawThemeParentBackground, draws the BP_GROUPBOX frame with DrawThemeBackground and redraws the caption with the theme's menu font (normal weight) and group box text color on a COLOR_BTNFACE background.

Call Subclass once after the group box has been created and has a parent. When no theme is active nothing extra is drawn.

QGROUPBOXUX inherits the properties, methods and events of QGROUPBOX; the tables below list only what the component adds or redefines (public members).

Requires

  • uxtheme.dll (Windows XP or later)
  • Callbacks.inc (included unless __RQCALLBACKS is defined) for SetNewCallBack_4
  • Windows API declarations from a Win32 API include when __WIN32API is defined; otherwise XPThemes.inc declares them itself

QGroupBoxUx Methods

MethodTypeDescription
SubclassSUBSubclasses the group box window procedure (through SetNewCallBack_4) so its frame and caption are repainted in XP visual style; does nothing on Windows versions older than XP (5.01), when the control has no handle yet, or when it is already subclassed.

Notes

  • The window DC from GetWindowDC is never released with ReleaseDC, and the created font is deleted while still selected into that DC.
  • The guard IF .Handle AND NOT .Subclassed uses bitwise AND/NOT, so a second call to Subclass may subclass the control again.
  • The caption is always drawn at x = 7 with the COLOR_BTNFACE background, regardless of the group box's own color.
  • The version test (GetVersion AND 255) + (GetVersion AND &HFF00) / 25600 >= 5.01 skips Windows 2000 and earlier.
