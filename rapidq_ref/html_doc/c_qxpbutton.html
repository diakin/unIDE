QXPBUTTON Component

Extends QBUTTON · source: inc/QXPButton.inc, line 181 · author: David Burkley (original Button_BMP_XP_Style code), edited by JohnK · date: July 15th, 2010

A QBUTTON extension that shows a bitmap on a Windows XP visual-style button by giving the button an image list with BCM_SETIMAGELIST.

A normal QBUTTON with a bitmap is owner-drawn and therefore cannot use the XP visual style. XPStyle copies the button's BMP into an internal QBitmap, adds it to the button's own QImageList with ImageList_AddMasked, removes the BS_OWNERDRAW style and sends BCM_SETIMAGELIST with the image list, margins and alignment. Windows then draws the image for the button states.

The best bitmap is one strip of six equal images, in order NORMAL, HOT, PRESSED, DISABLED, DEFAULTED and STYLUSHOT (the comments say all six must be present, but they may be the same picture). A bitmap whose width is more than 3 times its height is treated as such a strip of square images. The transparent colour is taken from pixel (0, 0).

Each button needs its own QImageList, which this component provides. The program needs a manifest for the XP visual styles; the source says to create one after building the executable. The code is derived from Button_BMP_XP_Style by David Burkley (July 15th, 2010) and edited by JohnK.

QXPBUTTON inherits the properties, methods and events of QBUTTON; the tables below list only what the component adds or redefines (public members).

Requires

  • a Windows XP (comctl32 version 6) manifest for the executable
  • a bitmap set with BMP or BMPHandle, typically a $RESOURCE (the examples use btn_states.bmp)
  • SendMessage, which this file does not declare; the examples include Rapidq2.inc or RapidQ.inc

QXPBUTTON Methods

MethodTypeDescription
XPStyleSUBApplies the bitmap in XP style: copies BMP (or creates a 6x1 white bitmap if there is none), sizes the image list, adds the bitmap to it, removes BS_OWNERDRAW and sends BCM_SETIMAGELIST, briefly hiding and showing the button.
UpdateBtnBmpSUBCalls XPStyle; used by the property setters to re-apply margins and alignment.

Notes

  • The header carries David Burkley's licence terms: no redistribution of the source without his permission, free use only in non-profit programs, and credit to the author is requested.
  • XP visual styles work only when the executable has a manifest; the source says to create it after building the executable.
  • Every call to XPStyle (and therefore every margin or alignment assignment) adds the bitmap to ImageList again with ImageList_AddMasked; the list is never cleared.
  • The comment says the background colour is the bottom-left pixel, but the code reads Pixel(0, 0).
  • The alignment adjustments in Set_AlignImage are marked in comments as needing refinement, because under some conditions the bitmap is not displayed where expected; an operating-system version check there is commented out.
  • A multi-image strip is detected only when width / height > 3, and each image is then assumed to be square.
  • Example code #3 in the file uses the type name QBtnBmpXP instead of QXPButton.

QXPBUTTON Examples

Example from the comments in the source file.

$INCLUDE <Rapidq2.inc>
$INCLUDE <QXPButton.inc>
$Resource btn_states As "btn_states.bmp"

CREATE MainForm AS QFORM
    Center
    CREATE Button AS QXPButton
        Width = 90
        Height = 30
        Left = (MainForm.ClientWidth \ 2) - (Button.Width \ 2)
        Top  = (MainForm.ClientHeight \ 2) - (Button.Height \ 2)
        BMPHandle = btn_states
        XPStyle
        Caption = "Click Me"
    END CREATE
END CREATE

MainForm.ShowModal
