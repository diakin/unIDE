QPROCESS Component

Extends QOBJECT · source: inc/QProcess.inc, line 48 · author: D. Glodt (original code), modified by JohnK · version: 1.1 · date: 12/06

A non-visual component that runs its OnProcess event handler in a separate Windows thread, with priority, suspend, resume and terminate.

Despite its name, QProcess works with threads: Open calls CreateThread (kernel32) with the address of an internal SUB that calls the OnProcess handler, then sets the thread priority. Close ends the thread with TerminateThread, and Suspend/Resume call SuspendThread and ResumeThread.

Priority uses SetThreadPriority values; the file defines ProcessIdle (-15), ProcessLow (-2), ProcessBelowNormal (-1), ProcessNormal (0), ProcessAboveNormal (1), ProcessHight (2) and ProcessTimeCritical (15). The file is protected against being included twice (__QPROCESS_INC). Original code by D. Glodt, modified by JohnK; the source comments are in French.

QPROCESS inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QProcess Properties

FieldTypeR/WDefaultDescription
PriorityLONGRW0Thread priority (default 0, ProcessNormal). Assigning it stores the value and, if a thread exists, applies it with SetThreadPriority.

QProcess Methods

MethodTypeDescription
SuspendSUBSuspends the thread with SuspendThread.
ResumeSUBResumes a suspended thread with ResumeThread.
OpenSUBTerminates any previous thread, starts a new thread that calls the OnProcess handler, and applies Priority.
CloseSUBTerminates the thread with TerminateThread if one was started.

QProcess Events

EventTypeOccurs when...
OnProcessSUBEvent OnProcess (no parameters); its handler runs in the new thread started by Open.

Notes

  • Close and Open end threads with TerminateThread, which stops the thread immediately without cleanup.
  • The thread handle is never closed (CloseHandle is declared but not used) and is not reset to 0 after Close.
  • Suspend and Resume do not check that a thread exists.
  • The constant for high priority is spelled ProcessHight.
  • CREATE_SUSPENDED is defined but not used.

Other versions

  NEXT i
