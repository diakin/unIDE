QANIM Component

Extends QIMAGE · source: inc/QAnim.inc, line 17 · version: 1.0

Animated image: a QImage that shows the frames of its QImageList one after another on a timer.

QAnim extends QImage and has an internal QTimer (default 200 ms). On each timer tick it puts the bitmap of ImageList frame Index into its BMP, shows itself, repaints and moves Index to the next frame, starting again at 0 after the last frame. The control is hidden until a frame has been shown.

Set Width and Height (they also set the image list size), add the frames to ImageList, set Speed and assign Move = True to start. The comments in the file are in French.

QANIM inherits the properties, methods and events of QIMAGE; the tables below list only what the component adds or redefines (public members).

QAnim Properties

FieldTypeR/WDefaultDescription
SpeedLONGRWAssigning sets the timer interval in milliseconds between frames (default 200). The value itself is not stored in the field.
ImageListQIMAGELISTRWQImageList that holds the animation frames.
IndexSHORTRW0Current frame. Assigning it while ImageList has images stores it, shows that frame and makes the control visible; with an empty list, assigning does nothing. The timer increases it.
WidthSHORTRWAssigning sets the control width and ImageList.Width.
HeightSHORTRWAssigning sets the control height and ImageList.Height.
BackColorLONGRWAssigning sets ImageList.BkColor and redraws the current frame when the list has images and the control is visible.
MaskedBOOLEANRWAssigning sets ImageList.Masked and redraws the current frame when the list has images and the control is visible.
MoveBOOLEANRWfalseAssigning True starts the animation timer, but only if ImageList has images. Assigning False stops the timer and decreases Index by one.

The component handles these events itself (EVENT blocks in the TYPE): Timer.OnTimer.

Notes

  • The Speed setter only changes the timer interval and does not store the value, so reading Speed does not return what was assigned.
  • Every assignment of Move = False decreases Index by one, even if the animation was already stopped.
  • In the BackColor and Masked setters, the line that makes the control visible is inside a block that runs only when it is already visible, so it never has an effect.

QAnim Examples

Example written for this page from the members above; not run.

$INCLUDE "QAnim.inc"
CREATE Form AS QFORM
  Width = 200
  Height = 150
END CREATE
DIM Anim AS QAnim
Anim.Parent = Form
Anim.Left = 20
Anim.Top = 20
Anim.Width = 32
Anim.Height = 32
Anim.ImageList.AddBMPFile("frame1.bmp", 0)
Anim.ImageList.AddBMPFile("frame2.bmp", 0)
Anim.ImageList.AddBMPFile("frame3.bmp", 0)
Anim.Speed = 100
Anim.Move = True
Form.ShowModal
