QDOWNLOAD Component

Extends QOBJECT · source: inc/qdownload.inc, line 4 · version: v2

A non-visual object that downloads a file from an HTTP server with a QSocket and returns it in a string or saves it to a file, with progress and speed reporting.

Qdownload extends QObject. Set Server, Port (default 80) and File, choose the output with OutDevice (1 = OutVar string, 2 = OutFile on disk) and call LeechFile. It connects with QSocket, sends "GET /" + File + " HTTP/1.0" and an empty line, reads the header lines until an empty one, takes the size from Content-Length, then reads the body in 32000-byte blocks until nothing more is transferred.

Progress is written to State (percent) or, when StateDevice is 2, to the StateGauge QGauge and the SpeedLbl QLabel (bytes per second); you must set the Parent and other properties of these controls yourself. On failure LeechFile returns False and sets LastError and LastStringError: 1 no server, 2 no port, 3 no file, 4 no output file, 5 cannot connect to host, 6 not connected to the internet, 7 connection closed by peer, 8 unknown error, 9 size unknown or 0 bytes, 10 transmission error (received size differs), 11 file not found (404).

QDOWNLOAD inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Qdownload Methods

MethodTypeDescription
checkFUNCTION AS LONGReturns True if the registry value "Remote Connection" under HKEY_LOCAL_MACHINE\System\CurrentControlSet\Services\RemoteAccess is 1, otherwise False. LeechFile uses it to choose the error message.
percentFUNCTION(now as long, complete as long) AS INTEGERPercent(now, complete) returns now*100/complete rounded.
speedFUNCTION(now$ as string, before$ as string, complete as long) AS INTEGERSpeed(now$, before$, complete) returns complete divided by the seconds between two TIME$ strings (hh:mm:ss), rounded.
leechfileFUNCTION AS LONGDownloads the file and returns True on success or False with LastError set; the call blocks until the download ends.

Notes

  • The request is HTTP/1.0 without a Host header, and only 404 status lines are recognized; redirects and other errors are not handled.
  • The comment shows File as "/Path/File.ext", but the code adds its own leading slash.
  • The download needs a Content-Length header (matched case-sensitively); without it Size stays 0, Percent divides by zero and the size check fails.
  • Speed divides by the elapsed seconds, which can be 0, and does not handle midnight.
  • Check only reads a Remote Access (dial-up) registry value; it does not test the network.
  • LeechFile runs in a loop with no DoEvents, so the program does not respond during the download; LastError is not cleared on success.
  • The OutDevice comment mentions qdownload.filestream, but the code saves to OutFile through a local QFileStream.

Qdownload Examples

Example written for this page from the members above; not run.

$INCLUDE "qdownload.inc"
DIM Dl AS Qdownload
Dl.Server = "www.example.com"
Dl.File = "index.html"
Dl.OutDevice = 2
Dl.OutFile = "C:\index.html"
IF Dl.LeechFile THEN
  ShowMessage "Downloaded " + STR$(Dl.Size) + " bytes"
ELSE
  ShowMessage Dl.LastStringError
END IF
