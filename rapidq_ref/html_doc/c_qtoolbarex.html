QTOOLBAREX Component

Extends QPANEL · source: inc/QToolBarEX.inc, line 36 · author: d_homans@yahoo.com.au · version: 1.1 · date: 1 Mar 2011

A toolbar built from a QPanel and an array of flat QCOOLBTN buttons whose images are cut from one horizontal bitmap strip.

QToolBarEX is a QPanel aligned to an edge of its parent (alTop by default). It owns an array tbButtons(0 to MAXTOOLBTNS) of QCOOLBTN (MAXTOOLBTNS is 64 unless you $DEFINE it before the $INCLUDE). The buttons are public so that other code, such as the RapidFRM application mentioned in the header, can copy their bitmaps.

Set BtnCount (and optionally NumBMPs, Align, Width or Height, Cursor, GroupIndex, BtnSpacer, BtnMask) first, then assign BMP (a bitmap file) or BMPHandle (a resource). The bitmap strip is split into BtnCount images by the global QImageListEX ButtonImages; the toolbar then sizes, places and shows BtnCount buttons and hides the rest.

A click on a button fires OnSelect with the button index (from 0). Hint takes a comma-separated list with one hint per button.

QTOOLBAREX inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

Requires

  • QImageListEX.inc ($INCLUDE) for the QImageListEX component
  • the global QImageListEX variable ButtonImages declared by this file (comment: MUST be global)
  • a $RESOURCE bitmap when BMPHandle is used

QToolBarEX Properties

FieldTypeR/WDefaultDescription
BMPSTRINGRWAssigning a bitmap file name loads the button strip and creates the buttons. Shows a message and does nothing if the file does not exist or BtnCount is 0; Align alClient or alNone is changed to alTop.
BMPHandleINTEGERRWAssigning a resource index loads the button strip from that resource (through ButtonImages.ExtractRes) and creates the buttons. Shows a message if BtnCount is 0.
BtnCountINTEGERRW0Number of button images in the bitmap strip. Assigning a value from 1 to MAXTOOLBTNS stores it; other values are ignored. Must be set before BMP or BMPHandle.
BtnSpacerINTEGERRW1Gap in pixels between buttons (default 1). Assigning a negative value is ignored. Used when the buttons are created.
BtnMaskINTEGERRW&hffffffTransparent colour passed to the image list when the strip is loaded (default &hFFFFFF). Assigning it only stores the value.
CursorINTEGERRW0Cursor for all buttons. Assigning a value from -21 to 0 stores it; others are ignored. Applied when the buttons are created.
EnabledINTEGERRWTrueAssigning it enables or disables all buttons and turns their hints on or off accordingly.
GroupIndexINTEGERRW0Assigning a value stores it and sets it on all buttons when it is 0 or when NumBMPs is 4, so a button in the group can stay down.
HeightINTEGERRW0Toolbar height; assigning a positive value sets the panel height and the button height (value - 2), but only when Align is alTop or alBottom.
HintSTRINGRW""Comma-separated hints, one per button. Assigning it sets each button's Hint and turns ShowHint on for buttons that get a hint; an empty string clears all hints.
NumBMPsINTEGERRW1Number of images per button in the strip (1 to 4, as for a QCOOLBTN). Assigning other values is ignored. Set it before BMP or BMPHandle.
WidthINTEGERRW0Toolbar width; assigning a positive value sets the panel width and the button width (value - 2), but only when Align is alLeft or alRight.
tbButtonsARRAY(MAXTOOLBTNS) OF QCOOLBTNRWArray tbButtons(0 to MAXTOOLBTNS) of QCOOLBTN holding the toolbar buttons; it cannot be resized at run time.

QToolBarEX Events

EventTypeOccurs when...
OnSelectSUB(Index AS integer)Event OnSelect(Index AS INTEGER) fired when a button is clicked, with the button's index (its Tag, from 0).

The component handles these events itself (EVENT blocks in the TYPE): OnClick.

Notes

  • The button images are held in the single global ButtonImages, so several QToolBarEX instances share and overwrite the same image list.
  • The BtnMask comment says it defaults to the bottom-left pixel of each image, but the constructor sets &hFFFFFF and the setter has a 'FIXME: Override default?' comment.
  • The button array has a fixed size (MAXTOOLBTNS, default 64); the comment notes it cannot be changed with REDIM at run time.
  • Width is only applied for alLeft/alRight and Height only for alTop/alBottom; otherwise assignments are ignored.
  • Loading from a resource goes through a temporary file __tmp.bmp in the current directory (see QImageListEX).
  • Errors are reported with ShowMessage ("File error! Cannot load bitmap", "Button count not set! Cannot load bitmap", "Unknown error! Failed to load bitmap").

QToolBarEX Examples

Example written for this page from the members above; not run.

$INCLUDE "QToolBarEX.inc"

SUB ToolClick(Index AS INTEGER)
  ShowMessage "Button " + STR$(Index)
END SUB

CREATE Form AS QFORM
  Caption = "QToolBarEX demo"
  Width = 400
END CREATE

DIM Tool AS QToolBarEX
Tool.Parent = Form
Tool.BtnCount = 4
Tool.Hint = "New,Open,Save,Print"
Tool.OnSelect = ToolClick
Tool.BMP = "toolbar.bmp"
Form.ShowModal
