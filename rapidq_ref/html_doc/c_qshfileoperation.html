QSHFILEOPERATION Component

Extends QOBJECT · source: inc/QSHFileOperation.inc, line 104 · author: Marcin Szafran · version: 1 · date: January 2002

A wrapper for the SHFileOperation API to copy, move, rename and delete files and folders.

QSHFileOperation extends QObject and calls SHFileOperationA from shell32.dll. It works with wildcards and recursively and, unlike the RapidQ keywords RENAME and KILL, also works with folders; Delete can send files to the Recycle Bin.

Each operation has a simple form (Copy, Move, Rename, Delete) that uses DefaultFlags and an extended form (CopyEx, MoveEx, RenameEx, DeleteEx) that combines DefaultFlagsEx with flags you pass and takes a window handle for the progress and confirmation dialogs. The fof* flag constants are defined in the file. The methods return the SHFileOperation result.

QSHFILEOPERATION inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

DeleteFUNCTION(dSHfoFrom As String, SHfoToBin As Integer, SHConfirm As Integer) AS LONGDelete(Files, ToBin, Confirm) deletes files or folders with DefaultFlags; ToBin = 1 sends them to the Recycle Bin and Confirm = 0 suppresses confirmation.

Notes

  • The header warns: be careful with delete and recurse.
  • The SHFILEOPSTRUCT variable and the string buffers are global, so all instances share them.
  • The comment on lpszProgressTitle says the progress title does not work; it is never set.
  • The comments say some flags need shell32.dll newer than version 4.0, and that deleting to the Recycle Bin needs a full path name (a bare file name is deleted permanently even with fofAllowUndo).
  • The ToBin and Confirm parameters are used in arithmetic, so only the values 0 and 1 give the documented result.
  • The file turns $TYPECHECK ON at the start and OFF at the end, which affects the code that includes it.

QSHFileOperation Examples

Example written for this page from the members above; not run.

$INCLUDE "QSHFileOperation.inc"
DIM FileOp AS QSHFileOperation
FileOp.Copy("C:\Temp\*.txt", "C:\Backup")
FileOp.MoveEx("C:\Temp\Old", "C:\Archive", fofNoConfirmation OR fofSilent, 0)
FileOp.Delete("C:\Temp\test.txt", 1, 1)
