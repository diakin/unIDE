FormLocale

FUNCTION · rapidqAllProc.inc, line 17555

Function FormLocale (AppForm As QForm, AppWidth As Integer, AppHeight As Integer) As Long

Positions and sizes AppForm so it does not cover the taskbar, using SHAppBarMessage(ABM_GETTASKBARPOS) and the screen size; AppWidth/AppHeight of 0 mean full screen. Returns the SHAppBarMessage result (0 means it failed and the form was not changed, e.g. with an auto-hide taskbar).
