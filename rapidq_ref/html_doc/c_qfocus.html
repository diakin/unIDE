QFOCUS Component

Extends QCANVAS · source: inc/qfocus.inc, line 63 · author: John Graves aka laddie@bellsouth.net

A canvas that can be moved and resized with the mouse and can draw a blinking dotted focus frame around itself.

QFocus extends QCanvas. An internal QTimer with a 1 ms interval drives it: when Show is 1 it draws a dotted rectangle around the canvas, alternating between color &H0000F and white, and while the mouse is held down inside it the canvas follows the cursor, positioned relative to the client area of the active window.

Pressing the mouse near the right or bottom edge (within 7 pixels) changes the cursor and lets the user resize the canvas; OnSize is called with the new width and height. CopyToClipboard copies the canvas pixels to the clipboard as a bitmap. The component uses global variables and GDI calls declared in the file and includes rapidq2.inc.

QFOCUS inherits the properties, methods and events of QCANVAS; the tables below list only what the component adds or redefines (public members).

Requires

  • rapidq2.inc

QFocus Properties

objectfocustimerQTIMERRWInternal: QTimer (interval 1 ms, always enabled) that draws the blinking frame and moves the canvas while it is dragged.
showLONGRWWhen 1, the timer draws the blinking dotted frame around the canvas. CopyToClipboard sets it to 1.

QFocus Methods

MethodTypeDescription
CopyToClipboardSUBRepaints the canvas, copies its pixels to the clipboard as a bitmap (format 2) and sets Show to 1.
PasteFromClipboardSUBIf the clipboard has a bitmap, loads it into the global focusimage and focusbitmap; it does not draw it on the canvas.
dragmeSUBMoves the canvas so that its center is at the mouse cursor, relative to the client area of the active window.

QFocus Events

EventTypeOccurs when...
OnSizeSUB(width,height)Raised while the canvas is resized with the mouse, with the new width and height.

The component handles these events itself (EVENT blocks in the TYPE): objectfocustimer.ontimer, OnMouseDown, OnMouseMove, onmouseup.

Notes

  • OnMouseMove contains two debug ShowMessage calls (the active window handle and "2"), so a message box appears on every mouse move over the canvas.
  • The timer handler has mismatched blocks ('with qfocus' closed by 'end if'), and the test 'x>6 or x<.width-6' is always true.
  • State is kept in global variables (dragenable, rectangledrag?, focusbitmap, focusimage, wrct, crct), so several QFocus objects share it; an unused global 'drag as qbutton' is also declared.
  • OnSize is called with CALLFUNC without checking that a handler is assigned.
  • CopyToClipboard deletes the bitmap handle right after passing it to the clipboard.
  • The timer runs every 1 ms for as long as the object exists.

QFocus Examples

Example written for this page from the members above; not run.

$INCLUDE "qfocus.inc"
CREATE Form AS QFORM
  Width = 400
  Height = 300
  CREATE Focus AS QFocus
    Left = 20
    Top = 20
    Width = 100
    Height = 60
  END CREATE
END CREATE
Focus.Show = 1
Form.ShowModal
