MasterCallBack_0

FUNCTION · rapidqAllProc.inc, line 6441

Function MasterCallBack_0 (hFunction As Long) As Long

Internal callback dispatcher for callbacks with no arguments: calls the RapidQ function whose address is hFunction via BIND/CALLFUNC and returns its result. Its address (lpCallBack_0) is used by SetNewCallBack_0; not normally called directly.

SetNewCallBack_0

FUNCTION · rapidqAllProc.inc, line 6447

Function SetNewCallBack_0 (hFunction As Long) As Long

Creates a callback pointer for a RapidQ function without arguments: pass CODEPTR of your function in hFunction and get back an address to give to a Windows API. Uses SetNewFwToCallBack, which allocates a small code thunk on the process heap (not freed).
