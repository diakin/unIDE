QSPINBUTTON Component

Extends QPANEL · source: inc/QSpinEdit.inc, line 22 · author: Nastase Eodor <eodor@idilis.ro> · version: 1.0.0 · date: 2004

A spin control built from a QPanel with two QCOOLBTN buttons (+ and -) and an optional QEDIT showing the value.

QSpinButton places a "+" and a "-" QCOOLBTN on the left of the panel and, when ShowEdit is True, a QEDIT aligned to the right that shows the value. Clicking + or - changes Value by IncrementBy within MinValue..MaxValue and updates the text; typing in the edit box sets Value to VAL of the text.

The layout is built by Draw, which the constructor calls and which runs again after each click or edit. After changing Width, Height, Style, ShowEdit, Font or Text yourself, call Draw. Style can be st3d (0) or stFlat (1), which are global variables defined in the file.

QSPINBUTTON inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

QSpinButton Properties

FieldTypeR/WDefaultDescription
FontQFONTRWQFont applied to the + and - buttons by Draw.
ValueVARIANTRW0Current value (VARIANT, default 0). Changed by the buttons and by typing in the edit box.
IncrementByVARIANTRW0.1Step added or subtracted by the buttons (VARIANT, default 0.1).
MaxValueDOUBLERW10Upper limit (default 10). If MaxValue and MinValue are both 0, the buttons do nothing.
MinValueDOUBLERW-10Lower limit (default -10).
ShowEditBOOLEANRWTrueTrue (default) shows the edit box and makes each button a quarter of the width; False hides it and the buttons take the full width. Applied by Draw.
StyleINTEGERRWst3dst3d (0, default) for raised buttons and a bordered edit box, or stFlat (1) for flat buttons and no border. Applied by Draw.
TextSTRINGRW"0"Text shown in the edit box; updated after each click or edit, and copied into the edit box by Draw.

QSpinButton Methods

MethodTypeDescription
DrawSUBLays out and configures the buttons and the edit box from the current size, Font, ShowEdit, Style, Text and ShowHint.
ClickSUB(Sender as QCoolBtn)Internal: OnClick handler of the + and - buttons; clamps Value to the limits, adds or subtracts IncrementBy, formats the text and calls Draw.
ChangeSUB(Sender as QEdit)Internal: OnChange handler of the edit box; sets Value to VAL of the text, copies the text and calls Draw.

Notes

  • There is no event to tell the program that Value changed.
  • Click clamps Value to MinValue..MaxValue before adding or subtracting IncrementBy, so Value can go one step past a limit; the next click brings it back.
  • For negative values the text is built as "-" + STR$(Value) (or STRF$), although the number string already contains a minus sign.
  • Values typed into the edit box are not checked against MinValue and MaxValue.
  • st3d and stFlat are global DEFINT variables, not constants.
  • Properties have no setters; Draw must be called to apply changes.

QSpinButton Examples

Example written for this page from the members above; not run.

$INCLUDE "QSpinEdit.inc"
CREATE Form AS QFORM
  Caption = "Spin demo"
END CREATE
DIM Spin AS QSpinButton
Spin.Parent = Form
Spin.Left = 10
Spin.Top = 10
Spin.Width = 80
Spin.MinValue = 0
Spin.MaxValue = 100
Spin.IncrementBy = 5
Spin.Draw
Form.ShowModal
PRINT Spin.Value
