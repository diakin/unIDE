QWEBCAM Component

Extends QOBJECT · source: inc/WebCam.inc, line 78 · author: John White (webcam.dll); wrapped as a component by JohnK

A non-visual wrapper around webcam.dll for showing a webcam preview in a form, capturing video, opening driver dialogs and grabbing frames.

QWebCam extends QObject and calls functions of webcam.dll, a DLL written by John White. When the include file is loaded it calls WEBCAM_AbortCapturing to load the library and checks it with LIBRARYINST; if the DLL is missing it shows "webCam.DLL not found, video capture disabled" and sets WebCamDLLPresent to 0.

CamInit opens a capture child window on a form, connects the driver and turns on hardware overlay if the camera supports it, or software preview otherwise. Other methods start and stop capturing, switch preview, open the driver dialogs, copy a frame to the clipboard or save it as a DIB file, and CleanUp closes everything in the reverse order.

QWEBCAM inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • webcam.dll (by John White)
  • Declarations from elsewhere for GetObject, TBITMAP and CF_BITMAP (used in GrabFrameToClipBoard)

QWebCam Methods

MethodTypeDescription
CamInitFUNCTION(Form AS QFORM) AS LONGCamInit(Form AS QFORM) opens the capture window on Form, connects the camera and starts overlay or preview; returns 1 on success. It runs only once (exits if Sts is set) and shows "Could not connect to Camera" on failure.
ShowDialogBoxSUB(TheBoxNum)ShowDialogBox(n) stops capturing and opens a driver dialog: 1 = video compression, 2 = video display, 3 = video format, 4 = video source.
StartCaptureSUBStarts capturing if not already capturing, and turns overlay on if the camera supports it.
PreviewOffSUBTurns preview scaling and preview off.
PreviewOnSUBTurns preview on.
StopCaptureSUBIf capturing, turns preview off and stops capturing.
CleanUpSUBTurns off overlay or preview, disconnects the driver and closes the capture window, depending on Sts. Call it before the program ends.
SelectSourceSUBOpens the video source dialog.
GrabFrameToClipBoardFUNCTION AS LONGTurns preview off, grabs a frame, copies it to the clipboard, reads the bitmap handle back and calls GetObject on it, then turns preview on again. Returns the GetObject result, not the image.
CopyFrameToFileFUNCTION(TheFileName AS STRING) AS LONGCopyFrameToFile(FileName) turns preview off, grabs a frame and saves it with FRAME_CopyToDIB; returns the DLL result.

Notes

  • In CamInit the IF WebCamDLLPresent THEN block has no matching END IF in the source.
  • ImageHeight, ImageWidth, FramesDropped, Preview, Tag and OnFrame are never updated or used; the OnFrame comment says the event does not work.
  • GrabFrameToClipBoard calls GetObject first on an empty local QBITMAP and then on the clipboard bitmap into a local TBITMAP that is discarded; GetObject, TBITMAP and CF_BITMAP are not declared in this file.
  • CopyFrameToFile turns preview off and does not turn it back on.
  • CleanUp does not reset Sts, so CamInit cannot be called again afterwards.
  • The component never sets a capture file name (WEBCAM_SetCaptureFilename is declared but not used).
  • Including the file shows a message box at startup when webcam.dll is missing.

QWebCam Examples

Example written for this page from the members above; not run.

$INCLUDE "WebCam.inc"
DIM Cam AS QWebCam
DECLARE SUB FormClose
CREATE Form AS QFORM
  Caption = "Webcam"
  Width = 360: Height = 300
  OnClose = FormClose
END CREATE
SUB FormClose
  Cam.CleanUp
END SUB
Form.Show
IF Cam.CamInit(Form) = 1 THEN Cam.CopyFrameToFile("C:\frame.bmp")
DO
  DoEvents
LOOP UNTIL Form.Visible = 0
