QODBC Component

Extends QOBJECT · source: inc/odbc.inc, line 46

Simple ODBC client object that lists drivers, connects with a connection string, lists tables, runs SQL queries and fetches rows as text.

qODBC calls the ODBC API in odbc32.dll directly. ODBCInit allocates the environment and connection handles and fills Driver with the installed driver names. Connect(sConn) connects with SQLDriverConnect, allocates a statement handle and fills Table with the table names.

Query runs an SQL statement with SQLExecDirect and fills Field.Name, Field.TypeNum, Field.TypeStr, Field.Size, Field.DecDigits and Field.Nullav for each result column. GetRecord fetches the next row into Field.Data (as text) and returns 1, or 0 when there are no more rows. Errors are shown with MESSAGEBOX. The file comments follow the numbered steps of an ODBC session (allocate, connect, execute, fetch, free, disconnect).

Including the file also creates a global object myDB AS qODBC and calls myDB.ODBCInit.

QODBC inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • ODBC driver for the target database

Notes

  • The include creates the global variables myDB and sSQL and calls myDB.ODBCInit, so the file cannot be included without that side effect.
  • DriverCount is incremented before each SQLDrivers call, including the last one that fails, so it counts one more than the number of drivers and the last entry holds stale text.
  • Query's error message shows the ODBC state and error text, but SQLError is never called, so those parts are empty.
  • Arrays are fixed at 100 drivers, tables and fields, and values are read into a 255-byte buffer.

qODBC Examples

Example written for this page from the members above; not run.

$INCLUDE "odbc.inc"
' myDB is created and initialized by the include
myDB.Connect("DRIVER={Microsoft Access Driver (*.mdb)};DBQ=C:\data\test.mdb;")
myDB.Query("SELECT * FROM Customers")
WHILE myDB.GetRecord
  PRINT myDB.Field.Data(1)
WEND
myDB.CloseQuery
myDB.CloseDB
myDB.CloseODBC
