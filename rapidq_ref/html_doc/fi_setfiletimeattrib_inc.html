ChangeFileDateAndTime

FUNCTIONI · rapidqAllProc.inc, line 19575

Functioni ChangeFileDateAndTime ( ... ) As Long

Sets file times: ChangeFileDateAndTime(path$, [which$], year, month, day, hour, min, sec). which$ may contain "CRE", "ACC" and/or "WRI"; empty means last-write time. Uses CreateFile, SystemTimeToFileTime and SetFileTime; reports errors in a local message (body longer than shown).
