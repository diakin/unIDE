QVIDEO Component

Extends QOBJECT · source: inc/QVideo.inc, line 44 · version: 1.3

A video player object that plays media files through MCI string commands.

QVideo extends QObject and controls a media file with mciSendString from winmm.dll. The file is opened under the fixed MCI alias MEDIA, either as a child window of a given window handle (Parent) or as its own popup or overlapped window. After opening, the length is read in milliseconds and in frames, the source size is read, and the MCI window handle is stored in Handle.

Use Open to load a file, then Play, Pause, Stop and Close. An internal QTimer with a 1000 ms interval polls the position while playing and raises OnChange with the current frame and time in seconds. Volume sets the wave output volume with waveOutSetVolume.

QVIDEO inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QVideo Methods

MethodTypeDescription
CloseSUBStops and closes the media and resets the length, size, position and state fields to 0 / VD_CLOSE.
OpenFUNCTION(FileName as string) AS BOOLEANOpen(FileName) opens the file under the alias MEDIA and fills the length, size and Handle fields. Returns true on success; on failure it sets Error (when MCI cannot open the file) and calls Close.
ShowSUBShows the video window (MCI window state show).
PlaySUBPlays from CurrentFrame and starts the position timer.
StopSUBStops playback, stops the timer, sets CurrentFrame to 0 and seeks to the start.
PauseSUBPauses playback when playing and stores the current position in CurrentFrame.

QVideo Events

EventTypeOccurs when...
OnChangeSUB(position as long,timePos as long)Raised every timer tick while playing, with the current frame (position) and the current time in seconds (timePos).

The component handles these events itself (EVENT blocks in the TYPE): Timer.OnTimer.

Notes

  • All instances use the same fixed MCI alias MEDIA, so only one file can be open at a time.
  • The file name is inserted into the MCI open command without quotes, so names containing spaces are not handled.
  • The AudioOff setter does not store the assigned value, so reading AudioOff does not reflect the sound state.
  • Volume sets wave output device 0, not only this media; negative values are not rejected.
  • Left, Top, Width and Height assignments are ignored (not stored) while no file is open.
  • Lenght and LenghtTime are misspelled in the source and must be used with that spelling.

QVideo Examples

Example written for this page from the members above; not run.

$INCLUDE "QVideo.inc"
DIM Video AS QVideo

CREATE Form AS QFORM
  Width = 400
  Height = 340
  CREATE Panel AS QPANEL
    Align = alClient
  END CREATE
END CREATE

Video.Parent = Panel.Handle
IF Video.Open("clip.avi") THEN
  Video.Play
ELSE
  ShowMessage Video.Error
END IF
Form.ShowModal
Video.Close
