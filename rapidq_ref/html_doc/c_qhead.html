QHEAD Component

Extends QCANVAS · source: inc/QHead.inc, line 1

Header bar drawn on a QCanvas, aligned to the top of its parent, with left and right caption texts, an optional icon and a color gradient line.

QHead paints itself in OnPaint with DrawComponent. It fills the background with Color, draws a 2-pixel line under the caption whose color changes by Increment from StartColor toward EndColor every 3 pixels, and draws LeftText and RightText with a grey shadow and white text. If ShowIcon is set, the Icon bitmap is drawn (transparent) at IconX, IconY, or under the caption line when AutoCenter is set.

DrawComponent always sets Align to 1 (top) and gives CaptionSize, CaptionX and CaptionY default values when they are 0. Most property setters store the value and redraw.

QHEAD inherits the properties, methods and events of QCANVAS; the tables below list only what the component adds or redefines (public members).

MethodTypeDescription

The component handles these events itself (EVENT blocks in the TYPE): OnPaint.

Notes

  • The setter names are swapped: ShowLeftText uses SetShowRightText and ShowRightText uses SetShowLeftText, but each setter writes the matching field, so the result is correct.
  • With ShowIcon on, the white LeftText is offset by IconY instead of IconX, so the text and its shadow can be misaligned.
  • Align is forced to 1 (top) on every redraw.
  • Once the gradient color reaches EndColor it moves back and forth around it by Increment.
