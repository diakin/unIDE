QRICHEDIT_API Component

Extends QOBJECT · source: inc/apiRe.inc, line 86

Minimal wrapper that creates a Windows RichEdit control (RICHED32.DLL) with CreateWindowEx and lets you move, size, show and hide it.

QRichEdit_api extends QObject, so it is not a RapidQ visual control. Assigning Parent (a window handle such as Form.Handle) loads RICHED32.DLL with LoadLibrary and creates a child window of class "RichEdit" at Left, Top, Width, Height; its handle is stored in Handle. The position and size setters then move the window with MoveWindow, and Visible calls ShowWindow.

There are no methods for the text; work with the control by sending messages to Handle. The file also defines many window style constants (WS_...) as Public Const.

QRICHEDIT_API inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • Constants WS_EX_CLIENTEDGE, WS_EX_MDICHILD and WS_EX_OVERLAPPEDWINDOW (used but not defined in this file; they are defined for example in Win32_constants.inc)
  • RICHED32.DLL (loaded at run time with LoadLibrary)

HandleINTEGERRWWindow handle of the created RichEdit control; 0 until Parent is assigned.

Notes

  • Each assignment of Parent loads the library again and creates a new window; the earlier window is not destroyed and FreeLibrary is never called.
  • Before Parent is assigned, the Left, Top, Width, Height and Visible setters call MoveWindow or ShowWindow with Handle = 0.
  • The window is created with the extended styles WS_EX_MDICHILD, WS_EX_OVERLAPPEDWINDOW and WS_EX_TRANSPARENT among others; a simpler call with only WS_EX_CLIENTEDGE is left commented out.
  • The file declares a global variable hInst, $DEFINE HWND INTEGER and many Public Const window styles, which can clash with other include files.

QRichEdit_api Examples

Example written for this page from the members above; not run.

CONST WS_EX_CLIENTEDGE = &H200
CONST WS_EX_MDICHILD = &H40
CONST WS_EX_OVERLAPPEDWINDOW = &H300
$INCLUDE "apiRe.inc"
CREATE Form AS QFORM
  Width = 400
  Height = 300
END CREATE
DIM RE AS QRichEdit_api
RE.Left = 5
RE.Top = 5
RE.Width = 380
RE.Height = 250
RE.Parent = Form.Handle
Form.ShowModal
