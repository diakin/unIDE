QFORMEX Component

Extends QFORM · source: inc/object/QFormEx.inc, line 53 · version: 1.2

An extended QFORM with file drag-and-drop, a system tray icon and taskbar handling.

QFormEx extends QFORM and replaces the window procedure of the form (SetWindowLong with GWL_WNDPROC) the first time DragEnable is assigned or AddTrayIcon is called. The new procedure handles WM_DROPFILES, WM_SYSCOMMAND and the tray icon callback message.

For drag-and-drop, set DragZone to the client area that accepts files and assign DragEnable; OnDrag is raised once for each dropped file whose drop point is inside DragZone. AddTrayIcon puts the application icon in the tray with the application title as tip; while it is shown, minimizing the form raises OnMinimise instead of minimizing, a right click raises OnTrayClick and a left double click raises OnTrayDblClick.

QFORMEX inherits the properties, methods and events of QFORM; the tables below list only what the component adds or redefines (public members).

QFormEx Properties

FieldTypeR/WDefaultDescription
DragZoneQRECTRWQRect in client coordinates; dropped files are accepted only when the drop point is inside it. It must be set, since the default empty rectangle accepts nothing.
DragEnableBOOLEANRWAssigning it calls DragAcceptFiles with the value to accept or refuse dropped files, and subclasses the window procedure the first time.
DeskBarBOOLEANRWAssigning true makes the desktop the owner of the form and the form the owner of the application window (SetWindowLong GWL_HWNDPARENT), described as putting the application in the desktop taskbar when minimized. Assigning false does nothing.
FormStyleINTEGERRWForm style. Assigning it sets the inherited FormStyle; the value 3 also sets the form Parent to a hidden internal QForm.

QFormEx Methods

MethodTypeDescription
AddTrayIconSUBAdds a tray icon with Application.Icon and Application.Title as tip, and subclasses the window procedure if needed.
DelTrayIconSUBRemoves the tray icon; minimizing works normally again.

QFormEx Events

EventTypeOccurs when...
OnDragSUB(file as string)Raised for each file dropped inside DragZone, with the file name.
OnTrayClickSUBRaised when the tray icon is clicked with the right mouse button (button up).
OnTrayDblClickSUBRaised when the tray icon is double-clicked with the left mouse button.
OnMinimiseSUBRaised instead of minimizing the form when the user minimizes it while the tray icon is shown.

Notes

  • With the default DragZone (all zeros) no dropped file is accepted.
  • Assigning DragEnable false only stops accepting files; the replaced window procedure stays in place. Assigning DeskBar false does nothing.
  • While the tray icon is shown, the minimize command is not passed to the original window procedure, so the form is not minimized unless the OnMinimise handler does it.
  • WM_DROPFILES and the tray callback message are not passed on to the original window procedure.

QFormEx Examples

Example written for this page from the members above; not run.

$INCLUDE "QFormEx.inc"
DECLARE SUB FileDropped(File AS STRING)

CREATE Form AS QFormEx
  Caption = "Drop files here"
  Width = 400
  Height = 300
END CREATE

SUB FileDropped(File AS STRING)
  ShowMessage File
END SUB

Form.DragZone.Left = 0
Form.DragZone.Top = 0
Form.DragZone.Right = Form.ClientWidth
Form.DragZone.Bottom = Form.ClientHeight
Form.OnDrag = FileDropped
Form.DragEnable = 1
Form.ShowModal
