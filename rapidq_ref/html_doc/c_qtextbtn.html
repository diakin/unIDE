QTEXTBTN Component

Extends QLABEL · source: inc/QTextBtn.inc, line 18 · version: 1.0

A label that acts as a text-only button by changing its font color when pressed, with momentary, latching and toggle modes.

QTextBtn extends QLabel. It is transparent and auto-sized, shows a hand cursor (Cursor = -21) and uses the font color to show its state: DownColor while pressed or down, UpColor when released.

The component handles OnMouseDown and OnMouseUp itself. Mode 0 (default) is a normal push button: the color returns to UpColor on mouse up and Down becomes False. Mode 1 sets Down to True on mouse up and keeps the down color. Mode 2 is a toggle: each click switches Down between True and False and restores UpColor when it is switched off. Comments in the source are in French.

QTEXTBTN inherits the properties, methods and events of QLABEL; the tables below list only what the component adds or redefines (public members).

QTextBtn Properties

FieldTypeR/WDefaultDescription
DownColorLONGRW&h0Font color used while the button is pressed or down (default &H0).
UpColorLONGRW&h0Font color of the released button. Assigning it stores the value and immediately sets the label's font color to it (default &H0).
modeSHORTRW0Operating mode read by the mouse-up handler: 0 = push button, 1 = stays down after release, 2 = toggle on each click. Assigning it only stores the value.
downBOOLEANRWfalseTrue when the button is in the down state. Assigning it (only when the label is enabled) sets the state and changes the font color to DownColor or UpColor.
enabledBOOLEANRWDeclared with PROPERTY SET SetEnabled, but no SetEnabled setter exists in the type; SetDown checks the inherited Super.Enabled instead.

The component handles these events itself (EVENT blocks in the TYPE): OnMouseDown, OnMouseUp.

Notes

  • Enabled is declared as "enabled as boolean property set SetEnabled" but the type defines no SetEnabled, so this declaration refers to a missing setter.
  • The type uses its own OnMouseDown and OnMouseUp event handlers to drive the button state.
  • The Mode values are not documented in the source; their meaning comes only from the OnMouseUp code.
