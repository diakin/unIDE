QLISTBOXEX Component

Extends QLISTBOX · source: inc/QListBoxEx.inc, line 15 · version: 1.0

A QListBox that raises an OnEnter event when the Enter key is pressed.

QListBoxEx extends QListBox. The constructor creates a hidden popup menu with one invisible item whose ShortCut is "Enter" and assigns it to PopupMenu; when the shortcut fires, OnEnter is raised.

QLISTBOXEX inherits the properties, methods and events of QLISTBOX; the tables below list only what the component adds or redefines (public members).

QListBoxEx Events

EventTypeOccurs when...
OnEnterSUBRaised when the Enter key is pressed while the list box has the focus.

The component handles these events itself (EVENT blocks in the TYPE): EnterKey.OnClick.

Notes

  • The component uses the PopupMenu property for its hidden menu, so assigning another popup menu removes the Enter handling.

QListBoxEx Examples

Example written for this page from the members above; not run.

$INCLUDE "QListBoxEx.inc"
DECLARE SUB ListEnter

CREATE Form AS QFORM
  CREATE List AS QListBoxEx
    AddItems "One", "Two", "Three"
    OnEnter = ListEnter
  END CREATE
END CREATE

SUB ListEnter
  IF List.ItemIndex >= 0 THEN ShowMessage List.Item(List.ItemIndex)
END SUB
