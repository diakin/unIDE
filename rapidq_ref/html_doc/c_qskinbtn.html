QSKINBTN Component

Extends QIMAGE · source: inc/QSkinBtn.inc, line 17 · version: 1.0

A skinnable button based on QIMAGE that shows different bitmaps for the up, down and disabled states, with push, latch and toggle modes.

QSkinBtn is a QIMAGE (AutoSize on) that switches its BMP between the bitmaps btUp, btDown and btEnable. Pressing the mouse shows btDown; on release the behaviour depends on Mode.

A hidden QCANVAS is used once to select the right picture on the first paint and is then made invisible. Clicks can be handled with the inherited QIMAGE events. The source comments are in French.

QSKINBTN inherits the properties, methods and events of QIMAGE; the tables below list only what the component adds or redefines (public members).

QSkinBtn Properties

FieldTypeR/WDefaultDescription
btUpQBITMAPRWQBitmap shown when the button is up.
btDownQBITMAPRWQBitmap shown when the button is pressed or down.
btEnableQBITMAPRWQBitmap shown when the button is disabled (despite its name).
modeSHORTRW0Button behaviour on mouse release: 0 returns to the up image (push button), 1 stays down, 2 toggles between down and up on each click. Assigning it only stores the value.
downBOOLEANRWfalseAssigning it while the button is enabled sets the down state and shows btDown (True) or btUp (False); ignored when disabled.
enabledBOOLEANRWtrueAssigning it shows the btEnable bitmap, repaints, and enables or disables the underlying QIMAGE.

The component handles these events itself (EVENT blocks in the TYPE): OnMouseDown, OnMouseUp, Show.OnPaint.

Notes

  • Assigning Enabled always switches to the btEnable (disabled) picture, even when enabling; the up or down picture comes back only on a later paint or mouse action.
  • The constructor sets show.Parent = qform, which names the QFORM class rather than a form instance.
  • With Mode 1 the button stays down after the first click and the mouse alone never releases it; assign Down = False to release it.
  • There is no dedicated click or change event; use the inherited QIMAGE events.

QSkinBtn Examples

Example written for this page from the members above; not run.

$INCLUDE "QSkinBtn.inc"
CREATE Form AS QFORM
  Caption = "Skin button"
END CREATE
DIM Btn AS QSkinBtn
Btn.btUp.BMP = "up.bmp"
Btn.btDown.BMP = "down.bmp"
Btn.btEnable.BMP = "disabled.bmp"
Btn.Mode = 2
Btn.Parent = Form
Form.ShowModal
