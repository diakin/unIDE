Function DecodeSubj( Subject As String) As String

Decodes an e-mail header such as Subject that contains MIME encoded-words (=?charset?Q|B?text?=), using quoted-printable or RQBASE64Decode, and converts koi8-r, utf-8 and utf-7 text to windows-1251 with RQConvertCodePage. Plain text that looks like KOI8 (isKOI8) is also converted. (body longer than shown)

Returns the charset of a MIME-encoded mail subject (the text between the first and second "?", as in =?koi8-r?B?...?=). If none is given but isKOI8 detects KOI8 text, returns "koi8-r"; otherwise an empty string.

IsEmail

Function IsEmail(wabMail As String) As long

Returns True if wabMail looks like an e-mail address: it matches *@*.* and the last domain part is 2 or 3 latin letters; otherwise False. A stricter per-character check is commented out.

Function isKOI8( Red$ As String) As long

Heuristic check whether a string is Russian text in KOI8-R shown as cp1251: returns 1 if it contains any of a list of letter pairs typical for that case, otherwise 0.
