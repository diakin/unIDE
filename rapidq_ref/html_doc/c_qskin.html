QSKIN Component

Extends QFORM · source: inc/QSkin.inc, line 20 · version: 1.2

Skinned form: a QFORM without title bar whose size follows a skin image, and which can be dragged by that image.

QSkin extends QFORM and contains Skin, an auto-sized QImage at 0, 0. Load the skin bitmap into Skin and call Resize: the form takes the size of the image plus OffsWidth and OffsHeight and hides its title bar. The same happens on every OnResize.

Pressing a mouse button on the skin calls ReleaseCapture and sends WM_SYSCOMMAND with &HF012 to the form, so the window is moved with the mouse. SetDeskBar changes the owner windows with SetWindowLongA (GWL_HWNDPARENT); the French comment describes it as the method for minimizing the application into the taskbar.

QSKIN inherits the properties, methods and events of QFORM; the tables below list only what the component adds or redefines (public members).

QSkin Properties

FieldTypeR/WDefaultDescription
SkinQIMAGERWQImage (AutoSize, at 0, 0) that holds the skin picture; pressing the mouse on it drags the form.
OffsWidthSHORTRW0Extra pixels added to the skin width when the form is sized by Resize or OnResize. Default 0.
OffsHeightSHORTRW0Extra pixels added to the skin height when the form is sized by Resize or OnResize. Default 0.

QSkin Methods

MethodTypeDescription
SetDeskBarSUBSets the form's owner to the desktop and makes the form the owner of the Application window, so that (per the comment) the application is minimized into the taskbar.
ResizeSUBSizes the form to the Skin size plus OffsWidth and OffsHeight and hides the title bar.

The component handles these events itself (EVENT blocks in the TYPE): OnResize, Skin.onmousedown.

Notes

  • The component uses the form's OnResize event itself, so every resize is forced back to the Skin size plus the offsets.
  • The constructor sets BorderStyle = 1 and calls DelBorderIcons 2.
