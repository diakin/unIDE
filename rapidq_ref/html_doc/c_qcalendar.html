QCALENDAR Component

Extends QPANEL · source: inc/qcalendar.inc, line 6 · author: Pasquale P.C.B. · date: 4-2001

A month calendar panel with a day grid, month/year navigation buttons, a month popup menu and a Today button, using Windows locale names.

qcalendar extends QPanel and builds its own child controls: a header panel (Panel1) with previous/next month and previous/next year buttons (Wingdings and Webdings arrow glyphs), a QStringGrid with the days, a Today button and a footer panel (Panel2) that shows the selected date in the long date format.

Month names, abbreviated day names (Monday first) and the long date format come from GetLocaleInfo, and dates are formatted with GetDateFormat; these, SYSTEMTIME, weekday and lastdaym come from the included apidate file. The Today caption is translated for a few country codes (Danes, Oggi, Aujourd'hui, Hoy, Heute, otherwise Today). Right-clicking the header shows a popup menu to choose the month.

Call Init after creating the control, with a date string "MM-DD-YYYY" or "" for today. Days of the previous and next month are drawn grayed and cannot be selected, today's date is circled, and Sunday is drawn in a different color. Read the selected date with QDate$ or the M, D and Y fields.

QCALENDAR inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

Requires

  • $include "apidate.bas" (provides SYSTEMTIME, GetDateFormat, GetLocaleInfo, weekday, lastdaym; the reference library has it as ApiDate.inc)

qcalendar Methods

MethodTypeDescription
LoadCalSUB(datum$ as string)LoadCal(datum$) fills the grid with the month of the date datum$ ("MM-DD-YYYY"), sets M, D and Y, updates the header and selects the day.
mnuclickSUB(s as QmenuItem)Internal: OnClick handler of the month menu items; shows the chosen month of the current year.
INITSUB(inidatum$)Init(inidatum$) must be called once: it validates the optional start date ("MM-DD-YYYY", or "" for today), fills month and day names from the locale, sets the Today caption and loads the calendar. For an invalid date it shows a message and hides the control.
QDate$FUNCTION AS STRINGReturns the selected date as month-day-year built with STR$ (fields not zero-padded).

The component handles these events itself (EVENT blocks in the TYPE): bntdowny.onclick, bntupy.onclick, btnnext.onclick, btnprev.onclick, grid.onDrawcell, grid.onselectcell, Today.onclick.

Notes

  • The include line names "apidate.bas"; the helper in this library is ApiDate.inc, so the path may need to be changed.
  • Init fills the header row with week(i) for i up to grid.ColCount+1 (9) while week is dimensioned 1 to 7.
  • Comments say ColCount and RowCount were changed from 7 to 8 because an error occurred.
  • There is no event for a date change; read D, M, Y or QDate$ yourself.
  • Years before 1753 are blocked by the navigation buttons.
  • Date strings must use the MM-DD-YYYY order of DATE$; the validation message even says 'MM-DD-YYYYY'.
  • Commented-out lines refer to absolute bitmap paths such as C:\RapidQ\cdx.bmp.

qcalendar Examples

Example written for this page from the members above; not run.

$INCLUDE "qcalendar.inc"
DECLARE SUB ShowDate
CREATE Form AS QFORM
  Caption = "Calendar"
  Width = 200: Height = 240
  CREATE Cal AS qcalendar
    Left = 5: Top = 5
  END CREATE
  CREATE Btn AS QBUTTON
    Top = 190: Left = 5
    Caption = "Get date"
    OnClick = ShowDate
  END CREATE
END CREATE
SUB ShowDate
  ShowMessage Cal.QDate$
END SUB
Cal.Init ""
Form.ShowModal
