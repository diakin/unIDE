Sub GetFormPos (Sender as QForm)

Reads the window placement of the form Sender with GetWindowPlacement and stores the normal position in the global Rectan and the minimized position in the globals MinLeft and MinTop.

SetFormPos

SUB · rapidqAllProc.inc, line 12594

Sub SetFormPos(hwnd as long, SetX as long, SetY as long)

Sets the minimized position (SetX, SetY) and the normal position of the window hwnd with SetWindowPlacement, using the global rectangle Rectan (filled by GetFormPos) as the normal position. Note: showCmd is set to SW_MINIMIZE, so the window is minimized.
