Appendix B: Custom Components

Components written in Rapid-Q itself (TYPE Name EXTENDS Base) that are kept in rapidq_ref/inc. Each page is built from the component source: the tables list the public fields, methods and events found in the TYPE block, defaults come from its CONSTRUCTOR, descriptions from the code and its comments. Older versions of the files are in rapidq_ref/inc/old; the full list with the reasons is in rapidq_ref/inc/COMPONENTS.md.

Examples marked "written for this page" were not run. Some components need files that are not in the collection (DLLs, bitmaps); see Requires and Notes on each page.
