QMD2MODEL Component

Extends QMEMORYSTREAM · source: inc/QGL.inc, line 469 · author: JohnK · version: alpha release 1.0

Loader and renderer for Quake MD2 animated 3D models, drawn with OpenGL through a QGL object.

QMD2model reads an MD2 file with LoadMD2File: the header, skin names (loaded as textures), texture coordinates, triangles and all frames with their vertices, scale and translate values. Frame names are scanned to build a KeyFrame list where the first three letters of the name change. Arrays are fixed-size at the limits defined by MD2_MAX_VERTICES (1024), MD2_MAX_TRIANGLES (2048), MD2_MAX_FRAMES (256) and MD2_MAX_TEXT_COORD (1024).

DrawMD2 draws one frame interpolated between two frames with glBegin(GL_TRIANGLES). CreateAnimationSet compiles a sequence of interpolated frames into OpenGL display lists and returns the index of the first one. Animate calls the display list for CurrentFrame, and an internal QTimer advances CurrentFrame at the rate set by FPS. If hDC is set, Animate also swaps buffers.

Skins are loaded with GL.CreateTextureFromFile, so the program must have a QGL instance named GL with an active rendering context before loading a model.

QMD2MODEL inherits the properties, methods and events of QMEMORYSTREAM; the tables below list only what the component adds or redefines (public members).

Requires

  • QGL component in the same file, as a global instance named GL
  • OpenGL includes used by QGL (GL\gl.inc, GL\glu.inc)
  • QD3DVECTOR (Position, Rotation, Scale)

Notes

  • Uses a global QGL instance named GL (GL.CreateTextureFromFile); the name is hard-coded.
  • CreateAnimationSet passes This.skins(1), a texture ID, as the skin index to DrawMD2.
  • CalcMD2Normals is empty (fully commented out), and the stored normal indexes are not used for lighting.
  • Array sizes are fixed at the MD2_MAX_* limits; larger models only produce a 'Too many ...' message and are still read.
  • Texture coordinates are divided by the size of QGLinternalBMP, that is, the last texture loaded.
  • A commented line notes that REDIM of the skins array crashes.

QMD2model Examples

Example written for this page from the members above; not run.

DIM GL AS QGL
DIM Model AS QMD2model
DIM StartIdx AS LONG

' after GL.Init(Form)
Model.LoadMD2File("tris.md2")
StartIdx = Model.CreateAnimationSet(0, 39, 0.25)
Model.hDC = GL.hDC
Model.FPS = 20
' in a timer or loop:
Model.Animate
