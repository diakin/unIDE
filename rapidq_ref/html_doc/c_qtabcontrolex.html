QTABCONTROLEX Component

Extends QTABCONTROL · source: inc/QtabControlEx.inc, line 6 · version: 1.0

A QTabControl that keeps a count of its tabs and adds methods to delete tabs and clear all tabs.

QTabControlEx extends QTabControl. It redefines AddTabs and InsertTab so that they also update TabCount, and adds DeleteTabs and Clear. The comments are in French and describe each method (tab count property, delete, add, redefined add, redefined insert, delete all tabs).

Original documentation: QTabControlEx documentation by D. Glodt (2004).

QTABCONTROLEX inherits the properties, methods and events of QTABCONTROL; the tables below list only what the component adds or redefines (public members).

QTabControlEx Properties

FieldTypeR/WDefaultDescription
TabCountINTEGERRW0Number of tabs, maintained by AddTabs, InsertTab, DeleteTabs and Clear. Its setter is empty and marked read only, so assigning it does nothing.

QTabControlEx Methods

MethodTypeDescription
DeleteTabsSUB(index as integer)DeleteTabs(index) removes the tab at index (through DelTabs) and decreases TabCount, if TabCount is greater than 0.
AddSUB(s as string)Add(s) adds one tab by calling the inherited AddTabs; it does not change TabCount.
AddTabsSUBI(...)AddTabs(caption1, caption2, ...) adds one tab per argument and increases TabCount for each.
InsertTabSUB(index as integer,s as string)InsertTab(index, s) inserts a tab at index with the inherited InsertTab and increases TabCount.
ClearSUBRemoves all tabs by deleting tab 0 TabCount times and sets TabCount to 0.

Notes

  • Add does not update TabCount, so adding tabs with Add leaves the count wrong; use AddTabs.
  • DeleteTabs does not check that index is within range.
  • Tabs added with the inherited methods before or outside these overrides are not counted.

QTabControlEx Examples

Example written for this page from the members above; not run.

$INCLUDE "QtabControlEx.inc"
CREATE Form AS QFORM
  Caption = "Tabs"
  CREATE Tabs AS QTabControlEx
    Align = 5
  END CREATE
END CREATE
Tabs.AddTabs "One", "Two", "Three"
Tabs.InsertTab 1, "New"
Tabs.DeleteTabs 0
Form.Caption = "Tabs: " + STR$(Tabs.TabCount)
Form.ShowModal
