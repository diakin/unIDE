QTEXTEDIT Component

Extends QRICHEDIT · source: inc/QTextEdit.inc, line 19

QRichEdit extension with a built-in Undo/Cut/Copy/Paste/Select All popup menu and extra editing methods (undo, text limit, replace selection, find).

QTEXTEDIT adds a QPopupMenu with Undo, Cut, Copy, Paste and Select All items and shortcuts. Before the menu pops up, each item is enabled or disabled from the editor state: undo availability (EM_CANUNDO), current selection, clipboard text and editor text.

The extra methods send edit-control messages to the window: Undo (EM_UNDO, &HC7), Limit (EM_LIMITTEXT, &HC5) and ReplaceSel (EM_REPLACESEL, &HC2). Find searches the text with INSTR and selects the match. The menu captions can be changed for translation.

At the end of the file, QRICHEDIT is redefined as QTEXTEDIT ($UNDEF/$DEFINE), so every QRICHEDIT declared after the include becomes a QTEXTEDIT.

QTEXTEDIT inherits the properties, methods and events of QRICHEDIT; the tables below list only what the component adds or redefines (public members).

QTEXTEDIT Methods

MethodTypeDescription
UndoSUBUndoes the last change (EM_UNDO).
CutSUBCuts the selection to the clipboard.
CopySUBCopies the selection to the clipboard.
PasteSUBPastes from the clipboard.
SelectAlSUBSelects all text (named SelectAl to avoid clashing with SelectAll).
LimitSUB(value as long)Limit(value) sets the maximum number of characters the user can enter (EM_LIMITTEXT).
ReplaceSelSUB(text as string)ReplaceSel(text) replaces the current selection with text; does nothing if nothing is selected.
FindFUNCTION(start as long,text as string,case as boolean) AS LONGFind(start, text, case) searches from the 1-based position start, case sensitive if case is True; selects the match and returns its 1-based position, or 0 if not found.
LinesScrollSUB(number as long)LinesScroll(number) moves the cursor to the start of the given 1-based line, counting 2 characters for each line break.
CanUndoFUNCTION AS BOOLEANReturns nonzero if the last change can be undone (EM_CANUNDO).

The component handles these events itself (EVENT blocks in the TYPE): MaxMenu.OnPopup.

Notes

  • The include redefines QRICHEDIT as QTEXTEDIT for all code that follows it.
  • The caption and UsePopup setters do not store the assigned value in the property field, so reading these properties does not return what was assigned.
  • LinesScroll assumes every line ends with a 2-character CR+LF.

QTEXTEDIT Examples

Example written for this page from the members above; not run.

$INCLUDE "QTextEdit.inc"
DIM Form AS QFORM
DIM Edit AS QTEXTEDIT
Edit.Parent = Form
Edit.Align = 5
Edit.UndoCaption = "&Annuler"
Edit.Limit(10000)
IF Edit.Find(1, "hello", 0) THEN Edit.ReplaceSel("world")
Form.ShowModal
