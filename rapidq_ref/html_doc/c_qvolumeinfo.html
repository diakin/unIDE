QVOLUMEINFO Component

Extends QOBJECT · source: inc/QVolumeInfo.inc, line 75 · author: Alain Besseleer alias Midipro2000 · version: 1.0 · date: July 25, 2009

QVolumeInfo is a non-visual object that retrieves the label, serial number, file system, size, free space and drive type of a drive.

Call SelectDrive with a drive letter first; it calls the kernel32 functions GetVolumeInformationA, GetDiskFreeSpaceA and GetDriveTypeA and fills all properties. Byte counts are computed as clusters x sectors per cluster x bytes per sector, and TotalSpace and FreeSpace are short text forms such as "12.5 GB" made by GetStringFormat.

The DRIVE_ constants are defined only if neither __WIN32API nor __QDRIVE_INC is defined; the file defines __QVOLUMEINFO_INC.

QVOLUMEINFO inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QVolumeInfo Methods

MethodTypeDescription
GetStringFormatFUNCTION(Bytes as double) AS STRINGGetStringFormat(Bytes) returns a short string for a byte count: below 1024 "n Bytes", otherwise KB, MB, GB or TB with one decimal.
SelectDriveSUB(DriveRoot as string)SelectDrive(DriveRoot) reads the information for the drive whose letter is the first character of DriveRoot and fills all properties; call it before reading them.

Notes

  • The file-system property is misspelled FileSytem.
  • Return values of the API calls are not checked.
  • Drive type 1 (DRIVE_NO_ROOT_DIR) is reported as "Unknown"; the DRIVE_ constants are defined but SelectDrive compares with literal numbers.

QVolumeInfo Examples

Example written for this page from the members above; not run.

$INCLUDE "QVolumeInfo.inc"
DIM Vol AS QVolumeInfo
Vol.SelectDrive("C")
ShowMessage Vol.DriveRoot + " " + Vol.Name + " (" + Vol.FileSytem + ") " + Vol.FreeSpace + " free of " + Vol.TotalSpace
