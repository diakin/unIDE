AsciiKrypt

FUNCTION · RQProc.inc, line 10777

Function AsciiKrypt (bpmKryptLine$ as string, bpmKryptPass$ as string, bpmKryptMode& as integer)

Simple character-shift cipher: adds (mode 1) or subtracts (other mode) the ASCII codes of the password bpmKryptPass$ to each character of bpmKryptLine$ and returns the result. Characters can overflow 0..255; not secure.

Function DivBytes (bpmNumBytes& as double, bpmBytesFormat$ as string) as long

GetFreeDrive

FUNCTION · RQProc.inc, line 10784

Function GetFreeDrive (bpmDriveLetter$ as string) as long

Returns the free space in bytes on drive bpmDriveLetter$ (one letter, without colon) using GetDiskFreeSpace; returns 0 if the drive does not exist or the argument is longer than one character. Result is a LONG, so large disks overflow.

GetLastError$

FUNCTION · RQProc.inc, line 10785

Function GetLastError$

Looks up the error code in the global bpmErrorCodeNumber& in a tab-separated text file named by the global bpmErrorFileName$ and returns its description and hex code. Note: on code 0 or a missing file the code executes END, which stops the program.
