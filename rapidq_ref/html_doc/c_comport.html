COMPORT Component

Extends QOBJECT · source: inc/ComPort.cmp, line 262 · author: Pete Kleinschmidt · version: 0.9 · date: December 13, 2001

Comport is a non-visual serial (COM) port component that opens, configures, writes to and reads from a port through the Win32 file and communications API.

Open calls CreateFile on Port, sets the driver buffers with SetupComm, purges them with PurgeComm, sets time-outs with SetCommTimeouts, reads the current DCB with GetCommState and writes BaudRate, DataBits, Parity and StopBits back with SetCommState. Settings that are not exposed keep their current values. All calls are synchronous (no overlapped I/O).

WriteString and ReadString use WriteFile and ReadFile, then wait the given number of milliseconds with kernel32 Sleep and update BytesNotWritten and BytesNotRead through ClearCommError. Every failure raises OnComError with a message that includes the system error text from FormatMessage. The header says the code is loosely based on VB code by David M. Hitchner (thescarms.com).

COMPORT inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • FILE_ATTRIBUTE_NORMAL constant defined elsewhere (its CONST is commented out in this file)

Comport Methods

MethodTypeDescription
OpenSUBOpens Port and applies buffer sizes, time-outs (ReadIntervalTimeout -1, ReadTotalTimeoutConstant 1000) and BaudRate, DataBits, Parity and StopBits; sets Connected and raises OnOpen, or raises OnComError and exits at the first failing step.
CloseSUBCloses the port handle with CloseHandle, sets Connected to FALSE and raises OnClose, or raises OnComError on failure.
WriteStringSUB(strData AS STRING, intWait AS INTEGER)WriteString(strData, intWait) writes the string to the port, sleeps intWait milliseconds, then raises OnWriteString if the output queue is empty or OnComError ("Could not send all the data in time specified...") if not.
ReadStringFUNCTION(dwRdSize AS DWORD, intWait AS INTEGER) AS STRINGReadString(dwRdSize, intWait) reads up to dwRdSize bytes and returns them as a string, then sleeps intWait milliseconds, updates BytesNotRead and raises OnReadString.

Comport Events

EventTypeOccurs when...
OnComErrorSUB(strErrorMessage AS STRING)Event OnComError_EventTemplate(strErrorMessage AS STRING), raised when an API call fails or not all data was sent; the message is a fixed text followed by the system error text.
OnOpenSUBEvent without parameters raised when Open has applied the port settings successfully.
OnCloseSUBEvent without parameters raised when Close has closed the handle successfully.
OnWriteStringSUBEvent without parameters raised by WriteString when, after the wait, no bytes remain in the output queue.
OnReadStringSUBEvent without parameters raised by ReadString after a successful read.

Notes

  • ReadString calls ReadFile with MyPort.Handle instead of ComPort.Handle, so it only works when the instance is named MyPort.
  • In Open, WriteTotalTimeoutMultiplier is assigned twice (0, then 1000) and WriteTotalTimeoutConstant is never set.
  • StopBits defaults to 1, which by the file's own constants is ONE5STOPBITS (1.5 stop bits), not one stop bit.
  • ReadString allocates a buffer of ReadBufSize bytes but asks ReadFile for dwRdSize bytes; dwRdSize larger than ReadBufSize is not checked.
  • When ClearCommError fails, the error message uses ERROR_CHANGING_PORTSETTINGS instead of ERROR_GETTING_PORT_STATUS.
  • FILE_ATTRIBUTE_NORMAL is used in Open but its CONST is commented out in the file.
  • The file declares kernel32 Sleep (milliseconds), CreateFile, ReadFile, WriteFile, CloseHandle, GetLastError, FormatMessage and many constants and types (DCB, OVERLAPPED, CREATE_NEW, OPEN_EXISTING and others) at global level, without $IFNDEF guards.

Other versions

  • inc/rapidq2.inc (line 5177) contains its own edition of COMPORT; it has members that are not in this file: DCBFLAGS, INQUE, OUTQUE, PURGEIN, PURGEOUT, WRITE.

Comport Examples

Example written for this page from the members above; not run.

$INCLUDE "ComPort.cmp"
DECLARE SUB PortError(Msg AS STRING)
DIM MyPort AS Comport   ' ReadString uses the name MyPort, see caveats
MyPort.Port = "COM2"
MyPort.BaudRate = 19200
MyPort.StopBits = ONESTOPBIT
MyPort.OnComError = PortError
MyPort.Open
IF MyPort.Connected THEN
  MyPort.WriteString("AT" + CHR$(13), 100)
  ShowMessage MyPort.ReadString(64, 200)
  MyPort.Close
END IF

SUB PortError(Msg AS STRING)
  ShowMessage Msg
END SUB
