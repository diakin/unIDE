RQCONST Component

Extends QSTRINGLIST · source: inc/QLibrary.Inc, line 49

A string list that loads CONST definitions from a RapidQ include file and returns the numeric value of a constant by name.

RQConst extends QStringList. Initialize reads the file named in FileId (default "RapidQ.Inc") and, for every line that contains CONST and does not start with a comment, stores an item "NAME;value". Trailing comments are removed, &H hexadecimal values are converted to decimal and RGB(r,g,b) expressions are converted to their color number.

ValueOf(Entry) calls Initialize on first use and returns the value of the constant whose name matches Entry, ignoring case and surrounding blanks. It is described in the file as a "RapidQ Keyword Extension" and uses the helper functions Trim$ and Equ$ from QLibrary.Inc.

RQCONST inherits the properties, methods and events of QSTRINGLIST; the tables below list only what the component adds or redefines (public members).

Requires

  • Helper functions Trim$ and Equ$ from the same file QLibrary.Inc
  • RapidQ.Inc (or the file named in FileId) at run time

RQConst Methods

MethodTypeDescription
InitializeSUBClears the list and loads all CONST definitions from FileId as "NAME;value" items, converting &H hex values and RGB() expressions to decimal numbers.
ValueOfFUNCTION(Entry As String) AS LONGValueOf(Entry) returns the numeric value of the constant named Entry (case-insensitive), loading the file first if needed.

Notes

  • Initialize stops at ItemCount-1, so the last line of the file is never parsed.
  • A line is treated as a constant when it contains "CONST" anywhere (case-sensitive), not only at the start.
  • ValueOf returns 0 when the name is not found, which cannot be told apart from a constant whose value is 0.
  • Positions are kept in a Byte variable (Point), so lines longer than 255 characters are parsed incorrectly.
