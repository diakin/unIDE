QCURSOR Component

Extends QOBJECT · source: inc/QCursor.inc, line 22 · version: 1.0

An object that loads mouse cursors from files or resources and shows, hides or moves the mouse cursor.

QCursor extends QObject. LoadFromFile and LoadFromResource load a .cur file with LoadCursorFromFile and put it into Screen.Cursors at the next index (1, 2, ...); Count holds the last index used, so a control can use it with Cursor = index.

LoadFromResource extracts a resource added with $RESOURCE to a temporary file temp.cur next to the executable, loads it and deletes the file. Visible calls ShowCursor and Move calls SetCursorPos.

QCURSOR inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QCursor Properties

FieldTypeR/WDefaultDescription
CountINTEGERRW0Number of cursors loaded, which is also the Screen.Cursors index of the last one. Read only: assigning it does nothing.
VisibleBOOLEANRWtrueAssigning it stores the value and calls ShowCursor with it to show or hide the mouse cursor (default true).

QCursor Methods

MethodTypeDescription
LoadFromResourceSUB(Res as long)LoadFromResource(Res) loads the cursor stored in resource number Res (0 to RESOURCECOUNT()-1) into the next Screen.Cursors index; invalid numbers are ignored.
LoadFromFileSUB(FileName as string)LoadFromFile(FileName) loads a cursor file into the next Screen.Cursors index if the file exists.
MoveSUB(x as long,y as long)Move(x, y) moves the mouse cursor to screen coordinates x, y.

Notes

  • LoadFromResource writes the temporary file temp.cur into the folder of the executable.
  • LoadFromFile and LoadFromResource give no error when the file or resource is missing.

QCursor Examples

Example written for this page from the members above; not run.

$INCLUDE "QCursor.inc"
DIM Cur AS QCursor
CREATE Form AS QFORM
  Caption = "Cursor test"
END CREATE
Cur.LoadFromFile("hand.cur")
Form.Cursor = Cur.Count
Cur.Move(100, 100)
Form.ShowModal
