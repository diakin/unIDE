QDRIVECOMBOBOX Component

Extends QCOMBOBOX · source: inc/QDriveCombobox.inc, line 10

QDriveComboBox is a QComboBox meant to list the drive letters present on the computer.

GetDrives checks the letters A to Z with GetDriveType from kernel32 and adds every root (such as "C:\") whose type is not 1 (no root directory), then selects the first item. The list is not filled automatically; call GetDrives yourself.

The whole type is inside $IFNDEF __RQINC2; the comment says the component was added to RapidQ2.inc, so this definition is skipped when that file is included. The file's comments are in French.

QDRIVECOMBOBOX inherits the properties, methods and events of QCOMBOBOX; the tables below list only what the component adds or redefines (public members).

QDriveComboBox Methods

MethodTypeDescription
GetDrivesSUBAdds the root of every existing drive (A:\ to Z:\) to the list using AddItems and sets ItemIndex to 0.
AddItemsSUBDeclared as an empty SUB in this type; it has no code of its own.
DelItemsSUBDeclared as an empty SUB in this type; it has no code of its own.
ClearSUBDeclared as an empty SUB in this type; it has no code of its own.

Notes

  • AddItems, DelItems and Clear are declared as empty SUBs, replacing the QComboBox methods of the same names, and GetDrives calls QDriveComboBox.AddItems; the source does not show whether the inherited methods are still reached.
  • GetDriveType is declared only when __WIN32API is not defined.
