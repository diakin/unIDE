QVUMETER Component

Extends QCANVAS · source: inc/QVuMeter.inc, line 17 · version: 1.0

A vertical bar-graph level meter (VU meter) drawn on a QCanvas.

QVuMeter extends QCanvas. In OnPaint it divides the height into horizontal bars of Thickness pixels separated by Interval pixels and fills them from the bottom: the bars up to the level of Value (scaled between Min and Max) in LightColor, the rest in DarkColor.

Assigning Value repaints the meter. Defaults: Min 0, Max 100, Thickness 2, Interval 1, DarkColor black, LightColor white. The file comments are in French (property interval, thickness, VU meter value, VU meter paint event).

QVUMETER inherits the properties, methods and events of QCANVAS; the tables below list only what the component adds or redefines (public members).

QVuMeter Properties

FieldTypeR/WDefaultDescription
MaxINTEGERRW100Value that lights all bars (default 100).
MinINTEGERRW0Value that lights no bars (default 0).
DarkColorLONGRW&h0Color of unlit bars (default &H0, black).
LightColorLONGRW&hffffffColor of lit bars (default &HFFFFFF, white).
ThicknessSHORTRW2Height of each bar in pixels (default 2). Assigning it stores the value as an integer; it does not repaint.
IntervalSHORTRW1Gap between bars in pixels (default 1). Assigning it stores the value as an integer; it does not repaint.
ValueLONGRW0Current level between Min and Max. Assigning it stores the value and repaints the meter.

The component handles these events itself (EVENT blocks in the TYPE): OnPaint.

Notes

  • If Max equals Min, OnPaint divides by zero.
  • Changing Min, Max, DarkColor, LightColor, Thickness or Interval does not repaint; assign Value or call Repaint afterwards.
  • The file defines True, False and boolean with $DEFINE if they are not already defined.

QVuMeter Examples

Example written for this page from the members above; not run.

$INCLUDE "QVuMeter.inc"
CREATE Form AS QFORM
  Caption = "VU"
  CREATE Vu AS QVuMeter
    Left = 10: Top = 10
    Width = 20: Height = 120
    LightColor = &H00FF00
  END CREATE
END CREATE
Vu.Value = 60
Form.ShowModal
