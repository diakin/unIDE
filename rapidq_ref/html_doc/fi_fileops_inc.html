FUNCTION SaveFileAs (Caption as string, Filter as string, initialdir as string) as string

Shows a QSaveDialog with the given caption, filter and initial directory (current directory if initialdir does not exist). If the chosen file exists, asks for confirmation to overwrite. Returns the chosen file name, or an empty string if cancelled or overwrite declined.
