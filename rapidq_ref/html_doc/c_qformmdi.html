QFORMMDI Component

Extends QFORM · source: inc/object/QFormMDI.inc, line 107 · version: 1.0

An MDI parent form that creates MDI child windows around existing controls and offers properties, methods and events to manage the child windows.

QFormMDI extends QFORM and sets FormStyle = 2 (MDI parent) with the application workspace color. On the first AddChild it registers a window class "MDIChild" whose window procedure is ChildProc and finds the MDICLIENT window. AddChild(handle, Title, index, Left, Top, Width, Height, DefaultSize) creates an MDI child window and moves the control with the given handle into it; the control is resized to fill the child's client area, and the index number is stored with the window so events can report which control it holds.

The Child* properties describe the active child window and assigning them moves, resizes, renames, minimizes, maximizes or restores it. Methods cascade, tile, arrange, minimize, maximize, restore, close and activate children, and the events OnChildClose, OnChildActive and OnChildResize receive the child handle, the control index and the title. When a child is destroyed its control is hidden and given back to the MDI form. Comments in the source are in French.

QFORMMDI inherits the properties, methods and events of QFORM; the tables below list only what the component adds or redefines (public members).

Notes

  • GetChild returns 0 both for the first window and when no title matches.
  • ActiveChild and the index returned by GetChild use the internal hChild list, which is only rebuilt by CloseAllChild, the minimize, maximize and restore methods, GetChild and ChildExist.
  • Assigning ChildIcon after children exist uses SetClassLong, so it changes the icon of all windows of the child class.
  • The child window class is registered with hInstance left at 0 (the line setting application.hinstance is commented out).
  • The internal child list is fixed at hChild(1024), which is why ChildMax is limited to 1024.

QFormMDI Examples

Example written for this page from the members above; not run.

CREATE Main AS QFormMDI
  Caption = "MDI demo"
  Width = 640
  Height = 480
END CREATE

CREATE Edit1 AS QRichEdit
  Parent = Main
END CREATE

Main.AddChild(Edit1.Handle, "Document 1", 0, 10, 10, 300, 200, 0)
Main.ShowModal
