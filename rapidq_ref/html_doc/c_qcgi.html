QCGI Component

Extends QOBJECT · source: inc/qcgi.inc, line 40 · author: Chris Warrington (with modifications by C. Baker) · version: 1.6 · date: 2005-Feb-22

Non-visual CGI helper that reads the CGI environment variables and parses GET or POST form data into name/value pairs.

The constructor reads the standard CGI environment variables (HTTP_ACCEPT, CONTENT_LENGTH, QUERY_STRING, REMOTE_ADDR, HTTP_USER_AGENT and so on) with ENVIRON$; each is returned by a method of the same name.

Parse reads the form data: for REQUEST_METHOD POST it reads CONTENT_LENGTH characters (at most MaxInput) from standard input with GET$, for GET it uses QUERY_STRING. The data is split at "&" and "="; with AutoConvert on, %XX codes and "+" are decoded. Names are stored in upper case in a table kept in alphabetical order, so Get finds them by binary search and the lookup is not case-sensitive.

Use it in a console program run by a web server: create a QCGI object and call Get(name, value) for each form field. Get calls Parse automatically the first time.

QCGI inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Notes

  • At most CGI_MAX_PAIRS (256) name/value pairs are stored; parsing stops when the table is full.
  • %XX codes are decoded only when they give a printable ASCII character (space to "~"); other codes, such as line breaks or non-ASCII bytes, stay in the text as "%XX".
  • A "+" followed by another "+" or a space is kept as "+" instead of being turned into a space.
  • When a name occurs more than once, only the last value is kept.
  • POST data is always parsed as name=value pairs; the content type is not checked.
  • Parse runs only once, so changing MaxInput or AutoConvert after the first Get has no effect.
  • The library is released under the GNU GPL version 2 or later; the header says programs that use it must release their source code.

QCGI Examples

Example written for this page from the members above; not run.

$APPTYPE CONSOLE
$INCLUDE "qcgi.inc"
DIM Cgi AS QCGI
DIM UserName AS STRING
PRINT "Content-type: text/plain"
PRINT ""
IF Cgi.Get("name", UserName) THEN
  PRINT "Hello, " & UserName
ELSE
  PRINT "No name given. Request method: " & Cgi.RequestMethod
END IF
