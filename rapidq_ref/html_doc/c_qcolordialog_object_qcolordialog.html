QCOLORDIALOG Component

Extends QOBJECT · source: inc/object/QColorDialog.inc, line 41 · version: 1.1

A color selection dialog object based on the Windows ChooseColor common dialog, with a custom caption, 16 custom colors and full-open options.

QCOLORDIALOG extends QOBJECT and wraps ChooseColorA from COMDLG32. Execute fills a TCHOOSECOLOR structure with the current Color and the 16 custom Colors, shows the dialog owned by the application window and, when the user presses OK, copies the chosen color and the custom colors back and returns True.

When Caption is not empty, a hook procedure is installed (CC_ENABLEHOOK) that centers the dialog on the screen and sets its title on WM_INITDIALOG. Style selects the layout: cdNormal (0), cdFullOpen (1, custom color section opened) or cdNoFullOpen (2, the Define Custom Colors button disabled). Comments in the source are in French.

QCOLORDIALOG inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Notes

  • The dialog is centered only when Caption is not empty, because the centering code is in the hook that is installed only in that case.
