QPOSICL Component

Extends QPANEL · source: inc/QPosicL.inc, line 11 · version: 1.00 · date: 22.02.2004

A panel with a vertical and a horizontal scroll bar and five buttons for adjusting a two-dimensional position (X/Y values).

QPosicL is a QPanel containing two QSCROLLBARs and five QBUTTONs with bitmaps (reset in the center, Undo, Redo, AllUp and AllDn in the corners). ValueH follows the horizontal scroll bar; ValueV is the vertical scroll bar position with the sign reversed, so its range is MinV..MaxV. Every change fires OnChange.

Set MinV, MaxV, ValueV, MinH, MaxH, ValueH and the size, then call Initial to apply the ranges and lay out the parts. The center button resets both values to 1; AllDn and AllUp move both scroll bars by one step in opposite directions. The header says it is based on the QSpinText component by Mesut Akcan and refers to the Rapid-Q documentation project at http://www.diakin.narod.ru/RQDP/index.html.

QPOSICL inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

Requires

  • Bitmap files reset.bmp, Undo1.bmp, Redo1.bmp, AllUp.bmp and AllDn.bmp in the folder BmpPath (C:\BAS\RAPIDQ\inc\), and MaxFast.bmp in the current folder (used by Initial)

QPosicL Properties

FieldTypeR/WDefaultDescription
maxvSHORTRWUpper limit of the vertical value; applied by Initial.
minvSHORTRWLower limit of the vertical value; applied by Initial.
valuevSHORTRWVertical value (negated position of the vertical scroll bar); set it before Initial to choose the start position.
maxhSHORTRWUpper limit of the horizontal value; applied by Initial.
minhSHORTRWLower limit of the horizontal value; applied by Initial.
valuehSHORTRWHorizontal value (position of the horizontal scroll bar); set it before Initial to choose the start position.

QPosicL Methods

MethodTypeDescription
initialSUBApplies the Min, Max and Value settings to the scroll bars, sets the parents of the child controls and lays them out according to the panel height.

QPosicL Events

EventTypeOccurs when...
OnChangeSUB(a as single)Event fired when a scroll bar moves or a button is clicked; its single parameter is always 1, so read ValueH and ValueV in the handler.

The component handles these events itself (EVENT blocks in the TYPE): btn.onclick, btnAllDn.onclick, btnAllUp.onclick, btnAllUp.OnMouseDown, btnRedo.onclick, btnUndo.onclick, sbh.onchange, sbv.onchange.

Notes

  • Button bitmaps are loaded from the absolute path C:\BAS\RAPIDQ\inc\ (BmpPath); Initial loads MaxFast.bmp from the current folder instead of reset.bmp.
  • The constructor and Initial lay out the parts differently (the constructor makes the vertical scroll bar vertical with Kind = 1, Initial sets Kind = 0).
  • The Undo and Redo buttons only fire OnChange and do not change any value.
  • AllUp does its work in OnMouseDown; its OnClick handler is empty (the code there is commented out).
  • OnChange is called with CALLFUNC without checking that a handler is assigned.

QPosicL Examples

Example written for this page from the members above; not run.

$INCLUDE "QPosicL.inc"

DECLARE SUB PosChange(a AS SINGLE)

CREATE Form AS QFORM
  CREATE PosCtl AS QPOSICL
    Left = 10
    Top = 10
    MinH = 0: MaxH = 100: ValueH = 50
    MinV = 0: MaxV = 100: ValueV = 50
    OnChange = PosChange
  END CREATE
END CREATE

SUB PosChange(a AS SINGLE)
  Form.Caption = STR$(PosCtl.ValueH) + ", " + STR$(PosCtl.ValueV)
END SUB
