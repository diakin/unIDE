QSQLTABLE Component

Extends QOBJECT · source: inc/qdataBaseSQL.inc, line 476 · author: Alberto (from Brasil) (netmask@ig.com.br)

ODBC SQL query object that runs SQL statements on an Access, dBase, Paradox, Excel or text database and moves through the result rows.

qSQLTABLE opens its own ODBC connection with DataBaseConnect (same driver numbers as qDATABASE), or uses a statement handle from qDATABASE.GetSTMT through DataBaseExtends. The statement uses a keyset-driven cursor so the result can be scrolled with SQLFetchScroll.

OpenSQL runs a SELECT, stores the column names in FieldName, counts the rows into RecCount and loads the first row as text into strData. MoveFirst, MoveLast, MoveNext and MovePreview scroll the cursor and reload strData. ExecSQL runs a statement that returns no rows. All functions return "0" on success or an error message.

QSQLTABLE inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • ODBC drivers for the chosen file type
  • qDATABASE (optional, for DataBaseExtends)

qSQLTABLE Methods

MethodTypeDescription
DataBaseConnectFUNCTION(DatabasePath AS STRING, DriverNum AS INTEGER) AS STRINGDataBaseConnect(DatabasePath, DriverNum) opens an ODBC connection and statement handle; returns "0" or an error message.
DataBaseExtendsFUNCTION(DBSTMT AS LONG) AS STRINGDataBaseExtends(DBSTMT) uses a statement handle from qDATABASE.GetSTMT instead of opening a connection; returns "0", or an error if the handle is -1.
ExecSQLFUNCTION(xSQL AS STRING) AS STRINGExecSQL(SQL) executes a statement (for example INSERT, UPDATE, DELETE) and closes the cursor; returns "0" or an error message.
OpenSQLFUNCTION(sSQL AS STRING) AS STRINGOpenSQL(SQL) executes a query, reads column names, counts rows and loads the first row; returns "0" or an error message.
MoveFirstFUNCTION AS STRINGMoves to the first row and reloads strData.
MoveLastFUNCTION AS STRINGMoves to the last row and reloads strData.
MoveNextFUNCTION AS STRINGMoves to the next row, if any, and reloads strData.
MovePreviewFUNCTION AS STRINGMoves to the previous row, if any, and reloads strData (the name means 'previous').
CloseSQLSUBCloses the cursor of the last OpenSQL and clears strSQL, FieldName, strData and FieldCount.
CloseDataBaseSUBFrees the statement handle; if the object owns its connection (not DataBaseExtends), also disconnects and frees the connection and environment.

Notes

  • The header comment lists SeekRec(RecNumber) as 'Not Implemented'; there is no such method.
  • If SQLDriverConnect or SQLAllocStmt fails, Connect shows a message box but still returns "0".
  • Values are read as text into a 255-byte buffer, so longer field values are cut off. FieldName and strData hold at most 255 columns.
  • The Excel driver name in UseDriver is in Portuguese ("Driver para o Microsoft Excel(*.xls)").

qSQLTABLE Examples

Example written for this page from the members above; not run.

DIM T AS qSQLTABLE
IF T.DataBaseConnect("C:\data\test.mdb", dbMSACCESS) = "0" THEN
  IF T.OpenSQL("SELECT * FROM Customers") = "0" THEN
    FOR i = 1 TO T.RecCount
      PRINT T.strData(1); " "; T.strData(2)
      T.MoveNext
    NEXT
    T.CloseSQL
  END IF
  T.CloseDataBase
END IF
