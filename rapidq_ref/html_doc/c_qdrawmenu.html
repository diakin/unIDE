QDRAWMENU Component

Extends QOBJECT · source: inc/QDrawMenu.inc, line 77 · version: 1.3

A non-visual helper that makes menu items owner-drawn so they show a bitmap next to the caption, optionally with a raised button frame.

AddBitmap changes a QMenuItem to an owner-drawn item with the Windows API ModifyMenu and stores the picture for its command number. The form's WndProc must be set to the component's MenuProc; it answers WM_MEASUREITEM with a size that fits the picture and caption, and on WM_DRAWITEM paints the background, the picture and the caption with system menu colours (highlighted, grayed or normal).

The character after & in a caption is drawn with an extra font style to mark the accelerator. When the button option is used, the selection highlight leaves the picture area out and a raised 3D frame is drawn around the picture of the selected item.

DelBitmap turns the item back into a normal text item. The source comments are in French.

QDRAWMENU inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • the form's WndProc set to MenuProc
  • when __RQINC2 is not defined, the file declares the TMEASUREITEMSTRUCT/TDRAWITEMSTRUCT types, the global MeasureItem, DrawItem and Mem variables, the menu constants, GetSysColor and ModifyMenu itself; when __RQINC2 is defined (RapidQ2.inc included) this block is skipped
  • $RESOURCE bitmaps: the demo code in the file uses \rapidQ\icon\play.bmp

QdrawMenu Methods

MethodTypeDescription
MenuProcSUB(hwnd AS LONG,uMsg AS LONG,wParam AS LONG,lParam AS LONG)Window procedure to assign to the form's WndProc. Handles WM_MEASUREITEM and WM_DRAWITEM for owner-drawn menu items: measures the item from the picture and caption and draws the picture, caption and highlight.
AddBitmapSUB(SubMenu as Qmenuitem,item as Qmenuitem,picture as Qbitmap,button as boolean,backcolor as long)AddBitmap(SubMenu, item, picture, button, backcolor) makes item (in SubMenu) owner-drawn, keeps its disabled state, stores a copy of picture for the item's command number with backcolor as its transparent colour, and when button is True draws it with a raised frame.
DelBitmapSUB(SubMenu as Qmenuitem,item as Qmenuitem)DelBitmap(SubMenu, item) changes item back to a normal string menu item (keeping its disabled state) and clears the transparent flag of its stored picture.

Notes

  • The demo program after END TYPE (eight $RESOURCE lines, the form and its SUBs) is not commented out, so including QDrawMenu.inc compiles and runs the demo; it must be removed before using the file as a library.
  • The demo's $RESOURCE lines use the absolute path \rapidQ\icon\play.bmp for all eight bitmaps.
  • Pictures and button flags are stored in arrays image(10000) and button(10000) indexed by the menu item's command number, so 10001 QBitmap objects are allocated and items with command numbers above 10000 cannot be used.
  • MenuProc handles only menu messages and is meant to be the form's WndProc; it does not call any other handler.

Other versions

QdrawMenu Examples

Example from the comments in the source file.

$RESOURCE Open_bmp as "\rapidQ\icon\play.bmp"
declare SUB Show
dim menu as qdrawmenu
dim picture as qbitmap

CREATE Form AS QForm
  Center
  Caption = "Ownerdraw Menus"
  OnShow=show
  WndProc=menu.MenuProc
  CREATE MainMenu AS QMainMenu
    CREATE FileMenu AS QMenuItem
      Caption = "&File"
      CREATE OpenItem AS QMenuItem
        Caption = "&Open"
      END CREATE
    END CREATE
  END CREATE
END CREATE
Form.ShowModal

Sub Show
  picture.bmpHandle=Open_bmp
  menu.AddBitmap(FileMenu,OpenItem,picture,true,&hC0C0C0)
End Sub
