QCHART Component

Extends QCANVAS · source: inc/QChart.inc, line 252 · author: Michael J. Zito · version: Build 3.6.04 · date: 2003-2004

QChart is a QCanvas-based charting class that draws bar, histogram, line, XY scatter, pie, box, hi-lo and real-time charts into an off-screen bitmap.

QChart extends QCanvas and draws every chart into a private off-screen QBITMAP buffer with GDI calls from gdi32 (CreatePen, CreateSolidBrush, CreateHatchBrush, Rectangle, Pie, LineTo and others). PaintChart copies the buffer to the canvas, so it should be assigned to the OnPaint event; RedrawChart resizes the buffer and should be called from the form's OnResize. Each chart routine computes an axis scale automatically unless XAxis.AutoScale or YAxis.AutoScale is FALSE.

Typical use: create the instance with a parent, call Initialize, set ChartType (ctBar, ctLine, ctBarLine, ctBox, ctPie, ctHiLo, ctXY, ctReal) and ChartStyle (csHisto, csBar, csStacked, csPctStacked, csPoints, csLines, csBoth, csAntenna, csHiLoBox, csPiePct, csPieVal), set Cols and Rows, REDIM Data (or XYData for XY charts) using the instance name explicitly, fill LegendList, LabelList and the data, then call DrawChart. Box plots need 5 rows (Max, Q3, Median, Q1, Min), HiLo plots 3 rows (Hi, Close, Lo), pie charts 1 column, BarLine charts 2 columns (bars, then line).

The chart can be printed (PrintChart), copied to the clipboard as a bitmap (CopyToClipboard) or saved as a .bmp file (SaveChart, SaveToFile). The header states it is released under the LGPL (written "LPGL") and refers to QChartEx.rqb and an HTML document for more examples.

Original documentation: QChart guide by Michael J. Zito (2003).

QCHART inherits the properties, methods and events of QCANVAS; the tables below list only what the component adds or redefines (public members).

QCHART Methods

MethodTypeDescription
InitializeSUBSets default values: buffer size from ClientWidth/ClientHeight, borders, legend, axis options, fonts, series styles; clears the titles, LegendList and LabelList; sets Cols and Rows to 1, ChartType to ctXY and ChartStyle to csPoints. Call it first, then set ChartType and the other properties.
PaintChartSUBDraws the off-screen buffer onto the canvas. Assign it to the OnPaint event of the QChart.
ClearAllSUBCalls Initialize, erases the buffer and repaints, giving an empty chart.
DrawChartSUB(Overlay AS INTEGER)DrawChart(Overlay) draws the chart selected by ChartType from the current data and repaints the canvas. With Overlay FALSE the buffer is cleared and axes, titles, labels and legend are redrawn; with Overlay TRUE only the data is drawn over the existing chart.
RedrawChartSUBResizes the buffer to the current client size and redraws the chart if ChartExists is TRUE. The comment says to call it from the form's OnResize event.
PrintChartSUBPrintChart(Prn, Orient, Margin, Copies, Colr) redraws the chart at page size (fonts and markers x3, autoscaling kept off) and prints it on printer index Prn with orientation Orient (0 = portrait), the given margin and number of copies; Colr FALSE prints in black and white. Afterwards it restores the screen settings and redraws.
CopyToClipboardSUB(Wid AS INTEGER, Hgt AS INTEGER)CopyToClipboard(Wid, Hgt) redraws the chart at Wid x Hgt pixels with fonts scaled accordingly, puts the bitmap on the clipboard and then redraws the chart at screen size.
SaveChartSUB(SaveAs AS BYTE)SaveChart(SaveAs) saves the buffer as a .bmp file. If the chart was saved before and SaveAs is FALSE it overwrites the same file; otherwise it shows dlgSaveQC ("Save Graph" or "Save Graph As"), adds .bmp if missing and asks before overwriting an existing file.
SaveToFileSUB(FileName AS String)SaveToFile(FileName) writes the buffer as a bitmap to FileName without any dialog or overwrite check.

Notes

  • The header warns that there is little error checking: the user must format the data correctly before calling each routine.
  • Data and XYData must be REDIMmed with the instance name written out, even inside a WITH block; the header calls this a RapidQ quirk.
  • Initialize sets ChartType to ctXY and ChartStyle to csPoints, so ChartType and ChartStyle must be set after calling Initialize.
  • The constructor sets FgColor to Colors(23) (bright magenta), PlotAreaColor to Colors(4) (cyan) and GridColor to Colors(25) (orange), while the comments next to them still say black, light grey and dark grey; these fields are marked "!!!" in the declarations and the original defaults are commented out in Initialize.
  • Logarithmic scaling of a value <= 0 shows a message box ("qcLog10: Log of Value <= 0 Undefined") and the chart is cleared.
  • At most 26 series (MaxSeries); title texts are fixed strings of 75 characters.
  • PrintChart uses hard-coded buffer sizes (1920 x 2400 portrait, 2560 x 1920 landscape), and computes the page rectangle from the control's own .Left and .Top inside WITH QCHART.
  • Setting BW or GreyScale also overwrites XAxis.ZeroColor and YAxis.ZeroColor with Colors(0); they are not restored when the option is turned off.
  • SaveChart and SaveToFile only write BMP files.

QCHART Examples

Example from the comments in the source file.

$INCLUDE "QChart.inc"
CREATE YourInstanceName AS QChart
  Parent = Form
END CREATE
WITH YourInstanceName
  .Initialize
  .ChartType = ctBar
  .ChartStyle = csBar
  .Cols = 2
  .Rows = 2
  REDIM YourInstanceName.Data(.Cols, .Rows)
  ' load data into .LabelList, .LegendList and .Data
  .DrawChart(FALSE)
END WITH
