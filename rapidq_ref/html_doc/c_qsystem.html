QSYSTEM Component

Extends QOBJECT · source: inc/rapidq2.inc, line 7503 · author: JohnK · version: 1.0c · date: 8/2006

A non-visual object that reports Windows system information (OS version, memory, disk space, power and system metrics) and can open Control Panel applets, sleep, hibernate, log off, shut down or reboot.

QSYSTEM wraps Windows API calls declared earlier in rapidq2.inc: GetVersionEx for the OS name and version numbers, GlobalMemoryStatus for memory figures, GetDiskFreeSpaceEx for free disk space, GetSystemMetrics for screen element sizes and flags, and GetSystemPowerStatus / SetSuspendState for power status and sleep or hibernation.

The constructor reads the power status and the OS version, so MajorVersion, MinorVersion, BuildNumber, ACLineStatus, PercentBattery and PowerStatus are filled when the object is created. ShowControlPanel starts rundll32.exe shell32.dll,Control_RunDLL with the .cpl file chosen from the first four letters of a panel name. ShutDown, ShutDownForce, LogOff and Reboot first enable the SeShutdownPrivilege for the process and then call ExitWindowsEx.

QSYSTEM inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • API declarations and constants in rapidq2.inc (OSVERSIONINFO, SYSTEM_POWER_STATUS, MEMORYSTATUS, SM_ and EWX_ constants, token privilege functions)
  • Powrprof.dll (SetSuspendState)

FieldTypeR/WDefaultDescription

BuildNumberINTEGERRWWindows build number, filled by OSName$.
ACLineStatusINTEGERRWAC power line status from GetSystemPowerStatus (AC_LINE_OFFLINE, AC_LINE_ONLINE, AC_LINE_BACKUP_POWER or AC_LINE_UNKNOWN); refreshed when PowerStatus is assigned 0.

Notes

  • OSName$ reports every NT 6.x version (including Windows 7) as "Windows Vista" and anything newer as "Newer than Vista".
  • SetSuspendState's first parameter is Hibernate; the code passes 0 for sysHibernateAsk/sysHibernateForce and 1 for sysSleepAsk/sysSleepForce, which looks swapped.
  • A comment says SetSystemPowerState must be used instead before Windows 98.
  • The SetPowerStatus setter assigns RESULT, which has no effect in a property setter.
  • ShowControlPanel: the "SYST" case has no comma before the index ("sysdm.cpl @0"+STR$(index)), and the "ADD " case puts the comparison inside UCASE$(LEFT$(PanelName, 12) = ...), so those branches may not work as intended.
  • Memory figures come from GlobalMemoryStatus with 32-bit DWORD fields.

QSYSTEM Examples

Example written for this page from the members above; not run.

$INCLUDE "rapidq2.inc"

DIM Sys AS QSYSTEM
ShowMessage Sys.OSName$ + " build " + STR$(Sys.BuildNumber)
ShowMessage "Free memory: " + STR$(Sys.PercentFreeMemory) + "%"
ShowMessage "Free on C: " + STR$(Sys.DiskFreeSpace("C:")) + " MB"
Sys.PowerStatus = 0
ShowMessage "Battery: " + STR$(Sys.PercentBattery) + "%"
