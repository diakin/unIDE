QD3DCAMERA Component

Extends QOBJECT · source: inc/RapidQ_D3D.inc, line 321 · author: JohnK · version: 1.1 · date: 10/2004

A non-visual camera helper for RapidQ Direct3D (QDXSCREEN) programs that keeps a camera position and orientation and applies them to a QDXSCREEN.

QD3DCamera is described in the source as a useful alternative to calling DXSCREEN.SetCameraXXXX directly. It stores the camera position (Pos) and a 6-element orientation vector (Orient: the view direction X, Y, Z plus the up vector DVX, DVY, DVZ) and offers methods to move, zoom and reset the camera.

Nothing is sent to Direct3D until you call Update with your QDXSCREEN; Update calls SetCameraPosition and SetCameraOrientation on that screen. Rendering and flipping are left to the caller (the Render/Flip calls are commented out).

The component also has fields for mouse-driven zooming (MouseDownButton, MouseDownX, MouseDownY, MouseZooming) and SaveMouse/RestoreMouse, which store a mouse position and later move the cursor back with the Windows API SetCursorPos.

QD3DCAMERA inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • QDXSCREEN (RapidQ DirectX screen) passed to Update
  • SetCursorPos (user32) must be declared by the program; RestoreMouse calls it but RapidQ_D3D.inc does not declare it
  • the constant MouseNotDown, used in the constructor but not defined in RapidQ_D3D.inc
  • QD3DVECTOR and QD3DOrientVector types (QD3DOrientVector is defined in RapidQ_D3D.inc)
  • d3drm.dll (Direct3D Retained Mode); RapidQ_D3D.inc DECLAREs D3DRMVectorCrossProduct, D3DRMVectorDotProduct and D3DRMVectorNormalize from it, although the component itself does not call them

QD3DCamera Properties

FieldTypeR/WDefaultDescription
PosQD3DVECTORRWCamera position as a QD3DVECTOR (x, y, z); starts at the origin.
OrientQD3DORIENTVECTORRWCamera orientation as a QD3DOrientVector: X, Y, Z is the view direction and DVX, DVY, DVZ the up vector; starts looking down the z-axis with up = (0, 1, 0).
HeightSINGLERW1.0Offset of the camera in the up (y) direction, default 1.0. It is only stored; no method of the component uses it.
ZoomFactorSINGLERW1.0Zoom amount, default 1.0. It is only stored; no method of the component uses it.
AngleXINTEGERRW0Integer angle index meant for sin/cos look-up tables (per the comment). Only stored and reset to 0 by ResetView.
AngleYINTEGERRW0Integer angle index for sin/cos look-up tables, also used for the up/down vector (per the comment). Only stored and reset to 0 by ResetView.
MouseDownButtonINTEGERRWMouseNotDownSignals which mouse button is down for dynamic zooming; initialised to MouseNotDown. Not used by the component's methods.
MouseDownXINTEGERRW0X coordinate where the mouse was pressed for dynamic zooming; SaveMouse copies it into private storage.
MouseDownYINTEGERRW0Y coordinate where the mouse was pressed for dynamic zooming; SaveMouse copies it into private storage.
MouseZoomingINTEGERRWFalseFlag that the mouse was used for zooming; initialised to False. Not used by the component's methods.

QD3DCamera Methods

MethodTypeDescription
GetRadiusFUNCTION AS SINGLEReturns the distance of the camera from the origin, SQR(x*x + y*y + z*z) of Pos.
GetXZRadiusFUNCTION AS SINGLEReturns the distance of the camera from the origin in the x-z plane, SQR(x*x + z*z).
GetXYRadiusFUNCTION AS SINGLEReturns the distance of the camera from the origin in the x-y plane, SQR(x*x + y*y).
TranslateSUB(dx AS SINGLE, dy AS SINGLE, dz AS SINGLE)Translate(dx, dy, dz) adds the given offsets to Pos.
ZoomXZSUB(Mag AS SINGLE)ZoomXZ(Mag) moves the camera forward or back along its orientation in the x-z plane only (Pos.x and Pos.z change by Orient.x*Mag and Orient.z*Mag).
ZoomSUB(Mag AS SINGLE)Zoom(Mag) moves the camera forward or back along its full orientation vector (x, y and z).
ResetViewSUBResets Orient to look straight down the z-axis with up vector (0, 1, 0) and sets AngleX and AngleY to 0; Pos is not changed.
FaceCameraSUB(BYREF Orient AS QD3DOrientVector, ObjPosX AS SINGLE, ObjPosY AS SINGLE, ObjPosZ AS SINGLE)FaceCamera(Orient, ObjPosX, ObjPosY, ObjPosZ) fills the given orientation vector so that an object at that position faces along the line from the camera to the object (billboarding). The up vector is copied from the camera; if the object is closer than 0.01 the direction is left unchanged.
UpdateSUB(DxScrn AS QDXSCREEN)Update(DxScrn) sends Pos and Orient to the QDXSCREEN with SetCameraPosition and SetCameraOrientation. It does not render or flip.
SaveMouseSUBStores the current MouseDownX and MouseDownY values in private fields.
RestoreMouseSUBMoves the mouse cursor back to the position stored by SaveMouse using the Windows API SetCursorPos.

Notes

  • The constructor uses the constant MouseNotDown and RestoreMouse calls SetCursorPos; neither is defined or declared in RapidQ_D3D.inc, so the program must provide them.
  • Height, ZoomFactor, MouseDownButton and MouseZooming are only stored; no method uses them.
  • The comment on GetXYRadius says x-z plane, but the code computes the radius in the x-y plane.
  • Update does not call Render or Flip (they are commented out with the note 'may not want these').

QD3DCamera Examples

Example written for this page from the members above; not run.

$INCLUDE "RapidQ_D3D.inc"
DIM Camera AS QD3DCamera
' DXScreen is a QDXSCREEN on your form
SUB MoveForward
  Camera.Zoom(0.5)
  Camera.Update(DXScreen)
  DXScreen.Render
  DXScreen.Flip
END SUB
Camera.Pos.z = -5
Camera.ResetView
