SUB changeE

Internal helper of the expression evaluator: rewrites exponent notation in formula$, turning 'e<digit>' into '*10^' and 'e-' into '*1/10^'. Any other unexpected 'e' shows "Syntax error." and sets EvaluateErrorFlag to 1.

CheckE

SUB · rapidqAllProc.inc, line 11945

SUB CheckE(newstring$ AS STRING)

Internal helper of the expression evaluator: converts a number string in scientific notation (with 'E' and a negative exponent) in newstring$ into plain decimal form in place. Exits unchanged if there is no 'E' or the exponent is 14 or more.

EvaluateExpression

FUNCTION · rapidqAllProc.inc, line 11939

FUNCTION EvaluateExpression (BYREF MathString$ AS STRING, DRGMode AS BYTE) AS DOUBLE

Evaluates a mathematical expression string such as sin(.1)^2-3e2*ln(tan(.1*PI)). DRGMode selects angle units: 0 degrees, 1 radians, 2 grads. Returns the result, or 0 if an error occurred; check the global EvaluateErrorFlag (0 = success). Uses the globals formula$ and EvaluateAnswer.
