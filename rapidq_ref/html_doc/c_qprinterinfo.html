QPRINTERINFO Component

Extends QOBJECT · source: inc/QPrinterInfo.inc, line 21 · version: 1.0

A non-visual object that returns printer page sizes, margins and resolution and converts between millimeters and printer pixels.

All functions call GetDeviceCaps (gdi32) on the device context of the RapidQ Printer object (Printer.Handle). Ppm is the number of printer pixels per millimeter (HORZRES / HORZSIZE) and is used by the conversion and physical size functions; Scale compares the printer's horizontal DPI with the screen's.

Typical use: compute positions in millimeters and convert them with MetricToPixel before drawing on Printer, taking PhLeftMargin and PhTopMargin into account.

QPRINTERINFO inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • The RapidQ Printer object (Printer.Handle)

QPrinterInfo Methods

MethodTypeDescription
ScaleFUNCTION AS DOUBLEReturns the printer's horizontal logical DPI divided by the screen's horizontal logical DPI.
DpiFUNCTION AS INTEGERReturns the printer's horizontal resolution in dots per inch (LOGPIXELSX).
PpmFUNCTION AS DOUBLEReturns the printer's horizontal pixels per millimeter (HORZRES / HORZSIZE).
MetricToPixelFUNCTION(mm as double) AS INTEGERConverts a length in millimeters to printer pixels, rounded.
PixelToMetricFUNCTION(pixel as integer) AS DOUBLEConverts a length in printer pixels to millimeters.
HorzPageSizeFUNCTION AS INTEGERReturns the width of the printable area in millimeters (HORZSIZE).
VertPageSizeFUNCTION AS INTEGERReturns the height of the printable area in millimeters (VERTSIZE).
PageWidthFUNCTION AS INTEGERReturns the width of the printable area in pixels (HORZRES).
PageHeightFUNCTION AS INTEGERReturns the height of the printable area in pixels (VERTRES).
PhWidthFUNCTION AS INTEGERReturns the physical page width in device units (PHYSICALWIDTH).
PhHeightFUNCTION AS INTEGERReturns the physical page height in device units (PHYSICALHEIGHT).
PhHorzFUNCTION AS INTEGERReturns the physical page width in millimeters, rounded.
PhVertFUNCTION AS INTEGERReturns the physical page height in millimeters, rounded.
PhMarginXFUNCTION AS DOUBLEReturns the left unprintable margin in millimeters (PHYSICALOFFSETX).
PhMarginYFUNCTION AS DOUBLEReturns the top unprintable margin in millimeters (PHYSICALOFFSETY).
PhLeftMarginFUNCTION AS INTEGERReturns the left unprintable margin in pixels (PHYSICALOFFSETX).
PhTopMarginFUNCTION AS INTEGERReturns the top unprintable margin in pixels (PHYSICALOFFSETY).

Notes

  • Vertical conversions (PhVert, PhMarginY) also use Ppm, which is computed from horizontal values only, so they are only correct when the printer has the same horizontal and vertical resolution.

QPrinterInfo Examples

Example written for this page from the members above; not run.

$INCLUDE "QPrinterInfo.inc"

DIM PInfo AS QPrinterInfo
ShowMessage "Printer DPI: " + STR$(PInfo.Dpi)
ShowMessage "Page: " + STR$(PInfo.HorzPageSize) + " x " + STR$(PInfo.VertPageSize) + " mm"
