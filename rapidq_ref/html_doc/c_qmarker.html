QMARKER Component

Extends QPANEL · source: inc/QMarker.inc, line 3

A panel that shows a vertical column of colored row strips, used to mark individual rows with a color or a bitmap.

QMarker extends QPanel and owns an array of 201 child QPanel objects (Row(0) to Row(200)). Draw lays them out one under another, each RowHeight pixels high and as wide as the marker, and paints them with RowColor (default &HC0C0C0).

SetMark changes the color of one row. SetImage places the Mark QImage inside a row and shows the bitmap compiled in from the resource Bit_Res (file Mark.bmp), aligned to fill the row, stretched and transparent. A typical use is a margin next to a list or editor that highlights the current or marked lines.

QMARKER inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

Requires

  • $RESOURCE Bit_Res AS "Mark.bmp" (the file Mark.bmp must exist at compile time)

QMarker Methods

MethodTypeDescription
DrawSUBCreates the layout: for each row index it sets Parent, Color (RowColor), Width (the marker width), Height (RowHeight) and Top (index * RowHeight). Call it again after changing Height or RowHeight.
SetMarkSUB(ARow as integer,AColor as integer)SetMark(ARow, AColor) sets the background color of row ARow to AColor.
SetImageSUB(ARow as integer)SetImage(ARow) moves the Mark image into row ARow and shows the Bit_Res bitmap there, transparent, stretched and aligned to fill the row (Align = 5).

Notes

  • Draw loops FOR i = 0 TO .Height instead of using the computed row count NoRow (which is calculated but never used), so it touches one Row per pixel of height; a marker taller than 200 pixels indexes past the end of the Row(200) array.
  • The constructor calls Draw while RowHeight is still 0 (its default assignment is commented out), so the first Draw divides by zero and stacks all rows at Top = 0.
  • MarkColor is declared but never used.
  • The bitmap is fixed at compile time by $RESOURCE Bit_Res AS "Mark.bmp"; there is no property to change it.
