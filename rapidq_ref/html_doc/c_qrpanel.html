QRPANEL Component

Extends QPANEL · source: inc/QrPanel.inc, line 17 · date: 1st of April 2004

A QPanel with rounded corners, made by applying a rounded-rectangle window region.

QrPanel is described in its header as a sister component to QRFORM. Assigning rBorder = 1 creates a rounded-rectangle region with CreateRoundRectRgn from the panel's current Width and Height and the corner sizes RndX and RndY, and applies it with SetWindowRgn.

RndX and RndY control how round the corners are (default 20); per the comments, values large enough make a completely round panel. Set the size and RndX/RndY first, then assign rBorder.

QRPANEL inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

QrPanel Properties

FieldTypeR/WDefaultDescription
RndXLONGRW20Width of the ellipse used for the rounded corners (default 20). Used the next time rBorder is assigned.
RndYLONGRW20Height of the ellipse used for the rounded corners (default 20). Used the next time rBorder is assigned.
rBorderBYTERW0Assigning a value greater than 0 rounds the panel corners by applying a rounded-rectangle region built from the current Width, Height, RndX and RndY; assigning 0 only stores the value.

Notes

  • The region is computed once from the size at the time rBorder is assigned; resizing the panel later does not update it.
  • Assigning rBorder = 0 does not remove an existing region.
  • DeleteObject is declared but not used.

QrPanel Examples

Example written for this page from the members above; not run.

$INCLUDE "QrPanel.inc"
CREATE Form AS QFORM
  Caption = "Rounded panel"
END CREATE
DIM Panel AS QrPanel
Panel.Parent = Form
Panel.Left = 20
Panel.Top = 20
Panel.Width = 150
Panel.Height = 100
Panel.RndX = 30
Panel.RndY = 30
Panel.rBorder = 1
Form.ShowModal
