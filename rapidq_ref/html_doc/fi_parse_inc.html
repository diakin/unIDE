function GetCharNum (Oper$ as string, getC as string) as long

Counts how many times the character getC occurs in the source line Oper$ outside quoted strings. If a ' comment comes before the first quote, the line is cut at the comment and TALLY is used. Uses the global constant qt (double quote); may modify Oper$.

GetOperators

SUB · RQProc.inc, line 5556

sub GetOperators (Oper$() as string,OperPos() as integer, SrcTxt$ as string,NumOpers as long)

Splits source text SrcTxt$ into statements separated by ':' outside strings, after blanking comments and joining '_' continuation lines. Fills Oper$() with the statements and OperPos() with their start positions; NumOpers receives the count. Arrays must be large enough.

GetVarPos

FUNCTION · RQProc.inc, line 5429

Function GetVarPos (Oper$ as string, getV$ as string) as long

Returns the position of the identifier getV$ in Oper$ (case-insensitive, whole word, bounded by separator characters), ignoring matches inside strings or after a ' comment. Returns 0 if the text is absent and -2 if it is present but not as a variable. Lowercases Oper$ and getV$ in place.

ParseDef

SUB · RQProc.inc, line 5458

sub ParseDef (Var$() as string,VarType$ as string, SrcTxt$ as string, VarCount as long)

Parses a DEFxxx statement (DEFSTR, DEFINT, DEFLNG, DEFSNG, DEFDBL) in SrcTxt$: VarType$ receives the full type name and Var$() the comma separated variable names, VarCount the count (0 if no DEF found). Uppercases SrcTxt$.

ParseDim

sub ParseDim (Var$() as string,VarType$() as string, SrcTxt$ as string, VarCount as long)

Parses a DIM statement in SrcTxt$ (e.g. DIM a AS INTEGER, b AS STRING) into variable names Var$() and types VarType$(); VarCount gets the number found (0 if there is no DIM). Uses GetVarPos and uppercases SrcTxt$.
