FUNCTION · rapidqAllProc.inc, line 10764

Function ConvertToTruePath(ByVal sPath As String) As String

Converts a path to the form shown by the Windows shell (e.g. long names instead of 8.3 short names) by calling SHGetFileInfo with SHGFI_DISPLAYNAME for each folder level. Uses the global structure SFI; result ends with a backslash.
