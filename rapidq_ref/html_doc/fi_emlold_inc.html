Function DecodeSubj1( Subject As String) As String

Variant of the MIME encoded-word header decoder (=?charset?Q|B?...?=): decodes quoted-printable or base64 parts, converts koi8-r, utf-8 and utf-7 to Windows-1251 via RQConvertCodePage1(VARPTR(...)), and applies a KOI8 fix-up if isKOI8 detects it. Returns the decoded subject.

Function DecodeSubjOld( MSubject As String) As String

Older decoder for MIME encoded-word e-mail headers (=?charset?Q|B?text?=). Decodes quoted-printable or base64 parts (RQBASE64Decode) and converts koi8-r, utf-8 or utf-7 to Windows-1251 with RQConvertCodePage1; returns the decoded subject. Kept as an earlier version of DecodeSubj.

DecodeSubjOld1

FUNCTION · rapidqAllProc.inc, line 11692

Function DecodeSubjOld1( Subject As String) As String

Earlier variant of the MIME encoded-word header decoder. Decodes each =?charset?Q|B?...?= part (quoted-printable or base64), converts koi8-r, utf-8 and utf-7 to Windows-1251 with RQConvertCodePage, keeps plain text between parts, and converts the whole result from KOI8 if isKOI8 detects it. Returns the decoded string.
