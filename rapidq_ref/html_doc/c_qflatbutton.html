QFLATBUTTON Component

Extends QIMAGE · source: inc/QFlatButton.inc, line 3

A flat image button derived from QImage that draws a raised border when the mouse is over it and a sunken border while it is pressed.

QFlatButton draws its 3D edges directly on the image with Line, using light (115%) and dark (30%) shades of the system button face color. The color is read from the registry key \Control Panel\Colors, value ButtonFace (default "150 150 150"), and split into the R, G and B fields.

OnMouseMove raises the button while the mouse is more than 3 pixels inside its edges and flattens it otherwise; OnMouseDown depresses it and OnMouseUp flattens it. CurrState uses the constants fbFlattened (0), fbRaised (1) and fbDepressed (2). The header refers to "Appendix A QFLATBUTTON.htm" for usage and thanks Erlend Rovik for the OnMouseDown/Up suggestion.

QFLATBUTTON inherits the properties, methods and events of QIMAGE; the tables below list only what the component adds or redefines (public members).

CurrStateINTEGERRW0Current drawing state: fbFlattened (0), fbRaised (1) or fbDepressed (2).
FlatBMPHandleSTRINGRWInternal: copy of BMPHandle saved by Depress and restored by Flatten.

QFlatButton Methods

MethodTypeDescription
GetColorsSUBReads the ButtonFace color from the registry and stores it in R, G and B.
DepressSUBDraws the sunken border (dark top and left, light bottom and right) and sets CurrState to 2.
FlattenSUBRestores the saved image without border and sets CurrState to 0.
RaiseSUBDraws the raised border (light top and left, dark bottom and right) and sets CurrState to 1.

The component handles these events itself (EVENT blocks in the TYPE): OnMouseDown, OnMouseMove, OnMouseUp.

Notes

  • In Depress the light bottom line ends at x = Height - 1 instead of Width - 1, so it is too short on buttons wider than they are high.
  • FlatBMPHandle is only saved in Depress; Flatten after a Raise without an earlier Depress restores an empty value.

QFlatButton Examples

Example written for this page from the members above; not run.

$INCLUDE "QFlatButton.inc"

SUB BtnClick
  ShowMessage "Clicked"
END SUB

CREATE Form AS QFORM
  CREATE Btn AS QFLATBUTTON
    Left = 10
    Top = 10
    BMP = "open.bmp"
    OnClick = BtnClick
  END CREATE
END CREATE
Form.ShowModal
