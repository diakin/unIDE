QXEDIT Component

Extends QEDIT · source: inc/QxEdit.inc, line 28 · author: psyclops420 <psyclops420@yahoo.com> · version: 1.1

QEdit replacement that subclasses the edit window to add OnGetFocus and OnLoseFocus events, a WndProc event and an option to make Enter move to the next control.

Shortly after creation, an internal timer (Interval 1) replaces the edit's window procedure with Proc using SetWindowLong(GWL_WNDPROC) and CODEPTR. Proc passes each message to the original procedure with CallWindowProc, then fires OnGetFocus on WM_SETFOCUS (&H7), OnLoseFocus on WM_KILLFOCUS (&H8), and the WndProc event for every message.

When EnterKey is nonzero, pressing Enter removes the WM_CHAR message for the parent with KillMessage and sends WM_NEXTDLGCTL (&H28) to the parent, moving focus as Tab does. The constants ekNormal (0) and ekTab (1) are defined for it.

At the end of the file, QEDIT is redefined as QxEDIT, so every QEDIT declared after the include becomes a QxEDIT. The comments say focus event handlers must take the Sender parameter.

QXEDIT inherits the properties, methods and events of QEDIT; the tables below list only what the component adds or redefines (public members).

The component handles these events itself (EVENT blocks in the TYPE): Tmr.OnTimer.

Notes

  • The include redefines QEDIT as QxEDIT for all code that follows it.
  • The comments say custom events must have at least one parameter, and the author had not found a way around this.
  • The window procedure is installed by a 1 ms timer after creation, so messages sent before the timer fires do not reach the new events.

QxEDIT Examples

Example written for this page from the members above; not run.

$INCLUDE "QxEdit.inc"
DIM Form AS QFORM
DIM Edit1 AS QEDIT   ' becomes QxEDIT
DIM Edit2 AS QEDIT
SUB EditFocus(Sender AS QEDIT)
  Form.Caption = "Editing " + Sender.Text
END SUB
Edit1.Parent = Form
Edit2.Parent = Form
Edit2.Top = 30
Edit1.EnterKey = ekTab
Edit1.OnGetFocus = EditFocus
Form.ShowModal
