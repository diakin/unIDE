QIMAGEDIALOG Component

Extends QOBJECT · source: inc/QImageDialog.inc, line 55 · version: 1.1

Custom open-file dialog built from RapidQ controls that shows a scaled preview of the selected image.

QImageDialog builds its own modal QForm with a drive combo box, folder and file lists, a file-name edit, a file-type combo box, Open and Cancel buttons and a scroll box with a QImage preview. Clicking a file shows it scaled to fit a 220x220 box.

BMP files are loaded directly. ICO files are loaded with LoadImage, and CUR and ANI files have their first icon extracted with ExtractIcon. GIF, JPG, JIF, DIB, RLE, TGA and PCX files are loaded with NViewLib.dll, which must be in the program folder or the Windows system folder; otherwise no preview is shown.

Set Filter (pairs of 'description|mask' separated by '|'), FilterIndex and InitialDir, then call Execute. It returns True when the user clicks Open with a file name, and the full path is in FileName. With MultiSelect on, the selected paths are in Selected.

QIMAGEDIALOG inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • NViewLib.dll (optional, for GIF, JPG, JIF, DIB, RLE, TGA and PCX previews)

QImageDialog Properties

FieldTypeR/WDefaultDescription
FileNameSTRINGRWFull path of the chosen file after Execute. Assigning a value puts its file-name part into the name box and, if its folder exists, switches the folder and file lists to that folder.
CaptionSTRINGRWAssigning it sets the dialog window's caption.
FilterSTRINGRWFile type filter as 'description|mask|description|mask...'; assigning it fills the file-type combo box with the descriptions.

ErrorLanguageSTRINGRWIf not empty, passed to NViewLibSetLanguage before NViewLib loads an image.
MultiSelectBOOLEANRWAssigning it turns multiple selection in the file list on or off.
SelCountINTEGERRWNumber of selected files after Open, set only when more than one file is selected; assigning it does nothing (read only).

QImageDialog Methods

MethodTypeDescription
ExecuteFUNCTION AS BOOLEANShows the dialog modally; returns True if the user clicked Open with a file name, False otherwise.

The component handles these events itself (EVENT blocks in the TYPE): BtCancel.OnClick, BtOpen.OnClick, DirList.OnDblClick, Drive.OnChange, EnterKey.OnClick, FileList.OnClick, FileType.OnChange.

Notes

  • The dialog layout uses hard-coded positions and sizes (form 422x325, preview box 220x220).
  • SelCount and Selected are only filled when more than one file is selected, and SelCount cannot be assigned.
  • Cancel also closes the form with ModalResult 1; Execute returns False because the internal Open flag stays False.
  • Drives are listed by trying A: to Z: with GetDriveType.

QImageDialog Examples

Example written for this page from the members above; not run.

DIM Dlg AS QImageDialog
Dlg.Caption = "Choose a picture"
Dlg.Filter = "Bitmaps|*.bmp|Icons|*.ico|All files|*.*"

IF Dlg.Execute THEN ShowMessage Dlg.FileName
