QCOLORBUTTON Component

Extends QPANEL · source: inc/QColorButton.inc, line 5 · author: Achilles B. Mina · date: Uploaded 7/5/03

QCOLORBUTTON is a small square QPanel that behaves like a push button with a pressed look.

The constructor makes a 26 x 26 panel with BevelInner = 2, color &HEEEEEE and cursor -21. On mouse down BorderStyle is set to 1 and a space is put before the caption, so the button looks pressed; on mouse up BorderStyle goes back to 0 and the space is removed.

Code to play a click sound with SOUND using SndFreq and SndDur is present but commented out, with a comment that it is not XP compatible.

QCOLORBUTTON inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

QCOLORBUTTON Properties

FieldTypeR/WDefaultDescription
SndFreqINTEGERRWIntended frequency of the click sound; it does nothing because the SOUND code that uses it is commented out.
SndDurSINGLERWIntended duration of the click sound; it does nothing because the SOUND code that uses it is commented out.

The component handles these events itself (EVENT blocks in the TYPE): OnMouseDown, OnMouseUp.

Notes

  • SndFreq and SndDur have no effect: the sound code is commented out with the note "XP compatibles ;-(".
  • OnMouseUp removes the added space with Caption - " ", which removes every space in the caption, so captions containing spaces lose them after a click.
  • The component assigns its own OnMouseDown and OnMouseUp handlers.

QCOLORBUTTON Examples

Example written for this page from the members above; not run.

$INCLUDE "QColorButton.inc"
DECLARE SUB BtnClick
CREATE Form AS QFORM
  Caption = "Button"
  CREATE Btn AS QCOLORBUTTON
    Parent = Form
    Caption = "A"
    OnClick = BtnClick
  END CREATE
END CREATE
Form.ShowModal

SUB BtnClick
  ShowMessage "Clicked"
END SUB
