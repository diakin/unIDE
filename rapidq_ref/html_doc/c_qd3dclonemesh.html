QD3DCLONEMESH Component

Extends QOBJECT · source: inc/RapidQ_D3D.inc, line 844 · author: JohnK · version: 1.0 · date: 10/2004

A non-visual helper that shows one QD3DMESHBUILDER (loaded from an X or 3DS file) in up to 100 QD3DFRAMEs, so the same model appears many times in a RapidQ Direct3D scene.

QD3DCloneMesh makes multiple objects from the same mesh. The source notes that arrays of custom objects cannot be made, so this component holds arrays of frames, positions and orientations itself (MaxD3DClones = 100).

Set File, CloneNum, the positions (Pos array, or RandPos with a Range) and Scale, then call Init with your QDXSCREEN. Init creates the mesh builder, loads File, scales the mesh, creates a frame for each clone 1 to CloneNum, adds the mesh to it and moves it to Pos(i).

Assigning Visible later adds the mesh to all frames (True) or removes it (False).

QD3DCLONEMESH inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • QDXSCREEN (RapidQ DirectX screen) passed to Init
  • QD3DMESHBUILDER and QD3DFrame (RapidQ Direct3D objects)
  • an X or 3DS model file named in File
  • a definition of null: New assigns null to File and TextureFile, but RapidQ_D3D.inc only $UNDEFs null at the end and never defines it
  • d3drm.dll (Direct3D Retained Mode); RapidQ_D3D.inc DECLAREs D3DRMVectorCrossProduct, D3DRMVectorDotProduct and D3DRMVectorNormalize from it, although the component itself does not call them

QD3DCloneMesh Methods

MethodTypeDescription
InitSUB(DXscreen AS QDXSCREEN)Init(DXscreen) removes the mesh from old frames if already initialised, creates the mesh builder, loads File, scales the mesh by Scale, then creates frames 1 to CloneNum, adds the mesh to each and positions them at Pos(i).
NewFUNCTION AS INTEGERResets all settings to defaults (not initialised, CloneNum 0, Range -1..1, Scale 1, positions 0, sphere wrap, colour 0). Called by the constructor.

Notes

  • Per-frame scaling is not possible: a commented-out AddScale call in Init is marked 'this crashes', and New has the comment 'can't scale each frame! Bug in program?'. All clones share the mesh scale.
  • Init's comment says the mesh scale 'works on each new load..but you can't remove them'.
  • TextureFile, the TexOrigin/TexScale/TexWrapType fields, Color and the Orient array are only stored; no method uses them.
  • New assigns null to File and TextureFile, but null is not defined in RapidQ_D3D.inc.
  • Frame(0), Pos(0) and Orient(0) exist but are never used; clones are numbered 1 to CloneNum.

QD3DCloneMesh Examples

Example written for this page from the members above; not run.

$INCLUDE "RapidQ_D3D.inc"
DIM Trees AS QD3DCloneMesh
' DXScreen is a QDXSCREEN on your form; call this after it is initialised
SUB PlantTrees
  Trees.File = "tree.x"
  Trees.CloneNum = 20
  Trees.Range.Left = -10
  Trees.Range.Right = 10
  Trees.Range.Bottom = -10
  Trees.Range.Top = 10
  Trees.RandPos = 1
  Trees.Init(DXScreen)
END SUB
