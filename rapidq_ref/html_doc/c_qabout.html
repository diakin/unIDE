QABOUT Component

Extends QOBJECT · source: inc/object/QAbout.inc, line 15 · version: 1.2

QAbout builds and shows a modal "About" dialog with an image, application name and version, a text, and clickable e-mail and web links.

Show lays out a private form: a group box containing the image, a label with AppName and "Version " + AppVersion, the Text, "Email:" + Email and "Web:" + Web, and an Ok button. The dialog size is calculated from the label sizes and it is shown centred with ShowModal.

Clicking the e-mail label opens "mailto:" + Email, and clicking the web label opens Web (with "http://" added if it does not contain "http"), both through ShellExecute from shell32 (declared as AboutExecute). E-mail and web labels use a hand cursor and are drawn in blue when their font color is the default.

QABOUT inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).
