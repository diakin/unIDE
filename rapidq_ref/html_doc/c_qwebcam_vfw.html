QWEBCAM Component

Extends QOBJECT · source: inc/VFW.inc, line 720 · author: John Kelly · date: 2/2005

Webcam capture component that creates a Video for Windows (avicap32) capture window on a form for live preview, frame callbacks and frame grabbing.

QWebCam wraps the Video for Windows capture API. CamInit creates a child capture window with capCreateCaptureWindow on the given form, sets the capture parameters (frame interval, yield, number of video buffers, no audio), connects to driver CamNum and turns on overlay and preview if available. The other cap* helpers in VFW.inc send WM_CAP_* messages to that window.

A frame callback can be set through OnFrame by passing the address of a function (CODEPTR). The source gives the template FUNCTION capVideoStreamCallback(hCapWnd AS LONG, lpVHdr AS VIDEOHDR) AS LONG. Image size and bit depth are changed through the video format (capGetVideoFormat/capSetVideoFormat). Capture starts streaming with no file. SaveFrameToFile writes the current frame as a DIB file. ShowDialogBox opens the driver's format, source, display or compression dialog.

Call CleanUp before closing to stop preview and capture, disconnect the driver and destroy the capture window.

QWEBCAM inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • SetWindowPos declaration from a Windows API include (used by ReSize, not declared in this file)
  • A Video for Windows capture driver

Notes

  • The source comment says OnFrame cannot be a real EVENT because function pointers do not give an absolute address; pass a CODEPTR address instead.
  • FrameInterval is used both as microseconds per frame (capture parameters) and as milliseconds (preview rate); a comment says 3333 = 30 frames per second.
  • GrabFrameToClipBoard does not return the bitmap; a local QBITMAP is declared but unused. The error text reads 'Cliboard'.
  • SetImageWidth is declared as SUB ... AS LONG, and ShowDialogBox is a FUNCTION that ends with END SUB.
  • ReSize calls SetWindowPos, which this file does not declare.
  • SetYield sends the capture setup even before CamInit has created the window.
  • In the constructor, ImageHeight and ImageWidth are assigned from SetImageHeight/SetImageWidth, which return no value while the camera is not initialized.

Other versions

QWebCam Examples

Example written for this page from the members above; not run.

$INCLUDE "VFW.inc"
DIM Form AS QFORM
DIM Cam AS QWebCam
Cam.ShowErrors = 1
IF Cam.CamInit(Form) THEN
  Cam.ReSize(Form)
END IF
Form.ShowModal
Cam.SaveFrameToFile("frame.bmp")
Cam.CleanUp
