QGAUGE Component

QGauge is a sophisticated progress monitor. Used visually to give users the progress of an operation.

 QGauge Examples 
$INCLUDE "RAPIDQ.INC"

  Center
  CREATE Gauge AS QGauge
    Position = 20
    Kind = gkPie
  END CREATE
