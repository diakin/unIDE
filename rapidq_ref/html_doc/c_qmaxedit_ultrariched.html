QMAXEDIT Component

Extends QRICHEDIT · source: inc/ultraRichEd.inc, line 11 · author: Psyclops

A QRichEdit with a Windows-style edit popup menu (Undo, Cut, Copy, Paste, Delete, Select All) and simple keyword highlighting.

QMAXEDIT extends QRichEdit. Its constructor builds a popup menu like the default Windows edit menu and assigns it to PopupMenu; before the menu opens, items are enabled according to the selection, the clipboard and EM_CANUNDO. Undo sends EM_UNDO and Delete sends WM_KEYDOWN with VK_DELETE.

It also contains the keyword highlighting code of QREdit (HiLight.inc): keywords added with AddSyntaxes are drawn bold in HiLightColor by HiLight, and OnKeyUp re-highlights the word at the caret. The control is set to PlainText with the "MS Sans Serif" font.

After the TYPE the file redefines QRICHEDIT as QMAXEDIT, so later code that creates a QRICHEDIT gets this component. The comments say: set UsePopup = 0 to turn off the popup, or set PopupMenu to use another one.

QMAXEDIT inherits the properties, methods and events of QRICHEDIT; the tables below list only what the component adds or redefines (public members).

Requires

  • A SendMessage declaration from elsewhere (Undo and Delete call SendMessage; the file declares only SendMessageA)

QMAXEDIT Methods

MethodTypeDescription
UndoSUBUndoes the last edit (sends EM_UNDO).
CutSUBCuts the selection to the clipboard.
CopySUBCopies the selection to the clipboard.
PasteSUBPastes from the clipboard.
DeleteSUBDeletes the selection or the character at the caret by sending a Delete key-down message.
SelectAlSUBSelects all text (calls SelectAll).
HiLightSUBHighlights all keywords: resets the whole text to RichFont, then finds every occurrence of each keyword (case-insensitive substring search) and makes it bold in HiLightColor. Call it after loading a file or inserting lines.
AddSyntaxesSUBI(...)AddSyntaxes(word1, word2, ...) appends keywords to the Syntaxes array.

The component handles these events itself (EVENT blocks in the TYPE): MaxMenu.OnPopup, OnKeyUp.

Notes

  • Undo and Delete call SendMessage, which this file does not declare.
  • Syntaxes has a fixed size of 100 and AddSyntaxes does not check the limit.
  • HiLight matches substrings, not whole words, so a keyword inside a longer word is also highlighted.
  • The OnKeyUp comments say the event may be skipped when typing fast and that splitting a word with a space is not handled.
  • The file redefines QRICHEDIT as QMAXEDIT after the TYPE, which affects every later QRICHEDIT in the program.

QMAXEDIT Examples

Example written for this page from the members above; not run.

$INCLUDE "ultraRichEd.inc"
CREATE Form AS QFORM
  Caption = "Editor"
  CREATE Editor AS QRICHEDIT  ' becomes QMAXEDIT
    Align = 5
  END CREATE
END CREATE
Editor.AddSyntaxes "IF", "THEN", "ELSE", "END"
Editor.Text = "IF a THEN b ELSE c"
Editor.HiLight
Form.ShowModal
