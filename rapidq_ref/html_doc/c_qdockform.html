QDOCKFORM Component

Extends QPANEL · source: inc/QDOCKFORM.inc, line 57

Dockable tool panel: a QPANEL with a title bar that can be dragged off its form into a floating borderless window and dragged back to dock again.

QDOCKFORM extends QPANEL. It contains an inner Panel (QDFPANEL) with a Canvas that draws the title area and a Client panel where you put your own controls. When the user drags the title bar (or the grip, for grip styles) more than 30 pixels away from the docked position, the Panel is moved into UndockedForm, a borderless QFORM sized UndockedWidth x UndockedHeight, and that form follows the mouse. Dragging the floating form back within 29 pixels of the original position docks it again. With Style = 1 it can also dock into an alternative panel on the opposite side of the form (or on the side given by AltAlign).

The title area is painted on each Canvas.OnPaint according to DockStyle (when docked) or UndockStyle (when floating): styles 0-2 and 10 have a caption bar 25 pixels high, styles 3-6 have a vertical grip on the left. The close button is drawn with the user32 DrawFrameControl function, style 10 uses DrawCaption, and resizing of the floating form (Sizeable = 1) is done by sending WM_SYSCOMMAND size commands to it. SetCapture, ReleaseCapture and ClientToScreen from user32 are used while dragging.

Use: set Parent and Align (default 3, left), Caption and the styles, then place child controls on .Client. The public SUB Close (not in the parsed member list) closes the panel the same way as the close button. Call Dock to dock or undock from code.

QDOCKFORM inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

PanelQDFPANELRWThe inner QDFPANEL that holds Canvas, Client and the close button; it is moved between the component, the alternative panel and UndockedForm.
CanvasQCANVASRWQCANVAS filling the Panel. The frame, caption and grip are painted on it, and its mouse events implement dragging and resizing.
ClientQPANELRWQPANEL where user controls are placed. It is positioned below the caption (or right of the grip) on every repaint.

ClosedINTEGERRWRead-only (its setter does nothing): set to 1 when the panel is closed with the close button, Close, or by closing the floating form; cleared by the next Dock.

QDOCKFORM Methods

MethodTypeDescription
DockSUB(Dock AS INTEGER)Dock(n): n = 1 docks the panel in its normal place; n = 2 docks it in the alternative panel when Style > 0 (otherwise like 1); any other value undocks it into the floating form, centered on the screen with UndockedWidth x UndockedHeight.

QDOCKFORM Events

EventTypeOccurs when...
OnDockSUB(Docked AS INTEGER, Alt AS INTEGER)Event (Docked AS INTEGER, Alt AS INTEGER) fired when the user docks or undocks by dragging: (0, 0) when undocked, (1, 0) when docked in the normal place, (1, 1) when docked in the alternative panel. Dock does not fire it.
OnPaintSUBEvent without parameters fired at the end of each Canvas repaint, after the title area has been drawn.
OnCloseSUBEvent without parameters fired when the close button is clicked, Close is called, or the user closes the floating form while CanClose = 1.

The component handles these events itself (EVENT blocks in the TYPE): CloseButton.OnMouseDown.

Notes

  • Dock centers the floating form by computing Left and Top, because (source comment) Center loses the parent, which is hard to get back.
  • Sizes are hard-coded: the caption area is 25 pixels high, the close button is 16 x 14 pixels, the grip area is 15 pixels wide, the resize border is 4 pixels, and docking snaps within 29-30 pixels.
  • MinWidth and MinHeight are commented out in the constructor, so the floating form has no minimum size when resized.
  • OnDock is fired only for docking by dragging, not by the Dock method.
  • Several API calls (ShowWindow, ReleaseCapture, SetWindowLong) are left commented out in the code.

Other versions

QDOCKFORM Examples

Example written for this page from the members above; not run.

$INCLUDE "QDOCKFORM.inc"
CREATE Form AS QFORM
  Width = 600
  Height = 400
END CREATE
DIM Tools AS QDOCKFORM
Tools.Parent = Form
Tools.Caption = "Tools"
Tools.DockStyle = 1
Tools.UndockStyle = 1
Tools.CanClose = 1
Tools.Sizeable = 1
DIM Btn AS QBUTTON
Btn.Parent = Tools.Client
Btn.Caption = "OK"
Form.ShowModal
