QSTATUSBAREX Component

Extends QSTATUSBAR · source: inc/object/QStatusBarEx.inc, line 15 · version: 1.0

A QSTATUSBAR extension that can place a QPanel (and the controls on it) inside one of its status bar panels.

AddOptPanel(panel, index) removes the panel's bevels, fits its height and width into status bar panel number index, positions it horizontally after the preceding panels and centres it vertically, then makes it a child of the status bar with the Windows API SetParent and shows it.

QSTATUSBAREX inherits the properties, methods and events of QSTATUSBAR; the tables below list only what the component adds or redefines (public members).

QStatusBarEx Methods

MethodTypeDescription
AddOptPanelSUB(panel as qpanel,index as integer)AddOptPanel(panel, index) places the QPanel inside status bar panel index (from 0): removes its bevels, limits its height to the bar height - 4 and its width to the panel width - 4, positions it, re-parents it to the status bar and makes it visible.

Notes

  • The panel is positioned once; it does not follow later changes of the status bar panel widths or of the bar height.
  • The header comment calls the class QStatusBar rather than QStatusBarEx.

QStatusBarEx Examples

Example written for this page from the members above; not run.

$INCLUDE "object/QStatusBarEx.inc"
CREATE Form AS QFORM
  Caption = "Status bar"
  CREATE Status AS QStatusBarEx
    AddPanels "Ready", ""
  END CREATE
  CREATE Box AS QPanel
    Width = 100
    Height = 14
  END CREATE
END CREATE
Status.Panel(0).Width = 150
Status.AddOptPanel(Box, 1)
Form.ShowModal
