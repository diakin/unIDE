    Appendix B: Custom Components (rapidq_ref/inc)
    • COMPORT — Comport is a non-visual serial (COM) port component that opens, configures, writes to and reads from a port through the Win32 file and communications API.
    • MYCOM_PORT — A serial (COM) port object that opens, configures, writes to and reads from a communications port through the Win32 file API, with events for errors and completed operations.
    • MYXPSKINNEDFORM — A skinned form that replaces the Windows title bar and borders with Windows XP Metallic style bitmaps, its own title buttons, a system popup menu, rounded corners and a default button.
    • QABOUT — QAbout builds and shows a modal "About" dialog with an image, application name and version, a text, and clickable e-mail and web links.
    • QANIM — Animated image: a QImage that shows the frames of its QImageList one after another on a timer.
    • QANIMATE — A wrapper for the Windows Animation common control (SysAnimate32) that plays silent AVI clips.
    • QAVI — Non-visual component that reads frames from AVI video files into bitmaps and writes bitmaps as frames into new AVI files, using the Video for Windows AVIFile API.
    • QBEVEL — Bevel control like the Delphi TBevel: a QPANEL that shows a raised or lowered box, frame or single line.
    • QBITMAPEX — An extended QBITMAP with GDI drawing methods, clipboard support and JPEG/GIF loading and JPEG saving through NViewLib.dll.
    • QBROWSEDIALOG — QBROWSEDIALOG shows the Windows "Browse for folder" dialog and returns the selected folder.
    • QBUTTONXP — A QButton that resets its window style so it can be drawn with Windows XP visual styles when used together with QXPTheme.inc.
    • QCALENDAR — A month calendar panel with a day grid, month/year navigation buttons, a month popup menu and a Today button, using Windows locale names.
    • QCANVASEX — Extended QCANVAS with GDI drawing that uses a pen style, pen size and raster (mix) mode, plus filled shapes, icons, flood fill, color inversion, mirroring and clipboard bitmap copy/paste.
    • QCDAUDIO — Non-visual audio CD player that controls the MCI "cdaudio" device: open, play, pause, stop, eject and track selection, with a change event while playing.
    • QCGI — Non-visual CGI helper that reads the CGI environment variables and parses GET or POST form data into name/value pairs.
    • QCHART — QChart is a QCanvas-based charting class that draws bar, histogram, line, XY scatter, pie, box, hi-lo and real-time charts into an off-screen bitmap.
    • QCICCIO — Empty test stub component with a single field of an undefined type ciccino and an empty constructor.
    • QCOLORBUTTON — QCOLORBUTTON is a small square QPanel that behaves like a push button with a pressed look.
    • QCOLORDIALOG — A color selection dialog object based on the Windows ChooseColor common dialog, with a custom caption, 16 custom colors and full-open options.
    • QCOLORDIALOG — A non-visual wrapper for the Windows color selection dialog (ChooseColor) that returns the color as an RGB value and as an HTML #RRGGBB string.
    • QCOLORDLG — QColorDlg is a color selection dialog wrapping the Windows ChooseColor dialog, with selectable style, screen position, caption and custom colors.
    • QCOOLBARXP — A toolbar panel that imitates the Windows XP toolbar (rebar) look, with image buttons, separators, a grip, a caption, drop-down menus, embedded edit/combo boxes and an overflow chevron menu.
    • QCURSOR — An object that loads mouse cursors from files or resources and shows, hides or moves the mouse cursor.
    • QD3DCAMERA — A non-visual camera helper for RapidQ Direct3D (QDXSCREEN) programs that keeps a camera position and orientation and applies them to a QDXSCREEN.
    • QD3DCLONEMESH — A non-visual helper that shows one QD3DMESHBUILDER (loaded from an X or 3DS file) in up to 100 QD3DFRAMEs, so the same model appears many times in a RapidQ Direct3D scene.
    • QD3DPRIMITIVE — A non-visual helper that builds simple polygon meshes (planes, box, pyramid, sphere, cylinder, cone) into a QD3DMESHBUILDER for RapidQ Direct3D programs.
    • QDATABASE — A non-visual component for a simple flat-file database of fixed-size text records, with field lookup and search functions.
    • QDATABASE — ODBC database object that connects to Access, dBase, Paradox, Excel or text files and reads the list of tables and their field definitions.
    • QDEBUG — A debug output object that prints strings into a resizable "Debug" window with a rich edit box.
    • QDESKTOP — Object with desktop helpers: copy the screen or the wallpaper into a device context, read a screen pixel and change the wallpaper.
    • QDFPANEL — Helper panel type used inside QDOCKFORM: a QPANEL whose appearance properties are hidden by redeclaring them as private.
    • QDIGDISPLAY — A canvas that shows a text string as digital display characters drawn from bitmap files.
    • QDIR — Non-visual file finder that scans a directory, or a directory tree, for files matching a filter and attribute rules, and fires an event for each file found.
    • QDIRLISTVIEW — A QListView that shows the folders and files of a directory with icons, size, type and date columns, and lets the user browse folders.
    • QDOCKFORM — Dockable tool panel: a QPANEL with a title bar that can be dragged off its form into a floating borderless window and dragged back to dock again.
    • QDOWNLOAD — A non-visual object that downloads a file from an HTTP server with a QSocket and returns it in a string or saves it to a file, with progress and speed reporting.
    • QDRAWFOCUS — QDrawFocus draws a rubber-band selection rectangle (a focus rectangle) on a device context and lets the user move it or resize it from its right and bottom edges with the mouse.
    • QDRAWMENU — A non-visual helper that makes menu items owner-drawn so they show a bitmap next to the caption, optionally with a raised button frame.
    • QDRIVE — An object that lists the drives on the computer and reports their type, size and free space.
    • QDRIVECOMBOBOX — QDriveComboBox is a QComboBox meant to list the drive letters present on the computer.
    • QFILEDIALOG — Open or Save file dialog object using the Windows common dialog (GetOpenFileName/GetSaveFileName), with overwrite warning and multiple selection.
    • QFILELISTVIEW — QListView that lists the files of a directory with their system icons, size, type and modification date, filtered by one or more masks.
    • QFLASHLABEL — QLabel that can flash its text by switching the font color between a dark and a light color on a timer.
    • QFLATBUTTON — A flat image button derived from QImage that draws a raised border when the mouse is over it and a sunken border while it is pressed.
    • QFOCUS — A canvas that can be moved and resized with the mouse and can draw a blinking dotted focus frame around itself.
    • QFORMEX — An extended QFORM with file drag-and-drop, a system tray icon and taskbar handling.
    • QFORMMDI — An MDI parent form that creates MDI child windows around existing controls and offers properties, methods and events to manage the child windows.
    • QFTPCLIENT — An FTP client object based on wininet.dll that connects to a server, manages directories, uploads, downloads, renames and deletes files, and lists files with their size, date and attributes.
    • QFTPDIRLISTVIEW — QFTPDirListView is an unfinished QListView-based file list meant to browse FTP directories; the code present lists folders and files of a local directory.
    • QGL — OpenGL wrapper object that sets up an OpenGL rendering context on a RapidQ form (or a bitmap) and provides viewport, texture, fog, full-screen and frame-rate helpers.
    • QGRIDCOLOR — QGridColor is a QPanel showing the 16 standard colors as clickable cells; left click picks a foreground color and right click a background color.
    • QGROUPBOXUX — A QGROUPBOX that repaints its frame and caption with Windows XP visual styles after Subclass is called.
    • QHEAD — Header bar drawn on a QCanvas, aligned to the top of its parent, with left and right caption texts, an optional icon and a color gradient line.
    • QHTML — A read-only viewer for simplified HTML pages, drawn on a panel in pure RapidQ code.
    • QICMP — A ping component that sends ICMP echo requests with icmp.dll.
    • QICON — A non-visual object that extracts icons from files and saves an icon or a 32x32 bitmap as a 16- or 256-color .ico file, or converts it to a cursor.
    • QID3TAG — Non-visual reader and writer for the ID3v1 tag at the end of MP3 files (title, artist, album, year, comment, track and genre), with a genre list and combo box.
    • QIMAGEBOX — A scroll box that displays an image file (BMP, ICO, CUR, ANI, and GIF, JPG, PCX, TGA and others through Nviewlib.dll), scaled down to fit and centered.
    • QIMAGEDIALOG — Custom open-file dialog built from RapidQ controls that shows a scaled preview of the selected image.
    • QIMAGEEX — QImage extension with clipboard copy and paste, bitmap loading at a chosen size, and loading of other image formats through NViewLib.dll.
    • QIMAGELISTEX — A QImageList extension that fills the list from one horizontal bitmap strip, from a file or a resource, optionally stretching the images.
    • QINI — QINI is a non-visual object for reading and writing values in an INI file section and for getting the Windows, System and Temp folders.
    • QINI — A non-visual object for reading and writing Windows INI files with the GetPrivateProfileString family of API calls.
    • QINIFILE — A QStringList-based INI file reader and writer with section and key lookup and typed read/write methods.
    • QINIFILE — A simple INI file reader and writer that reads and writes single entries or whole sections of a text INI file.
    • QINPUTBOX — A non-visual object that shows a modal input dialog and returns the text the user typed.
    • QLED — A round LED indicator drawn on a QCanvas, with six colors and on/off states.
    • QLEDSCROLL — A scrolling text banner on a QCanvas, with an optional grid overlay that gives an LED display look.
    • QLINE — A canvas that draws an etched (3D) horizontal or vertical separator line.
    • QLINEGRAPH — Simple line graph object that plots X/Y points from a QStringGrid on a QCanvas, with title, axis titles, automatic scale and tick labels.
    • QLISTBOXEX — A QListBox that raises an OnEnter event when the Enter key is pressed.
    • QLISTVIEWEX — Extended QListView in report style with clickable flat header buttons for sorting, CSV loading and saving, and filtering of rows.
    • QMARKER — A panel that shows a vertical column of colored row strips, used to mark individual rows with a color or a bitmap.
    • QMAXEDIT — QRichEdit extension with a popup menu like the standard Windows edit context menu (Undo, Cut, Copy, Paste, Delete, Select All) and line-position helpers.
    • QMAXEDIT — A QRichEdit with a Windows-style edit popup menu (Undo, Cut, Copy, Paste, Delete, Select All) and simple keyword highlighting.
    • QMAXSPLITTER — Splitter control based on QPANEL that emulates the Delphi 6 splitter styles: dragging it resizes the neighboring aligned control.
    • QMD2MODEL — Loader and renderer for Quake MD2 animated 3D models, drawn with OpenGL through a QGL object.
    • QMENU — A helper object that makes form menu items owner-drawn with icons and shows item descriptions in a status bar.
    • QMENUEX — An owner-drawn menu helper, derived from QIMAGELIST, that draws bitmaps or icons next to menu items and reports a help text for the item under the mouse.
    • QMIDI — A non-visual MIDI file player built on the Windows MCI sequencer, with play, pause, stop, seeking, volume and a position-change event.
    • QMP3 — A non-visual component that reads MP3 frame header information, reads and writes ID3 v1.x tags, and plays or stops an MP3 file through MCI.
    • QODBC — Simple ODBC client object that lists drivers, connects with a connection string, lists tables, runs SQL queries and fetches rows as text.
    • QPAGESETUP — A page setup dialog object based on the Windows PageSetupDlg common dialog that returns paper size, orientation and margins.
    • QPANELUX — A QPanel that draws its border with the Windows XP visual style color after Subclass is called.
    • QPOSIC — A square two-axis position control made of a vertical and a horizontal scroll bar plus reset, undo, redo and diagonal step buttons.
    • QPOSICL — A panel with a vertical and a horizontal scroll bar and five buttons for adjusting a two-dimensional position (X/Y values).
    • QPRINTERINFO — A non-visual object that returns printer page sizes, margins and resolution and converts between millimeters and printer pixels.
    • QPROCESS — A non-visual component that runs its OnProcess event handler in a separate Windows thread, with priority, suspend, resume and terminate.
    • QPROGRESS — A progress bar component that creates a Windows msctls_progress32 control on a parent window given by handle.
    • QPROGRESS — A progress indicator derived from QIMAGE that shows either a standard QGAUGE or an animated marquee (moving dot, rectangles, blur or barber pole) for tasks of unknown length.
    • QPROGRESSBAR — Progress bar component that creates a real Windows progress bar control (msctls_progress32) with colors, smooth, vertical and marquee styles and a state setting.
    • QRC4 — Non-visual RC4 stream cipher that encrypts and decrypts strings with a key.
    • QREDEX — An extended QRichEdit with a built-in edit popup menu, Search and Replace dialogs, scroll position save/restore, text size limit and font/color dialogs.
    • QREDIT — A QRichEdit with simple automatic keyword (syntax) highlighting.
    • QRICHEDITUX — A QRICHEDIT that draws its border with the Windows XP visual style color after Subclass is called.
    • QRICHEDIT_API — An unfinished wrapper that creates a Windows RichEdit control directly with CreateWindowExA instead of using QRICHEDIT.
    • QRICHEDIT_API — Minimal wrapper that creates a Windows RichEdit control (RICHED32.DLL) with CreateWindowEx and lets you move, size, show and hide it.
    • QRICHEDIT_XT — A QRichEdit extension that adds automatic URL detection, a text limit, a scroll position property, auto-font control and experimental keyword syntax highlighting painted over the control.
    • QRPANEL — A QPanel with rounded corners, made by applying a rounded-rectangle window region.
    • QRUN — A non-visual object for starting programs and documents and for finding and controlling other windows (enumerate, close, minimize, maximize, restore, focus, topmost).
    • QSAVEPLUS — A save file dialog extended with file name checks: missing path, invalid name, missing extension and overwrite confirmation.
    • QSCROLLBOXUX — A QSCROLLBOX that draws its border with the Windows XP visual style color after Subclass is called.
    • QSHFILEOPERATION — A wrapper for the SHFileOperation API to copy, move, rename and delete files and folders.
    • QSHUTDOWN — A non-visual object that shuts down, force-shuts down, reboots Windows or logs off the current user.
    • QSKIN — Skinned form: a QFORM without title bar whose size follows a skin image, and which can be dragged by that image.
    • QSKINBTN — A skinnable button based on QIMAGE that shows different bitmaps for the up, down and disabled states, with push, latch and toggle modes.
    • QSOCKETEX — A QSocket extension with Winsock helpers: corrected GetPeerName, host name and address lookup, connection check, CR LF line writing, write with error code, shutdown, blocking mode and error text.
    • QSPINBUTTON — A spin control built from a QPanel with two QCOOLBTN buttons (+ and -) and an optional QEDIT showing the value.
    • QSPINTEXT — A spin edit: a panel with a QEdit and a vertical QScrollBar for entering a number between Min and Max, with an OnChange event.
    • QSPLASH — QSplash shows a borderless splash window with an image and optional text, for a given time or until the program closes it.
    • QSQLTABLE — ODBC SQL query object that runs SQL statements on an Access, dBase, Paradox, Excel or text database and moves through the result rows.
    • QSTATUSBAREX — A QSTATUSBAR extension that can place a QPanel (and the controls on it) inside one of its status bar panels.
    • QSTRINGGRIDEX — A QStringGrid with an editor style per row instead of per column: a row can show a drop-down list, an ellipsis button or a plain edit.
    • QSTRINGGRIDUX — A QStringGrid that draws its border with the Windows XP visual style color after Subclass is called.
    • QSYSTEM — A non-visual object that reports Windows system information (OS version, memory, disk space, power and system metrics) and can open Control Panel applets, sleep, hibernate, log off, shut down or reboot.
    • QTABCONTROLEX — A QTabControl that keeps a count of its tabs and adds methods to delete tabs and clear all tabs.
    • QTBUTTON — A skinnable push button derived from QButton that draws its face from a bitmap skin or from Windows XP visual styles, with hover effect, icon, multi-line caption and button groups.
    • QTEXTBTN — A label that acts as a text-only button by changing its font color when pressed, with momentary, latching and toggle modes.
    • QTEXTEDIT — QRichEdit extension with a built-in Undo/Cut/Copy/Paste/Select All popup menu and extra editing methods (undo, text limit, replace selection, find).
    • QTOOLBAR — A toolbar component that wraps the Windows common-controls toolbar (ToolBarWindow32) with image lists, check and drop-down buttons, tooltips and a context menu.
    • QTOOLBAREX — A toolbar built from a QPanel and an array of flat QCOOLBTN buttons whose images are cut from one horizontal bitmap strip.
    • QTREEVIEWEX — QtreeviewEx extends QTreeView with methods to find parents, children and items by text, and to move items and whole branches up, down, in and out.
    • QVIDEO — A video player object that plays media files through MCI string commands.
    • QVOLUMEINFO — QVolumeInfo is a non-visual object that retrieves the label, serial number, file system, size, free space and drive type of a drive.
    • QVUMETER — A vertical bar-graph level meter (VU meter) drawn on a QCanvas.
    • QWAVE — A non-visual object that plays, records, edits and saves WAV files through MCI string commands.
    • QWEBCAM — Webcam capture component that creates a Video for Windows (avicap32) capture window on a form for live preview, frame callbacks and frame grabbing.
    • QWEBCAM — A non-visual wrapper around webcam.dll for showing a webcam preview in a form, capturing video, opening driver dialogs and grabbing frames.
    • QXEDIT — QEdit replacement that subclasses the edit window to add OnGetFocus and OnLoseFocus events, a WndProc event and an option to make Enter move to the next control.
    • QXPBUTTON — A QBUTTON extension that shows a bitmap on a Windows XP visual-style button by giving the button an image list with BCM_SETIMAGELIST.
