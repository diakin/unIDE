QRICHEDIT_XT Component

Extends QRICHEDIT · source: inc/QRichEditXt.inc, line 193

A QRichEdit extension that adds automatic URL detection, a text limit, a scroll position property, auto-font control and experimental keyword syntax highlighting painted over the control.

QRichEdit_xt starts a one-shot QTIMER (interval 1) in its constructor. When the timer fires it applies the settings: scroll position (EM_SETSCROLLPOS), loading the keyword list file when HiLight is 1, clearing the auto-font language option, enabling EM_AUTOURLDETECT when AutoURLDetect is 1, the text limit (EM_EXLIMITTEXT), getting a device context with GetDC, and subclassing the control's window procedure with SetWindowLong so that Proc receives its messages.

When HiLight is not 0, Proc lets the original window procedure paint on WM_PAINT and then draws over the visible lines with TextOut on HandleDC: quoted strings, comments, keywords found in the keyword list, operators and brackets each get their own colour. The tokenizer is adapted from a BASIC-to-HTML converter (the HTML output lines are left commented out). Comments in the code are in Russian.

The file defines many EM_*, SES_* and IMF_* rich edit constants and its own Point type.

QRICHEDIT_XT inherits the properties, methods and events of QRICHEDIT; the tables below list only what the component adds or redefines (public members).

Requires

  • a global QRichEdit (or QRichEdit_xt) object named RichEdit: Proc reads RichEdit.Handle and RichEdit.Line() instead of the component itself
  • a global QFont named HiLiteFont used as the highlight font
  • constants not defined in this file: WM_PAINT, TRANSPARENT, GWL_WNDPROC, clOrange, clDGreen, clPurple, clDRed (clGreen and clBlue are standard RapidQ colours)
  • a keyword list text file named in KeyListName

QRichEdit_xt Methods

MethodTypeDescription
ProcFUNCTION(hWnd AS LONG, uMsg AS LONG, wParam AS LONG, lParam AS LONG) AS LONGInternal: subclassed window procedure installed with SetWindowLong. It calls the original procedure, paints the highlighting on WM_PAINT when HiLight is on, and then calls the private WndProc event if one is set.

The component handles these events itself (EVENT blocks in the TYPE): Tmr.OnTimer.

Notes

  • Proc uses the global names RichEdit and HiLiteFont instead of the component itself, so highlighting only works if the instance is named RichEdit and a QFont named HiLiteFont exists.
  • The setters and Proc contain PRINT debug statements (for example "SCROLLPOS=", "RichEdit WM_PAINT=", "end bas2Html").
  • AutoURLDetect, LimitText, AutoFont, KeyListName and the loading of the keyword list take effect only once, when the initialisation timer fires; changing them later has no effect.
  • The auto-font option is cleared with the expression '... & -IMF_AUTOFONT'; -IMF_AUTOFONT is -2, which is not the bitwise complement of IMF_AUTOFONT (that would be -3).
  • The device context from GetDC is kept for the life of the control and never released.
  • Keywords are matched with INSTR against the whole keyword list text in upper case, so any substring of the list counts as a keyword.
  • Highlight colours are hard-coded, and several colour constants (clOrange, clDGreen, clPurple, clDRed) and API constants are not defined in the file.
  • The file declares its own TYPE Point with fields Left and Top, which can conflict with a Point type from Windows API include files.

QRichEdit_xt Examples

Example written for this page from the members above; not run.

$INCLUDE "QRichEditXt.inc"
DIM HiLiteFont AS QFONT
CREATE Form AS QFORM
  Width = 500
  Height = 400
  CREATE RichEdit AS QRichEdit_xt
    Align = 5
    AutoURLDetect = 1
    KeyListName = "keywords.txt"
    HiLight = 1
  END CREATE
END CREATE
Form.ShowModal
