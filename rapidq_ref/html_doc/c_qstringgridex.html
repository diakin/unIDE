QSTRINGGRIDEX Component

Extends QSTRINGGRID · source: inc/QStringGridEx.inc, line 9 · author: D. Glodt (per object/lire.txt) · version: 1.0 · date: June 2003 (object/lire.txt)

A QStringGrid with an editor style per row instead of per column: a row can show a drop-down list, an ellipsis button or a plain edit.

QStringGridEx is a template type: the size of its row arrays is given when the variable is declared, for example DIM Grid AS QStringGridEx<20>. RowStyle(Row) and RowList(Row) hold the style and the list text for each row.

QSTRINGGRID only has styles per column (ColumnStyle, ColumnList). When a cell is selected (OnSelectCell) or the current row is drawn (OnDrawCell), the component copies the style of that row into the column of the cell: RowStyle grsList (2) sets ColumnList(Col) = RowList(Row) and ColumnStyle(Col) = 0, grsEllipsis (1) sets ColumnStyle(Col) = 1, grsNone (0) sets ColumnStyle(Col) = 2.

The file defines the constants grsNone = 0, grsEllipsis = 1 and grsList = 2. It was added to the D. Glodt component set in June 2003 (object/lire.txt: a component inherited from QStringGrid with the row style).

QSTRINGGRIDEX inherits the properties, methods and events of QSTRINGGRID; the tables below list only what the component adds or redefines (public members).

QStringGridEx Properties

FieldTypeR/WDefaultDescription
RowStyleARRAY(Size) OF INTEGERRWArray (0 to Size): editor style of each row - grsNone (0), grsEllipsis (1) or grsList (2).
RowListARRAY(Size) OF STRINGRWArray (0 to Size): list items for rows with RowStyle grsList; copied to ColumnList of the selected column.

The component handles these events itself (EVENT blocks in the TYPE): OnDrawCell, OnSelectCell.

Notes

  • The OnSelectCell and OnDrawCell handlers are defined inside the TYPE; assigning your own handler to these events in the program may replace them (not checked).
  • The format of the RowList text (separator between items) is not given in the source; it is passed to ColumnList unchanged.

QStringGridEx Examples

Example written for this page from the members above; not run.

$INCLUDE "QStringGridEx.inc"
DIM Form AS QFORM
DIM Grid AS QStringGridEx<10>
Grid.Parent = Form
Grid.ColCount = 3
Grid.RowCount = 5
Grid.RowStyle(1) = grsList
Grid.RowList(1) = "Red" + CHR$(13) + "Green" + CHR$(13) + "Blue"
Grid.RowStyle(2) = grsEllipsis
Form.ShowModal
