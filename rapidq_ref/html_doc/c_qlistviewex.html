QLISTVIEWEX Component

Extends QLISTVIEW · source: inc/QListviewEx.inc, line 6 · author: Dreadsoft® Corporation

Extended QListView in report style with clickable flat header buttons for sorting, CSV loading and saving, and filtering of rows.

Qlistviewex places the list view inside its own panel (ParentPanel) and replaces the standard column headers with a row of QCoolBtn buttons on a header panel. Clicking a header button sorts the list by that column. Columns are added with AddCol, which takes names separated by '/', and Draw rebuilds the header buttons.

Data is loaded only from the csv string list: each line is split by Separator (default ';') into an item and its subitems, and empty fields are shown as '-'. LoadFromCsvFile loads csvFile first. UpdateCSV writes the list contents back to csv, and SaveToCsvFile, SaveToFileAs and DirectSaveAs save to a file. Exclude and Filter remove rows by comparing a column to a string, not case sensitive.

Set ParentPanel.Parent to the form (and align the panel as needed); the list view itself is placed in the panel by Draw.

QLISTVIEWEX inherits the properties, methods and events of QLISTVIEW; the tables below list only what the component adds or redefines (public members).

Notes

  • The AddCol comment says '(See example)', but the file contains no example.
  • Methods share the global variables lx, ly, ix and iy declared with DEFINT at file level.
  • Exclude, Filter, UpdateCSV and DirectSaveAs use DO ... LOOP UNTIL loops that run once before checking, so an empty list or a single column is not handled.
  • SaveToFileAs saves the csv string list without calling UpdateCSV first, so edits made in the list are not included.
  • FieldsCount is taken from the first CSV line only.

Other versions
