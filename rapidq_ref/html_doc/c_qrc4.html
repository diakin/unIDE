QRC4 Component

Extends QOBJECT · source: inc/RC4crypt.inc, line 63 · author: Martin Wehner · date: 2003-10-04

Non-visual RC4 stream cipher that encrypts and decrypts strings with a key.

QRC4 is an adaptation of the RC4 algorithm to RapidQ Basic. Init(key) sets up the 256-byte state table from a key of any length, and Pipe(s) returns s XORed with the next bytes of the key stream. Because RC4 is symmetric, decoding is the same operation: call Init with the same key again and pass the encoded string to Pipe.

The state continues from one Pipe call to the next, so data can be processed in pieces of any size: Pipe(s) & Pipe(t) is always equal to Pipe(s & t).

QRC4 inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QRC4 Methods

MethodTypeDescription
ResetSUBSets the state table back to 0..255 in order and clears the indexes. Init and the constructor call it.
InitSUB(key AS STRING)Init(Key): resets the state and runs the RC4 key setup with Key. With an empty key only the reset is done.
PipeFUNCTION(str AS STRING) AS STRINGPipe(Str): encodes or decodes Str with the key stream and returns the result, continuing the stream state.

Notes

  • Init must be called again with the same key before decoding, because Pipe continues the key stream.
  • Init with an empty key gives no error; the object keeps the unkeyed state.

QRC4 Examples

Example from the comments in the source file.

$INCLUDE "RC4crypt.inc"
DEFSTR k = "1234567890"   ' This is the key
DEFSTR s = "abcdefghijklmnopqrstuvwxyz"
DEFSTR t = "ABCDEFGHIJKLMNOPQRSTUVWXYZ"
DIM rc4 AS QRC4
rc4.Init(k)   ' Initialize RC4 object with the key
s = rc4.Pipe(s)   ' Encode stream element s
t = rc4.Pipe(t)   ' Encode stream element t
rc4.Init(k)   ' Initialize RC4 object with the key again
ShowMessage(rc4.Pipe(s & t))   ' Concatenate and decode
