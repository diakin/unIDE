QD3DPRIMITIVE Component

Extends QOBJECT · source: inc/RapidQ_D3D.inc, line 455 · author: JohnK · version: 1.1 · date: 9/2005

A non-visual helper that builds simple polygon meshes (planes, box, pyramid, sphere, cylinder, cone) into a QD3DMESHBUILDER for RapidQ Direct3D programs.

QD3DPrimitive holds a QD3DMESHBUILDER (Mesh) and a QD3DFRAME (Frame) and has Make... methods that add faces to the mesh. The source says it is meant for floors, sky boxes, clouds, boxes, pyramids and similar objects, and that it exists because a QD3DMeshbuilder cannot be extended.

Each Make method takes the QDXSCREEN (needed to create QD3DFace objects with CreateFace), adds the faces with Face.AddVertex and Mesh.AddFace, and sets Visible to True. DrawCenter shifts the shape, and ViewFromOutside chooses the vertex order so faces are seen from outside (True) or from inside (False), for example for a sky box.

You must create Mesh and Frame yourself with the QDXSCREEN (CreateMeshBuilder, CreateFrame) and attach the mesh to a frame. LoadTextureFile loads a .bmp texture into the mesh, asking for a file with a QOPENDIALOG when TextureFile is empty.

QD3DPRIMITIVE inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • QDXSCREEN (RapidQ DirectX screen) passed to the Make methods
  • QD3DMESHBUILDER, QD3DFRAME and QD3DFace (RapidQ Direct3D objects)
  • QD3DRGBA type and D3DRMRENDER_* / D3DRMWRAP_* constants defined in RapidQ_D3D.inc
  • a definition of null: New assigns null to TextureFile, but RapidQ_D3D.inc only $UNDEFs null at the end and never defines it
  • d3drm.dll (Direct3D Retained Mode); RapidQ_D3D.inc DECLAREs D3DRMVectorCrossProduct, D3DRMVectorDotProduct and D3DRMVectorNormalize from it, although the component itself does not call them

QD3DPrimitive Methods

MethodTypeDescription
NewFUNCTION AS INTEGERResets all public settings to their defaults (flat render quality, sphere wrap, white colour, DrawCenter at the origin, BoxSides 5, ViewFromOutside True, Visible False). Called by the constructor; it does not clear the mesh.
LoadTextureFileSUBLoads TextureFile into the mesh with Mesh.LoadTexture. If TextureFile is empty it first shows a QOPENDIALOG filtered to *.bmp and shows the message 'Texture file does not exist' if the chosen file is missing.
MakeHorizPlaneSUB(DXScreen AS QDXSCREEN)MakeHorizPlane(DXScreen) adds one horizontal square face 2 units wide at height DrawCenter.y, shifted by DrawCenter.x.
MakeVertZPlaneSUB(DXScreen AS QDXSCREEN)MakeVertZPlane(DXScreen) adds one vertical face along the z-axis (x = DrawCenter.x), 1 unit high and 2 units long.
MakeVertXPlaneSUB(DXScreen AS QDXSCREEN)MakeVertXPlane(DXScreen) adds one vertical face along the x-axis (z = DrawCenter.z), 1 unit high and 2 units wide.
MakeBoxSUB(DXScreen AS QDXSCREEN)MakeBox(DXScreen) builds a box from the plane methods: back, front, left and right walls, then the ceiling and floor depending on BoxSides. DrawCenter and ViewFromOutside are restored afterwards.
MakePyramidSUB(DXScreen AS QDXSCREEN)MakePyramid(DXScreen) adds four triangular faces from the apex (0, 0, 0) to the corners (+-1, +-1, 1). When ViewFromOutside is False an extra vertex is added to each face to avoid culling, per the comment.
MakeSphereSUB(DXScreen AS QDXSCREEN, NumFaces AS INTEGER)MakeSphere(DXScreen, NumFaces) adds a sphere of radius 1 around DrawCenter built from quads; the step angle is pi/SQR(NumFaces).
MakeCylinderSUB(DXScreen AS QDXSCREEN, NumFaces AS INTEGER)MakeCylinder(DXScreen, NumFaces) adds the side wall of a cylinder of radius 1 from y = -1 to y = 1 around DrawCenter, using NumFaces quads; no end caps are made.
MakeConeSUB(DXScreen AS QDXSCREEN, NumFaces AS INTEGER)MakeCone(DXScreen, NumFaces) adds a cone of radius 1 with its base at y = -1 and apex at y = 1 around DrawCenter, using NumFaces triangles; no base cap is made.

Notes

  • New assigns null to TextureFile, but null is not defined in RapidQ_D3D.inc (the file only $UNDEFs it at the end).
  • RenderQuality, the TexOrigin/TexScale/TexWrapType fields and Color are only stored; no method applies them to the mesh.
  • MakeHorizPlane ignores DrawCenter.z (the z coordinates are fixed at -1 and 1).
  • MakePyramid ignores DrawCenter and calls CreateFace only once, then adds the vertices of all four faces to the same Face object.
  • MakeBox declares a Face variable that it never uses.
  • The comments of MakeCylinder and MakeCone say 'simple sphere from center' (copied comment).

QD3DPrimitive Examples

Example written for this page from the members above; not run.

$INCLUDE "RapidQ_D3D.inc"
DIM Room AS QD3DPrimitive
' DXScreen is a QDXSCREEN on your form; call this after it is initialised
SUB BuildRoom
  DXScreen.CreateMeshBuilder(Room.Mesh)
  DXScreen.CreateFrame(Room.Frame)
  Room.ViewFromOutside = False
  Room.BoxSides = 6
  Room.MakeBox(DXScreen)
  Room.TextureFile = "wall.bmp"
  Room.LoadTextureFile
  Room.Frame.AddVisual(Room.Mesh)
END SUB
