QDIGDISPLAY Component

Extends QCANVAS · source: inc/QDigDisplay.inc, line 8 · author: Peter Molloy · version: 1.00 · date: 13 April 2001

A canvas that shows a text string as digital display characters drawn from bitmap files.

QDigDisplay extends QCanvas. The constructor loads 33 bitmaps, 32.bmp to 64.bmp, into a private QImageList of 12 x 24 pixel images; each file is the image of the character with that ASCII code (space to @, including the digits and the colon).

Set Display to the text to show. On each paint, DrawDisplay sizes the canvas to the image height and to the image width times the text length, then draws one image per character.

QDIGDISPLAY inherits the properties, methods and events of QCANVAS; the tables below list only what the component adds or redefines (public members).

Requires

  • Bitmap files 32.bmp to 64.bmp (12 x 24 pixels, one per character), loaded from the current folder

QDigDisplay Properties

FieldTypeR/WDefaultDescription
LeftLONGRWDeclared as a LONG field of the type; DrawDisplay uses it as the X offset of the first character inside the canvas.
TopLONGRWDeclared as a LONG field of the type; DrawDisplay uses it as the Y offset of the characters inside the canvas.
WidthLONGRWDeclared as a LONG field of the type; DrawDisplay sets it to the image width times the length of Display.
HeightLONGRWDeclared as a LONG field of the type; DrawDisplay sets it to the image height (24).
DisplaySTRINGRW"0"Text to show (default "0"). Only characters with ASCII codes 32 to 64 have images.

QDigDisplay Methods

MethodTypeDescription
DrawDisplaySUBResizes the canvas to fit Display and draws its characters; called from OnPaint.

The component handles these events itself (EVENT blocks in the TYPE): OnPaint.

Notes

  • The 33 bitmap files are loaded by relative file name, so they must be in the current folder at run time.
  • Characters outside ASCII 32 to 64 (for example letters) give an image index outside the loaded list.
  • Left, Top, Width and Height are redeclared as plain LONG fields in the type, which may hide the QCanvas properties of the same names.
