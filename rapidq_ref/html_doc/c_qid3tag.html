QID3TAG Component

Extends QOBJECT · source: inc/Qid3Tag.inc, line 19 · author: Dreadsoft® Corporation

Non-visual reader and writer for the ID3v1 tag at the end of MP3 files (title, artist, album, year, comment, track and genre), with a genre list and combo box.

ReadTags opens FileName with a QFileStream, goes to the last 128 bytes of the file, skips the 3-byte header and reads the fixed-size fields: title, artist and album (30 bytes each), year (4), comment (29), track (1 byte) and genre number (1 byte). The genre name is looked up in GenresList. WriteTags writes the same fields back into the same place, each padded with CHR$(0) or cut to its size by the global helper function fitlength.

GenresList (QStringList) holds the standard genre names in ID3v1 order. GenresCB is a drop-down combo box that can be filled with LoadList; choosing an entry sets GenreID through SelectGenre. The header refers to a help file for details.

QID3TAG inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

MethodTypeDescription

writetagsSUBWrites the properties into the ID3v1 fields at the end of FileName.

Notes

  • Neither ReadTags nor WriteTags checks for the "TAG" signature. On a file without an ID3v1 tag, ReadTags returns garbage and WriteTags overwrites the last 125 bytes of the audio data instead of adding a tag.
  • ReadTags removes all CHR$(0) characters from each text field and then cuts one more character, so a field that fills its whole size loses its last character.
  • ReadTags looks up GenresList.Item(GenreID) without checking the range, for example for genre number 255.
  • fitlength is a global function defined outside the type.
  • The header says "See help file for details", but no help file comes with the include.

Qid3tag Examples

Example written for this page from the members above; not run.

$INCLUDE "Qid3Tag.inc"
CREATE Form AS QFORM
  Width = 300
  Height = 100
END CREATE
DIM Tag AS Qid3tag
Tag.FileName = "song.mp3"
Tag.ReadTags
Form.Caption = Tag.Artist & " - " & Tag.Title & " (" & Tag.Genre & ")"
Tag.GenresCB.Parent = Form
Tag.LoadList
Tag.GenresCB.ItemIndex = Tag.GenreID
Form.ShowModal
Tag.Comment = "Edited with RapidQ"
Tag.WriteTags
