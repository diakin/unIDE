QPOSIC Component

Extends QPANEL · source: inc/Qposic1.inc, line 16 · version: 1.00 · date: 22.02.2004

A square two-axis position control made of a vertical and a horizontal scroll bar plus reset, undo, redo and diagonal step buttons.

Qposic extends QPanel (100 x 100 pixels by default). It places a vertical and a horizontal QScrollBar in a cross shape and five bitmap buttons in the center and corners: reset (center), undo (top left), all-down (bottom left), all-up (top right) and redo (bottom right). Moving a scroll bar updates ValueH or ValueV and raises OnChange; the vertical bar is inverted so that up increases ValueV.

Set MinH, MaxH, MinV and MaxV and then call Initial to apply the ranges and rebuild the layout. The reset button sets both values to 1; the all-down button decreases ValueH and ValueV by one step and the all-up button (on mouse down) increases both. The undo and redo buttons only raise OnChange. Per the header, it is based on the QSpinText component by Mesut Akcan.

QPOSIC inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

Requires

  • $RESOURCE files reset.bmp, Undo1.bmp, Redo1.bmp, AllUp.bmp and AllDn.bmp (referenced with absolute paths C:\_F\bas\rapidq\RQIDE\inc\...)

Qposic Methods

MethodTypeDescription
initialSUBApplies MinH, MaxH, MinV and MaxV to the scroll bars and recalculates the size and position of all parts from the panel Height. Call it after setting the ranges or resizing.

Qposic Events

EventTypeOccurs when...
OnChangeSUB(a as single)Event OnChange(a AS SINGLE), raised when a scroll bar moves and when the reset, undo or redo button is clicked; the argument is always 1.

The component handles these events itself (EVENT blocks in the TYPE): btn.onclick, btnAllDn.onclick, btnAllUp.onclick, btnAllUp.OnMouseDown, btnRedo.onclick, btnUndo.onclick, sbh.onchange, sbv.onchange.

Notes

  • The $RESOURCE lines use absolute paths (C:\_F\bas\rapidq\RQIDE\inc\reset.bmp and others); they must be changed to compile on another machine.
  • OnChange always receives 1, so the handler cannot tell which part caused the change; the undo and redo buttons do nothing except raise OnChange.
  • The reset button sets the vertical scroll bar position to 1 although that bar stores the value with inverted sign.
  • The all-up button acts in OnMouseDown; its OnClick handler is empty (the code is commented out).
  • The layout is computed from Height only and assumes a square panel; the constructor fixes Width and Height at 100.
  • The ranges are not applied until Initial is called.

Qposic Examples

Example written for this page from the members above; not run.

DECLARE SUB PosChanged (a AS SINGLE)

CREATE Pos AS Qposic
  Parent = Form
  MinH = -50: MaxH = 50
  MinV = -50: MaxV = 50
  OnChange = PosChanged
END CREATE
Pos.Initial

SUB PosChanged (a AS SINGLE)
  Form.Caption = STR$(Pos.ValueH) + ", " + STR$(Pos.ValueV)
END SUB
