function PrintRichedit(sender as qrichedit,lmarge as integer) as long

Prints the text of a QRichEdit to the printer, starting at left margin lmarge pixels. Parses the RTF (font table, color table, bold/italic/underline, sizes) and handles page breaks. If text is selected it asks whether to print only the selection; returns 1 if the user cancels.
