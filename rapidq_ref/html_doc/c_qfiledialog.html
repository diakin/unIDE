QFILEDIALOG Component

Extends QOBJECT · source: inc/QFileDialog.inc, line 103 · author: JohnK · version: 1.0 · date: 11/2004

Open or Save file dialog object using the Windows common dialog (GetOpenFileName/GetSaveFileName), with overwrite warning and multiple selection.

QFILEDIALOG fills an OPENFILENAME structure from its properties and calls GetOpenFileName or GetSaveFileName from comdlg32, depending on Mode (fdOpen = 0, fdSave = 1). Filter uses '|' between descriptions and masks; it is converted to the null-separated form the API expects. The read-only check box is always hidden, and the overwrite prompt is added when WarnIfOverWrite is set.

After Execute returns nonzero, FileName holds the selected path and FileTitle the name without the path. With MultiSelect, Files(0) holds the folder and Files(1) to Files(SelCount) the selected file names.

The source says the code was adapted from RQDIALOG.INC by Bill K (1-2003).

QFILEDIALOG inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QFILEDIALOG Methods

MethodTypeDescription
ExecuteFUNCTION AS LONGShows the dialog; returns nonzero if the user chose a file, 0 on Cancel.

Notes

  • Execute checks and appends pdfStrTerm$, which is not defined (the constant is fdStrTerm$), so the filter terminator check has no effect.
  • The USAGE and EXAMPLE comments in the header describe the older RQShowDialog function, not this object.
  • Buffers are fixed: 1024 characters for the file name and at most fdMaxFiles (256) selected files.

Other versions

  • inc/rapidq2.inc (line 5877) contains its own edition of QFILEDIALOG.
  • inc/old/QFileDialogDoc.inc — older version (moved; the reason is in COMPONENTS.md).

QFILEDIALOG Examples

Example written for this page from the members above; not run.

$INCLUDE "QFileDialog.inc"
DIM Form AS QFORM
DIM Dlg AS QFILEDIALOG
Dlg.Parent = Form.Handle
Dlg.Mode = fdSave
Dlg.Caption = "Save File"
Dlg.Filter = "RQ Files|*.bas;*.rqb"
Dlg.InitialDir = "C:\RapidQ"
IF Dlg.Execute THEN ShowMessage Dlg.FileName
