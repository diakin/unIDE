QLINE Component

Extends QCANVAS · source: inc/QLine.inc, line 7 · version: 1.0

A canvas that draws an etched (3D) horizontal or vertical separator line.

QLine extends QCanvas and has no public members of its own. On each paint it draws an etched edge with DrawEdge from user32 (declared as DrawLine).

The direction comes from Align and the size: with Align 3 or 4, or no alignment and Height greater than Width, it draws a vertical line and sets Width to 2; with Align 1 or 2, or no alignment and Width greater than Height, it draws a horizontal line and sets Height to 2. Place it like any control and set its length with Width or Height.

QLINE inherits the properties, methods and events of QCANVAS; the tables below list only what the component adds or redefines (public members).

The component handles these events itself (EVENT blocks in the TYPE): OnPaint.

The component adds no public members of its own.

Notes

  • The thickness is fixed at 2 pixels: Width or Height is reset to 2 on every paint.
