QWAVE Component

Extends QOBJECT · source: inc/QWave.inc, line 36 · version: 1.2

A non-visual object that plays, records, edits and saves WAV files through MCI string commands.

QWave sends MCI commands with mciSendStringA from winmm.dll to a waveaudio device opened under the alias "sound", with the time format set to milliseconds. Open loads a file and reads its length, bits per sample, sample rate and channels; New opens an empty recording buffer. Play, Pause, Stop, Record, Save and Delete map to the MCI commands of the same names.

An internal QTIMER (Timer, interval 1000 ms) runs while playing or recording: on each tick it updates CurrentPos and State, calls Stop when the device reports "stopped", and fires OnChange with the current position. State uses the constants WV_CLOSE, WV_PLAY, WV_PAUSE, WV_STOP and WV_RECORD. Volume is set for wave output device 0 with waveOutSetVolume.

QWAVE inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

ModeSHORTRWNumber of channels. Assigning WV_MONO or WV_STEREO while a file is open and stopped or paused changes the wave format.
VolumeINTEGERRWOutput volume 0-100. Assigning it calls waveOutSetVolume for device 0 with the same value for both channels; values above 100 are ignored.

QWave Methods

MethodTypeDescription
CloseSUBStops and closes the MCI device and resets FileOpen, Lenght, CurrentPos and State.
OpenFUNCTION(FileName as string) AS BOOLEANOpens a WAV file, reads its length and format and returns True on success; on failure sets Error and closes the device.
PlaySUBStarts playback from CurrentPos and starts the timer.
StopSUBStops playback or recording, re-reads the length, stops the timer and seeks to the start.
PauseSUBPauses playback and stores the current position.
NewSUBOpens a new empty waveaudio buffer for recording, if no file is open.
RecordSUBStarts recording (MCI 'record sound to' Lenght) when a file is open and stopped or paused, and starts the timer.
SaveFUNCTION(FileName as string) AS BOOLEANSaves the sound to a file when it is stopped and returns True on success.
DeleteSUB(pos1 as long,pos2 as long)Deletes the part between pos1 and pos2 (milliseconds) when stopped, then re-reads the length.

QWave Events

EventTypeOccurs when...
OnChangeSUB(position as long)Event fired on every timer tick with the current position in milliseconds.

The component handles these events itself (EVENT blocks in the TYPE): Timer.OnTimer.

Notes

  • The private GetPosition function tests Wave.FileOpen instead of QWave.FileOpen, so it only works when the instance is named Wave.
  • SetFrequence accepts 8000, 11025 and 44100 but not 22050, although the constant WV_KHZ22 is defined.
  • All instances use the same MCI alias "sound", so only one QWave can have a file open at a time.
  • File names are not quoted in the open and save commands, so names with spaces may fail.
  • Record records 'to' the current Lenght; for a buffer created with New, Lenght is 0.
  • Volume always targets wave output device 0; values from 51 to 99 are computed as negative numbers before being passed to waveOutSetVolume.

QWave Examples

Example written for this page from the members above; not run.

$INCLUDE "QWave.inc"

DIM Wave AS QWave

CREATE Form AS QFORM
END CREATE

SUB WaveChange(position AS LONG)
  Form.Caption = STR$(position) + " / " + STR$(Wave.Lenght)
END SUB

Wave.OnChange = WaveChange
IF Wave.Open("test.wav") THEN
  Wave.Volume = 80
  Wave.Play
ELSE
  ShowMessage Wave.Error
END IF
Form.ShowModal
Wave.Close
