QMIDI Component

Extends QOBJECT · source: inc/QMidi.inc, line 27 · version: 1.2

A non-visual MIDI file player built on the Windows MCI sequencer, with play, pause, stop, seeking, volume and a position-change event.

QMidi sends MCI command strings with mciSendStringA (winmm.dll). Open opens the file as a "sequencer" device under the alias MEDIA, sets the time format to milliseconds and reads the length. Play, Pause and Stop send the matching MCI commands, and CurrentFrame lets you seek while stopped or paused.

While playing, an internal QTIMER (1000 ms) reads the current position and mode, calls Stop when playback has finished, and fires OnChange with the position in milliseconds.

State holds MD_CLOSE (0), MD_PLAY (1), MD_PAUSE (2) or MD_STOP (3). Volume uses waveOutSetVolume. The source comments are in French.

QMIDI inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QMidi Properties

FieldTypeR/WDefaultDescription
TimerQTIMERRWQTIMER (interval 1000 ms) that polls the position and mode during playback and fires OnChange; enabled by Play and disabled by Pause, Stop and Close.
LenghtLONGRWLength of the open file in milliseconds (the name is spelled Lenght in the source); 0 when closed.
StateINTEGERRWMD_CLOSECurrent state: MD_CLOSE (0), MD_PLAY (1), MD_PAUSE (2) or MD_STOP (3).
FileOpenBOOLEANRWTrue while a file is open.
ErrorSTRINGRWText of the MCI error when Open fails (from mciGetErrorStringA).
CurrentFrameLONGRWCurrent position in milliseconds. Assigning it while a file is open and stopped or paused clamps the value to 0..Lenght and seeks there; Play then starts from this position. In other states the assignment is ignored.
VolumeINTEGERRWVolume from 0 to 100. Assigning a value up to 100 stores it and sets the left and right volume of wave output device 0 with waveOutSetVolume; values above 100 are ignored.

QMidi Methods

MethodTypeDescription
CloseSUBStops the timer, sends "stop" and "close" for the MEDIA alias and resets FileOpen, Lenght, CurrentFrame and State.
OpenFUNCTION(FileName as string) AS BOOLEANOpen(FileName) opens a MIDI file through MCI and returns True on success; on failure it sets Error and closes the device.
PlaySUBStarts playback from CurrentFrame and enables the timer.
StopSUBStops playback, disables the timer, sets State to MD_STOP and seeks back to the start.
PauseSUBPauses playback if playing, disables the timer and stores the current position in CurrentFrame.

QMidi Events

EventTypeOccurs when...
OnChangeSUB(position as long)Event OnChange(position AS LONG) fired every timer tick during playback with the current position in milliseconds.

The component handles these events itself (EVENT blocks in the TYPE): Timer.OnTimer.

Notes

  • Open puts the file name into the MCI command without quotes, so paths containing spaces will fail to open.
  • All instances use the fixed MCI alias MEDIA, so only one QMidi (or any other code using that alias) can be open at a time.
  • Volume calls waveOutSetVolume on device 0 (declared as MidiSetVolume), which sets the wave output volume rather than a MIDI device volume.
  • The length property is spelled Lenght.
  • Error is set only by Open; other MCI failures are not reported.

QMidi Examples

Example written for this page from the members above; not run.

$INCLUDE "QMidi.inc"
DIM Midi AS QMidi

SUB MidiChange(position AS LONG)
  PRINT position; " of "; Midi.Lenght
END SUB

Midi.OnChange = MidiChange
IF Midi.Open("C:\music\song.mid") THEN
  Midi.Volume = 80
  Midi.Play
ELSE
  ShowMessage Midi.Error
END IF
