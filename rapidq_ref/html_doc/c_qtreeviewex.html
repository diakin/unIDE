QTREEVIEWEX Component

Extends QTREEVIEW · source: inc/QTreeviewEx.inc, line 4

QtreeviewEx extends QTreeView with methods to find parents, children and items by text, and to move items and whole branches up, down, in and out.

All methods work on the flat item index of the tree and on each item's Level. The search methods walk the items forward or backward comparing levels or texts.

MoveDown, IncLevel and DecLevel save the tree to a temporary text file (homedir + "tmp_tree.tv"), edit the lines in a QStringList (moving lines or adding or removing a leading Tab), reload the tree from the file and delete the file. homedir comes from the included fileops.inc.

QTREEVIEWEX inherits the properties, methods and events of QTREEVIEW; the tables below list only what the component adds or redefines (public members).

Requires

  • $INCLUDE "fileops.inc" (homedir function)

QtreeviewEx Methods

MethodTypeDescription
getparentFUNCTION(i as integer) AS INTEGERGetParent(i) returns the index of the parent of item i (the nearest preceding item with a lower level), or -1 for a top-level item.
getindexFUNCTION(from as integer, itemtext as string) AS INTEGERGetIndex(from, itemtext) returns the index of the first item at or after from whose text equals itemtext, or -1 if none is found.
strgetparentFUNCTION(itemtext as string) AS INTEGERStrGetParent(itemtext) returns the parent index of the first item whose text equals itemtext.
getchildrenlistFUNCTION(i as integer) AS STRINGGetChildrenList(i) returns the texts of the direct children of item i as a comma-separated string.
addchildtoSUB(startfrom as integer, itemtext as string, childtext as string)AddChildTo(startfrom, itemtext, childtext) finds the first item with text itemtext at or after startfrom and adds a child item with text childtext to it.
BranchlengthFUNCTION(i as integer) AS INTEGERBranchLength(i) returns the number of items in the branch of item i including the item itself; 1 for an item without children.
MoveDownSUB(i as integer)MoveDown(i) moves item i with its branch below its next sibling, through a temporary file, and selects the moved item.
MoveUpSUB(i as integer)MoveUp(i) moves item i with its branch above its previous sibling, by calling MoveDown on that sibling, and selects it.
IncLevelSUB(i as integer)IncLevel(i) indents item i and its branch by one level (adds a Tab to each saved line), making it a child of the item above; does nothing for item 0.
DecLevelSUB(i as integer)DecLevel(i) moves item i and its branch one level up (removes one leading Tab) and places it before its former parent; does nothing for a top-level item.

Notes

  • MoveDown, IncLevel and DecLevel write and delete a temporary file tmp_tree.tv in the program folder, so the folder must be writable.
  • GetParent and GetChildrenList assign an early result (-1 or "") but do not exit, so they continue scanning; GetChildrenList then returns LEFT$ of an empty list with length -1.
  • BranchLength sets result 0 when the item is the last one but still enters its loop.
  • MoveDown compares i with ItemCount (not the last index) to detect the last item.
  • DecLevel selects the item at parentindex - 1 after the move.
  • The file turns on $TYPECHECK ON for the including program.

  END CREATE
