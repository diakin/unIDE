QDESKTOP Component

Extends QOBJECT · source: inc/QDesktop.inc, line 18 · version: 1.0

Object with desktop helpers: copy the screen or the wallpaper into a device context, read a screen pixel and change the wallpaper.

QDesktop wraps a few Windows API calls. Copy gets the screen DC with GetDC(0) and copies an area starting at the screen's top-left corner into another device context with BitBlt. CopyWallPaper draws the desktop pattern or wallpaper into a DC with PaintDesktop. GetPixel reads the color of a screen pixel. ChangeWallPaper sets a new wallpaper with SystemParametersInfo(SPI_SETDESKWALLPAPER), saving it to the user profile and notifying other programs.

The handle arguments are device context handles, for example the Handle of a QCanvas or QBitmap.

QDESKTOP inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Notes

  • SetActiveDesktop is declared (as an alias of SetActiveWindow) but its only use is commented out.
  • Copy always reads from the screen's top-left corner (0, 0).

QDesktop Examples

Example written for this page from the members above; not run.

DIM Form AS QFORM
DIM Canvas AS QCANVAS
DIM Desk AS QDesktop
Canvas.Parent = Form
Canvas.Align = 5
SUB CanvasPaint
  Desk.Copy(Canvas.Handle, 0, 0, Canvas.Width, Canvas.Height)
END SUB
Canvas.OnPaint = CanvasPaint
Form.ShowModal
