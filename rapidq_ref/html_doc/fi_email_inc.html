eMail

FUNCTION · RQProc.inc, line 11508

Function eMail (eRecipients As String, eSubject As String, eMessage As String, eAttachments As String) As Long

Sends a message through Simple MAPI (MAPISendMail in MAPI32.DLL). eRecipients and eAttachments are ';'-separated lists; a recipient prefixed with '>' is CC, '<' is BCC, and ':' separates a display name from an smtp address. Returns the MAPISendMail result code.

MAPISendMail

Declare Function MAPISendMail Lib "MAPI32.DLL" Alias "MAPISendMail" (iSession As Long, iParam As Long, lpMapiMessage As MapiMessage, iFlags As Long, iReserved As Long) As Long

Simple MAPI: sends a mail message described by a MapiMessage structure, optionally showing the mail client dialog. Returns SUCCESS_SUCCESS (0) or an error code. Deprecated in newer Windows.
