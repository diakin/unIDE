QBEVEL Component

Extends QPANEL · source: inc/QBevel.inc, line 24

Bevel control like the Delphi TBevel: a QPANEL that shows a raised or lowered box, frame or single line.

QBEVEL extends QPANEL and adds only Shape and Style. For the box and frame shapes it uses the panel's own BevelInner and BevelOuter. For the line shapes it aligns a 2-pixel Canvas to the matching side of the panel and draws a two-color line on it (gray &H808080 and white &HFFFFFF; the order depends on Style).

Constants: Style bsLowered (0), bsRaised (1); Shape bsSpacer (0), bsBox (1), bsTopLine (2), bsBottomLine (3), bsLeftLine (4), bsRightLine (5), bsFrame (6).

QBEVEL inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

QBEVEL Properties

FieldTypeR/WDefaultDescription
StyleLONGRWAssigning sets lowered (0, bsLowered) or raised (1, bsRaised): for bsBox it sets BevelOuter to Style+1, for bsFrame it sets BevelInner to 2-Style and BevelOuter to 1+Style, and for the other shapes it clears the bevels and repaints the line.
ShapeLONGRWAssigning sets the shape: 0 bsSpacer (nothing drawn), 1 bsBox, 2 to 5 a line at the top, bottom, left or right (the Canvas is aligned to that side), 6 bsFrame.
CanvasQCANVASRWQCANVAS, 2 pixels wide or high, on which the line shapes are drawn.

The component handles these events itself (EVENT blocks in the TYPE): Canvas.OnPaint.

Notes

  • For Shape 0 (bsSpacer) the setter assigns Canvas.Align = -1.
  • When the shape changes from a line to bsBox or bsFrame, the Canvas keeps its old alignment (nothing is drawn on it for those shapes).
  • The line colors are fixed RGB values, not system colors.
  • The header mentions combo boxes of a demo program that is not part of the include.

QBEVEL Examples

Example written for this page from the members above; not run.

$INCLUDE "QBevel.inc"
CREATE Form AS QFORM
  Width = 300
  Height = 200
END CREATE
DIM Line1 AS QBEVEL
Line1.Parent = Form
Line1.Left = 10
Line1.Top = 40
Line1.Width = 270
Line1.Height = 2
Line1.Shape = bsTopLine
Line1.Style = bsLowered
DIM Frame1 AS QBEVEL
Frame1.Parent = Form
Frame1.Left = 10
Frame1.Top = 60
Frame1.Width = 270
Frame1.Height = 100
Frame1.Shape = bsFrame
Form.ShowModal
