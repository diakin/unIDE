QCOLORDIALOG Component

Extends QOBJECT · source: inc/QColorDialog.inc, line 37

A non-visual wrapper for the Windows color selection dialog (ChooseColor) that returns the color as an RGB value and as an HTML #RRGGBB string.

Execute fills a CHOOSECOLOR structure and calls ChooseColorA from comdlg32. The dialog starts with DefColor selected and the 16 custom colors from Customer; with Full set it opens with the custom color panel expanded (CC_FULLOPEN). When the user presses OK, Customer receives the edited custom colors, RgbColor the chosen color and HtmlColor the same color as "#RRGGBB", and Execute returns True.

Init (called by the constructor) sets DefColor and all custom colors to white. The comments are in French (Properties, color dialog display method, custom color init method).

QCOLORDIALOG inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

MethodTypeDescription
ExecuteFUNCTION(form as QFORM) AS INTEGERShows the color dialog owned by the given form and returns True if the user pressed OK, False otherwise.
InitSUBResets DefColor and all 16 custom colors to white (&HFFFFFF).

Notes

  • HtmlColor is built from characters 3 to 8 of HEX$(RgbColor), which assumes an 8-digit hex string; if HEX$ returns fewer digits (no leading zeros) the HTML string is wrong.
  • DefColor is declared AS INTEGER while RGB colors are LONG values.

Other versions

  • inc/rapidq2.inc (line 6050) contains its own edition of QCOLORDIALOG; it has members that are not in this file: CAPTION, COLOR, COLORS, HEIGHT, STYLE, WIDTH, WINDOWHANDLE.

QColorDialog Examples

Example written for this page from the members above; not run.

$INCLUDE "QColorDialog.inc"

CREATE Form AS QFORM
END CREATE

DIM ColorDlg AS QColorDialog
ColorDlg.Full = 1
ColorDlg.DefColor = Form.Color
IF ColorDlg.Execute(Form) THEN
  Form.Color = ColorDlg.RgbColor
  Form.Caption = ColorDlg.HtmlColor
END IF
Form.ShowModal
