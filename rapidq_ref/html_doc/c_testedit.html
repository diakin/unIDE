TESTEDIT Component

Extends QRICHEDIT · source: inc/TstRichEd.inc, line 6

A small test QRichEdit extension with one function that returns the character index of the first character of the caret line.

TestEDIT extends QRICHEDIT and adds LINEINDEX, which sends EM_LINEINDEX (187) with WhereY (the caret line) and returns the result. The Russian comment says it returns the position of the first character in the line.

After the TYPE the file redefines QRICHEDIT as QMAXEDIT, so later code that creates a QRICHEDIT gets the QMAXEDIT component from ultraRichEd.inc.

TESTEDIT inherits the properties, methods and events of QRICHEDIT; the tables below list only what the component adds or redefines (public members).

Requires

  • QMAXEDIT (ultraRichEd.inc) for code after this file, because of $DEFINE QRICHEDIT QMAXEDIT

TestEDIT Methods

MethodTypeDescription
LINEINDEXFUNCTION AS LONGReturns the character index of the first character of the line given by WhereY (sends EM_LINEINDEX).

Notes

  • The file has a stray top-level line "Declare Function LINEINDEX as long" with no library.
  • The $UNDEF/$DEFINE at the end maps QRICHEDIT to QMAXEDIT, which is not defined in this file; ultraRichEd.inc must be included before any later QRICHEDIT use.
  • ultraRichEd.inc declares the same SendMessageA function, so including both files may give a duplicate declaration.
  • The base class is whatever QRICHEDIT means at the point of inclusion, which can already be redefined by another include.

TestEDIT Examples

Example written for this page from the members above; not run.

$INCLUDE "TstRichEd.inc"
DECLARE SUB EdKeyUp(Key AS WORD, Shift AS INTEGER)
CREATE Form AS QFORM
  Caption = "Line index"
  CREATE Ed AS TestEDIT
    Align = 5
    OnKeyUp = EdKeyUp
  END CREATE
END CREATE
SUB EdKeyUp(Key AS WORD, Shift AS INTEGER)
  Form.Caption = STR$(Ed.LINEINDEX)
END SUB
Form.ShowModal
