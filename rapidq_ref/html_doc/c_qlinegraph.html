QLINEGRAPH Component

Extends QOBJECT · source: inc/qgraph.inc, line 41 · author: Jonathan Boles · date: 2002

Simple line graph object that plots X/Y points from a QStringGrid on a QCanvas, with title, axis titles, automatic scale and tick labels.

QLineGraph extends QObject and draws on its Image field (a QCanvas). The data points are stored in the Data grid: X in Data.Cell(0, i) and Y in Data.Cell(1, i). Paint clears the canvas, writes the title and axis titles, draws the axes at fixed fractions of the canvas size, rounds the largest X and Y values up to a power-of-ten based scale, draws the tick marks with labels and joins the points with lines in LineColour.

Set the properties and fill Data, then call Initialise: it copies the position and size to Image and sets Image.OnPaint to Paint, so the graph is redrawn on every repaint. The component does not set Image.Parent; the program has to do that. SaveToFile copies the canvas into a QBitmap and saves it as a .bmp file.

QLINEGRAPH inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • clWhite color constant (not defined in this file; defined for example in rapidq.inc)

QLineGraph Methods

MethodTypeDescription
PaintSUBDraws the whole graph on Image; called by Image.OnPaint after Initialise.

Notes

  • SaveToFile: the header says the author could not get it to work.
  • XScale and YScale are never used.
  • The canvas is always cleared with clWhite; BackColour is only the text background.
  • The X axis title is centered using the width of YTitle instead of XTitle.
  • With ExtrapolateToZero, the line from the origin goes to the row given by the loop variable i left over from the Y tick loop, not to the first data row.
  • MaxX and MaxY are never reset, so they can only grow between repaints.
  • The loops that find the maximum values run from row 0 to RowCount, one row past the last row.
  • The scale is computed with log(MaxX) and log(MaxY); without positive values these stay 0.

QLineGraph Examples

Example written for this page from the members above; not run.

$INCLUDE "rapidq.inc"
$INCLUDE "qgraph.inc"
CREATE Form AS QFORM
  Width = 420
  Height = 340
END CREATE
DIM Graph AS QLineGraph
DIM i AS INTEGER
Graph.Data.ColCount = 2
Graph.Data.RowCount = 5
FOR i = 0 TO 4
  Graph.Data.Cell(0, i) = STR$(i * 10)
  Graph.Data.Cell(1, i) = STR$(i * i)
NEXT
Graph.Title = "Squares"
Graph.XTitle = "x"
Graph.YTitle = "y"
Graph.Image.Parent = Form
Graph.Initialise
Form.ShowModal
