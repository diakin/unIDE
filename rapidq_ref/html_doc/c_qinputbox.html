QINPUTBOX Component

Extends QOBJECT · source: inc/QInputBox.inc, line 5

A non-visual object that shows a modal input dialog and returns the text the user typed.

QInputBox extends QObject and builds a small dialog (QForm with a prompt QLabel, a QEdit and OK and Cancel buttons) inside the object. Show(Prompt, Title, Default) takes up to three optional string arguments: the prompt text (shown followed by " :", or "Prompt :" when empty), the window title (Application.Title when empty) and the initial text of the edit box.

The dialog is centered, uses the dialog border style and is shown with ShowModal. OK returns the edited text; Cancel, closing the window, or OK with an empty edit box returns the Default text.

QINPUTBOX inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • A DECLARE for SetFocus (user32) must exist elsewhere: Show calls SetFocus, but its declaration in this file is commented out.

QInputBox Methods

MethodTypeDescription
ShowFUNCTIONI(...) AS STRINGShow([Prompt], [Title], [Default]) displays the modal input dialog and returns the entered string; on Cancel or close it returns the Default text.

The component handles these events itself (EVENT blocks in the TYPE): btnCancel.Onclick, btnOk.Onclick, form.Onclose.

Notes

  • SetFocus is called but its DECLARE at the top of the file is commented out.
  • An empty answer cannot be returned: if the user clears the box and presses OK, the OnClose handler replaces the empty result with the Default text.
  • Dialog size and control positions are hard-coded (form 249 x 117 pixels, edit box 209 pixels wide).
