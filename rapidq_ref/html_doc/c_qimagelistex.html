QIMAGELISTEX Component

Extends QIMAGELIST · source: inc/QImageListEx.inc, line 11

A QImageList extension that fills the list from one horizontal bitmap strip, from a file or a resource, optionally stretching the images.

ExtractFile loads a bitmap, divides its width by NumImages to get the image size (or uses FixWidth and FixHeight when they are greater than 0, stretching the strip), and adds each image to the list with AddBMPFile and the given transparent colour.

Each image is copied into a temporary QBitmap, saved as __tmp.bmp in the current directory, added to the list and the file is deleted. ExtractRes first writes a $RESOURCE bitmap to __tmp.bmp and then calls ExtractFile. The strip must be laid out horizontally.

QToolBarEX uses this component to build its button images.

QIMAGELISTEX inherits the properties, methods and events of QIMAGELIST; the tables below list only what the component adds or redefines (public members).

Requires

  • a $RESOURCE bitmap for ExtractRes
  • write access to the current directory for the temporary file __tmp.bmp

QImageListEX Properties

FieldTypeR/WDefaultDescription
FixWidthINTEGERRW0If greater than 0, the width of each image; the strip is stretched to fit. 0 (default) uses the bitmap width divided by the number of images.
FixHeightINTEGERRW0If greater than 0, the height of each image; the strip is stretched to fit. 0 (default) uses the bitmap height.

QImageListEX Methods

MethodTypeDescription
ExtractFileSUB(filename AS string, NumImages AS integer, ColorMask AS integer)ExtractFile(filename, NumImages, ColorMask) clears the list and fills it with NumImages images cut from the horizontal strip in the bitmap file, using ColorMask as the transparent colour. Does nothing if the file does not exist or NumImages <= 0.
ExtractResSUB(ResIndex AS integer, NumImages AS integer, ColorMask AS integer)ExtractRes(ResIndex, NumImages, ColorMask) writes the resource RESOURCE(ResIndex) to __tmp.bmp and calls ExtractFile on it.

Notes

  • A temporary file named __tmp.bmp is written to and deleted from the current directory; an existing file with that name is overwritten and deleted.
  • LoadImageList deletes __tmp.bmp after each image and then calls KILL "__tmp.bmp" once more after the loop, when the file no longer exists.
  • Only horizontal strips are supported.
