QANIMATE Component

Extends QOBJECT · source: inc/QAnimate.inc, line 20 · author: Nastase Eodor · version: 1.2 (stable)

A wrapper for the Windows Animation common control (SysAnimate32) that plays silent AVI clips.

QAnimate extends QObject and creates its own window class QAnimate based on SysAnimate32. Register (called by the constructor) subclasses the control window procedure and the parent window procedure through SetNewCallBack_4 callbacks, so it can paint the background, raise OnPaint, and raise OnStart and OnStop from the ACN_START and ACN_STOP notifications.

The window is created when Parent (a QForm), Parent2 (a QPanel) or ParetWindow (a raw window handle) is assigned. The clip comes either from an AVI file (File) or from one of the standard animations in shell32.dll (CommonAvi, using the aviFindFolder, aviFindFile, aviFindComputer, aviCopyFiles, aviCopyFile, aviRecycleFile, aviEmptyRecycle and aviDeleteFile defines). GetAnimateInfo reads the frame count and frame size from the AVI header.

Style properties (BorderStyle, Transparent, Center, AutoPlay) recreate the window when assigned; the frame range and repeat count restart playback.

QANIMATE inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • Win32 API declarations and constants that the file uses but does not include, such as CreateWindowEx, InvalidateRect, RedrawWindow, FindResource, MoveWindow, GetClassInfo, RegisterClass, InitCommonControls, ACM_OPEN/ACM_PLAY/ACM_STOP, ACS_* styles and ACN_START/ACN_STOP
  • Helper routines used but not defined in the file: SetNewCallBack_4 (defined in CallBack_4.Inc and rapidq2.inc in this library), NewZStr (Memory.inc), MemCpy, MakeLong, HiWord

QAnimate Methods

MethodTypeDescription
InvalidateSUBMarks the control window for repainting with InvalidateRect.
UpdateSUBForces an immediate repaint with UpdateWindow.
RepaintSUBErases and invalidates the window with RedrawWindow, then calls Update.
GetAnimateInfoSUBReads the first 18 DWORDs of the AVI header (from File, or from the shell32.dll resource when File is empty) and sets FrameCount, FrameWidth and FrameHeight.
OpenSUBOpens the clip from File or CommonAvi in the control (ACM_OPEN) and reads its header information.
PlaySUBRepaints and plays from StartFrame to StopFrame (StopFrame 0 means FrameCount) with the Repeat count.
StopSUBStops playback (ACM_STOP).
CreateWndSUBInternal: creates the control window with the current style properties if it does not exist yet.
ReCreateWndSUBInternal: destroys and recreates the window, then opens and plays again if it was opened or playing before.
ParentWndProcFUNCTION(hWnd&,Msg&,wParam&,lParam&) AS INTEGERInternal: replacement window procedure of the parent window; it raises OnStart and OnStop from WM_COMMAND notifications.
WndProcFUNCTION(hWnd&,Msg&,wParam&,lParam&) AS INTEGERInternal: window procedure of the QAnimate class; it handles WM_NCHITTEST, WM_PAINT (OnPaint) and WM_ERASEBKGND (fills with Color).
RegisterSUBInternal: called by the constructor; creates the callbacks, registers the QAnimate window class based on SysAnimate32, gets the shell32.dll handle and creates the background brush.

QAnimate Events

EventTypeOccurs when...
OnStartSUB(Sender&)Raised when the control reports that playback started (ACN_START), with the sender handle.
OnStopSUB(Sender&)Raised when the control reports that playback stopped (ACN_STOP), with the sender handle.
OnPaintSUB(Sender&,Dc&)Raised on WM_PAINT after the default painting, with the window handle and the device context from wParam.

Notes

  • Position is declared with PROPERTY SET SetPosition, but the source contains no SetPosition setter.
  • The file declares none of the Win32 functions and constants it uses; they must come from other include files.
  • When the clip resource is not found, GetAnimateInfo does nothing; the error branch contains only the comment 'Raise Error'.
  • In Open, both branches for File (resource in the executable or not) do the same thing, and GetAnimateInfo always opens File as a disk file.
  • Assigning Repeat, StartFrame or StopFrame always calls Play, so it starts playback even if the clip was stopped.

QAnimate Examples

Example written for this page from the members above; not run.

$INCLUDE "QAnimate.inc"
CREATE Form AS QFORM
  Width = 300
  Height = 150
END CREATE

DIM Anim AS QAnimate
Anim.Parent = Form
Anim.CommonAvi = aviCopyFiles
Anim.Play
Form.ShowModal
