RSOCKET Component

Extends QSOCKET · source: inc/RSocket.INC, line 55 · author: doctorelectron@cwdom.dm (Global Services) · date: June 6,2003

A QSocket extension that adds Winsock helpers: host name and address lookup, peer address, raw connect with timeout check, blocking mode, shutdown and readable error messages.

RSocket extends QSocket and calls wsock32.dll directly. S creates a socket from the inherited Family, Type and Protocol values; Connect connects it to a dotted IP address and port; IsConnected uses select() with a timeout to check whether a connection attempt succeeded. NonBlock and Block switch the socket mode with ioctlsocket(FIONBIO).

AddrByName and NameByAddr convert between host names and IP strings (gethostbyname, gethostbyaddr, inet_ntoa), GetPeerName returns the remote IP of a connected socket, WriteLine sends a string followed by CR LF, EndConnection calls shutdown() and LastError turns WSAGetLastError into a text message.

RSOCKET inherits the properties, methods and events of QSOCKET; the tables below list only what the component adds or redefines (public members).

RSocket Methods

MethodTypeDescription
GetPeerNameFUNCTION(S As LONG) AS STRINGGetPeerName(S) returns the IP address of the remote end of socket S as a dotted string, or an empty string on error.
AddrByNameFUNCTION(strName As STRING) AS STRINGAddrByName(strName) resolves a host name and returns its first IP address as a dotted string, or an empty string if it cannot be resolved or is not an IP address.
NameByAddrFUNCTION(strIP As STRING) AS STRINGNameByAddr(strIP) returns the host name for a dotted IP address, or an empty string if it cannot be found.
SFUNCTION AS LONGCreates a new socket with socket(Family, Type, Protocol) using the component's inherited values and returns its handle.
CloseFUNCTION(S As LONG) AS LONGClose(S) closes socket S with closesocket and returns its result.
NonBlockFUNCTION(S As LONG) AS LONGNonBlock(S) puts socket S into non-blocking mode (ioctlsocket FIONBIO = 1).
BlockFUNCTION(S As LONG) AS LONGBlock(S) puts socket S into blocking mode (ioctlsocket FIONBIO = 0).
ConnectFUNCTION(S As LONG,Remote As STRING,Port As INTEGER) AS LONGConnect(S, Remote, Port) connects socket S to the dotted IP address Remote and Port; returns -1 if the address is invalid, otherwise the result of connect().
IsConnectedFUNCTION(S As LONG,Secs As LONG) AS LONGIsConnected(S, Secs) waits up to Secs seconds: returns -1 if select() reports an error on the socket, otherwise the select() result for writability (1 when connected, 0 on timeout).
EndConnectionFUNCTION(S As LONG) AS LONGEndConnection(S) calls shutdown(S, 2) to stop both sending and receiving.
LastErrorFUNCTION AS STRINGReturns the last Winsock error as text: the error number followed by a description.
WriteLineFUNCTION(S As LONG,str As STRING) AS LONGWriteLine(S, str) sends str followed by CR LF on socket S and returns the result of send().

Notes

  • Working variables (arg, num, ptr1, ptr2, bs, struc, FD_SET, TimeType, str1) are global DIMs outside the TYPE, and the Winsock functions are declared under their plain names (send, recv, socket, shutdown and others); these names can clash with the user's code.
  • Connect accepts only a dotted IP address (inet_addr); use AddrByName first for host names.
  • AddrByName decides that an IP address was returned by checking that HEX$ of a structure field ends in "02".

RSocket Examples

Example written for this page from the members above; not run.

DIM Sock AS RSocket
DIM hSock AS LONG
DIM ip AS STRING
ip = Sock.AddrByName("example.com")
hSock = Sock.S
IF Sock.Connect(hSock, ip, 80) <> 0 THEN
  ShowMessage Sock.LastError
ELSE
  Sock.WriteLine(hSock, "HEAD / HTTP/1.0")
  Sock.WriteLine(hSock, "")
END IF
Sock.Close(hSock)
