QCDAUDIO Component

Extends QOBJECT · source: inc/Qcdaudio.inc, line 27

Non-visual audio CD player that controls the MCI "cdaudio" device: open, play, pause, stop, eject and track selection, with a change event while playing.

Qcdaudio sends MCI command strings ("open cdaudio", "play cdaudio from ...", "status cdaudio position" and so on) with mciSendStringA from winmm.dll. Times are kept in the MCI tmsf (track:minute:second:frame) format as strings.

Call Open to open the device; it checks that a disc is present and reads the number of tracks and the total length. Set CurrentTrack to choose a track and call Play. While playing, an internal timer polls the current track, position and mode once per second and fires OnChange. The states are given by the constants CD_CLOSE (0), CD_PLAY (1), CD_PAUSE (2) and CD_STOP (3).

The comments in the file are in French.

QCDAUDIO inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

ErrorSTRINGRWMCI error text, set when "open cdaudio" fails.
CurrentTrackINTEGERRWCurrent track number. Assigning it while the device is open limits the value to 1..TrackNumber, seeks to that track and reads its length into TrackTime; it does not start playback. While the device is closed, assigning does nothing.

Qcdaudio Methods

MethodTypeDescription
CloseSUBStops the timer, stops and closes the cdaudio device and resets the properties; State becomes CD_CLOSE.
OpenFUNCTION AS BOOLEANCloses the device first, then opens cdaudio, checks that a disc is present and reads TrackNumber and Time. Returns True on success; on failure it closes the device again.
PlaySUBStarts playback from TimePosition when paused, otherwise from CurrentTrack, and starts the timer.
StopSUBStops playback, stops the timer, sets CurrentTrack to 1 and seeks to the start of the disc.
PauseSUBPauses when playing and stores the current track and position for Play to resume.
EjectSUBCalls Stop and Close, opens the drive door and sets Present to False.

Qcdaudio Events

EventTypeOccurs when...
OnChangeSUB(track as integer,time as string)Event (Track AS INTEGER, Time AS STRING) fired by the timer every second while playing, with the current track and position.

The component handles these events itself (EVENT blocks in the TYPE): Timer.OnTimer.

Notes

  • The MCI declarations and the event template event_change are inside $IFNDEF __WIN32API, so they are skipped when a Windows API include defining __WIN32API is loaded first, and the component then misses mciSendCdaudio, mciGetErrorCdaudio and event_change.
  • The timer calls OnChange with CALLFUNC without checking that a handler has been assigned.
  • Position is never updated.
  • Close assigns CurrentTrack = 0 after setting AudioOpen to False, so the setter ignores it and CurrentTrack keeps its old value.
  • Several MCI calls are written with a stray "+" before the comma, for example mciSendCdaudio("status cdaudio current track"+,...).
  • The MCI device name "cdaudio" is fixed, so there is no way to choose a drive.

Qcdaudio Examples

Example written for this page from the members above; not run.

$INCLUDE "Qcdaudio.inc"
CREATE Form AS QFORM
  Width = 300
  Height = 100
END CREATE
DIM CD AS Qcdaudio
SUB CDChange(Track AS INTEGER, Time AS STRING)
  Form.Caption = "Track " & STR$(Track) & "  " & Time
END SUB
CD.OnChange = CDChange
IF CD.Open THEN
  CD.CurrentTrack = 2
  CD.Play
ELSE
  ShowMessage CD.Error
END IF
Form.ShowModal
CD.Close
