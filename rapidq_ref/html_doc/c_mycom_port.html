MYCOM_PORT Component

Extends QOBJECT · source: inc/COMPORTxp.CMP, line 262 · author: Pete Kleinschmidt · version: 0.9 · date: December 13, 2001

A serial (COM) port object that opens, configures, writes to and reads from a communications port through the Win32 file API, with events for errors and completed operations.

MyCom_Port extends QObject. Open calls CreateFile on Port (default "COM1"), sets the buffer sizes with SetupComm, purges the buffers, sets the timeouts and then changes BaudRate, DataBits, Parity and StopBits in the current DCB (other settings keep their current values). On success Connected becomes True and OnOpen is raised; every failing step raises OnComError with a message plus the system error text from FormatMessage.

WriteString(strData, intWait) writes the string with WriteFile, sleeps intWait milliseconds and raises OnWriteString if no bytes are left in the output queue (otherwise OnComError). ReadString(dwRdSize, intWait) reads up to dwRdSize bytes with ReadFile, sleeps intWait milliseconds, updates BytesNotRead and raises OnReadString. Close closes the handle, clears Connected and raises OnClose. Per the header, it is loosely based on VB code by David M. Hitchner.

MYCOM_PORT inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • Constants FILE_SHARE_READ, FILE_SHARE_WRITE, OPEN_EXISTING and FILE_ATTRIBUTE_NORMAL (commented out in this file, must be defined elsewhere)

Notes

  • ReadString calls ReadFile with MyPort.Handle instead of MyCom_Port.Handle, so it only works when the instance is named MyPort.
  • The constructor sets StopBits = 1, which in the DCB means ONE5STOPBITS (1.5 stop bits); use ONESTOPBIT (0) for one stop bit.
  • In Open, WriteTotalTimeoutMultiplier is assigned twice (0, then 1000) and WriteTotalTimeoutConstant is never set.
  • When ClearCommError fails, the error message used is ERROR_CHANGING_PORTSETTINGS instead of ERROR_GETTING_PORT_STATUS.
  • ReadString allocates a buffer of ReadBufSize bytes but reads dwRdSize bytes into it; dwRdSize must not exceed ReadBufSize.
  • If Open fails after CreateFile succeeded, the handle is left open and Connected stays False.
  • The header names the file ComPort.cmp; the file is COMPORTxp.CMP.

MyCom_Port Examples

Example written for this page from the members above; not run.

DECLARE SUB PortError (strErrorMessage AS STRING)

CREATE MyPort AS MyCom_Port
  Port = "COM2"
  BaudRate = 19200
  StopBits = ONESTOPBIT
  OnComError = PortError
END CREATE

SUB PortError (strErrorMessage AS STRING)
  ShowMessage strErrorMessage
END SUB

MyPort.Open
IF MyPort.Connected THEN
  MyPort.WriteString("AT" + CHR$(13), 100)
  ShowMessage MyPort.ReadString(64, 100)
  MyPort.Close
END IF
