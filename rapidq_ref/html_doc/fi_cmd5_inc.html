ConvertToWordArray

FUNCTION · rapidqAllProc.inc, line 7529

Function ConvertToWordArray(sMessage As String) As Long

MD5 preparation: packs sMessage into 32-bit words, adds the 1-bit terminator and the message length in bits, padded to a multiple of 512 bits. The result is stored in the global array WordArray (the function return value is not set). Fails on an empty string.

LShift

FUNCTION · rapidqAllProc.inc, line 7143

Function LShift(ByVal lValue As Long, ByVal iShiftBits As Integer) As Long

Shifts the 32-bit value lValue left by iShiftBits bits (0 to 31), filling with zeros, like << in C; handles the sign bit without overflow. Uses the global tables m_l2Power and m_lOnBits. Shifts outside 0..31 are undefined.

MD5

FUNCTION · rapidqAllProc.inc, line 7653

Function MD5(sMessage As String) As String

Returns the MD5 hash of sMessage as a 32-character lowercase hex string. Uses ConvertToWordArray (global WordArray), the round helpers MD5_FF..MD5_II and the global constants S11..S44, m_l2Power and m_lOnBits, which must be initialized.
