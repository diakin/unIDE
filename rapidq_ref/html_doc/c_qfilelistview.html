QFILELISTVIEW Component

Extends QLISTVIEW · source: inc/QFileListView.inc, line 53 · version: 1.1

QListView that lists the files of a directory with their system icons, size, type and modification date, filtered by one or more masks.

QFileListView extends QListView. Refresh clears the list, attaches the system image lists (large and small icons, obtained with SHGetFileInfoA from shell32.dll), and adds one item per file found with Dir$ for each mask. Every item gets its icon, its size in KB, its type name from the shell and its date as "dd/mm/yyyy hh:mm". The four columns are created the first time Refresh runs and the list is then sorted.

Assigning Directory or Mask refreshes the list. Several masks can be given separated by ";". When the selection changes, FileName is set to the full path and OnFileChange fires; double-clicking an item or pressing Enter fires OnFileSelect. Use the report view (ViewStyle) to see the columns. The comments in the file are in French.

QFILELISTVIEW inherits the properties, methods and events of QLISTVIEW; the tables below list only what the component adds or redefines (public members).

QFileListView Properties

FilenameSTRINGRW""Read-only (its setter does nothing): full path of the selected file (Directory plus item caption), set when the selection changes; empty when nothing is selected.

MaskSTRINGRW"*.*"File mask, for example "*.bas" or "*.bas;*.inc". Assigning it stores it and refreshes the list. Default "*.*".

Notes

  • The system image lists are obtained by querying the hard-coded path "c:\".
  • Column widths are hard-coded (150, 80, 80 and 120 pixels).
  • Only files are listed (Dir$ with attribute 0); subdirectories are not shown.
  • Files whose name has no "." get no icon or type name.
  • Files smaller than 1 KB, including empty files, are shown as "1 KB".
  • The date column is built by splitting FileRec.Date at "-" as month-day-year and FileRec.Time at ":".
  • The SHFILEINFO type, the constants and the API declarations (SHGetFileInfoFileListView, DestroyIconFileListView, SetFocusFileListView) are inside $IFNDEF __WIN32API, so they are missing when a Windows API include defining __WIN32API is loaded first.

QFileListView Examples

Example written for this page from the members above; not run.

$INCLUDE "QFileListView.inc"
CREATE Form AS QFORM
  Width = 500
  Height = 300
END CREATE
DIM Files AS QFileListView
SUB FileChosen(File AS STRING)
  ShowMessage File
END SUB
Files.Parent = Form
Files.Align = 5
Files.ViewStyle = 3   ' report view, shows the columns
Files.OnFileSelect = FileChosen
Files.Mask = "*.bas;*.inc"
Files.Directory = "C:\RapidQ"
Form.ShowModal
