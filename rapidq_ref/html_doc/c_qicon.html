QICON Component

Extends QOBJECT · source: inc/QICON.inc, line 30 · version: 1.2

A non-visual object that extracts icons from files and saves an icon or a 32x32 bitmap as a 16- or 256-color .ico file, or converts it to a cursor.

Assigning FileName loads an icon with ExtractIcon from shell32.dll (or, when Associated is True, the icon of the associated application with ExtractAssociatedIcon); Count receives the number of icons in the file and Handle the icon handle. Assigning Index extracts another icon from the same file.

SaveToFile draws the current icon into a 32x32 QBitmap with DrawIconEx, saves it to a memory stream and writes an .ico file from a built-in 62-byte header, the bitmap palette and pixels, and a monochrome mask. With mask set, white (16 colors) or palette entry &H13 (256 colors) becomes transparent; otherwise the mask is opaque. SaveBmpToFile does the same for a 32x32 QBitmap. ConvertAsCursor patches an .ico file into a .cur file with a hot spot.

QICON inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QICON Properties

FieldTypeR/WDefaultDescription
FileNameSTRINGRWFile to take icons from. Assigning a non-empty name destroys the previous icon, then extracts icon 0 (or the associated icon when Associated is True) and sets Count and Handle; assigning an empty string only destroys the current icon.
countINTEGERRWNumber of icons found in the file (1 in Associated mode).
handleLONGRWHandle (HICON) of the current icon.
AssociatedBOOLEANRWWhen True, assigning FileName uses ExtractAssociatedIcon, so a document file gives the icon of its associated program. Set it before FileName.
indexINTEGERRWIcon number in the file. Assigning it destroys the current icon and extracts the icon with that index if the value is not greater than Count.

QICON Methods

MethodTypeDescription
SaveToFileSUB(FileName as string,pixelFormat as integer,mask as integer)Saves the current icon as a 32x32 .ico file; pixelFormat 2 gives 16 colors, any other value 256 colors; mask non-zero makes a transparency mask.
SaveBmpToFileSUB(bitmap as QBitmap,FileName as string,pixelFormat as integer,mask as integer)Saves a 32x32 QBitmap as an .ico file with the same pixelFormat and mask options; does nothing for other sizes.
ConvertAsCursorSUB(FileName as string,XHotSpot as byte,YHotSpot as byte)Changes an existing .ico file into a cursor: writes the cursor type and the X and Y hot spot into the header and renames the file to .cur (deleting an existing .cur of that name).

Notes

  • CreateMask16 tests characters 7 and 8 of HEX$ of a single byte, which is at most 2 characters long, so the 16-color transparency mask never marks any pixel as transparent.
  • SetIndex accepts Index equal to Count, one past the last icon (icons are numbered from 0), and does not store the new value in Index.
  • After DestroyIcon the Handle field is not reset, so when FileName is set to an empty string or Index is out of range Handle still holds the destroyed handle.
  • ConvertAsCursor builds the new name from the first '.' in the path, so a directory name containing a dot gives a wrong name.
  • Only 32x32 icons are written; the header bytes are hard-coded.

QICON Examples

Example written for this page from the members above; not run.

$INCLUDE "QICON.inc"

DIM Ico AS QICON
Ico.FileName = "C:\WINDOWS\NOTEPAD.EXE"
ShowMessage "Icons found: " + STR$(Ico.Count)
Ico.SaveToFile("notepad.ico", 3, 1)
Ico.ConvertAsCursor("notepad.ico", 16, 16)
