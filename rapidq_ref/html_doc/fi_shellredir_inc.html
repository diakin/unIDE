ShellRedir

FUNCTION · rapidqAllProc.inc, line 19737

Function ShellRedir (CommandLine As String) As String

Runs CommandLine as a hidden console process with stdout and stderr redirected to a pipe (CreatePipe, CreateProcess, ReadFile). Passes each chunk to the user SUB ShellRedirCallBack and returns all collected output; on failure returns an error text.

ShellRedirCallBack

declaration only · rapidqAllProc.inc, line 19733

Declare Sub ShellRedirCallBack (Text As String)

Callback declaration: the program must write SUB ShellRedirCallBack(Text As String). ShellRedir calls it with each chunk of console output as it arrives, and with an error message if the pipe or process cannot be created.
