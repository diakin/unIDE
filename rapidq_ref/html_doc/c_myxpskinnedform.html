MYXPSKINNEDFORM Component

Extends QFORM · source: inc/XPSkinMetallic_2.11_Res.inc, line 462 · version: 2.13 · date: 28 juin, 2003

A skinned form that replaces the Windows title bar and borders with Windows XP Metallic style bitmaps, its own title buttons, a system popup menu, rounded corners and a default button.

myXPSkinnedForm extends QForm. In OnShow it hides the real title bar, cuts the window to a rounded rectangle (CreateRoundRectRgn, SetWindowRgn) and builds the frame from QImage pieces (title left, middle and right, side borders, bottom pieces) loaded from bitmap resources, plus close, maximize, minimize and help buttons, an icon, a caption and a default button MainBtn (caption "Fermer", closes the form). Dragging the title moves the window; clicking the icon or right-clicking the title shows an XP-style popup menu (a borderless QForm) with Always on top, Move, Minimize, Maximize and Close items, with French captions.

The skin switches between active and inactive bitmaps; ActiveInactive installs a replacement window procedure (SetWindowLong GWL_WNDPROC) that does this on WM_NCPAINT and WM_ACTIVATE. The first instance is the main form; every later instance is treated as a dialog (PopupBox): it is centered, has no minimize and maximize buttons and disables the main window while shown. Closing the main form terminates the application. TweakSkin draws simple colored lines instead of border bitmaps. All comments are in French.

MYXPSKINNEDFORM inherits the properties, methods and events of QFORM; the tables below list only what the component adds or redefines (public members).

Requires

  • Bitmap and icon resources declared by the user with $RESOURCE (the file declares none): ICO, TITLE_LEFT, TITLE_MID, TITLE_RIGHT, TITLE_LDIS, TITLE_MDIS, TITLE_RDIS, TITLE_CAP, TITLE_CAPDIS, TITLE_ICO, BOT_LEFT, BOT_MID, BOT_RIGHT, BOT_LDIS, BOT_MDIS, BOT_RDIS, BORDER_LEFT, BORDER_RIGHT, BORDER_LDIS, BORDER_RDIS, TCLOSE_BMP, TCLOSEON_BMP, TCLOSEPRS_BMP, TCLOSEDIS_BMP, TFIX_BMP, TFIXON_BMP, TFIXPRS_BMP, TFIXDIS_BMP, TRED_BMP, TREDON_BMP, TREDPRS_BMP, TREDDIS_BMP, TAIDE_BMP, TAIDEON_BMP, TAIDEPRS_BMP, TAIDEDIS_BMP, BNORM_BMP, BSEL_BMP, BOVER_BMP, BPRES_BMP, ItmOnTop_BMP, ItmReduire_BMP, ItmRestaurer_BMP, ItmAgrandir_BMP, ItmFermer_BMP
  • CONST myMainFormName (the main window caption) defined before the $INCLUDE
  • The main form instance must be named MainForm
  • The global QBitmap array TitleBtnsBg(0 TO 1) (title button background, inactive and active) must be loaded by the user; the file declares it but never loads it

Notes

  • The file name says 2.11 but the header says Windows XP Metallic Skin v2.13.
  • The main form must be named MainForm and myMainFormName must be defined before the include; if it is missing or the main window is not found, OnShow shows a French warning message. At include time the code also uses FindWindow with myMainFormName to bring an already running copy to the front and END the new one.
  • No $RESOURCE lines are included: all skin bitmaps and the ICO icon must be provided by the program, and the global TitleBtnsBg bitmaps are never loaded by this file.
  • In OnShow, EnableWindow(mhWnd,) is called with an empty second argument.
  • In WindowProc the CASE list is "WM_NCPAINT, WM_ACTIVATE, .XPPopupMenu.Visible=0", so the boolean expression is compared with the message number.
  • Known problems listed in the header: menu images are not redrawn when an item is hovered; bottom borders are drawn incorrectly with ActiveInactive(True); a second window tries to appear in the taskbar; external dialog boxes are hidden behind the main window in always-on-top mode (the header suggests CTRL+ALT+F4); some bitmap formats crash the program and should be re-saved from Internet Explorer.
  • The header says WM_NCACTIVATE causes problems, and that after always-on-top mode is used the inactive colors still have a bug.
  • ActiveInactive never sets its return value; the Options item and the help button have no action; Minimized is never set by active code.
  • The constructor fixes the size at 400 x 400 and the popup menu width at 123 pixels; button positions are hard-coded offsets from the right edge (27, 50, 73, 98 pixels).

myXPSkinnedForm Examples

Example written for this page from the members above; not run.

CONST myMainFormName = "Form style WinXP"
' $RESOURCE lines for ICO, TITLE_LEFT, TITLE_MID, ... (see requires)
$INCLUDE "XPSkinMetallic_2.11_Res.inc"

CREATE MainForm AS myXPSkinnedForm
  Caption = myMainFormName
  Width = 320
  Height = 240
END CREATE

MainForm.AddTitleIcons(tiMinimize, tiMaximize)
MainForm.ActiveInactive(True)
MainForm.ShowModal
