QLED Component

Extends QCANVAS · source: inc/QLed.inc, line 10

A round LED indicator drawn on a QCanvas, with six colors and on/off states.

QLed draws a filled circle of the chosen color and a gradient highlight with QCanvas.Circle; in the off state the color is half bright. The canvas is made square with the side Size. The colors are the constants LdCyan, LdPurple, LdBlue, Ldyellow, LdGreen and LdRed (1 to 6); each bit of the value switches off one of the red, green and blue channels. LdOn (1) and LdOff (0) are the states.

The LED is redrawn in OnPaint and whenever LedColor or LedState is assigned. Defaults: Size 15, LedColor LdRed.

QLED inherits the properties, methods and events of QCANVAS; the tables below list only what the component adds or redefines (public members).

QLed Properties

FieldTypeR/WDefaultDescription
LedColorBYTERWLdRedLED color, one of LdCyan, LdPurple, LdBlue, Ldyellow, LdGreen, LdRed. Assigning it redraws the LED.
LedStateINTEGERRWLdOn (1) for a bright LED, LdOff (0) for a dim one. Assigning it redraws the LED.
SizeINTEGERRW15Diameter in pixels; the canvas Width and Height are set to it on each Draw (default 15).

QLed Methods

MethodTypeDescription
DrawSUBResizes the canvas to Size and draws the LED in its current color and state.

The component handles these events itself (EVENT blocks in the TYPE): OnPaint.

Notes

  • The SetColor property setter ends with End Sub instead of End Property.
  • Draw uses qled.size instead of This.Size inside the gradient loop.

QLed Examples

CREATE Form AS QFORM
  CREATE Led AS QLED
    Left = 10
    Top = 10
    Size = 20
    LedColor = LdGreen
    LedState = LdOn
  END CREATE
END CREATE
