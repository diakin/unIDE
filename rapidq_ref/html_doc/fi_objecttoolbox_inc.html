ObjectToolbox.TypeOf

FUNCTION · rapidqAllProc.inc, line 14226

Function ObjectToolbox.TypeOf(Object as long) as string

Returns the RapidQ component name for the window handle Object: gets the Win32 class name, changes a leading T to Q, drops a trailing s, and maps TBitBtn to QButton, TApplication to Application and #32768 to QMenuItem.

ObjectToolbox.TypeOfA

FUNCTION · rapidqAllProc.inc, line 14216

Function ObjectToolbox.TypeOfA(Object as long) as string

Returns the native Win32 class name of the window handle Object (via ObjectToolbox_GetClassName, i.e. GetClassName), for example TButton.

Declare Function ObjectToolbox_GetClassName lib "user32" alias "GetClassNameA" (ByVal hWnd as long, ByRef lpClassName as string, ByVal nMaxCount as long) as long

Retrieves the name of the window class to which a window belongs. Returns the number of characters copied, or 0 on failure.

TypeOf

FUNCTIONI · rapidqAllProc.inc, line 14256

Functioni TypeOf(...) as string

Returns the class name of an object handle. TypeOf(handle) gives the RapidQ name (ObjectToolbox.TypeOf); TypeOf(handle, 1) gives the native Win32 class name (ObjectToolbox.TypeOfA). Uses BIND and CALLFUNC.
