XPGROUPBOX Component

Extends QPANEL · source: inc/XP_MANIFEST.INC, line 91 · author: Paul Ludgate (xpGroupBox); file based on QXpTheme by Nicolas Tillet, additions by robin_q_master, modified for RQ2 by JohnK · date: 4/2006

A group box drawn in the Windows XP style: a rounded thin border with a colored caption, drawn on a QCanvas inside a QPanel.

XpGroupBox extends QPanel (BevelWidth 0) and places a client-aligned QCanvas on it. In the canvas OnPaint it draws a one-pixel border with rounded corners, starting half a text line from the top, and writes Caption at x = 7 in CaptionColor on the button face color.

When LunaDetect is on (the default), the border color is chosen from the system button face color read with GetSysColor(15): &H5C7777 for the silver theme, &HBFD0D0 for the blue or olive theme; otherwise BorderColor is used. The same file contains the XPButton helper and the $XP_MANIFEST SUB, which writes a manifest file (program path plus .manifest) for Common Controls 6 so other controls get the XP look.

XPGROUPBOX inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

Requires

  • A GetSysColor declaration from elsewhere (used in the paint code, not declared in this file)

XpGroupBox Properties

FieldTypeR/WDefaultDescription
CaptionSTRINGRWText drawn in the top border; shown on the next paint.
BorderColorLONGRW&HBFD0D0Border color used when LunaDetect is 0 (default &HBFD0D0).
CaptionColorLONGRW&HD54600Color of the caption text (default &HD54600).
LunaDetectLONGRW1When non-zero (default 1), the border color is picked automatically from the system button face color instead of BorderColor.

The component handles these events itself (EVENT blocks in the TYPE): Canvas.OnPaint.

Notes

  • GetSysColor is called but not declared in this file.
  • Theme detection only compares the button face color with &HE3DFE0 (silver); any other color is treated as the blue or olive theme.
  • Caption, BorderColor, CaptionColor and LunaDetect are plain fields; changing them does not repaint the box.
  • The $XP_MANIFEST helper in the same file writes the manifest only when the major version is at least 5 and the minor version is above 0, so for example Windows Vista (6.0) is skipped.

XpGroupBox Examples

Example written for this page from the members above; not run.

$INCLUDE "XP_MANIFEST.INC"
$XP_MANIFEST
CREATE Form AS QFORM
  Caption = "Group box"
  CREATE Group AS XpGroupBox
    Left = 10: Top = 10
    Width = 200: Height = 120
    Caption = "Options"
  END CREATE
END CREATE
Form.ShowModal
