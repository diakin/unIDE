QICMP Component

Extends QOBJECT · source: inc/QICMP.INC, line 47

A ping component that sends ICMP echo requests with icmp.dll.

QICMP extends QObject and uses IcmpCreateFile, IcmpSendEcho and IcmpCloseHandle from icmp.dll. The request options (ReqOpts) and the reply buffer (Reply) are LONG and BYTE arrays rather than TYPE structures, because the source says RapidQ may not store type structures contiguously.

Call Ping with a dotted IP address string; it returns the round-trip time in milliseconds or -1 on failure. After a ping, ReplyAddress, ReplyStatus, ReplyData and ReplyTTL decode the reply. The IP_* status constants are defined in the file.

QICMP inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • icmp.dll

QICMP Methods

MethodTypeDescription
PingFUNCTION(RemoteIP As String) AS LONGPing(RemoteIP) sends an echo request to a dotted IPv4 address (converted with inet_addr; host names are not resolved). Returns the round-trip time in ms, or -1 if the handle cannot be created, the address is invalid or no reply arrives.
ReplyAddressFUNCTION AS STRINGReturns the address that replied as a dotted string, or an empty string if there is none.
ReplyStatusFUNCTION AS STRINGReturns the reply status as text, for example "ip success" or "ip req timed out".
ReplyDataFUNCTION AS STRINGReturns the data echoed back in the reply, or an empty string when the round-trip time is 0.
ReplyTTLFUNCTION AS LONGReturns the TTL value of the reply, decoded from the options field.
CloseHandleFUNCTION AS LONGCloses the ICMP handle and returns the IcmpCloseHandle result, or -1 if no handle was open.

Notes

  • CloseHandle does not reset h to 0, so a Ping after CloseHandle reuses the closed handle. There is no destructor that closes the handle.
  • ReplyAddress and ReplyTTL take fixed character positions from HEX$ of the value; if HEX$ returns fewer than 8 digits (no leading zeros), the decoded address or TTL is wrong.
  • ReplyData returns an empty string when the round-trip time is 0 ms, even if data was received.
  • Ping accepts only numeric IPv4 addresses.

QICMP Examples

Example written for this page from the members above; not run.

$INCLUDE "QICMP.INC"
DIM Icmp AS QICMP
DIM Ms AS LONG
Ms = Icmp.Ping("192.168.0.1")
IF Ms >= 0 THEN
  PRINT "Reply from "; Icmp.ReplyAddress; " in "; Ms; " ms"
ELSE
  PRINT "Failed: "; Icmp.ReplyStatus
END IF
