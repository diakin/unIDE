QSHUTDOWN Component

Extends QOBJECT · source: inc/QShutdown.inc, line 63 · date: Feb, 2006

A non-visual object that shuts down, force-shuts down, reboots Windows or logs off the current user.

QShutDown extends QOBJECT. Each public method sets an ExitWindowsEx flag and calls the private DoShutDown, which first enables the SeShutdownPrivilege for the current process (OpenProcessToken, LookupPrivilegeValueA, AdjustTokenPrivileges from advapi32) and then calls ExitWindowsEx from user32. The privilege step is needed, per the source comment, or the reboot fails.

The LUID, LUID_AND_ATTRIBUTES and TOKEN_PRIVILEGES types and the advapi32 declarations are defined only when __WIN32API is not defined; ExitWindowsEx, GetCurrentProcess and the EWX_ constants are defined only when __RQINC2 is not defined, so with those include files the declarations come from them instead.

QSHUTDOWN inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QShutDown Methods

MethodTypeDescription
ShutDownSUBShuts Windows down (ExitWindowsEx with EWX_SHUTDOWN) after enabling the shutdown privilege.
ShutDownForceSUBShuts Windows down with EWX_FORCE OR EWX_SHUTDOWN, which forces applications to close.
LogOffSUBLogs off the current user (EWX_LOGOFF).
RebootSUBRestarts Windows (EWX_REBOOT) after enabling the shutdown privilege.

Notes

  • The source says it comes from a RapidQ Yahoo Groups posting; no author is named.
  • Return values of OpenProcessToken, LookupPrivilegeValue, AdjustTokenPrivileges and ExitWindowsEx are ignored, so the methods give no indication of failure.
  • TOKEN_PRIVILEGES is flattened (the LUID_AND_ATTRIBUTES array is replaced by LowPart, HighPart and Attributes fields) and only supports one privilege.
