QDATABASE Component

Extends QOBJECT · source: inc/qdataBaseSQL.inc, line 130 · author: Alberto (from Brasil) (netmask@ig.com.br)

ODBC database object that connects to Access, dBase, Paradox, Excel or text files and reads the list of tables and their field definitions.

qDATABASE uses the ODBC API in odbc32.dll. The driver is chosen by a number (dbMSACCESS=0, dbDBASE=1, dbPARADOX=2, dbEXCEL=3, dbTEXT=4), and the helper UseDriver builds a connection string with DRIVER=...;DBQ=<path>. It allocates the ODBC environment and connection, connects with SQLDriverConnect, lists tables and views with SQLTables, then runs SELECT * on each table to count records and describe columns.

The results are stored in the arrays Table.Name, Table.TYPE, Table.RecCount, Table.FieldCount, Table.FieldName, Table.FieldType, Table.FieldSize, Table.DecDigits and Table.NullAV (up to 150 tables and 255 fields). All methods return the string "0" on success or an error message.

GetDataBaseInfo reads the structure and closes the connection. OpenDataBase reads it and keeps the connection open, so GetSTMT can hand a statement handle to a qSQLTABLE object through its DataBaseExtends method.

QDATABASE inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • ODBC drivers for the chosen file type

qDATABASE Methods

MethodTypeDescription

CloseDataBaseSUBDisconnects and frees the ODBC connection and environment handles.
GetSTMTFUNCTION AS LONGAllocates a new ODBC statement handle on the open connection (keyset cursor) and returns it, or -1 on failure; pass it to qSQLTABLE.DataBaseExtends.

Notes

  • The Excel driver name is in Portuguese ("Driver para o Microsoft Excel(*.xls)"), so it only matches a Portuguese ODBC installation.
  • Arrays are fixed at 150 tables and 255 fields per table.
  • Field indexes in Table.FieldName and related arrays start at 1, while table indexes start at 0.
  • Record counts are found by fetching every row of every table, which can be slow on large databases.

qDATABASE Examples

Example written for this page from the members above; not run.

DIM DB AS qDATABASE
DIM Res AS STRING
Res = DB.OpenDataBase("C:\data\test.mdb", dbMSACCESS)
IF Res = "0" THEN
  FOR i = 0 TO DB.TableCount - 1
    PRINT DB.Table.Name(i); " "; DB.Table.TYPE(i); " "; DB.Table.RecCount(i)
  NEXT
END IF
DB.CloseDataBase
