QRICHEDITUX Component

Extends QRICHEDIT · source: inc/XPThemes.inc, line 103

A QRICHEDIT that draws its border with the Windows XP visual style color after Subclass is called.

QRichEditUx extends QRICHEDIT with a window procedure hook. After Subclass is called, every WM_NCPAINT is first passed to the original procedure; then, if the EDIT theme of uxtheme.dll is active, the WS_EX_CLIENTEDGE 3D border is replaced by a single WS_BORDER line and repainted with the theme's border color (TMT_BORDERCOLOR). In classic mode it restores the client edge border instead.

Call Subclass once after the control has been created and has a parent, for example just before showing the form.

QRICHEDITUX inherits the properties, methods and events of QRICHEDIT; the tables below list only what the component adds or redefines (public members).

Requires

  • uxtheme.dll (Windows XP or later)
  • Callbacks.inc (included unless __RQCALLBACKS is defined) for SetNewCallBack_4
  • Windows API declarations from a Win32 API include when __WIN32API is defined; otherwise XPThemes.inc declares them itself

QRichEditUx Methods

MethodTypeDescription
SubclassSUBSubclasses the control's window procedure (through SetNewCallBack_4) so its border is redrawn in XP visual style; does nothing on Windows versions older than XP (5.01) or when the control has no handle yet. The guard against subclassing twice uses a bitwise AND NOT on Subclassed, so a second call may subclass again (see Notes).

Notes

  • The window DC from GetWindowDC is never released with ReleaseDC.
  • The guard IF .Handle AND NOT .Subclassed uses bitwise AND/NOT, so a second call to Subclass may subclass the control again when the handle has bits other than bit 0 set.
  • The version test (GetVersion AND 255) + (GetVersion AND &HFF00) / 25600 >= 5.01 skips Windows 2000 and earlier.
