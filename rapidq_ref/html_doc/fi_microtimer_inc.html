microTIMER

FUNCTION · RQProc.inc, line 13948

FUNCTION microTIMER() AS DOUBLE

Returns a high-resolution relative time in seconds as Double, using QueryPerformanceCounter divided by QueryPerformanceFrequency (read once on first call). Returns 0.0 if the counter frequency does not fit in 32 bits.

MicroTimer_dwToDbl

FUNCTION · RQProc.inc, line 13945

FuncTion MicroTimer_dwToDbl (iDw As Long) As Double

Converts a 32-bit value held in a signed Long to an unsigned value as Double (adds 2^31 when the sign bit is set). Helper for microTIMER.
