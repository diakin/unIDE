QPDecode

FUNCTION · rapidqAllProc.inc, line 10506

Function QPDecode( Source As String) As String

Decodes a quoted-printable string: removes soft line breaks (= at line end) and replaces each =XX hex code with its character. Returns the decoded text. Assumes every = is followed by two hex digits.

QPDecodeOld

FUNCTION · rapidqAllProc.inc, line 10428

Function QPDecodeOld( Source As String) As String

Old decoder for MIME quoted-printable encoded-words (=?charset?Q?text?=) in a mail header; returns the decoded text, or Source unchanged if there is no =? or the encoding is not Q. Prints debug output with PRINT. Superseded by DecodeSubj.

QPMSGHeaderDecode

FUNCTION · rapidqAllProc.inc, line 10510

Function QPMSGHeaderDecode( Source As String) As String

Decodes quoted-printable MIME encoded-words (=?charset?Q?text?=) in a mail header and returns the text; returns Source unchanged if there is no =? or the encoding is not Q. Prints debug output with PRINT. Same logic as QPDecodeOld.
