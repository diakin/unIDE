QIMAGEEX Component

Extends QIMAGE · source: inc/object/QImageEx.inc, line 36 · version: 1.1

QImage extension with clipboard copy and paste, bitmap loading at a chosen size, and loading of other image formats through NViewLib.dll.

QImageEx adds GDI and clipboard helpers to QImage. CopyToClipboard copies a rectangle of the image into a new compatible bitmap with BitBlt and puts it on the clipboard as CF_BITMAP. PasteFromClipboard takes a CF_BITMAP handle from the clipboard and assigns it to the image's Handle.

LoadFromFile loads a .bmp file with LoadImage (LR_LOADFROMFILE), either at its real size or at a given width and height. LoadOtherImage loads formats supported by NViewLib.dll (NViewLibLoad) and sets the image size from the loaded picture.

QIMAGEEX inherits the properties, methods and events of QIMAGE; the tables below list only what the component adds or redefines (public members).

Requires

  • NViewLib.dll (for LoadOtherImage)

QImageEx Methods

MethodTypeDescription
CopyToClipboardSUB(rect as QRECT)CopyToClipboard(rect AS QRECT) copies the given rectangle of the image to the clipboard as a bitmap.
PasteFromClipboardSUBIf the clipboard holds a bitmap, assigns its handle to the image.
LoadFromFileSUB(FileName as string,width as short,height as short,real as boolean)LoadFromFile(FileName, width, height, real) loads a bitmap file; if real is True it keeps the file's own size, otherwise it is loaded at width x height.
CanPasteFUNCTION AS BOOLEANReturns True if the clipboard holds a bitmap.
LoadOtherImageSUB(FileName as string,Progress as boolean,Language as string)LoadOtherImage(FileName, Progress, Language) loads an image with NViewLib.dll (passing Language to NViewLibSetLanguage and Progress to the loader) and sets Width and Height from it.

Notes

  • CanPaste is declared as a Function but ends with End Sub.
  • CopyToClipboard deletes the bitmap handle right after placing it on the clipboard.
  • Load_JPG, Load_GIF and NViewLibSaveAsJPG are declared but not used.

QImageEx Examples

Img.Parent = Form
Img.LoadOtherImage("photo.jpg", False, "English")
IF Img.CanPaste THEN Img.PasteFromClipboard
