QHTML Component

Extends QPANEL · source: inc/QHTML.inc, line 73 · author: Pascal Delcombel · version: 1.0 · date: 2003-2008

A read-only viewer for simplified HTML pages, drawn on a panel in pure RapidQ code.

QHTML extends QPanel and shows HTML text without any Windows API call or DLL; the header says this was done so the class could be ported to the Linux version. It parses the markup into fixed-size element arrays (htmlMaxElements = 200000) and paints them on an internal QImage with a vertical scroll bar and a status bar that shows the URL of the hovered link.

Supported tags include A, AREA, B, BIG, BR, BLOCKQUOTE, BODY (BGCOLOR, TEXT, LINK, BACKGROUND), CENTER, EM, FONT (FACE, COLOR), H1-H6, I, IMG, MAP, P, PRE/KBD, SMALL, S/STRIKE, STRONG, TITLE and U. A page that contains FRAMESET is replaced by an error page. Named HTML colors are taken from a built-in table.

Load a page with OpenFile or by assigning HTMLText. Images and the BODY background are drawn only when an OnLoadImage handler loads the file into the QImage it receives; otherwise the image source text is shown. OnTagClick gives the HREF of a clicked link, so the program can open the next page itself. PrintPreview opens a maximized preview window with print, page navigation, save-as-bitmap and printer selection; SearchText finds and highlights text.

QHTML inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

QHTML Properties

FieldTypeR/WDefaultDescription
HTMLTextSTRINGRWHTML source of the page. Assigning it parses the text and starts a repaint with the scroll bar recalculated; the setter does not store the value in HTMLText.
DocumentTitleSTRINGRWPage title taken from the TITLE tag during parsing. Read only: assigning it does nothing.
DefaultFontNameSTRINGRW"Arial"Font name used for text that has no FONT FACE (default "Arial"). Assigning it only stores the value; it is applied the next time a page is parsed.
DefaultFontSizeINTEGERRW12Font size used for text that has no explicit size (default 12). Assigning it only stores the value; it is applied the next time a page is parsed.

QHTML Methods

MethodTypeDescription
OpenFileSUB(FileName as String)OpenFile(FileName) reads the whole file with a QFileStream, parses it and repaints. FileName is a local file, not a URL.
RepaintSUBRedraws the current page and recalculates the scroll bar without parsing it again.
PrintPreviewSUBOpens a maximized preview window of the page split into printer pages, with buttons for print current page, print all pages, first/previous/next/last page, save current page as a bitmap, a With background check box and a printer selection combo box.
SearchTextFUNCTION(Text as String, Popupwindow as integer) AS INTEGERSearchText(Text, Popupwindow) searches the page for Text and highlights the match; the next call continues after the previous match. With Popupwindow true, or an empty Text, it opens a modal Search dialog with Next and Cancel buttons. Returns true if a match was found.

QHTML Events

EventTypeOccurs when...
OnHoverSUB(TypeObject as String, URL as string)Raised when the mouse moves over the page, with TypeObject ("HREF" for a link, otherwise the element type or an empty string) and URL (the link HREF or the hovered element text).
OnTagClickSUB(URL as string)Raised on mouse up over a hovered element, with HoveredTag as the only parameter: the HREF (URL or file name) for a link, the element text for other elements.
OnLoadImageSUB(Image as QImage, FileName as String)Raised when an image or background file is needed, with an invisible QImage and the file name; the handler must load the picture into that QImage (for example JPEG or GIF through an external routine). If the QImage width stays 0, the image is treated as not drawable.

The component handles these events itself (EVENT blocks in the TYPE): bar.OnChange, Image.OnMouseMove, Image.OnMouseUp.

Notes

  • The header lists the limits: only a few tags are supported (tables are named as not included), no frames, no form controls, no download, and at most 200000 elements because the arrays cannot be resized inside a QObject; the limit is the constant htmlMaxElements.
  • The header documents OnHover and OnTagClick with extra x, y and shift parameters, but the event templates and the CALLFUNC calls pass only TypeObject and URL (OnHover) and URL (OnTagClick).
  • The HTMLText setter never stores the assigned text, so reading HTMLText back does not return the page source.
  • Without an OnLoadImage handler no image or background picture is drawn; only the image source text is shown.
  • The function AdjustCompletePath is defined but never called, so image and link paths are passed on exactly as written in the page.
  • Until a page is loaded, a built-in copyright page (QHTML v0.1 2002) is shown.
  • Mouse hover detection only handles anchor areas with the RECT shape.

QHTML Examples

Example written for this page from the members above; not run.

$INCLUDE "QHTML.inc"
DECLARE SUB LinkClick(URL AS STRING)
DECLARE SUB LoadImg(Image AS QImage, FileName AS STRING)

CREATE Form AS QFORM
  Width = 640
  Height = 480
  CREATE Html AS QHTML
    Align = alClient
    OnTagClick = LinkClick
    OnLoadImage = LoadImg
  END CREATE
END CREATE

SUB LinkClick(URL AS STRING)
  Html.OpenFile URL
END SUB

SUB LoadImg(Image AS QImage, FileName AS STRING)
  IF FileExists(FileName) THEN Image.BMP = FileName
END SUB

Html.OpenFile "index.htm"
Form.ShowModal
