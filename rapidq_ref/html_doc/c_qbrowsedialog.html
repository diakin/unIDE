QBROWSEDIALOG Component

Extends QOBJECT · source: inc/QBrowseDialog.inc, line 55 · author: Psyclops

QBROWSEDIALOG shows the Windows "Browse for folder" dialog and returns the selected folder.

The header describes it as easier to use than QDirTree when only a folder name is needed. Like QOpenDialog it is created with DIM or CREATE and shown with Execute, which returns 1 when the user presses OK and 0 on Cancel or close.

Execute calls SHBrowseForFolder from shell32 with a BROWSEINFO structure and converts the result with SHGetPathFromIDList, freeing it with CoTaskMemFree. The callback BrowseHook centers the dialog, selects InitialDir and sets Caption. Virtual folders such as the Recycle Bin or Fonts can be chosen too, but only their display name is returned, not a usable path.

QBROWSEDIALOG inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • MAX_PATH constant defined elsewhere, for example in WINDOWS.INC or WIN32API.INC (its CONST is commented out in this file)

QBROWSEDIALOG Properties

FieldTypeR/WDefaultDescription
CaptionSTRINGRWText for the dialog's title bar; when empty the default ("Browse for folder") is kept.

DirectorySTRINGRWSelected folder after Execute returns 1; for a virtual folder it holds only the folder's display name.
XSTRINGRWPurpose not clear from the source; the field is never used.

QBROWSEDIALOG Methods

MethodTypeDescription
BrowseHookFUNCTION(hWnd AS LONG, uMsg AS LONG, lParam AS LONG, lpData AS LONG) AS LONGInternal: callback passed to SHBrowseForFolder; on initialization it centers the dialog, selects InitialDir and sets Caption.
ExecuteFUNCTION AS LONGShows the dialog; returns 1 and sets Directory when the user presses OK, 0 when the dialog is cancelled or closed.

Notes

  • Execute appends CHR$(0) to InitialDir every time it is called, so the property grows with repeated calls.
  • ulFlags of BROWSEINFO is never set, so the defined BIF_RETURNONLYFSDIRS constant is not used and virtual folders can be selected.
  • The MAX_PATH constant is commented out and must come from another include.

QBROWSEDIALOG Examples

Example written for this page from the members above; not run.

$INCLUDE "QBrowseDialog.inc"
DIM Browse AS QBROWSEDIALOG
Browse.Caption = "Select folder"
Browse.Title = "Choose the output folder:"
Browse.InitialDir = "C:\"
IF Browse.Execute THEN ShowMessage Browse.Directory
