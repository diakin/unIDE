ExtractFileName

FUNCTION · rapidqAllProc.inc, line 4069

FUNCTION ExtractFileName(FileName as STRING) AS STRING

Returns the file name without the path: the text after the last backslash or "/". Files.inc is under $ESCAPECHARS ON, so "\\" in the code is one backslash. The two positions are combined with OR (bitwise), so a path that has both "\" and "/" can give a wrong position.

ExtractFilePath

FUNCTION ExtractFilePath(FileName as STRING) AS STRING

Returns the path part of FileName up to and including the last backslash or "/" (Files.inc is under $ESCAPECHARS ON, so "\\" in the code is one backslash). The two positions are combined with OR (bitwise), so a path that has both separators can give a wrong result.

SUB io2RndInter (io$, rndf$, LostP)

Converts a text file of "point,value" lines to a binary SINGLE file rndf$, filling missing points by linear interpolation. Also writes the point numbers to a companion file (name + "Arg" + ext). LostP returns the missed-point count (pass by reference); if LostP is -1 on entry DOEVENTS is called.
