QINIFILE Component

Extends QSTRINGLIST · source: inc/QIniFile.inc, line 11 · author: Nastase Eodor · date: 2008

A QStringList-based INI file reader and writer with section and key lookup and typed read/write methods.

QIniFile extends QStringList and keeps the whole INI file in its items. CreateFile picks the file, loads it if it exists or creates it empty. Sections are lines starting with "[", keys are matched case-insensitively on the text before "=".

WriteInteger, WriteFloat and WriteString replace an existing key, insert a new key at the end of its section, or append a new section; every write saves the file immediately. ReadInteger, ReadFloat and ReadString return the value or the given default. ReadSection and ReadSections copy lines into another QStringList. The Windows folder is found with GetWindowsDirectory from kernel32.

QINIFILE inherits the properties, methods and events of QSTRINGLIST; the tables below list only what the component adds or redefines (public members).

Requires

  • $Include "SysUtils.inc" (ExtractFileName, ExtractFilePath, ChangeFileExt), unless __RQSYSUTILS is already defined

Notes

  • The constructor sets a default name (program name with .ini), but CreateFile overwrites it before use, so it is never used; passing only a folder path makes File equal to the folder.
  • CreateFile must be called before writing, otherwise File is empty when the file is saved.
  • ReadString returns only the text between the first and second "=", so values that contain "=" are cut.
  • SectionExists removes every "[" and "]" from the line before comparing; spaces around keys are not trimmed.
  • ReadInteger is declared As Integer although the default and write value are Long.

QIniFile Examples

Example written for this page from the members above; not run.

$INCLUDE "QIniFile.inc"
DIM Ini AS QIniFile
Ini.CreateFile "C:\MyApp\settings.ini"
Ini.WriteString "Main", "User", "Bob"
Ini.WriteInteger "Main", "Count", 5
ShowMessage Ini.ReadString("Main", "User", "none") + STR$(Ini.ReadInteger("Main", "Count", 0))
