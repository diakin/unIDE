QMENU Component

Extends QOBJECT · source: inc/qmenu.inc, line 3

A helper object that makes form menu items owner-drawn with icons and shows item descriptions in a status bar.

QMenu extends QOBJECT. Set subclasses the window procedure of a form and handles WM_MEASUREITEM, WM_DRAWITEM and WM_MENUSELECT. OwnerDraw turns a menu item into an owner-drawn item with SetMenuItemInfo and remembers an image index from imgs and a description text for its command ID.

Owner-drawn items are drawn with the image on the left, a raised frame and a dark blue highlight when selected, and the caption with its & accelerator underlined. When Descrip is nonzero, the description of the selected item is shown in panel Panel of a status bar named StatusBar. Call Close to restore the original window procedure.

The code uses the global variables mii, DrawItem, MeasureItem and Mem and the API declarations from API.INC.

QMENU inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • API.INC
  • A QStatusBar named StatusBar (used when Descrip is nonzero)

Notes

  • OwnerDraw contains the typo '.dwItemData = = VARPTR(S)'.
  • In ShowDescription the END IF and END WITH blocks cross each other.
  • Item size is fixed at 60 x 19 pixels in WM_MEASUREITEM; the comment says it should be big enough to fit your items.
  • The status bar must be a global object named StatusBar; the name is hard-coded.
  • The arrays bitmap() and descp() are declared without a size and indexed by menu command ID.

QMenu Examples

Example written for this page from the members above; not run.

$INCLUDE "qmenu.inc"
DIM Menu AS QMenu

CREATE Form AS QFORM
  CREATE StatusBar AS QSTATUSBAR
    AddPanels ""
  END CREATE
  CREATE MainMenu AS QMAINMENU
    CREATE FileMenu AS QMENUITEM
      Caption = "&File"
      CREATE OpenItem AS QMENUITEM
        Caption = "&Open"
      END CREATE
    END CREATE
  END CREATE
END CREATE

Menu.imgs.AddBMPFile "open.bmp", 0
Menu.Set Form
Menu.Descrip = 1
Menu.Panel = 0
Menu.OwnerDraw FileMenu, OpenItem, 0, "Open a file"
Form.ShowModal
Menu.Close
