QDRIVE Component

Extends QOBJECT · source: inc/QDrive.inc, line 26

An object that lists the drives on the computer and reports their type, size and free space.

QDrive extends QObject. The constructor calls GetDrives, which checks the letters A to Z with GetDriveType and stores every drive that has a root directory in Name(1) ... Name(Count) as "X:\".

GetType, GetSize and GetFreeSpace take a 1-based index into Name and use GetDriveType and GetDiskFreeSpace from kernel32. The DRIVE_* constants for the result of GetType are defined in the file unless another include already defines them.

QDRIVE inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QDrive Methods

MethodTypeDescription
GetTypeFUNCTION(index as integer) AS LONGGetType(index) returns the drive type from GetDriveType (DRIVE_UNKNOWN, DRIVE_NO_ROOT_DIR, DRIVE_REMOVABLE, DRIVE_FIXED, DRIVE_REMOTE, DRIVE_CDROM or DRIVE_RAMDISK).
GetFreeSpaceFUNCTION(index as integer) AS LONGGetFreeSpace(index) returns the free space in bytes (sectors per cluster x bytes per sector x free clusters), or 0 if the call fails.
GetSizeFUNCTION(index as integer) AS LONGGetSize(index) returns the total size in bytes (sectors per cluster x bytes per sector x total clusters), or 0 if the call fails.
GetDrivesSUBScans the drive letters A to Z and adds each existing drive to Name and Count; called by the constructor.

Notes

  • GetSize and GetFreeSpace compute the result in 32-bit LONG/INTEGER values, so large disks give wrong (overflowed) values.
  • GetDrives does not reset Count; calling it again adds the drives to Count a second time while Name is refilled from index 1.
  • The methods check only index <= Count, not index >= 1.

QDrive Examples

Example written for this page from the members above; not run.

$INCLUDE "QDrive.inc"
DIM Drives AS QDrive
DIM i AS INTEGER
FOR i = 1 TO Drives.Count
  PRINT Drives.Name(i); " type "; Drives.GetType(i); " free "; Drives.GetFreeSpace(i)
NEXT i
