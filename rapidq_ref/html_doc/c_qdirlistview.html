QDIRLISTVIEW Component

Extends QLISTVIEW · source: inc/qdirlistview.inc, line 40 · author: Rene Saarsoo

A QListView that shows the folders and files of a directory with icons, size, type and date columns, and lets the user browse folders.

QDirListView extends QListView. Refresh clears the list, adds the subfolders found with Dir$(... faDirectory) and DirExists, then the files matching Mask, with sub-items for size (B or KB), type ("EXT File") and modification date (DD.MM.YYYY plus time) taken from FileRec. Columns are created once, on the first Refresh, from the FilenameSize, FilenameType and FilenameDate flags.

Double-clicking an item, or pressing Enter (a hidden popup menu item with the Enter shortcut), opens a folder or, for a file, fires OnFileSelect; Backspace goes up one folder. Icons come from four $RESOURCE icons: index 0 is the folder icon and index 1 the default file icon in SmallImageList and LargeImageList. To give an extension its own icon, add the lowercase extension to ExtensionsList and the icons to both image lists at the same index.

Assigning Directory, Mask or ShowRoot refreshes the list. The constructor starts in the program's own folder with Mask "*.*".

QDIRLISTVIEW inherits the properties, methods and events of QLISTVIEW; the tables below list only what the component adds or redefines (public members).

Requires

  • $RESOURCE icons resource\dir_XP_small.ico, resource\dir_XP_large.ico, resource\default_small.ico, resource\default_large.ico
  • Function vidnum$ (used for file sizes; it is commented out in this file, it exists in conversion.inc)

Notes

  • FilenameSize, FilenameType and FilenameDate share the setter Set_FilenameProp, which always writes FilenameSize, so assigning FilenameType or FilenameDate from code changes FilenameSize instead.
  • AddFileProperties always adds size, type and date sub-items in that order, but columns are added only for the enabled flags; with the defaults (Size=1, Type=0, Date=1) the Date Modified column shows the type text. With Type=0 the code also sets Column(3).Width when only three columns exist.
  • Columns are built only once; later changes to the column flags have no effect unless ColumnsInitialized is reset.
  • vidnum$ is used but its definition is commented out in this file.
  • LoadDirectories discards the first result of Dir$ (it immediately calls Dir$ again), and the check for "." is empty.
  • LoadFiles declares PontPlace but uses PointPlace; Refresh uses an undeclared variable QDirListViewcheckboxes.
  • The icon resources use relative paths under resource\.
  • Refresh hides and shows the control to force a repaint (author comment) and changes ViewStyle back and forth to avoid truncated captions.
  • The author's note says the code is not well commented and needs some work.

QDirListView Examples

Example written for this page from the members above; not run.

$INCLUDE "qdirlistview.inc"
DECLARE SUB FileChosen(Tag AS INTEGER)
CREATE Form AS QFORM
  Caption = "Files"
  Width = 420: Height = 300
  CREATE Files AS QDirListView
    Align = 5
    ShowRoot = TRUE
    OnFileSelect = FileChosen
  END CREATE
END CREATE
SUB FileChosen(Tag AS INTEGER)
  ShowMessage Files.FileName
END SUB
Files.Directory = "C:\"
Form.ShowModal
