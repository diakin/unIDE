FUNCTIONI USING$(...)

Port of QBasic PRINT USING: USING$(format$, values...) returns a formatted string. Supports # . , + $$ ** ^^^^ for numbers and & ! \ \ for strings; a number too large for its format is shown preceded by %. Does not print anything itself.
