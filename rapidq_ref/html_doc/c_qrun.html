QRUN Component

Extends QOBJECT · source: inc/QRun.inc, line 56 · version: 1.1

A non-visual object for starting programs and documents and for finding and controlling other windows (enumerate, close, minimize, maximize, restore, focus, topmost).

QRun wraps shell32.dll and user32.dll calls. FindApplication returns the program associated with a file (FindExecutableA); FileRun and ExeRun start a file or a program with ShellExecuteA and a SW_ show command. EnumWindow walks all top-level windows with GetWindow and fires OnEnumWindows for each one that has a title; EnumFromPoint does the same for the window at a screen point and fires OnEnumFromPoint.

The window commands take a window handle and send messages to it: Close sends WM_CLOSE, Minimize, Maximize and Restore send WM_SYSCOMMAND, SetFocus sends WM_SETFOCUS, and SetTopMost calls SetWindowPos with HWND_TOPMOST or HWND_NOTOPMOST. The SW_ constants are defined in the file unless __WIN32API is defined.

QRUN inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QRun Methods

MethodTypeDescription
FindApplicationFUNCTION(FileName as string) AS STRINGReturns the full name of the program associated with a file, or an empty string if none is found.
FileRunSUB(FileName as string,cmdShow as short)Opens a file or program with ShellExecute ('open') using the given show command (SW_ constant).
ExeRunSUB(ExeName as string,Param as string,cmdShow as short)Starts a program with a parameter string and show command; the working folder is the folder part of ExeName.
EnumWindowFUNCTION(All as boolean) AS BOOLEANEnumerates top-level windows and fires OnEnumWindows for each; with All = False only visible windows are reported. Returns True if any window was found.
FindChildFUNCTION(handle as long,class as string,name as string) AS LONGReturns the handle of a child window of handle with the given class and title (FindWindowEx).
EnumFromPointFUNCTION(x as long,y as long) AS BOOLEANFinds the window at screen point x, y and fires OnEnumFromPoint for it; returns True if a window was found.
CloseSUB(handle as long)Sends WM_CLOSE to the window.
MinimizeSUB(handle as long)Minimizes the window (WM_SYSCOMMAND, SC_MINIMIZE).
MaximizeSUB(handle as long)Maximizes the window (WM_SYSCOMMAND, SC_MAXIMIZE).
RestoreSUB(handle as long)Restores the window to its normal size (WM_SYSCOMMAND, SC_RESTORE).
SetFocusSUB(handle as long)Sends WM_SETFOCUS to the window.
SetTopMostSUB(handle as long,flag as boolean)Makes the window stay on top of others when flag is True, or removes that state when False, without moving or resizing it.

QRun Events

EventTypeOccurs when...
OnEnumWindowsSUB(handle as Long,name as string,ClassName as string)Event fired by EnumWindow for each window with a non-empty title; parameters handle, name (window title) and ClassName.
OnEnumFromPointSUB(handle as Long,name as string,ClassName as string)Event fired by EnumFromPoint for the window at the given point if it has a title; parameters handle, name and ClassName.

Notes

  • OnEnumFromPoint is declared with OnEnumWindows_eventTemplate instead of OnEnumFromPoint_eventTemplate (the signatures are the same).
  • SetFocus only sends the WM_SETFOCUS notification message; it does not call the SetFocus or SetForegroundWindow API.
  • ExeRun takes LEFT$(ExeName, RINSTR(ExeName, "\") - 1) as the folder, which is wrong when ExeName has no backslash.
  • Windows without a title are skipped by both enumerations.

QRun Examples

Example written for this page from the members above; not run.

$INCLUDE "QRun.inc"

DIM Run AS QRun

CREATE Form AS QFORM
  CREATE List AS QLISTBOX
    Align = 5
  END CREATE
END CREATE

SUB ListWindow(handle AS LONG, name AS STRING, ClassName AS STRING)
  List.AddItems name + " [" + ClassName + "]"
END SUB

Run.OnEnumWindows = ListWindow
Run.EnumWindow(False)
Run.FileRun("readme.txt", SW_SHOWNORMAL)
Form.ShowModal
