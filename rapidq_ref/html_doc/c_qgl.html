QGL Component

Extends QOBJECT · source: inc/QGL.inc, line 76 · author: JohnK · version: alpha release 1.0

OpenGL wrapper object that sets up an OpenGL rendering context on a RapidQ form (or a bitmap) and provides viewport, texture, fog, full-screen and frame-rate helpers.

QGL connects OpenGL to a RapidQ window. Init gets the form's device context with GetDC, chooses and sets a double-buffered RGBA pixel format (ChoosePixelFormat/SetPixelFormat from gdi32) and creates and activates a rendering context with wglCreateContext/wglMakeCurrent from opengl32. ReSize sets the glViewport and a gluPerspective projection from FOV, AspectRatio, Front and Back. Flip calls SwapBuffers and counts frames; an internal one-second QTimer copies the count into FrameRate.

Textures are created with CreateTextureFromFile or CreateTextureFromBitmap. The image is copied into a global QBITMAPEX (QGLinternalBMP), then uploaded with glTexImage2D, or with gluBuild2DMipmaps when MipMap is set. JPG, TGA, GIF and PCX files are loaded through QBITMAPEX.LoadOtherImage. Fog is controlled by FogEnabled, FogMode, FogColor and SetFogParams. RenderToBitmap switches rendering to a separate context on the Bitmap property, and FullScreen changes the screen resolution.

Per the source comment, run Init in the form's OnShow event and pass the form to draw on; call Close at program end to free the rendering context and DC.

QGL inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • $INCLUDE <\GL\gl.inc>
  • $INCLUDE <GL\glu.inc>
  • QBITMAPEX component (QBitmapEx.inc), used for the global QGLinternalBMP but not included by this file

QGL Methods

MethodTypeDescription
ReSizeSUB(width AS INTEGER, height AS INTEGER)ReSize(width, height) sets the glViewport and resets the projection matrix with gluPerspective using FOV, AspectRatio, Front and Back; call it from the form's OnResize.
InitFUNCTION(MainForm AS QFORM) AS INTEGERInit(MainForm) sets up the pixel format and OpenGL rendering context on the form; returns the form's DC on success or 0 on failure.
CloseSUBRestores the screen resolution if FullScreen is on, deletes the rendering contexts and releases the form's DC; the source says it must run at program end.
FlipSUBSwaps the front and back buffers (SwapBuffers) and increments the internal frame counter.
CreateTextureFromFileFUNCTION(ImgFileName as string) AS LONGCreateTextureFromFile(FileName) loads an image file and returns an OpenGL texture ID, or 0 if the file does not exist or the image is too small.
CreateTextureFromBitMapFUNCTION(ImgBMP as QBITMAP) AS LONGCreateTextureFromBitmap(Bmp) copies a QBITMAP (at least 2x2 pixels) and returns an OpenGL texture ID, or 0.
FogColorSUB(R#, G#, B#)FogColor(R#, G#, B#) sets the fog color with glFogfv; alpha is always 1.0.
SetFogParamsSUB(Start#, End#, Density#)SetFogParams(Start#, End#, Density#) sets fog density, start and end depth and the GL_FOG_HINT.

Notes

  • Flip calls SwapBuffers on GL.hDC, not QGL.hDC, so it only works if the QGL instance is named GL.
  • The source comment says the PFD_GENERIC_ACCELERATED flag 'probably won't work'.
  • CreateTextureFromFile uses NViewLibPresent, which is not defined in this file. Because AND binds tighter than OR, that check only applies to the .PCX case.
  • Only 24-bit and 32-bit textures are supported; 8-bit and 16-bit images are converted to 24 bit. The power-of-two size check is commented out.
  • Full-screen fallback resolutions are hard-coded (640x480, 800x600, 1024x768).

QGL Examples

Example written for this page from the members above; not run.

$INCLUDE "QBitmapEx.inc"
$INCLUDE "QGL.inc"
DIM Form AS QFORM
DIM GL AS QGL

SUB FormShow
  IF GL.Init(Form) = 0 THEN ShowMessage "OpenGL init failed"
  GL.ReSize(Form.ClientWidth, Form.ClientHeight)
END SUB

SUB FormClose
  GL.Close
END SUB

Form.OnShow = FormShow
Form.OnClose = FormClose
Form.ShowModal
