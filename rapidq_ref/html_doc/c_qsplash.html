QSPLASH Component

Extends QOBJECT · source: inc/QSplash.inc, line 17 · version: 1.2

QSplash shows a borderless splash window with an image and optional text, for a given time or until the program closes it.

The object owns a private form containing Image and a label. Show sizes the form to the image width, places the text either below the image or over it (TextTransparent), hides the title bar, centers and shows the form.

If Show is given a time greater than 0 it calls SLEEP with that value and then closes the form; otherwise the form stays open. The file's comments are in French, with an addition marked "added JK".

QSPLASH inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QSplash Properties

FieldTypeR/WDefaultDescription
ImageQIMAGERWQImage displayed at the top-left of the splash form (auto-sized); load the picture into it before calling Show.
TextSTRINGRW""Text shown on the splash; nothing is shown when empty.
TextCenterBOOLEANRWFalseWhen TRUE the text is centred horizontally; otherwise it is placed at TextLeft.
TextTopSHORTRWTop position of the text, used only when TextTransparent is TRUE.
TextLeftSHORTRW5Left position of the text when TextCenter is FALSE; default 5.
TextFontQFONTRWQFont used for the text.
TextTransparentBOOLEANRWWhen TRUE the text is drawn transparently over the image at TextTop; when FALSE it is placed 10 pixels below the image and the form is made taller.

QSplash Methods

MethodTypeDescription
ShowSUB(Time as short)Show(Time) builds and shows the splash form; with Time greater than 0 it sleeps for Time (RapidQ SLEEP) and closes the form, otherwise the form stays visible.

Notes

  • The comment says the user can close a splash shown with Time 0 using QSplash.Form.Close, but form is declared PRIVATE.
  • With Time greater than 0, Show blocks the program while it sleeps.
