QMENUEX Component

Extends QIMAGELIST · source: inc/rapidq2.inc, line 5564 · author: John Kelly · version: 1.2

An owner-drawn menu helper, derived from QIMAGELIST, that draws bitmaps or icons next to menu items and reports a help text for the item under the mouse.

QMenuEx subclasses the window procedure of a form (Init) through the callback forwarder SetNewCallBack_4 and handles WM_MEASUREITEM, WM_DRAWITEM and WM_MENUSELECT. Menu items are switched to owner-draw with ModifyMenu (MF_OWNERDRAW); each item is then drawn with its picture, its caption (the & letter underlined) and the colors set in BackColor, ForeColor, HighLightColor, HighLightTextColor and DisabledColor.

Usage: call Init with the form, Parent with the menu item that holds the sub menu, then for each item call MenuModify with a QIMAGE, or add an image with AddBMPFile or ICOFile and call AddDescription. The description strings are passed to OnMouseHover while the menu is open. Call Close to restore the original window procedure.

Pictures and descriptions are stored in arrays of 1000 entries indexed by the menu item's Command number.

QMENUEX inherits the properties, methods and events of QIMAGELIST; the tables below list only what the component adds or redefines (public members).

Requires

  • rapidq2.inc callback forwarder SetNewCallBack_4 and the QMenuEx API section (MEASUREITEMSTRUCT, DRAWITEMSTRUCT, ODT_/ODS_ constants, ModifyMenu)
  • Based on Qmenu.inc by Jordi Ramos and D. Glodt

Notes

  • Pictures and descriptions are arrays of 1000 entries indexed by MenuItem.Command; larger command numbers are out of range.
  • AddBMPFile and ICOFile set Transparent and TransparentColor on image(.LastMenu), which is only updated by AddDescription and MenuModify, so the transparency settings may go to the previously described item.
  • AddDescription always returns 0.
  • Close is declared as FUNCTION but ends with END SUB.
  • OnMouseHover is called with CALLFUNC without checking that a handler is assigned.
  • The item width in WM_MEASUREITEM is estimated as LEN(caption) * Font.Size * 0.6 rather than measured.
  • A comment notes that the MEASUREITEMSTRUCT and DRAWITEMSTRUCT variables must be global for unknown reasons.

QMenuEx Examples

Example written for this page from the members above; not run.

$INCLUDE "rapidq2.inc"

CREATE Form AS QFORM
  CREATE MainMenu AS QMAINMENU
    CREATE mFile AS QMENUITEM
      Caption = "&File"
      CREATE mOpen AS QMENUITEM
        Caption = "&Open"
      END CREATE
    END CREATE
  END CREATE
  CREATE imgOpen AS QIMAGE
    Visible = 0
    BMP = "open.bmp"
  END CREATE
END CREATE

DIM Menu AS QMenuEx
Menu.Init(Form)
Menu.Parent(mFile)
Menu.MenuModify(mOpen, imgOpen, "Open a file")
Form.ShowModal
Menu.Close
