QMP3 Component

Extends QOBJECT · source: inc/Qmp3.inc, line 34 · author: Dreadsoft Corporation (dreadsoft@yahoo.it)

A non-visual component that reads MP3 frame header information, reads and writes ID3 v1.x tags, and plays or stops an MP3 file through MCI.

Qmp3 works on the file named in FileName. ReadHeader looks for the MPEG frame header, decodes its bits and fills Version, Layer, Protection, Bitrate, Frequency, Padding, Channels, IntensityStereo, MS_Stereo, Copyright, Original and Emphasis as text or numbers.

ReadTags and WriteTags handle the 128-byte ID3 v1.x tag at the end of the file (Title, Artist, Album, Year, Comment, Track and the genre number). GenresList holds the standard genre names; LoadList copies them into the GenresCB combo box, and picking a genre there sets GenreID.

Play opens the file with the Windows MCI function mciSendString (winmm.dll) under an alias made from the file name and starts playback; Stop stops and closes it. The source credits the info.bas file by grog and an MP3 example by sm0oth2003, and thanks Tamas Szekeres for a binary-header bug fix; it also says to see the help file for details.

QMP3 inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • a global Qmp3 variable named mp3: HeaderStart and ReadHeader open mp3.filename instead of the component's own FileName

Qmp3 Methods

MethodTypeDescription
HeaderStartFUNCTION AS INTEGERInternal: searches the first 3071 bytes of the file for the frame sync and returns its offset; used by ReadHeader.
ReadHeaderFUNCTION AS INTEGERReads the 4-byte MPEG frame header and fills the header properties. Shows a message if FileName is empty.
IsTaggedFUNCTION(itfs as Qfilestream) AS INTEGERIsTagged(stream) returns 1 if the last 128 bytes of the open QFileStream start with "TAG", otherwise 0.
SelectGenreSUBInternal: OnChange handler of GenresCB; sets GenreID to the selected item index.
loadlistSUBCopies all names from GenresList into the GenresCB combo box.
readtagsSUBReads the ID3 v1 tag into Title, Artist, Album, Year, Comment, Track, GenreID and Genre. Shows a message if FileName is empty or the file has no tag.
writetagsSUBWrites Title, Artist, Album, Year, Comment, Track and GenreID into the ID3 v1 tag, padding or cutting each text to its field size.
StopSUBSends the MCI commands "Stop" and "Close" for Alias.
PlaySUBStops any current playback, opens FileName through MCI with an alias derived from the file name and plays it.

Notes

  • HeaderStart and ReadHeader open mp3.filename, a global variable named mp3, instead of the component's own FileName; they only work when the instance is named mp3.
  • HeaderStart compares a BYTE with 256, which a byte can never equal, so the frame-sync search never matches and the function's result is never assigned.
  • WriteTags refers to tagstream, a variable that belongs to ReadTags, when it checks for an existing tag and computes the tag position.
  • ReadTags removes CHR$(0) characters from each text field and then also cuts off its last character.
  • Play builds the MCI alias from the file name without quoting it, so file names containing spaces will not form a valid alias.
  • Play, Stop and ReadTags/ReadHeader report errors only through ShowMessage; MCI return codes are ignored.

Qmp3 Examples

Example written for this page from the members above; not run.

$INCLUDE "Qmp3.inc"
DIM mp3 AS Qmp3
mp3.FileName = "C:\Music\song.mp3"
mp3.ReadHeader
mp3.ReadTags
PRINT mp3.Artist, mp3.Title, mp3.Bitrate, mp3.Frequency
mp3.Play
