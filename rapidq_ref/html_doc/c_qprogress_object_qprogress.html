QPROGRESS Component

Extends QOBJECT · source: inc/object/QProgress.inc, line 28

A progress bar component that creates a Windows msctls_progress32 control on a parent window given by handle.

Assigning Parent (a window handle, for example Form.Handle) creates the progress bar with CreateWindowExA, class msctls_progress32, at the current Left, Top, Width and Height. The range is set to 0..20500 (&H5014) with PBM_SETRANGE.

Assigning Value scales it by 205 (Range / 100) and sends PBM_SETPOS, so Value is effectively a percentage from 0 to 100. Left, Top, Width, Height and Visible move, resize, show or hide the window.

QPROGRESS inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • SendMessage, which this file does not declare

ParentINTEGERRWWindow handle of the parent. Assigning it creates the progress bar window in that parent at the current position and size, sets Visible to 1 and sets the range and step.

HeightSHORTRW20Height (default 20); assigning it resizes the window with MoveWindow.
VisibleBOOLEANRWAssigning 0 hides the window and any other value shows it (ShowWindow).
HandleINTEGERRWWindow handle of the progress bar, set when Parent is assigned.

Notes

  • Each assignment to Parent creates a new progress bar window; the old one is not destroyed.
  • Reading Value returns the scaled value (percentage x 205), not the number that was assigned.
  • The range is fixed at 0..20500 and the step value set with PBM_SETSTEP is never used (there is no step method).
  • Assigning Left, Top, Width or Height before Parent calls MoveWindow with a zero handle.
  • CreateWindowExA is called with hInstance 0; the line passing Application.hInstance is commented out.

QProgress Examples

Example written for this page from the members above; not run.

$INCLUDE "object/QProgress.inc"
CREATE Form AS QFORM
  Caption = "Progress"
END CREATE
DIM Bar AS QProgress
Bar.Left = 10
Bar.Top = 10
Bar.Width = 200
Bar.Parent = Form.Handle
Bar.Value = 50
Form.ShowModal
