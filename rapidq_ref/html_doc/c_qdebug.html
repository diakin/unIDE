QDEBUG Component

Extends QOBJECT · source: inc/QDebug.inc, line 28 · author: Pete Kleinschmidt · version: 0.9 · date: March 2, 2002

A debug output object that prints strings into a resizable "Debug" window with a rich edit box.

Including the file creates the form frmDebug with a QRICHEDIT that fills it, and a global object Debug of type QDebug with Enabled = True, so the Debug window is shown at once. Debug.Print adds a line to the rich edit box, moves the cursor to the end, scrolls it into view (EM_SCROLLCARET), enables input to the Debug window with EnableWindow and calls DOEVENTS.

Set Debug.Enabled = False to close the window and make Print do nothing.

QDEBUG inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QDebug Properties

FieldTypeR/WDefaultDescription
EnabledSHORTRWTrueAssigning True shows the Debug window and lets Print add text; assigning any other value closes the window and makes Print do nothing. Default True.

QDebug Methods

MethodTypeDescription
PrintSUB(StringToPrint AS STRING)Adds a string to the Debug window, scrolls to it and processes pending events, when Enabled is True.

Notes

  • The include creates the global form frmDebug and the global object Debug, so the names frmDebug, edtDebug and Debug are taken and the Debug window appears as soon as the file is included.
  • All QDebug instances write to the same global frmDebug window.
