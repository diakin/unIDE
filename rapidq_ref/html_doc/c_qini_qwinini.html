QINI Component

Extends QOBJECT · source: inc/QWinIni.inc, line 18

A non-visual object for reading and writing Windows INI files with the GetPrivateProfileString family of API calls.

According to the usage comment: first call Ini.Load([Path/FileName.ini]) (the parameter is optional), then read values with Ini.Get(Section, Key, Default) and write them with Ini.Write(Section, Key, Value). Without a parameter Load uses the program's own name with .EXE replaced by .INI.

Get and Write also fill the Section, Key and Value fields with the last values used. Get removes anything after a ';' in the returned value, treating it as a comment. The include creates a global instance named Ini.

QINI inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QINI Properties

FieldTypeR/WDefaultDescription
FileSTRINGRW""Full name of the INI file used by Get, Write and GetSection; set by Load.
SectionSTRINGRW""Section name of the last successful Get, Write or GetSection.
KeySTRINGRW""Key name of the last successful Get or Write.
ValueSTRINGRW""Value returned by the last Get or GetSection, or written by the last Write.

QINI Methods

MethodTypeDescription
LoadFUNCTIONI(...) AS INTEGERSets File to the given name, or to the program name with .EXE replaced by .INI when no parameter is given; returns 1 if the file exists, otherwise 0.
GetFUNCTION(sSection As String, sKey As String, sDefault As String) AS STRINGReturns the value of a key in a section, without any ';' comment, or the default value if the key is missing; returns an empty string if File is empty.
WriteFUNCTION(sSection as string, sKey as string, sValue as string) AS LONGWrites a key value into a section and returns non-zero on success; returns 0 if File is empty.
GetSectionFUNCTION(sSection as string) AS STRINGReturns the raw contents of a whole section as returned by GetPrivateProfileSection (up to 1000 bytes), or an empty string.

Notes

  • Load is written as 'Functioni Load (...)' in the source.
  • The default file name is built with a case-sensitive REPLACESUBSTR$ of ".EXE", so a program name with a lower-case .exe is not changed.
  • Get reads into a 260-byte buffer but passes 250 as its size; GetSection uses a 1000-byte buffer, so longer values or sections are cut.
  • GetSection does not check whether File is empty.
  • Get cuts the value at the first ';', so values that contain a semicolon are truncated.
