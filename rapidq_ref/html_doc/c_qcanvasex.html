QCANVASEX Component

Extends QCANVAS · source: inc/QCanvasEx.inc, line 105

Extended QCANVAS with GDI drawing that uses a pen style, pen size and raster (mix) mode, plus filled shapes, icons, flood fill, color inversion, mirroring and clipboard bitmap copy/paste.

QCanvasEx extends QCANVAS and draws directly with gdi32 and user32 functions on the canvas Handle. Each shape method creates a pen from PenStyle, PenSize and the given color (and a solid brush for the filled versions), sets the raster operation from MixMode with SetROP2, draws, and then restores and deletes the GDI objects. Line, Rectangle, Circle, RoundRect and TextOut replace the QCANVAS methods of the same name, some with different parameters.

Constants for MixMode (R2_..._CAN), PenStyle (PS_..._CAN) and raster copy modes (..._CAN) are defined in the file. Clipboard methods copy a rectangle of the canvas as a CF_BITMAP and paste a clipboard bitmap at a position. The comments in the file are in French.

QCANVASEX inherits the properties, methods and events of QCANVAS; the tables below list only what the component adds or redefines (public members).

Notes

  • CopyToClipboard calls DeleteObject on the bitmap right after giving it to the clipboard with SetAsHandle.
  • The file defines a global TBITMAP type without an $IFNDEF guard, which can clash with other include files that define TBITMAP.
  • GetWidthClipboard and GetHeightClipboard do not set a result when the clipboard holds no bitmap.

Other versions

QCanvasEx Examples

Example written for this page from the members above; not run.

$INCLUDE "QCanvasEx.inc"
CREATE Form AS QFORM
  Width = 320
  Height = 240
END CREATE
DIM Cnv AS QCanvasEx
Cnv.Parent = Form
Cnv.Align = 5
SUB PaintCnv
  Cnv.PenSize = 3
  Cnv.RectangleFilled(10, 10, 150, 100, &H000000, &H00FFFF)
  Cnv.CircleFilled(60, 30, 200, 160, &HFF0000, &H00FF00)
  Cnv.TextOut(20, 180, "QCanvasEx", &H0000FF, 0)
END SUB
Cnv.OnPaint = PaintCnv
Form.ShowModal
