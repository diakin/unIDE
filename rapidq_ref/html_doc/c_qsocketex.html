QSOCKETEX Component

Extends QSOCKET · source: inc/QSocketEx.inc, line 76 · author: d_homans, JohnK · date: 03/06/2007

A QSocket extension with Winsock helpers: corrected GetPeerName, host name and address lookup, connection check, CR LF line writing, write with error code, shutdown, blocking mode and error text.

QSocketEx extends QSocket and is a cleaned-up version of RSocket.inc. It overrides GetPeerName (described as a bug fix for QSocket), adds NameByAddr and AddrByName lookups, IsConnected (select() with a timeout), NonBlock and Block (ioctlsocket FIONBIO), ShutDown (shutdown with both directions) and LastError (WSAGetLastError as text, with 0 reported as Success).

WriteLine overrides the QSocket method so that every line ends with CR LF, and WriteEx calls the inherited Write and returns WSAGetLastError (0 when the write succeeded). The file is guarded by $IFNDEF QSOCKET_INC; the comments explain that the lookup functions copy a 16-byte Winsock structure into a byte or long array to extract the data.

QSOCKETEX inherits the properties, methods and events of QSOCKET; the tables below list only what the component adds or redefines (public members).

QSocketEx Methods

MethodTypeDescription
GetPeerNameFUNCTION(SockNum AS integer) AS STRINGGetPeerName(SockNum) returns the IP address of the remote end of the socket as a dotted string, or an empty string on error; replaces the QSocket version.
NameByAddrFUNCTION(strIP AS string) AS STRINGNameByAddr(strIP) returns the host name for a dotted IP address, or an empty string if the address is invalid or no name is found.
AddrByNameFUNCTION(strName AS string) AS STRINGAddrByName(strName) resolves a host name and returns its IP address as a dotted string, or an empty string on failure.
IsConnectedFUNCTION(SockNum As LONG, TimeOutSecs As LONG) AS LONGIsConnected(SockNum, TimeOutSecs) returns -1 if select() reports an error on the socket within the timeout, otherwise the select() result for writability (1 when connected, 0 on timeout).
WriteLineSUB(SockNum AS integer, Str As STRING) AS LONGWriteLine(SockNum, Str) writes Str followed by CR LF with the inherited Write; it replaces the QSocket method.
WriteExFUNCTION(SockNum AS integer, Message AS string, NumBytes AS integer) AS LONGWriteEx(SockNum, Message, NumBytes) writes NumBytes of Message with the inherited Write and returns WSAGetLastError (0 if OK).
ShutDownFUNCTION(SockNum AS integer) AS LONGShutDown(SockNum) calls Winsock shutdown with how = 2 (no more sends or receives) and returns its result.
NonBlockFUNCTION(hSocket As LONG) AS LONGNonBlock(hSocket) sets the socket to non-blocking mode: per the comment, Read then returns an empty string when no data is waiting.
BlockFUNCTION(hSocket As LONG) AS LONGBlock(hSocket) sets the socket to blocking mode: per the comment, Read waits until data arrives, possibly forever.
LastErrorFUNCTION AS STRINGReturns the last Winsock error as "number: description"; per the comment, the value may not be reliable when several connections are open.

Notes

  • The CONSTRUCTOR block has no END CONSTRUCTOR: the line "Tag =0" is followed directly by END TYPE.
  • LastError starts with DEFSTR tstr = "' which is an unterminated string literal.
  • WriteLine is written as a SUB with an "As LONG" return type and returns nothing.
  • NameByAddr passes QSocketEx.Protocol as the address-type argument of gethostbyaddr, where RSocket.inc passes 2 (AF_INET).
  • The header mentions a new function WriteBinData&(), but the function in the code is named WriteEx; IsConnected still uses EXIT FUNCTION although the notes say those calls were removed.
  • The Winsock functions are declared under plain names (shutdown, gethostbyname, inet_addr and others), which can clash with other include files.

QSocketEx Examples

Example written for this page from the members above; not run.

DIM Sock AS QSocketEx
DIM hSock AS INTEGER
hSock = Sock.Connect(Sock.AddrByName("example.com"), 80)
IF Sock.IsConnected(hSock, 5) = 1 THEN
  IF Sock.WriteEx(hSock, "HEAD / HTTP/1.0" + CHR$(13) + CHR$(10) + CHR$(13) + CHR$(10), 19) <> 0 THEN ShowMessage Sock.LastError
END IF
Sock.ShutDown(hSock)
