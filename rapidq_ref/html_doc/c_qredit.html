QREDIT Component

Extends QRICHEDIT · source: inc/HiLight.inc, line 23 · author: William Yu

A QRichEdit with simple automatic keyword (syntax) highlighting.

QREdit extends QRichEdit and is William Yu's syntax highlighting example turned into a component. Add keywords with AddSyntaxes, then call HiLight after loading a file or inserting lines: it selects text ranges and sets SelAttributes to a bold RichFont in HiLightColor, instead of generating RTF.

While typing, OnKeyUp finds the word around the caret (separated by spaces or line breaks) and highlights it if it is a keyword. The control is set to PlainText with the "Courier" font. After the TYPE the file redefines QRICHEDIT as QREdit, so later code that creates a QRICHEDIT gets this component.

QREDIT inherits the properties, methods and events of QRICHEDIT; the tables below list only what the component adds or redefines (public members).

Requires

  • $INCLUDE "RAPIDQ.INC"

QREdit Methods

MethodTypeDescription
HiLightSUBHighlights all keywords: resets the whole text to RichFont, then finds every occurrence of each keyword (case-insensitive substring search) and makes it bold in HiLightColor. Call it after loading a file or inserting lines.
AddSyntaxesSUBI(...)AddSyntaxes(word1, word2, ...) appends keywords to the Syntaxes array.

The component handles these events itself (EVENT blocks in the TYPE): OnKeyUp.

Notes

  • The author describes it as not very complete.
  • The OnKeyUp comments say the event may be skipped when typing fast and that splitting a word with a space is not handled.
  • HiLight matches substrings, not whole words, so a keyword inside a longer word is also highlighted.
  • Syntaxes has a fixed size of 100 and AddSyntaxes does not check the limit.
  • The include file itself sets $APPTYPE GUI and $TYPECHECK ON and includes RAPIDQ.INC.
  • The header comment calls the color property HiLighColor; the field is HiLightColor.
  • The file redefines QRICHEDIT as QREdit after the TYPE, which affects every later QRICHEDIT in the program.

QREdit Examples

Example written for this page from the members above; not run.

$INCLUDE "HiLight.inc"
CREATE Form AS QFORM
  Caption = "Highlight"
  CREATE Editor AS QREdit
    Align = 5
  END CREATE
END CREATE
Editor.AddSyntaxes "SUB", "END", "DIM", "AS"
Editor.Text = "SUB Test" + CHR$(13) + "DIM a AS INTEGER" + CHR$(13) + "END SUB"
Editor.HiLight
Form.ShowModal
