QMAXEDIT Component

Extends QRICHEDIT · source: inc/RichEdPopUp.inc, line 26 · author: Psyclops

QRichEdit extension with a popup menu like the standard Windows edit context menu (Undo, Cut, Copy, Paste, Delete, Select All) and line-position helpers.

QMAXEDIT assigns its own QPopupMenu to PopupMenu. When it pops up, items are enabled from the editor state: undo availability (message &HC6), selection length, clipboard text and whether all text is already selected.

Line helpers send rich edit messages: LINEINDEX and GetLINEIdx use EM_LINEINDEX (187) to get the position of the first character of a line, and LINEFROMCHAR and LINEFROMPos use EM_LINEFROMCHAR (201) to get the line containing a character. GoToLineBegin and GoToLineEnd move the cursor within the current line.

At the end of the file, QRICHEDIT is redefined as QMAXEDIT, so a QRICHEDIT declared after the include becomes a QMAXEDIT. The comments say: set UsePopup = 0 to turn the popup off, or assign another menu to PopupMenu.

QMAXEDIT inherits the properties, methods and events of QRICHEDIT; the tables below list only what the component adds or redefines (public members).

The component handles these events itself (EVENT blocks in the TYPE): MaxMenu.OnPopup.

Notes

  • The include redefines QRICHEDIT as QMAXEDIT for all code that follows it.
  • RichFont is declared but never used.
  • GoToLineEnd and GoToLineBegin are declared as functions returning LONG but return no value.
  • The Set_Popup setter does not store the value in UsePopup.

QMAXEDIT Examples

Example written for this page from the members above; not run.

$INCLUDE "RichEdPopUp.inc"
DIM Form AS QFORM
DIM Edit AS QRICHEDIT   ' becomes QMAXEDIT
Edit.Parent = Form
Edit.Align = 5
Edit.UsePopup = 0       ' turn the popup off
