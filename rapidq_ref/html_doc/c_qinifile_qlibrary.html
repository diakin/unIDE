QINIFILE Component

Extends QOBJECT · source: inc/QLibrary.Inc, line 137

A simple INI file reader and writer that reads and writes single entries or whole sections of a text INI file.

QIniFile extends QObject and works on the text file named in Name using the QStringList Lines. ReadEntry returns the value of a key in a section, ReadSection loads all lines of a section into Lines, WriteEntry replaces or adds a key (creating the section if needed) and saves the file, and WriteSection replaces or appends a whole section from a QStringList. Section and key names are compared without regard to case or surrounding blanks.

Edit opens the INI file in an external editor whose command line is read from the key TextEditor in section [QIniFile] of QLibrary.Ini. The type uses the helper functions Trim$, CatStr$ and Equ$ defined at the top of QLibrary.Inc.

QINIFILE inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • Helper functions Trim$, CatStr$ and Equ$ from the same file QLibrary.Inc
  • QLibrary.Ini with key TextEditor in section [QIniFile] (for Edit)

QIniFile Methods

MethodTypeDescription
ClearEndingSUBInternal: deletes empty lines from the end of Lines.
AddBrackets$FUNCTION(Datum As String) AS STRINGInternal: puts square brackets around a section name.
ReadEntryFUNCTION(Section As String, KeyWord As String) AS STRINGReadEntry(Section, KeyWord) returns the text after "=" for KeyWord in Section, or an empty string if not found; the whole file is left in Lines.
ReadSectionSUB(Section As String)ReadSection(Section) clears Lines and fills it with the lines of Section (without the header), up to the next line starting with "[".
WriteEntrySUB(Section As String, KeyWord As String, KeyEntry As String)WriteEntry(Section, KeyWord, KeyEntry) sets KeyWord = KeyEntry in Section, adding the key or the whole section if missing, and saves the file.
WriteSectionSUB(Section As String,SectionList As QStringList)WriteSection(Section, SectionList) replaces Section with the lines of SectionList (or appends it at the end if it does not exist) and saves the file; the section header is inserted at the start of SectionList.
EditSUBOpens the INI file with the editor command taken from TextEditor in section [QIniFile] of QLibrary.Ini (run with SHELL).

Notes

  • AddBrackets$ only works for names without brackets: if the name already contains "[" the result is not initialized, so passing "[Section]" yields "]" or an empty string instead of the section name.
  • WriteSection keeps the section position in a Byte variable (Point), so a section starting after line 255 is not placed correctly, and a section on the very first line (index 0) is treated as not found and appended again.
  • Several methods store string positions in Byte variables (Point), which overflow for lines longer than 255 characters.
  • WriteSection modifies the passed SectionList by inserting the section header at index 0.
  • The code uses True and False, which QLibrary.Inc does not define.
