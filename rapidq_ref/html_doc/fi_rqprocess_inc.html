FindProcessId

FUNCTION · RQProc.inc, line 19424

FUNCTION FindProcessId(name AS STRING) AS LONG

Returns the process ID of a running process whose module name equals name (case-insensitive, e.g. "notepad.exe"), or -1. Uses EnumProcesses, OpenProcess, EnumProcessModules and GetModuleBaseName (psapi); also stores a closed handle in global procExit.
