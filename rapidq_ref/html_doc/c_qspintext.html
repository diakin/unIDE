QSPINTEXT Component

Extends QPANEL · source: inc/qspintext.inc, line 16 · author: Mesut Akcan; OnChange event added by Andrew Shelkovenko · version: 1.01 · date: 7 July 2000, update 7 Sept. 2000; updated 20.04.04

A spin edit: a panel with a QEdit and a vertical QScrollBar for entering a number between Min and Max, with an OnChange event.

Qspintext extends QPanel and contains an edit box (Ed) and a vertical scroll bar (Sb). The scroll bar works with negated values so that the up arrow increases the number. After setting Min, Max, Value and the colors, call Initial to apply them and place the child controls.

Clicking the scroll bar updates Value and the edit box and fires OnChange. In the edit box the Up and Down arrow keys move the value, and Enter takes the typed number. While other keys are typed the panel turns red as a sign that the value is not confirmed yet; Enter or Down restores BgColor.

QSPINTEXT inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

Qspintext Properties

FieldTypeR/WDefaultDescription
maxLONGRWLargest value; applied by Initial.
minLONGRWSmallest value; applied by Initial.
valueLONGRWCurrent value; updated when the scroll bar changes. Assigning it directly does not update the controls until Initial is called.
bgcolorLONGRW-2147483643Background color of the edit box (and of the panel after confirming input); applied by Initial.
fontcolorLONGRW0Text color of the edit box; applied by Initial.
edQEDITRWThe QEdit that shows and accepts the number.
sbQSCROLLBARRWThe vertical QScrollBar used as the spin buttons (works with negated values).

Qspintext Methods

MethodTypeDescription
initialSUBApplies Min, Max, Value, BgColor and FontColor to the child controls and lays them out to the panel width. Call it after setting these fields.

Qspintext Events

EventTypeOccurs when...
OnChangeSUB(vl AS long)Event OnChange(vl AS LONG), fired with the new value when the scroll bar changes or Enter is pressed in the edit box.

The component handles these events itself (EVENT blocks in the TYPE): ed.onchange, ed.onkeydown, sb.onchange.

Notes

  • The events use a variable vl that is not declared in the type; on Enter OnChange is called with vl as left by the last scroll-bar change.
  • On Enter the code sets the scroll-bar position and then calls OnChange directly, so if the scroll bar's own OnChange also runs, the handler can be called twice.
  • The Ed.OnChange handler is empty (its code is commented out), so typing alone does not change Value.
  • The Up arrow key does not restore the panel color after it was turned red.
  • Typed values are not checked against Min and Max.

Qspintext Examples

Example written for this page from the members above; not run.

$INCLUDE "qspintext.inc"
DECLARE SUB SpinChange(vl AS LONG)
CREATE Form AS QFORM
  Caption = "Spin"
  CREATE Spin AS Qspintext
    Left = 10: Top = 10
    Width = 80
    Min = 0: Max = 100: Value = 10
    OnChange = SpinChange
  END CREATE
END CREATE
SUB SpinChange(vl AS LONG)
  Form.Caption = STR$(vl)
END SUB
