QGRIDCOLOR Component

Extends QPANEL · source: inc/QGridColor.inc, line 11 · author: Nastase Eodor · version: 1.0.0 · date: 2004

QGridColor is a QPanel showing the 16 standard colors as clickable cells; left click picks a foreground color and right click a background color.

The panel contains 16 child QPanel cells filled with the classic 16-color palette (Black, Navy, Green, ... White). The layout is chosen with Style: st1x16 (one row), st2x8 (two rows) or st4x4 (four rows); cell sizes are derived from the panel's Width and Height when Draw runs.

A left click stores the cell color in FGColor, a right click in BKColor, and OnCellClick is fired. With ShowCaption the selected cells are marked "FG" and "BK"; with ShowHints each cell shows its color name as a hint.

QGRIDCOLOR inherits the properties, methods and events of QPANEL; the tables below list only what the component adds or redefines (public members).

QGridColor Properties

FieldTypeR/WDefaultDescription
FGColorINTEGERRWColor of the last cell clicked with the left mouse button.
BKColorINTEGERRWColor of the last cell clicked with the right mouse button.
StyleINTEGERRWCell layout: st1x16 (0), st2x8 (1) or st4x4 (2). Assigning it stores the value and calls Draw to lay out the cells again.
ShowCaptionINTEGERRWWhen non-zero, the cell last clicked with the left button shows "FG" and the one clicked with the right button shows "BK".
ShowHintsINTEGERRWAssigning a non-zero value sets each cell's hint to its color name and turns ShowHint on.

QGridColor Methods

MethodTypeDescription
LoadColorsSUBInternal: fills the 16 color values and their names; called by the constructor.
CellClickSUB(Button as integer,x as integer,y as integer,Shift as integer,Sender as QPanel)Internal: OnMouseDown handler assigned to every cell; updates FGColor or BKColor, the captions, and fires OnCellClick.
DrawSUBPositions and sizes the 16 cells according to Style and the current Width and Height, sets their colors, hints and click handler. Call it after changing the panel size.

QGridColor Events

EventTypeOccurs when...
OnCellClickSUBEvent without parameters (CellClicked), fired after a left or right click has updated FGColor or BKColor.

Notes

  • The constructor calls Draw with the panel's default size; after changing Width or Height the cells are not resized until Style is assigned or Draw is called.
  • Assigning 0 to ShowHints does not turn off hints that were already enabled.
  • Only the left (Button 0) and right (Button 1) mouse buttons are handled.
  • The file defines global constants st1x16, st2x8 and st4x4 and declares a global SUB CellClicked as the event template.

QGridColor Examples

Example written for this page from the members above; not run.

$INCLUDE "QGridColor.inc"
DECLARE SUB ColorPicked
CREATE Form AS QFORM
  Caption = "Colors"
  CREATE Grid AS QGridColor
    Parent = Form
    Width = 160
    Height = 40
    Style = st2x8
    ShowCaption = 1
    ShowHints = 1
    OnCellClick = ColorPicked
  END CREATE
END CREATE
Form.ShowModal

SUB ColorPicked
  Form.Color = Grid.FGColor
END SUB
