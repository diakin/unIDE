FUNCTION RQshowdialog(capt$,filter$,fltrindex%,initdir$,savedlog%,nooverwriteprompt%,formhnd&) as STRING

Shows the Windows Open (savedlog%=0) or Save file dialog via GetOpenFileName/GetSaveFileName owned by window formhnd&. filter$ uses "|" separators, initdir$ defaults to the current folder; on Save an overwrite prompt is shown unless nooverwriteprompt% is set. Returns the chosen path or an empty string.
