QTBUTTON Component

Extends QBUTTON · source: inc/QTButton95.inc, line 400 · author: D-evolution · date: 2004 - 2005

A skinnable push button derived from QButton that draws its face from a bitmap skin or from Windows XP visual styles, with hover effect, icon, multi-line caption and button groups.

QTButton replaces the face of a QButton with a picture it builds itself. Without XP themes it stretches a skin bitmap (the global QTBtnBMP, loaded from a resource named btn_BMP) piece by piece (center, corners, edges) for up to 4 states. When XPThemeEnabled is on and the program runs on Windows XP, it draws the states with uxtheme.dll (OpenThemeData/DrawThemeBackground) using the Button, Toolbar or Tab theme class. The state images are laid out side by side in the order normal, disabled, pressed, hot; the hover image is shown with TransparentBlt from msimg32.dll while the mouse is captured.

The caption is drawn with DrawText; & underlines the next letter and chr$(10) or \n starts a new line. An icon in ICOBMP (possibly holding NumICOBMPs images side by side) can be placed left, right, above or below the caption with Layout and Spacing. Buttons with the same GroupIndex and the same parent act as a group: clicking one sets its Down state and releases the others. Arrow keys and Tab move the focus to the next or previous control (the constructor sets OnKeyDown to QTButton_KeyDown).

The header comments say: set Left and Top first, then NumBMPs (if greater than 1), then Height and Width; call ReDraw after changing the font. Full usage is described in QTButton.html, which the header refers to.

QTBUTTON inherits the properties, methods and events of QBUTTON; the tables below list only what the component adds or redefines (public members).

Requires

  • A bitmap resource named btn_BMP declared before the include (the source has the commented line '$REsource btn_BMP As "_RES\Boutons.bmp"'); alternatively assign QTBtnBMP.BMP from a bitmap object as the comments explain
  • msimg32.dll (TransparentBlt, Windows 98 and later)
  • uxtheme.dll (XP visual styles)
  • QTButton.html documentation (referred to in the header)

LayoutINTEGERRWFalsePosition of the icon relative to the caption, as computed in DrawCaption: 0 left (default), 1 right, 2 above, 3 below. Assigning it redraws the caption.
SpacingINTEGERRWmaxNumBMPs_QTBtnDistance in pixels between the icon and the caption (default 4). Assigning it redraws the caption.
HeightINTEGERRWButton height. Assigning it sets the inherited Height as well and redraws the button.
WidthINTEGERRWButton width. Assigning it sets the inherited Width as well and redraws the button.
NumBMPsINTEGERRWTrueNumber of state images in the skin (normal, disabled, pressed, hot), capped at 4. Assigning it sets the inherited NumBMPs and redraws; the hover effect needs 4.
NumICOBMPsINTEGERRWTrueNumber of images stored side by side in ICOBMP (default 1). Assigning it redraws the button or its caption.
FlickeringTrickINTEGERRWWhen set to a value greater than 0, clips the button window with a region 2 pixels inside its border (HideBevelTrick_QTBtn) to hide the bevel and reduce flicker.
HideFocusRectINTEGERRWWhen set to a value greater than 0, clips the button window with a region 5 pixels inside its border so the focus rectangle is not visible.

The component handles these events itself (EVENT blocks in the TYPE): HotTimer.OnTimer, OnMouseDown, OnMouseMove, OnMouseUp.

Notes

  • The skin bitmap comes from a resource named btn_BMP that the include does not declare; the $RESOURCE line is commented out.
  • XP theme drawing is used only when GetVersionEx reports exactly Windows NT 5.1 (Windows XP); on other Windows versions the classic skin bitmap is used.
  • TODO list: when Kind is not 0 and Caption is empty the button is drawn badly; the Align property needs fixing; Visible is not handled; changing the font requires ReDraw.
  • Known problems listed in the source: the order of property assignments matters (Left, Top, then NumBMPs, then Height, Width), otherwise the button may not be drawn; with several forms a not yet visible button can draw strangely (workaround: Dim DummyBtn As QTButton and DummyBtn.ReDraw); the button image may get lost in memory and disturb owner-drawn controls; setting Height or Width on the first button can draw it badly (workaround: call ReDraw before showing the form).
  • Each GroupIndex assignment appends to the global handle lists; entries are never removed, although a comment says they should be cleaned when GroupIndex is 0.
  • In ReDraw, the copy of BMP into ICOBMP is guarded by a STATIC variable, so it happens only for the first button that is redrawn.
  • CloseThemeData is called twice on the same theme handle in BMPStretch_Property.

QTButton Examples

Example written for this page from the members above; not run.

$RESOURCE btn_BMP AS "_RES\Boutons.bmp"
$INCLUDE "QTButton95.inc"

CREATE Form AS QFORM
  Caption = "QTButton demo"
  CREATE Btn AS QTBUTTON
    Left = 10
    Top = 10
    NumBMPs = 4
    Height = 25
    Width = 75
    Caption = "&OK"
  END CREATE
END CREATE
Form.ShowModal
