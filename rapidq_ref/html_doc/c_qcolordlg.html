QCOLORDLG Component

Extends QFORM · source: inc/RapidFRM.inc, line 92 · author: D. Glodt (original version)

QColorDlg is a color selection dialog wrapping the Windows ChooseColor dialog, with selectable style, screen position, caption and custom colors.

The file comments describe it as a bug-fixed version of the QCOLORDIALOG component of RapidQ2.inc, originally by D. Glodt. Execute fills a CHOOSECOLOR structure (owner Application.Handle, initial Color, the 16 custom Colors, a hook procedure) and calls ChooseColorDlg. The hook handles WM_INITDIALOG to move the dialog to Left and Top (or center it when they are negative) and set the caption.

Style chooses the dialog form: cdNormal (compact but expandable, default), cdFullOpen (custom-color part open) or cdNoFullOpen (compact, no custom-color part). The custom colors are written back to Colors on exit. RapidFRM.inc also contains other helpers of the RapidFRM program (a mouse hook, QTabControl functions, QOvalBtn code and component $DEFINEs) that are not part of this component.

QCOLORDLG inherits the properties, methods and events of QFORM; the tables below list only what the component adds or redefines (public members).

Requires

  • Declarations from rapidq2.inc or an equivalent Windows API include: CHOOSECOLOR type, ChooseColorDlg, CC_RGBINIT, CC_SHOWHELP, CC_ENABLEHOOK, CC_FULLOPEN, CC_PREVENTFULLOPEN, WM_INITDIALOG, GetWindowRect, MoveWindow, SetWindowText

QColorDlg Methods

MethodTypeDescription
ExecuteFUNCTION AS INTEGERShows the color dialog; returns True and updates Color when the user presses OK, otherwise returns False.

Notes

  • Width, Height and WindowHandle have no effect on the dialog; the comment marks WindowHandle as not used.
  • Execute always sets CC_SHOWHELP, so the dialog shows a Help button; the file contains no code handling it.
  • The hook moves the window with a width and height one pixel larger than its current rectangle (Right - Left + 1).
  • The comment says focus is captured until the dialog is closed and only one instance should be used.

QColorDlg Examples

Example written for this page from the members above; not run.

$INCLUDE "RapidQ2.inc"
$INCLUDE "RapidFRM.inc"
DIM ColorDlg AS QColorDlg
CREATE Form AS QFORM
  Caption = "Color test"
END CREATE
ColorDlg.Style = cdFullOpen
ColorDlg.Caption = "Pick a color"
ColorDlg.Color = Form.Color
IF ColorDlg.Execute THEN Form.Color = ColorDlg.Color
Form.ShowModal
