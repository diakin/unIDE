QINI Component

Extends QOBJECT · source: inc/object/QIni.inc, line 29

QINI is a non-visual object for reading and writing values in an INI file section and for getting the Windows, System and Temp folders.

Set FileName and Section, then use Get(Key, Default) and Write(Key, Value); they call GetPrivateProfileStringA and WritePrivateProfileStringA from kernel32. Assigning FileName also sets Exist to show whether the file exists.

The constructor calls GetIniPath, which fills the read-only WinDir, SystemDir and TempDir properties with GetWindowsDirectoryA, GetSystemDirectoryA and GetTempPathA. The file's comments are in French.

QINI inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QINI Properties

FieldTypeR/WDefaultDescription
FileNameSTRINGRW""Path of the INI file. Assigning it stores the name and sets Exist to TRUE or FALSE depending on whether the file exists.
ExistBOOLEANRWfalseTRUE if the file named in FileName existed when FileName was assigned.
SectionSTRINGRW""INI section used by Get and Write.
WinDirSTRINGRWRead-only: Windows folder, filled by GetIniPath; assigning it has no effect (empty setter).
SystemDirSTRINGRWRead-only: Windows system folder, filled by GetIniPath; assigning it has no effect (empty setter).
TempDirSTRINGRWRead-only: temporary folder returned by GetTempPath, filled by GetIniPath; assigning it has no effect (empty setter).

QINI Methods

MethodTypeDescription
GetFUNCTION(Key as string,Default as string) AS STRINGGet(Key, Default) returns the value of Key in Section of FileName, or Default if the key is missing or empty.
WriteFUNCTION(Key as string,Value as string) AS LONGWrite(Key, Value) writes Value for Key in Section of FileName and returns the API result (non-zero on success).
GetIniPathSUBInternal: fills WinDir, SystemDir and TempDir; called by the constructor.

Notes

  • Get returns an empty string (not Default) and Write does nothing when FileName or Section is empty.
  • Get reads into a fixed 260-character buffer, so longer values are truncated.
  • Exist is updated only when FileName is assigned, not when the file is later created by Write.

QINI Examples

Example written for this page from the members above; not run.

$INCLUDE "QIni.inc"
DIM Ini AS QINI
Ini.FileName = CURDIR$ + "\settings.ini"
Ini.Section = "Main"
Ini.Write("User", "Alex")
ShowMessage Ini.Get("User", "unknown")
ShowMessage Ini.TempDir
