QDRAWFOCUS Component

Extends QOBJECT · source: inc/QDrawFocus.inc, line 39 · author: modified by JohnK · version: 1.3 · date: 8/2007

QDrawFocus draws a rubber-band selection rectangle (a focus rectangle) on a device context and lets the user move it or resize it from its right and bottom edges with the mouse.

The rectangle is drawn with the Windows DrawFocusRect function, which draws by XOR, so drawing the same rectangle again erases it. The object does not handle mouse events itself: the program calls Start from OnMouseDown, Draw from OnMouseMove and Stop from OnMouseUp, passing a DC handle (for example from GetDC) and the mouse coordinates.

Start begins a new rectangle, or, when the click is inside the visible one, prepares to move it or to resize it from the right edge, bottom edge or bottom-right corner (a 10-pixel border zone). Left, Top, Width, Height, Move and Inside report the state and are read-only. When ShowCursor is TRUE the screen cursor changes to show the current action.

QDRAWFOCUS inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

QDrawFocus Properties

FieldTypeR/WDefaultDescription
LeftSHORTRWRead-only: left coordinate of the current rectangle; assigning it has no effect (empty setter). Updated by Start and Draw.
TopSHORTRWRead-only: top coordinate of the current rectangle; assigning it has no effect (empty setter).
WidthSHORTRW0Read-only: width of the current rectangle; assigning it has no effect (empty setter).
HeightSHORTRW0Read-only: height of the current rectangle; assigning it has no effect (empty setter).
MoveBOOLEANRWRead-only: TRUE after Draw has moved or resized an existing rectangle; Stop removes the rectangle only when it is TRUE. Assigning it has no effect.
VisibleBOOLEANRWTRUE while the rectangle is drawn on the DC; set by Draw and cleared by Remove.
InsideBOOLEANRWRead-only: TRUE when the last point given to Start or Draw (without drawing) was inside the visible rectangle or on its resize border. Assigning it has no effect.
NoResizeBOOLEANRWWhen TRUE the rectangle can only be moved, not resized from its edges.
ShowCursorBOOLEANRWtrueWhen TRUE (default) Screen.Cursor is changed to show drawing, moving or the resize direction, and reset to the default by Remove and Stop.

QDrawFocus Methods

MethodTypeDescription
RemoveSUB(handle as long)Remove(handle) erases the rectangle from the DC by drawing it again (XOR) if it is visible, and resets the cursor when ShowCursor is TRUE.
StartSUB(handle as long,x as integer,y as integer)Start(handle, x, y) is called on mouse down: inside the visible rectangle it prepares a move or a resize; elsewhere it removes the old rectangle and starts a new one at x, y.
DrawSUB(handle as long,x as integer,y as integer,flagDraw as boolean)Draw(handle, x, y, flagDraw) is called on mouse move. With flagDraw TRUE it erases and redraws the rectangle moved, resized or stretched to x, y; with flagDraw FALSE it only updates Inside and the cursor.
StopSUB(handle as long,flagRemove as boolean)Stop(handle, flagRemove) is called on mouse up: if the rectangle was moved and flagRemove is TRUE it removes it; the cursor is reset when ShowCursor is TRUE.

Notes

  • A comment says the internal rectangle uses the RECT type because QRect crashes on Windows XP.
  • The resize border width (10 pixels) is a private field with no way to change it.
  • RECT and GetDC are declared only when neither __WIN32API nor __RQ2WIN32API is defined, and DrawFocusRect only when __WIN32API is not defined.
  • When stretching a new rectangle, the upward test compares y with .Top while the leftward test compares x with .StartX.

QDrawFocus Examples

Example written for this page from the members above; not run.

$INCLUDE "QDrawFocus.inc"
DECLARE SUB FormDown(Button AS INTEGER, X AS INTEGER, Y AS INTEGER, Shift AS INTEGER)
DECLARE SUB FormMove(X AS INTEGER, Y AS INTEGER, Shift AS INTEGER)
DECLARE SUB FormUp(Button AS INTEGER, X AS INTEGER, Y AS INTEGER, Shift AS INTEGER)
DIM Focus AS QDrawFocus
DIM hDC AS LONG
DIM Dragging AS INTEGER
CREATE Form AS QFORM
  Caption = "Select an area"
  OnMouseDown = FormDown
  OnMouseMove = FormMove
  OnMouseUp = FormUp
END CREATE
hDC = GetDC(Form.Handle)
Form.ShowModal

SUB FormDown(Button AS INTEGER, X AS INTEGER, Y AS INTEGER, Shift AS INTEGER)
  Dragging = 1
  Focus.Start(hDC, X, Y)
END SUB

SUB FormMove(X AS INTEGER, Y AS INTEGER, Shift AS INTEGER)
  Focus.Draw(hDC, X, Y, Dragging)
END SUB

SUB FormUp(Button AS INTEGER, X AS INTEGER, Y AS INTEGER, Shift AS INTEGER)
  Dragging = 0
  Focus.Stop(hDC, 0)
  ShowMessage STR$(Focus.Width) + " x " + STR$(Focus.Height)
END SUB
