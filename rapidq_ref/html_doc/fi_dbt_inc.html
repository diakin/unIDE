sub dbtCreate( dbtArch as string)

Creates a new dBase memo (.dbt) file dbtArch with a 512-byte header (next free block = 1), using the global QFileStream fs. If the file cannot be created it prints a message and ends the program.

dbtOpen

SUB · RQProc.inc, line 11251

sub dbtOpen(dbtArch as string, mode as integer)

Opens a dBase memo (.DBT) file in the global file stream fs with the given mode, reads the block count from its first four bytes into blockCount and resets currentRecID to -1. If the file cannot be opened it prints a message and ENDs the program.

MemoAppend

FUNCTION · RQProc.inc, line 11274

function MemoAppend(text as string) as integer

Appends text as a new memo record at the end of the .DBT file opened in fs, padded to 512-byte block boundaries and terminated with &H1A, then updates the block count in the file header. Returns the starting block number (the memo pointer to store in the DBF record); returns nothing for empty text.

Memoget

FUNCTION · RQProc.inc, line 11310

function Memoget(n as long) as string

Returns the memo text stored at block n of the open .DBT file (up to the &H1A end mark). Sets currentRecID to n and uses readRecord and the global __s buffer; returns empty if n is out of range.

memoUpdate

FUNCTION · RQProc.inc, line 11314

function memoUpdate(newtext as string) as long

Replaces the memo last read with Memoget (currentRecID) with newtext. Writes in place if it fits in the original blocks, otherwise appends it with MemoAppend and leaves the old record unreferenced. Returns the (possibly new) block pointer and resets currentRecID; returns -1 if no record was read.
