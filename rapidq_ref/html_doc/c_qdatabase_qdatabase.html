QDATABASE Component

Extends QOBJECT · source: inc/QDataBase.inc, line 31 · version: 1.0

A non-visual component for a simple flat-file database of fixed-size text records, with field lookup and search functions.

QDataBase stores records in one file. The file starts with a 16-byte header (the record count and the length of the format string, each as an 8-character string), followed by the record format string and then the records, each RecordSize bytes long. The record format is a comma-separated list of name:size entries, for example "Name:20,City:15,Age:3"; RecordSize is the sum of the sizes.

Create makes a new database file, Open reads an existing one and Close only clears the in-memory state. Every record operation opens the file with a QFileStream, does its work and closes it again. Records are numbered from 1 and can be passed as strings of exactly RecordSize characters, or as a pointer to a user-defined type (the ...Udt methods copy RecordSize bytes through a QMemoryStream).

The search methods (SearchByRecord, SearchByField, SearchByRequest) scan all records and fire OnSearch once for each matching record index. Methods return True on success; on failure the Error property holds one of the constants ErrDbCreate (1), ErrDbOpen (2), ErrDbFile (3), ErrDbIndex (4), ErrDbRecordEmpty (5) or ErrDbRecordSize (6).

QDATABASE inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

OnSearchSUB(index as long)Event OnSearch(index AS LONG) fired by the search methods once for each matching record number.

Notes

  • GetRecord and GetRecordUdt are opened with FUNCTION but closed with END SUB.
  • GetFieldCount only counts fields when the format contains a comma, so a format with a single field gives FieldCount 0 and GetFieldName/GetFieldSize then return nothing.
  • SearchByField and SearchByRequest compute the field offset starting at 0 (sum of the previous field sizes) but pass it to MID$, whose positions start at 1, so the extracted field text starts one character early.
  • GetFieldIndex matches name as a substring of the whole name:size entry, so a short name can match a longer field name or a size.
  • IsOpen only checks that FileName is set and the file exists; the file is not kept open between calls.
  • The ...Udt methods trust the caller: they copy RecordSize bytes from or to the given address without checking the size of the type.
  • The source comments are in French.

QDataBase Examples

Example written for this page from the members above; not run.

$INCLUDE "QDataBase.inc"
DIM Db AS QDataBase
DIM rec AS STRING

SUB Found(index AS LONG)
  Db.GetRecord(index, rec)
  PRINT index, rec
END SUB

Db.OnSearch = Found
IF Db.Create("people.db", "Name:20,City:15") THEN
  Db.AddRecord(LEFT$("John" + SPACE$(20), 20) + LEFT$("Paris" + SPACE$(15), 15))
  Db.SearchByField("paris", 2)
END IF
