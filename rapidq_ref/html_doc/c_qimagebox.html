QIMAGEBOX Component

Extends QSCROLLBOX · source: inc/QImageBox.inc, line 53 · version: 1.0

A scroll box that displays an image file (BMP, ICO, CUR, ANI, and GIF, JPG, PCX, TGA and others through Nviewlib.dll), scaled down to fit and centered.

QImageBox extends QScrollbox and contains a stretched QImage. Assigning FileName loads the file into an internal QBitmap and shows it: .bmp files are loaded directly, .ico files with LoadImageA, and .ani and .cur files with ExtractIconA (drawn at 32 x 32 on the box color). GIF, JPG, JIF, DIB, RLE, TGA and PCX files are loaded with the NViewLibLoad function of Nviewlib.dll, which must be in the program folder or the Windows system folder.

An image larger than the box (minus 10 pixels) is reduced by the same percentage in both directions to fit; smaller images are shown at their own size. The image is centered and redrawn when the box is resized. ImgWidth and ImgHeight give the original size of the loaded image. Comments in the source are in French.

QIMAGEBOX inherits the properties, methods and events of QSCROLLBOX; the tables below list only what the component adds or redefines (public members).

Requires

  • NVIEWLIB.DLL (Nviewlib.dll) for GIF, JPG, JIF, DIB, RLE, TGA and PCX files; it must be in the program folder or the Windows system folder

QImageBox Properties

FieldTypeR/WDefaultDescription
LanguageSTRINGRWString passed to NViewLibSetLanguage before a file is loaded through Nviewlib.dll (only when not empty); the source does not say which values are accepted.
ProgressBOOLEANRWPassed as the Progress argument of NViewLibLoad when a file is loaded through Nviewlib.dll; the source does not say what it changes.
FileNameSTRINGRWImage file to display. Assigning it loads and shows the file according to its extension; for an unsupported extension, or a DLL format when Nviewlib.dll is missing, the image is hidden and ImgWidth and ImgHeight are set to 0.
ImgWidthINTEGERRWRead only (the setter is empty): width in pixels of the loaded image before scaling.
ImgHeightINTEGERRWRead only (the setter is empty): height in pixels of the loaded image before scaling.

The component handles these events itself (EVENT blocks in the TYPE): OnResize.

Notes

  • The file type is chosen with INSTR on the lowercase name, so the extension text anywhere in the name matches (for example "a.bmp.jpg" is treated as BMP).
  • Images are only reduced to fit, never enlarged.
  • Nviewlib.dll is looked for only in the folder of the executable and in the Windows system folder.
  • Icons other than .ico (.ani, .cur) are always drawn at 32 x 32.

QImageBox Examples

Example written for this page from the members above; not run.

CREATE ImgBox AS QImageBox
  Parent = Form
  Width = 320
  Height = 240
END CREATE

ImgBox.FileName = "photo.jpg"
ShowMessage STR$(ImgBox.ImgWidth) + " x " + STR$(ImgBox.ImgHeight)
