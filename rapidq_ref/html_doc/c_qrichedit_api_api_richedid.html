QRICHEDIT_API Component

Extends QOBJECT · source: inc/API_RichEdid.inc, line 56

An unfinished wrapper that creates a Windows RichEdit control directly with CreateWindowExA instead of using QRICHEDIT.

Most of the TYPE block is a list of QRICHEDIT properties, methods and events copied in as DIM and SUB declarations without code, plus a few planned additions (AutoURLDetect, FindText, ReplaceSel, ScrollCaret). The working part is at the end: Left, Top, Width, Height, Visible and Parent have setters. Assigning Parent (a window handle) creates a child window of class "RichEdit" with WS_CHILD and WS_VISIBLE at the current position and size; the position and size setters then move it with MoveWindow and Visible shows or hides it with ShowWindow.

The Russian comments (in DOS code page 866) say that ReplaceSel replaces the selected text and ScrollCaret scrolls the text until the line with the cursor becomes visible.

QRICHEDIT_API inherits the properties, methods and events of QOBJECT; the tables below list only what the component adds or redefines (public members).

Requires

  • SW_HIDE and SW_SHOW constants, which this file uses but does not define (for example from a Win32 API include)

QRichEdit_api Methods

MethodTypeDescription
AddStringsSUBIDeclared as SUBI AddStrings without a body, as part of the copied list of QRICHEDIT methods; it has no implementation in this file.

Notes

  • Most methods and events are declarations without bodies (SUB Clear, SUB LoadFromFile, SUB FINDTEXT, SUB OnChange and others), so the file is a draft and may not compile as is.
  • LoadLibrary and FreeLibrary are declared but never called, so nothing in this file loads the DLL that registers the "RichEdit" window class.
  • SW_HIDE and SW_SHOW are used but not defined in the file.
  • SetParent contains commented-out progress bar code (PBM_SETRANGE, PBM_SETSTEP) left over from another component.
  • The findtextex TYPE and the FormWndProc declaration are not used.
  • The file name is spelled API_RichEdid.inc.
