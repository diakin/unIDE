QPROGRESS Component

Extends QIMAGE · source: inc/QProgress.inc, line 39 · author: Johnk

A progress indicator derived from QIMAGE that shows either a standard QGAUGE or an animated marquee (moving dot, rectangles, blur or barber pole) for tasks of unknown length.

For Kind 0 to 4 the component shows its embedded QGAUGE (gkText, gkHorizontalBar, gkVerticalBar, gkPie, gkNeedle) and Value and Range are passed to it. For Kind 5 to 8 (gkMovingDot, gkMovingRect, gkMovingBlur, gkBarberPole) it draws a pattern in Color on BackColor into a bitmap twice as wide as the control and scrolls it by StepSize pixels every Interval seconds.

The animation starts when Visible is set to non-zero and stops when it is set to 0. By default a QTIMER drives it; with UseThreading = True a thread created with CreateThread (kernel32) runs a drawing loop instead. The header says the original component did not work reliably and was totally redone, and that threading is needed because it will not update on one thread.

QPROGRESS inherits the properties, methods and events of QIMAGE; the tables below list only what the component adds or redefines (public members).

QProgress Properties

FieldTypeR/WDefaultDescription
CaptionSTRINGRWText drawn on the marquee bitmap (Kind 5 to 8 only).
GaugeQGAUGERWThe embedded QGAUGE used for Kind 0 to 4.
StepSizeINTEGERRW50Number of pixels the marquee moves per update (default 50; set to half the object size if 0).
IntervalSINGLERW0.500Update interval of the marquee in seconds (default 0.5).
VisibleINTEGERRWFALSEShows or hides the control. For Kind 5 to 8, assigning non-zero starts the timer or the drawing thread and assigning 0 stops it.
ColorINTEGERRWRGB(128 , 128 , 128)Foreground color of the gauge or marquee. Assigning it sets Gauge.ForeColor and redraws the marquee pattern.
BackColorINTEGERRW0Background color. Assigning it sets Gauge.BackColor and redraws the marquee pattern.
RangeINTEGERRWMaximum value. Assigning it sets Gauge.Max to the value and Gauge.Min to 0.
valueINTEGERRWCurrent progress value. Assigning it sets Gauge.Position.
KindINTEGERRW0Display style: 0 gkText, 1 gkHorizontalBar, 2 gkVerticalBar, 3 gkPie, 4 gkNeedle (QGAUGE kinds), 5 gkMovingDot, 6 gkMovingRect, 7 gkMovingBlur, 8 gkBarberPole. Assigning a value above 4 draws the marquee and hides the gauge; otherwise the gauge is shown with that Kind.
HeightINTEGERRW20Control height. Assigning it sets the inherited Height and redraws the marquee pattern.
WidthINTEGERRW200Control width. Assigning it sets the inherited Width and redraws the marquee pattern.
UseThreadingINTEGERRWFALSEWhen True the marquee is animated by a separate thread instead of a QTIMER (default False).

Notes

  • The header warns: if you use threading you cannot use CODEPTR on any other SUB in the program, because the address is used up.
  • A comment in the timer routine says not to put SLEEP in it and that DoEvents does nothing there.
  • With UseThreading, SetVisible busy-waits with DO: LOOP UNTIL .Visible = TRUE before the inherited Visible is set, so it may never return.
  • Width and Height assignments do not resize the Gauge; only the threading loop copies the size to it.
  • The Range setter does not store the value in the Range field.
  • The caption is drawn at x = .Left + .Width \ 2, which includes the control's own Left position.

QProgress Examples

Example written for this page from the members above; not run.

$INCLUDE "QProgress.inc"

CREATE Form AS QFORM
  CREATE Prog AS QPROGRESS
    Left = 10
    Top = 10
    Width = 200
    Height = 20
    Color = &HFF8000
    Kind = gkBarberPole
  END CREATE
END CREATE
Prog.Visible = 1
Form.ShowModal
