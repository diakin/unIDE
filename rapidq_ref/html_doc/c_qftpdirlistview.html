QFTPDIRLISTVIEW Component

Extends QLISTVIEW · source: inc/qftpdirlistview.inc, line 39 · author: Andrew Shelkovenko

QFTPDirListView is an unfinished QListView-based file list meant to browse FTP directories; the code present lists folders and files of a local directory.

The header says the component is by Andrew Shelkovenko and is based on QFTPCLIENT.INC by Jacques Philippe and QDirListView.inc by Rene Saarsoo. Host, User and Password properties exist, but their setters are empty and no FTP connection is made by the component: LoadDirectories contains a pasted QFtpClient sample with a hard-coded server, followed by a local Dir$ listing.

Refresh clears the list, adds sub-folders (LoadDirectories) and files matching Mask (LoadFiles) of Directory, creates the Name, Size, Type and Date Modified columns on first use, and repaints the control. Icons for folders and unknown files come from four $RESOURCE .ico files loaded into SmallImageList and LargeImageList. Double-clicking or pressing Enter on a folder opens it; on a file it fires OnFileSelect. Backspace goes to the parent folder (hidden popup-menu items provide the shortcuts).

QFTPDIRLISTVIEW inherits the properties, methods and events of QLISTVIEW; the tables below list only what the component adds or redefines (public members).

Requires

  • $INCLUDE "QFTPCLIENT.INC"
  • $RESOURCE ICO_DIR_SMALL from C:\bas\RapidQ\inc\dir_XP_small.ico
  • $RESOURCE ICO_DIR_LARGE from C:\bas\RapidQ\inc\dir_XP_large.ico
  • $RESOURCE ICO_DEFAULTFILE_SMALL from C:\bas\RapidQ\inc\default_small.ico
  • $RESOURCE ICO_DEFAULTFILE_LARGE from C:\bas\RapidQ\inc\default_large.ico
  • FileRec record and vidnum$ function, used but not defined in this file (vidnum$ is only present as a commented-out copy)

Notes

  • Work in progress: LoadDirectories contains a pasted QFtpClient sample with a hard-coded host ("www.bigftp.com"), user and password and PRINT statements, followed by a line of exclamation marks ("!!!!!!!!!!!!") that is not valid code.
  • No FTP access is implemented: Host, User and Password have empty setters and listing uses the local Dir$ and DirExists functions.
  • The $RESOURCE lines use absolute paths (C:\bas\RapidQ\inc\...); the comment says the full path to the resources has to be set.
  • AddFileProperties uses FileRec and vidnum$, which are not defined in this file (vidnum$ is commented out).
  • Set_FilenameProp is defined three times with the same name; only FilenameSize is declared with a setter, the setters of FilenameType and FilenameDate are commented out.
  • Refresh uses an undeclared variable QFTPDirListViewcheckboxes, and LoadFiles declares PontPlace but uses PointPlace.
  • The file declares SetFocus from user32; the comment says to remove it if the program already declares it.

QFTPDirListView Examples

Example written for this page from the members above; not run.

$INCLUDE "qftpdirlistview.inc"
DECLARE SUB FileChosen(Tag AS INTEGER)
CREATE Form AS QFORM
  Caption = "Files"
  CREATE FileList AS QFTPDirListView
    Parent = Form
    OnFileSelect = FileChosen
  END CREATE
END CREATE
FileList.Directory = "C:\"
Form.ShowModal

SUB FileChosen(Tag AS INTEGER)
  ShowMessage FileList.FileName
END SUB
