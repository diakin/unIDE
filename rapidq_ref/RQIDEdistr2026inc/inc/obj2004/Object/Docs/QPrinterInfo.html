QPrinterInfo Composant

QPrinterInfo est un composant d'information supplémentaire sur l'imprimante par défaut.


QPrinterInfo Proprietés
Champs Type L/E Défaut

QPrinterInfo Méthodes
Méthode Type Description Parametres
Scale FUNCTION AS DOUBLE retourne l'échelle d'impression de l'imprimante pour image bitmap 0
Dpi FUNCTION AS INTEGER retourne le nombre de points par pouce 0
Ppm FUNCTION AS DOUBLE retourne le nombre de pixels par millimetre 0
MetricToPixel FUNCTION(mm as double) AS INTEGER retourne la conversion millimetres en pixels 1
PixelToMetric FUNCTION(pixel&) AS DOUBLE retourne la conversion pixels en millimetres 1
HorzPageSize FUNCTION AS INTEGER retourne la largeur de la page en millimetres 0
VertPageSize FUNCTION AS INTEGER retourne la hauteur de la page en millimetres 0
PageWidth FUNCTION AS INTEGER retourne la largeur de la page en pixels 0
PageHeight FUNCTION AS INTEGER retourne la hauteur de la page en pixels 0
PhWidth FUNCTION AS INTEGER retourne la largeur physique de la page en pixels 0
PhHeight FUNCTION AS INTEGER retourne la hauteur physique de la page en pixels 0
PhHorz FUNCTION AS INTEGER retourne la largeur physique de la page en millimetres
PhVert FUNCTION AS INTEGER retourne la hauteur physique de la page en millimetres 0
PhMarginX FUNCTION AS DOUBLE retourne la marge x physique en millimetres 0
PhMarginY FUNCTION AS DOUBLE retourne la marge y physique en millimetres 0
PhLeftMargin FUNCTION AS INTEGER retourne la marge x physique en pixels 0
PhTopMargin FUNCTION AS INTEGER retourne la marge y physique en pixels 0
