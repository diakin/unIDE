QCursor Composant

QCursor est un composant non visible utilisé pour charger des curseurs a partir de resources ou de fichiers curseur.

          L'utilisation des curseurs chargés se fait par affectation(valeur de 1 a n) des proprietés Cursor de chaque composant.

QCursor Proprietés
Champs Type L/E Défaut
Count INTEGER L 0
Nombre de curseurs chargé par le composant.
Visible BOOLEAN L/E TRUE

QCursor Methodes
Methode Type Description Parametres
LoadFromResource SUB(Resource&) Charge un curseur a partir d'une resource,le parametre Resource est
le numéro de resource(0 a n) du curseur dans le programme.		 1
LoadFromFile SUB(FileName$) Charge un cirseur a partir d'un fichier 1
Move SUB(x&,y&) Deplace le curseur a la position x , y de l'écran 2

QCursor Evenements
Evenement Type Declenchement Parametres

QCursor Exemples
$TypeCheck On
$include "Object/QCursor.inc"

$resource cur1 as "Pen.cur"
$resource cur2 as "Paint.cur"

dim curseur asQCursor
    curseur.loadfromResource(0) 'chargement du curseur cur1
    curseur.loadfromResource(1) 'chargement du curseur cur2
    curseur.loadfromfile("M_Busy.ani") 'chargement a partir d'un fichier

CREATE Form ASQFORM
    Center
    Cursor=2 'utilisation du curseur cur2
    ShowModal
END CREATE
