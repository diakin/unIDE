Appendix A: QFileListView

QFileListView Composant

QFileListView est un composant liste de fichier hérité du composant QListView.
Ce composant possede des colonnes pour le nom , la taille, le type et la date des fichiers ainsi
qu' une icone associé pour chaque type de fichier.

QFileListView Proprietés

Champs

Type

L/E

Défaut

Filename

STRING

L

Nom du fichier selectionné.

ColumnCaption

ARRAY(4) OF STRING

L/E

Libellés des colonnes
index 1=libellé nom fichier
index 2=libellé taille
index 3=libellé type
index 4=libellé date 

Directory

STRING

L/E

Nom du repertoire des fichiers a lister.

Mask

STRING

L/E

*.*

Type de fichier a lister.

QFileListView Exemples
$TYPECHECK ON
$INCLUDE "RAPIDQ.INC"
$INCLUDE "Object\QFileListView.inc"

declare sub DirListFileSelect(file as string)
declare sub ChangeDirectory

CREATE Form AS QFORM
    Width=500
    Height=300
    Center
    Caption="Exploreur"
    CREATE Splitter1 AS QSPLITTER
      Align=alLeft
      width=5
    END CREATE
    CREATE DirTree AS QDirTree
      InitialDir=CURDIR$
      Align=alLeft
      Width=200
      OnChange=ChangeDirectory
    END CREATE
    create DirList as QFileListView
      Align=alClient
      width=200
      ViewStyle=vsReport
      OnFileSelect= DirListFileSelect
      ColumnCaption(1)="Nom" 'Libellé des colonnes
      ColumnCaption(2)="Taille"
      ColumnCaption(3)="Type"
      ColumnCaption(4)="Modifié"
      Mask="*.*"
    end create
end create

Form.ShowModal

sub DirListFileSelect(file as string)  
  ShowMessage("File"+File+" was selected.")
end sub

SUB ChangeDirectory
  DirList.Directory =DirTree.Directory
END SUB
