QINI Composant

QINI est un composant non visuel permettant de lire et d'écrire des fichiers d'init d'application.


QINI Proprietés
Champs Type L/E Defaut
FileName STRING LE
Nom du fichier .ini
Exist INTEGER L FALSE
TRUE si le fichier .ini existe
Section STRING LE
Nom de la section des parametres du fichier
WinDir STRING L
Chemin du repertoire de window
SystemDir STRING L
Chemin du repertoire systeme de window
TempDir STRING L
Chemin du repertoire fichiers temporaires de window

QINI Methodes
Methode Type Description Parametres
Get FUNCTION(Key$,Default$) AS STRING Retourne la valeur du parametre Key$ 2
Write FUNCTION(Key$,Value$) AS LONG Ecris la valeur du parametre Key$ dans le fichier .ini 2

QINI Evenements
Evenement Type Déclenchement Parametres

QINI Exemples 

$TYPECHECK ON
$Include "Rapidq.inc"
$include "Object\QINI.inc"

dim ini as QINI
ini.FileName="c:\Temp\test.ini"
ini.Section="Parametres"
ini.write("par1","1")
ini.write("par2","2")

CREATE Form AS QFORM
  Caption="init"
  Width=300
  Height=110
  Center
END CREATE
if ini.exist then form.caption=ini.get("par1","no param")
Form.ShowModal
