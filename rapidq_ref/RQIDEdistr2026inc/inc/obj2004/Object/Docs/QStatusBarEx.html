QStatusBarEx Composant

QStatusBarEx est identique a QStatusBar avec addition de composants QPanel afin de pouvoir afficher des images ou d'autres composants.

          Il est nécéssaire d'utiliser la méthode AddPanel avant d'ajouter un composant QPanel.

QStatusBarEx Proprietés
Champs Type L/E Défaut

QStatusBarEx Methodes
Methode Type Description Parametres
AddOptPanel SUB(QPANEL,index&) Ajoute un composant QPanel dans un panel existant, le parametre index& determine la position
dans la barre lorsque plusieurs panel ont été additionné , une valeur 0 correspond au premier 
panel de la barre.
La proprieté Height du composant QPanel doit etre inférieur a la proprieté Height de la barre.		 2

QStatusBarEx Exemples
$TYPECHECK ON
$resource BM_OPEN as "open.bmp"
$include "Object\QStatusBarEx.inc"
CREATE Form AS QFORM
    Caption="Form1"
    Width=400
    Height=240
    Center
    CREATE Panel as QPANEL
      CREATE img as QIMAGE
        bmpHandle=BM_OPEN
      END CREATE
    END CREATE
    CREATE StatusBar1 AS QSTATUSBAREX
      height=20
      AddPanels "","","",""
      Panel(0).Width=100
      Panel(1).Width=100
      Panel(2).Width=100
      AddOptPanel Panel,1
    END CREATE
END CREATE

Form.ShowModal
