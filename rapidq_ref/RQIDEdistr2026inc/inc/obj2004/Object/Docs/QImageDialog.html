QImageDialog Composant

QImageDialog est une boite de dialogue sélection de fichiers avec visualisation des types graphique.
Ce composant nécessite la dll NVIEWLIB pour la visualisation des types jig,gif,jpg,pcx,tga,dib,rle ,si celle-ci
n'est pas présente dans le systeme ou dans le repertoire de l'executable , seuls les types bmp,ico,cur,ani seront
visualisés.


QImageDialog Proprietés
Champs Type L/E Défaut
Caption STRING L/E
Titre de la boite dialogue
FileName STRING L/E
Nom du fichier sélectionné incluant le repertoire
Filter STRING L/E
Filtre type de fichier
FilterIndex INTEGER L/E
Index filtre type de fichier
InitialDir STRING L/E
Repertoire initial
DlgCaption ARRAY OF STRING L/E
Libellé des controles boite de dialogue,en anglais par défaut
l'élément 1 est le libellé du label nom du fichier
l'élément 2 est le libellé du label type de fichier
l'élément 3 est le libellé du bouton ouvrir
l'élément 4 est le libellé du bouton annuler
ErrorLanguage STRING L/E
Language d'erreur pour la dll.
(French,English,German,Dutch,Portuguese,Spanish,Japanese,Italian)
MultiSelect BOOLEAN L/E FALSE
SelCount INTEGER L
Nombre de fichiers sélectionnés
Selected QSTRINGLIST L/E
Contient les fichiers sélectionnés incluant le reprtoire

QImageDialog Methodes
Methode Type Description Parametres
Execute FUNCTION AS BOOLEAN Affiche la boite de dialogue 0

QImageDialog Evenements
Evenement Type Declenchement Parametres

QImageDialog Exemples 

$typecheck on
$include "object\QImageDialog.inc"

dim a as QimageDialog
    a.filter="Tous format(*.bmp;*.ico;*.ani;*.cur*.gif;*.jpg;*.dib;*.rle;*.tga;*.pcx)|*.bmp;*.ico;*.ani;*.cur*.gif;*.jpg;*.dib;*.rle;*.tga;*.pcx|Fichiers bitmap(*.bmp)|*.bmp|Fichiers gif(*.gif)|*.gif|Fichiers jpg(*.jpg)|*.jpg|Fichiers ico(*.ico)|*.ico|Fichiers curseur(*.cur;*.ani)|*.cur;*.ani"
    a.caption="Ouvrir"
    a.DlgCaption(1)="Nom du fichier:"
    a.DlgCaption(2)="Type du fichier:"
    a.DlgCaption(3)="Ouvrir"
    a.DlgCaption(4)="Annuler"
    a.errorLanguage="french"
    a.MultiSelect=true
    a.execute
    end
