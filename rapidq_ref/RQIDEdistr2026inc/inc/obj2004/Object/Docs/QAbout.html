QAbout Composant

QAbout est une boite de dialogue "A propos" affichant le nom,la version,l'auteur d'une application,lien e-mail et lien web.


QAbout Proprietés
Champs Type L/E Défaut
Caption STRING L/E
Titre de la boite dialogue
AppName STRING L/E
Nom de l'application
AppVersion STRING L/E
Version et révision de l'application
Image QIMAGE L/E
Icone ou image de l'application
Text STRING L/E
Texte de l'application décrivant l'auteur et le copyright
Email STRING L/E
Lien adresse e-mail , exemple: "dominique.glodt@libertysurf.fr"
Web STRING L/E
Lien site web , exemple: "www.allapi.net"
AppFont QFONT L/E
TextFont QFONT L/E
EmailFont QFONT L/E
WebFont QFONT L/E

QAbout Methodes
Methode Type Description Parametres
Show SUB Affiche la boite de dialogue

QAbout Evenements
Evenement Type Declenchement Parametres

QAbout Exemples
$TYPECHECK ON
$include "object\qabout.inc"
 

$resource ico as "icone.ico"
declare sub routine1
dim about as QAbout

create form as QFORM
  width=300
  height=200
  center
  onclick=routine1
end create

form.showmodal

sub routine1
  about.AppFont.color=&h007700
  about.AppFont.bold=1
  about.Appname="Platforme"
  about.Appversion="1.02"
  about.caption="A propos de "+about.Appname
  about.text="Auteur:Glodt dominique"+chr$(13)+"Copyright(c)software 2000-2002  "
  about.image.icohandle=ico
  about.email="dominique.glodt@libertysurf.fr"
  about.web="www.allapi.net"
  about.show
end sub
