Параметры запуска

Параметры командной строки qemu-system-i386, которые пригодятся для своей команды запуска. Значения с пробелами берутся в кавычки целиком: "file=D:\My Iso\bootcd.iso,media=cdrom"; запятая внутри пути удваивается (,,).

Машина

ПараметрЧто задаёт
-m 1024Память в МБ.
-smp 2Число процессоров (по умолчанию 1).
-cpu pentium3Модель процессора (-cpu help — список).
-rtc base=localtimeЧасы машины — по местному времени, как у Windows.
-name "ReactOS"Заголовок окна.
-vga stdВидеокарта: std (VESA), cirrus, vmware, none.

Диски и загрузка

ПараметрЧто задаёт
-cdrom bootcd.isoCD-ROM (короткая запись).
-hda disk.qcow2Первый жёсткий диск (короткая запись).
-drive file=...,if=ide,index=0,media=disk,format=qcow2Диск подробно: интерфейс, место на шине IDE (0, 1 — первый канал, 2, 3 — второй), тип, формат.
-boot d, -boot cЗагрузка с CD или с жёсткого диска.
-boot once=dС CD только первый раз; после перезагрузки внутри машины — с жёсткого диска.
-snapshotНичего не записывать в файлы дисков: все изменения пропадут при закрытии QEMU.

Сеть

ПараметрЧто задаёт
-netdev user,id=net0Сеть через QEMU (NAT): из машины есть интернет, драйвер в системе не нужен.
-device ne2k_pci,netdev=net0Сетевая карта NE2000 PCI (её подключает unIDE). Другие модели: pcnet, rtl8139, e1000 — подойдут, если в гостевой системе есть их драйвер.
-nic noneБез сети.

Порты и окно

ПараметрЧто задаёт
-serial "file:D:\log\serial.log"COM1 — в файл (перезаписывается при запуске).
-serial vcCOM1 — вкладкой serial0 в окне QEMU.
-display gtk, -display sdlВид окна.
-full-screenСразу во весь экран.

Своя команда запуска

Project Properties → поле Запуск (Run). Пусто — unIDE запускает свой QEMU с параметрами из раздела о запуске. Иначе выполняется ваша команда; перед запуском в ней заменяются:

ПодстановкаЧем заменяется
%ISO%, %IMAGE%Полный путь собранного образа
%BUILDDIR%Папка сборки
%SOURCEDIR%Папка исходников
%SERIAL%<папка сборки>\unide-qemu\serial.log
%QEMU%qemu-system-i386w.exe своего QEMU (при надобности он предлагается к установке)

Пути с пробелами берите в кавычки. Примеры:

"%QEMU%" -m 512 -cdrom "%ISO%" -boot d -serial "file:%SERIAL%"
"%QEMU%" -m 1024 -smp 2 -hda "%BUILDDIR%\unide-qemu\hdd.qcow2" -cdrom "%ISO%" -boot once=d
"%QEMU%" -m 1024 -cdrom "%ISO%" -boot d -snapshot -serial vc

Рабочая папка команды — папка сборки. Окно QEMU не ждётся: unIDE запускает команду и продолжает работать.
