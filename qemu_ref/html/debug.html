Отладочный вывод

Отладочные сборки ReactOS пишут журнал загрузки в последовательный порт COM1 (параметры загрузки DEBUG KDSERIAL DEBUGPORT=COM1). unIDE направляет COM1 машины в файл <папка сборки>\unide-qemu\serial.log.

Что в нём

(ntoskrnl/kd64/kdinit.c:75) ReactOS 0.4.15-x86 (Build ...)
(ntoskrnl/kd64/kdinit.c:76) 1 System Processor [1024 MB Memory]
(ntoskrnl/kd64/kdinit.c:80) Command Line: DEBUG KDSERIAL DEBUGPORT=COM1 ...

Каждая строка — файл исходников и номер строки, откуда вызван вывод (DPRINT, DPRINT1), и само сообщение: так видно, до какого места дошла загрузка и какой драйвер сообщил об ошибке.

Как смотреть

  • Открыть serial.log в unIDE (File → Open). Файл дописывается, пока машина работает; перечитать — открыть заново.
  • Видеть вывод сразу в окне QEMU: своя команда запуска с -serial vc (см. Своя команда) — вывод во вкладке serial0 меню View.
  • Файл перезаписывается при каждом запуске: нужный журнал сохраните под другим именем до следующего Run.
