Окно QEMU

QEMU в unIDE показывает экран виртуальной машины в окне с меню Machine и View (интерфейс GTK).

Меню Machine

ПунктЧто делает
PauseОстановить машину (и продолжить).
ResetСброс — как кнопка Reset на корпусе: перезагрузка без завершения работы системы.
Power DownСигнал выключения (как короткое нажатие кнопки питания): система завершает работу сама, если умеет.
QuitЗакрыть QEMU сразу — как выдернуть шнур питания.

Меню View

  • Fullscreen — во весь экран.
  • Zoom In / Zoom Out / Best Fit / Zoom To Fit — масштаб изображения.
  • Grab Input — захватить клавиатуру и мышь; Grab On Hover — захватывать, когда указатель над окном.
  • VGA — экран машины; compatmonitor0 — монитор QEMU (командная строка управления машиной); parallel0 — параллельный порт.
  • Show Tabs, Detach Tab — экраны вкладками или отдельными окнами; Show Menubar — спрятать или показать меню.

Клавиши

Все сочетания QEMU начинаются с Ctrl+Alt:

КлавишиЧто делают
Ctrl+Alt+GОсвободить (или захватить) мышь и клавиатуру
Ctrl+Alt+FВо весь экран / обратно
Ctrl+Alt++, Ctrl+Alt+-Крупнее, мельче
Ctrl+Alt+0Масштаб 1:1
Ctrl+Alt+1, Ctrl+Alt+2, ...Консоли по порядку пунктов меню View (первая — экран VGA)
Ctrl+Alt+MСпрятать / показать меню
Ctrl+Alt+QЗакрыть QEMU

Ctrl+Alt+Del перехватывает Windows и в машину не передаёт. Послать его гостевой системе: монитор QEMU, команда sendkey ctrl-alt-delete.

Мышь

Щелчок в окне захватывает мышь: указатель остаётся внутри машины, и вывести его наружу можно только через Ctrl+Alt+G (подсказка — в заголовке окна). Пока мышь захвачена, все нажатия клавиш тоже идут в машину.
