Диски и qemu-img

qemu-img.exe лежит рядом с QEMU (tools\qemu) и работает с файлами дисков. Запускать его надо при закрытом QEMU, когда диск не занят. Пример запуска из командной строки Windows:

"D:\...\tools\qemu\qemu-img.exe" info D:\...\output-MinGW-i386\unide-qemu\hdd.qcow2

Форматы

ФорматОсобенности
qcow2Родной формат QEMU: файл растёт по мере записи, поддерживает снимки. unIDE создаёт диск в нём.
raw (.img)Байт в байт как настоящий диск; занимает полный размер.
vpc (.vhd)Virtual PC / Hyper-V.
vdiVirtualBox.
vmdkVMware.

Команды

КомандаЧто делает
qemu-img create -f qcow2 disk.qcow2 8GНовый диск 8 ГБ.
qemu-img info disk.qcow2Формат, размер, занято на самом деле, снимки.
qemu-img resize disk.qcow2 +4GУвеличить на 4 ГБ (раздел внутри гостевой системы потом расширяется её средствами).
qemu-img convert -O vdi disk.qcow2 disk.vdiПреобразовать в другой формат (vdi, vpc, vmdk, raw) — например, чтобы открыть систему в VirtualBox.
qemu-img snapshot -l disk.qcow2Список снимков.
qemu-img snapshot -c имя disk.qcow2Снимок диска (при закрытом QEMU — только диска, без памяти).
qemu-img snapshot -a имя disk.qcow2Вернуть диск к снимку.
qemu-img snapshot -d имя disk.qcow2Удалить снимок.
