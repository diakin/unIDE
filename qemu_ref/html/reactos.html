Установка ReactOS в QEMU

bootcd: первый этап

  1. Соберите цель bootcd и запустите (Compile & Run или ReactOS → Run Image). При первом запуске создаётся пустой диск unide-qemu\hdd.qcow2.
  2. Машина грузится с CD, открывается текстовая установка ReactOS: язык, раздел диска (на новом диске всё место ещё не размечено — на нём создаётся раздел), файловая система, папка установки.
  3. Программа установки копирует файлы, ставит загрузчик и перезагружает машину.

bootcd: после перезагрузки

После перезагрузки CD по-прежнему подключён, и BIOS снова начинает загрузку с него. Если на жёстком диске уже есть загрузочный раздел, загрузчик CD ReactOS пишет:

Press any key to boot from the ReactOS medium.....

Ничего не нажимайте: когда точки кончатся, загрузка пойдёт с жёсткого диска, и продолжится второй (графический) этап установки ReactOS. Нажатие клавиши (и щелчок мышью по окну) запускает установку с CD заново.

Убрать CD совсем: монитор QEMU (View → compatmonitor0) → eject ide1-cd0 (см. Монитор QEMU). При следующем запуске из unIDE CD будет подключён снова.

Следующие запуски

Каждый Run подключает свежесобранный bootcd.iso и тот же диск hdd.qcow2 с установленной системой: не нажимая клавиш при «Press any key...», вы загружаете установленную ReactOS.

Поставить заново на чистый диск — закройте QEMU и удалите unide-qemu\hdd.qcow2 в папке сборки: при следующем запуске будет создан новый пустой диск.

livecd

Цель livecd — ReactOS, которая работает прямо с CD без установки. Диск hdd.qcow2 тоже подключается (для ISO он подключается всегда), но ставить на него ничего не нужно.

Сохранить состояние

Если перед опытом с драйвером хочется вернуться к нынешнему состоянию установленной системы: монитор QEMU, savevm перед_опытом; вернуть — loadvm перед_опытом (см. Снимки). Или скопируйте hdd.qcow2, пока QEMU закрыт.
