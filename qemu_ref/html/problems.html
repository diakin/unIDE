Если не работает

QEMU сразу закрывается

unIDE ждёт 3 секунды; если QEMU закрылся, в Compilation log выводятся код завершения и начало unide-qemu\qemu.log — там сообщение QEMU о том, что ему не понравилось (файл, параметр). При своей команде запуска журнал не пишется: проверьте её, запустив в командной строке Windows.

«Эмулятор уже работает»

Прежнее окно QEMU, запущенное из unIDE, ещё открыто. Закройте его (Machine → Quit или выключите гостевую систему) и запустите снова.

Мышь не выходит из окна

Ctrl+Alt+G. Подробнее — Клавиши.

Снова начинается установка с CD

При «Press any key to boot from the ReactOS medium» была нажата клавиша (или щелчок по окну). Подождите, не трогая окно: загрузка пойдёт с жёсткого диска (см. Установка ReactOS).

«Нет образа»

В папке сборки нет <цель>.iso (.img, .vhd): проект не собран, сборка не дошла до конца или цель ninja — модуль (ntoskrnl и т. п.), у которого образа нет. Цель задаётся в Project Properties.

Очень медленно

Процессор машины эмулируется программно, без аппаратного ускорения: так QEMU работает в Windows 7 без установки драйверов. Это ожидаемо; ускорители QEMU (HAXM, WHPX) требуют установки драйвера или Windows 10, unIDE их не использует.

QEMU не скачивается

Причина выводится в Compilation log. Ошибка 12157 — в Windows не включён TLS 1.2 (Свойства браузера → Дополнительно → «Использовать TLS 1.2»). Вручную: скачать qemu-w64-setup-20220419.exe (или qemu-w32-...) с qemu.weilnetz.de, распаковать 7-Zip в tools\qemu так, чтобы qemu-system-i386w.exe и папка share лежали прямо в нём.
