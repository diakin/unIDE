Команды RosBE

Команды RosBE — командные файлы из папки RosBE (она в PATH после RosBE.cmd). Здесь — как они устроены в RosBE 2.2.1.

КомандаЧто делает
help [команда]Список команд или справка по одной.
make [цели]Если в текущей папке есть *.ninja — запускает ninja -j 1 [цели] (иначе mingw32-make). Показывает время сборки и пишет журнал в RosBE-Logs\BuildLog-*.txt текущей папки. Запускать в папке сборки.
makex [цели]То же, но с числом заданий по числу ядер процессора.
basedirПерейти в папку исходников (папку, из которой была открыта командная строка RosBE).
cleanВ папке исходников: удалить папку сборки output-MinGW-<архитектура> целиком.
clean logsУдалить журналы сборки в output-...\RosBE-Logs.
clean <модуль>Выполнить make <модуль>_clean.
remake <модули>, remakexОчистить модули и собрать заново (remakex — на всех ядрах).
charch <архитектура>Сменить архитектуру сборки для этой консоли (i386, amd64...).
chdefdir, chdefgccСменить папку исходников / папку компилятора для этой консоли.
raddr2line <файл> <адрес>Перевести адрес из отладочного вывода (например, из стека при сбое) в файл и строку исходников. Запускать в папке исходников: файлы ищутся в output-MinGW-i386; имя можно указать частично (ntoskrnl*).
kdbgВывод отладчика KDBG и ввод его команд (через именованный канал виртуальной машины).
scutСписок сохранённых папок исходников и переключение между ними.
optionsОкно настроек RosBE (журнал, ccache, звук, PATH...); сохраняются в %APPDATA%\RosBE.
versionВерсии инструментов.
updateОбновления RosBE: файлы берутся с svn.reactos.org/downloads/rosbe (её же RosBE.cmd проверяет при запуске).

Цели make и ninja — цели сборки ReactOS (см. Цели ninja).
