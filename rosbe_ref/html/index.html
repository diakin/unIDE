RosBE: справка

RosBE (ReactOS Build Environment) — набор инструментов для сборки ReactOS в Windows: компиляторы GCC (MinGW), binutils, CMake, Ninja, Flex, Bison и командные файлы, которые настраивают окружение. Для проекта reactosVG14 (ReactOS 0.4.14) нужен RosBE 2.2.1.

RosBE в unIDE

ГдеЧто делает
ReactOS → Install RosBE 2.2.1 (reactosVG14)...Находит уже установленный RosBE или скачивает и распаковывает его (см. Установка). Путь к RosBE.cmd записывается в настройки и в скрипт окружения открытого проекта ReactOS, если он там не задан.
Compile, Compile & Run (проект ReactOS)Сборка через RosBE: configure и ninja (см. Сборка в unIDE).
Project Properties → рамка ReactOS / LiberNTПапка сборки, цель ninja, параметры configure, скрипт RosBE, производители PCI, команда запуска.
ReactOS → Download Build ToolsСтраницы загрузки RosBE и других инструментов в браузере.
Help → RosBEЭта справка (rosbe_ref\help\rosbe.chm).
