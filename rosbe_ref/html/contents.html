Папки

ПутьЧто там
C:\RosBE\RosBE.cmdНастройка окружения (PATH, переменные сборки)
C:\RosBE\*.cmdКоманды RosBE: make, clean, basedir... (см. Команды)
C:\RosBE\bincmake, ninja, flex, bison, вспомогательные программы
C:\RosBE\i386GCC и binutils для i386 (он же компилятор для программ сборки, работающих на самом компьютере)

Что ставит RosBE.cmd

  • ROS_ARCH=i386 (или архитектуру из параметра: RosBE.cmd amd64);
  • PATH: папка RosBE, bin, samples, компиляторы (i386\bin) — перед системным PATH;
  • _ROSBE_ROSSOURCEDIR — текущая папка при запуске (её считает папкой исходников команда basedir);
  • журналы сборки команд make — в RosBE-Logs;
  • свои настройки пользователя, если есть, из %APPDATA%\RosBE\rosbe-options-2.2.1.cmd (их пишет команда options).
