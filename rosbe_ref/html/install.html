Установка RosBE 2.2.1

Что делает Install RosBE

  1. Ищет уже установленный RosBE: запись его установщика (App Paths, RosBE.cmd) и папку C:\RosBE. Нашёл — только запоминает путь.
  2. Иначе нужен свой 7-Zip unIDE (tools\7zip); его нет — сначала предлагается скачать его (около 2 МБ).
  3. Скачивает установщик RosBE-2.2.1.exe с SourceForge (74 МБ) во временную папку и сверяет SHA-256. Если там уже лежит файл с той же суммой, второй раз не качается.
  4. Распаковывает его своим 7-Zip в C:\RosBE (около 300 МБ) — так, как ставит установщик по умолчанию: без его служебных папок, деинсталлятора и компилятора AMD64 (в установщике он выключен).
  5. Путь к RosBE.cmd записывается в editor.ini ([ReactOS] RosBE221Dir) и в поле «Скрипт RosBE» открытого проекта ReactOS, если оно пусто.

Ход — в окне установки, подробности — в Compilation log.

Почему не запуском установщика

Файл RosBE-2.2.1.exe с SourceForge не проходит собственную проверку целостности установщика NSIS: при запуске он сообщает «Installer integrity check has failed» и завершается, а обойти проверку ключом /NCRC его сценарий не позволяет. Сами файлы внутри целы, и 7-Zip распаковывает их без ошибок. RosBE.cmd не требует записей в реестре и работает из любой папки, поэтому распакованный RosBE полноценен; нет только ярлыков в меню Пуск и записи в «Программах и компонентах».

Папка C:\RosBE

Сценарий установщика RosBE 2.2.1 всегда ставит в C:\RosBE (папку /D= он не учитывает), и unIDE распаковывает туда же. Переносить RosBE можно: после переноса укажите новый путь к RosBE.cmd в Project Properties.

Если RosBE уже стоит

Install RosBE его не трогает. Другая версия RosBE (не 2.2.1) для reactosVG14 может не подойти: версия компилятора должна соответствовать дереву исходников.
