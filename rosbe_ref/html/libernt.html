LiberNT

Проект ReactOS / LiberNT в unIDE собирается так же (configure.cmd + ninja), но с другими инструментами: RosBE 2.2.1 для него не нужен, его configure.cmd находит RosBE сам, поле «Скрипт RosBE» остаётся пустым.

Инструменты (ReactOS → Download Build Tools)

ПунктЗачем
RosBE для LiberNT — выпуски winget-rosbeАрхивы компонентов RosBE. Их установщик rosbe.exe на Windows 7 не запускается, поэтому архивы распаковываются вручную в %LOCALAPPDATA%\RosBE\pkgs\<версия>.
Universal C Runtime (KB2999226)Нужен GCC 16 и Clang из этих архивов на Windows 7.
Python 3.8.10Последний Python для Windows 7; нужен для сборки LiberNT с /clang.
Git for Windows 2.46.2Последний для Windows 7 (в unIDE есть свой — ReactOS → Find or Install Git).

Параметры configure LiberNT

По подсказке поля «Параметры configure»: /gcc (по умолчанию), /clang, /arch=amd64, /r — release. Папка сборки LiberNT — output-<метка>-<arch>-<debug|release>; цели образов — ещё liberntimg, liberntvhd.
