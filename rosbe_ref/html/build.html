Сборка в unIDE

Настройки проекта

Project Properties, рамка «ReactOS / LiberNT: CMake + Ninja» (хранится в editor.ini, в разделе проекта, ключи ReactOS_*):

ПолеЧто задаёт
Папка сборкиПапка, которую создаёт configure.cmd: для reactosVG14 с RosBE 2.2.1 — output-MinGW-i386 (путь внутри папки исходников хранится от неё). Список — найденные папки output-*.
Цель ninjabootcd, livecd или имя модуля (ntoskrnl и т. п.).
Параметры configureЧто дописать к configure.cmd (см. configure.cmd).
Скрипт RosBEПолный путь к RosBE.cmd: он выполняется перед каждым шагом. Для LiberNT — пусто: его configure.cmd находит RosBE сам.
Производители PCIДля ReactOS → Generate System Devices INF.
Запуск (Run)Команда эмулятора; пусто — свой QEMU unIDE (Help → QEMU).

Папка проекта — корень исходников: в нём должны быть configure.cmd, CMakeLists.txt и PreLoad.cmake.

Шаги сборки

  1. Проверки: папка проекта — корень исходников ReactOS; файл скрипта RosBE существует.
  2. Проверка CMakeCache.txt (если папка сборки уже есть): какой папке исходников она настроена (ниже).
  3. configure — только если в папке сборки нет build.ninja: call RosBE.cmd, затем configure.cmd <параметры> в папке исходников.
  4. ninja — call RosBE.cmd, затем ninja <цель> в папке сборки.
  5. Готово — путь к <цель>.iso в Compilation log; у Compile & Run — запуск образа.

Каждый шаг — свой .cmd во временной папке, вывод — в Compilation log, ход ninja ([12/3456]) — в окне хода; кнопка Стоп снимает ninja со всеми компиляторами. Ошибки компилятора попадают в Error log.

Проверка CMakeCache.txt

В CMakeCache.txt папки сборки записан путь исходников, для которых она настроена (CMAKE_HOME_DIRECTORY), отдельно — в кэше host-tools. Если дерево перенесли или скопировали, путь там старый: ninja перезапустит CMake со старым путём и остановится; configure.cmd свой кэш удаляет сам, а кэш host-tools — нет.

unIDE сравнивает путь из кэшей с папкой проекта и пишет результат в Compilation log. Не совпадает — спрашивает: удалить CMakeCache.txt (и в host-tools) и запустить configure заново, всё равно запустить ninja или остановиться.

Чистая сборка

Закройте QEMU, удалите папку сборки (output-MinGW-i386) — при следующем Compile configure создаст её заново. То же делает команда clean в командной строке RosBE (см. Команды).
