Если не собирается

«Сборка остановлена: нет скрипта окружения»

В Project Properties указан RosBE.cmd, которого нет по этому пути. Укажите правильный путь или выполните ReactOS → Install RosBE 2.2.1.

'ninja' не является внутренней или внешней командой

ninja не найден в PATH: поле «Скрипт RosBE» пусто (для reactosVG14 оно нужно) или указан не тот файл. Скрипт RosBE ставит PATH к cmake, ninja и gcc.

«Your source path contains at least one space»

configure.cmd не работает, если в пути к исходникам есть пробел. Перенесите дерево в папку без пробелов.

Папка сборки настроена для других исходников

Дерево исходников перенесли или скопировали, а в CMakeCache.txt остался старый путь. unIDE замечает это перед сборкой и предлагает удалить кэши и запустить configure заново (см. Проверка CMakeCache.txt).

«Installer integrity check has failed»

Это сообщение установщика RosBE-2.2.1.exe с SourceForge при запуске. unIDE его не запускает, а распаковывает (см. Установка).

Ошибки компилятора

Строки ошибок — в Error log и в Compilation log; ninja останавливается на первой неудачной команде (продолжать — -k 0 в командной строке RosBE). После исправления Compile пересобирает только изменившееся.

Странные ошибки после смены версии RosBE или переноса

Чистая сборка: удалить папку сборки целиком (или clean в командной строке RosBE) и собрать заново — configure запустится сам.
