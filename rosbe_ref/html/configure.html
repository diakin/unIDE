configure.cmd и ninja

configure.cmd

Скрипт в корне исходников ReactOS: создаёт папку сборки и настраивает её CMake для сборщика Ninja. В reactosVG14 (ReactOS 0.4.14):

configure.cmd [параметры скрипта] [параметры CMake]
  • Запущенный в папке исходников, создаёт output-MinGW-i386 (MinGW из RosBE, архитектура из ROS_ARCH) и работает в ней; запущенный в другой папке — настраивает её.
  • Перед настройкой удаляет CMakeCache.txt в папке сборки.
  • Путь к исходникам не должен содержать пробелов — иначе configure.cmd останавливается с сообщением «Your source path contains at least one space».
  • Папку, настроенную для Ninja, нельзя перенастроить для VSSolution и наоборот.
ПараметрЧто даёт
help, /?Подсказка по параметрам.
Codeblocks, EclipseФайлы проекта для этих сред (вместо Ninja).
MakefilesMinGW Makefiles вместо Ninja.
VSSolution, clangДля сборки средствами Visual Studio (не RosBE MinGW).
-DИМЯ:ТИП=ЗНАЧЕНИЕПеременная CMake, например -DENABLE_ROSTESTS:BOOL=1.

В unIDE параметры configure задаются в Project Properties (поле «Параметры configure») и применяются при следующем configure: он запускается, когда в папке сборки нет build.ninja.

Цели ninja

ЦельЧто собирает
(без цели), allВсе модули, без образов дисков.
bootcdУстановочный CD — bootcd.iso.
livecdCD, работающий без установки, — livecd.iso.
<модуль>Один модуль с зависимостями: ntoskrnl, hal, usbport...

Список всех целей: ninja -t targets all (длинный; удобно с | findstr usb).

Параметры ninja

ПараметрЧто даёт
-C папкаСобрать в указанной папке, не переходя в неё.
-j NЧисло одновременных заданий (без него ninja выбирает сам по числу ядер процессора).
-k 0Не останавливаться на ошибках, собрать всё, что можно.
-vПоказывать полные команды компилятора.
-t cleanУдалить собранные файлы (настройка CMake остаётся).
-nПоказать, что было бы собрано, ничего не делая.

ninja сам перезапускает CMake, если изменились файлы CMakeLists.txt.
