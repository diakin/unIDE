Командная строка RosBE

unIDE выполняет шаги сборки сам, но собирать можно и вручную — в командной строке RosBE.

Как открыть

Распакованный unIDE RosBE ярлыков не имеет. Командная строка RosBE открывается так (Win+R или cmd.exe), находясь в папке исходников:

cd /d D:\_F\balan\_SyntaxHLClaude\SyntaxHLBeta\projects\reactosVG14
cmd /k "C:\RosBE\RosBE.cmd"

Окно очищается, появляется заголовок «ReactOS Build Environment 2.2.1» и подсказка help. Папка, из которой открыта консоль, становится папкой исходников для команды basedir. Сборка для amd64 — cmd /k "C:\RosBE\RosBE.cmd" amd64 (нужен компилятор x86_64).

Сборка вручную

configure.cmd
cd output-MinGW-i386
ninja bootcd

configure.cmd создаёт папку output-MinGW-i386 и в ней build.ninja; ninja bootcd собирает образ bootcd.iso в той же папке.

Собрать только один модуль: ninja ntoskrnl. Вместо ninja можно писать make / makex — команды RosBE, которые запускают тот же ninja и пишут журнал (см. Команды).

Вернуться в папку исходников — basedir; список команд RosBE — help, справка по команде — help clean.
