# RqLcl — компоненты RapidQ поверх LCL для FreeBASIC (прототип)

Проверка подхода: классы RapidQ (QFORM, QBUTTON, …) не пишутся заново, а берутся из LCL (Lazarus). LCL собрана в DLL с плоским набором функций; программа на FreeBASIC подключает `rqlcl.bi`, где классы RapidQ — обычные `Type` со свойствами и событиями.

`Label.Font = Font` копирует значения шрифта в элемент, как в RapidQ. `Label.Font` при чтении — QFONT поверх шрифта самого элемента: `Label.Font.Size = 20` меняет элемент. `Font` и `SelAttributes` в `rqlcl.bi` — функции `ByRef`, а не свойства: у свойства FreeBASIC с парой get/set запись `Label.Font.Size = 20` не компилируется (fbc 1.10.1); присваивание `Label.Font = Font` идёт через `Operator Let` у QFONT.

WndProc: у элемента с окном (QFORM, QEDIT, QLISTBOX) DLL подменяет оконную процедуру окна (`SetWindowLongPtrW`, `GWLP_WNDPROC`) — обработчик получает все сообщения Windows этого окна, в том числе те, которые LCL дальше не передаёт (WM_COPYDATA, WM_USER и выше, сообщения `WSAAsyncSelect` у QSOCKET), и вызывается до обработки сообщения LCL; результат сообщения обработчик не меняет (у RapidQ WndProc — SUB). Окно создаётся сразу при назначении WndProc (до Show); если LCL создаёт окно заново (смена BorderStyle и т. п.), подмена ставится снова по первому сообщению LCL. У QLABEL окна нет: обработчик получает сообщения LCL этой надписи (номера сообщений мыши совпадают с WM_…), Hwnd — окно родителя; что передаёт RapidQ в этом случае — не проверено. wParam и lParam — 32 бита (в 64-битной программе старшая половина теряется). В DLL — `dll/rqlclwnd.pas`.

Обработчик может быть в четырёх видах: с этими параметрами; с ними и `ByRef Sender As <класс>` последним (как в RapidQ: `SUB GridDraw(Col%, Row%, State%, Rect AS QRect, Sender AS QStringGrid)`); только с Sender; без параметров. Shift — как TShiftState Delphi: Shift 1, Alt 2, Ctrl 4, кнопки мыши 8/16/32, двойной щелчок 64. Button: 0 левая, 1 правая, 2 средняя. State в OnDrawCell: выделена 1, в фокусе 2, фиксированная 4. `Key = 0` в OnKeyPress — символ не вводится; `CanSelect = 0` в OnSelectCell — ячейку выбрать нельзя; `Key` в OnKeyDown/OnKeyUp тоже возвращается в LCL. Препроцессор сам приводит заголовок обработчика к этим типам (`Key AS WORD` → `ByRef Key As Long`), потому что адрес процедуры в rqlcl.bi передаётся без преобразования и типы должны совпасть точно.

В DLL: `RqSetEventEx(объект, событие, номер, процедура)`; LCL вызывает переходник `TRqEventLink`, тот — процедуру с номером события и записью `TRqEventArgs` (8 целых и строка). В rqlcl.bi обработчики лежат в `QCONTROL.EventProcs`, вызывает их `RqLclEventEx`.

Рисование на QSTRINGGRID, QLISTBOX, QCOMBOBOX (обычно в OnDrawCell / OnDrawItem; координаты — в окне таблицы, прямоугольник ячейки — параметр R): FillRect(x1, y1, x2, y2, цвет), TextOut(x, y, текст, цвет, фон; фон -1 — прозрачный), Line, Rectangle, RoundRect, Circle(x1, y1, x2, y2, цвет, заливка), Pset, Paint. QRECT — Left, Top, Right, Bottom.

QSTRINGGRID — `TStringGrid` LCL. У свойства FreeBASIC один индекс, поэтому `Cell(c, r)` — функция, а запись — `SetCell(c, r, значение)`; препроцессор сам переводит `Grid.Cell(c, r) = x` в `Grid.SetCell(c, r, x)`. Ячейка вне таблицы: Smart — пустая строка и предупреждение в лог, Compat — сообщение и конец программы. Начальные значения как в документации RapidQ (DefaultColWidth 64, DefaultRowHeight 24); ScrollBars 1–3 — полосы, только когда нужны (так у Delphi). Separator по умолчанию — Tab (в документации RapidQ значения по умолчанию нет). LoadFromFile(файл, RowOffset, ColOffset, MaxRows): строка файла — строка таблицы с RowOffset, ячейки — с ColOffset, MaxRows 0 — все строки; RowCount становится RowOffset + число строк, ColCount растёт под самую длинную строку — как это делает RapidQ, не проверено. ColumnStyle(i): 0 gcsList — редактор ячейки — выпадающий список (пункты — ColumnList(i) через LF или из OnListDropDown), 1 gcsEllipsis — поле с кнопкой "…" (OnEllipsisClick), 2 gcsNone — обычный; редактор нужен — `AddOptions(goEditing)`. TabStops(i) = 0 — Tab (с goTabs) проходит столбец мимо (в LCL TabStops нет, переход делает DLL).

QDIRTREE — `TShellTreeView` LCL (диски и папки). Directory — без `\` в конце, кроме корня диска. OnChange при выборе папки пользователем; при `Directory = …` из программы LCL OnChange не вызывает (как в RapidQ — не проверено).

QSTRINGLIST и QREGISTRY повторяют TStringList и TRegistry Delphi: IndexOf/Sort без учёта регистра (CompareString Windows); Text — строки через CR LF и CR LF в конце; OpenKey("a") — от текущего ключа, OpenKey("\a") — от корня; ReadString несуществующего значения — "", ReadInteger/ReadFloat — ошибка. Smart: ошибка (номер вне списка, нет файла, нет значения) — предупреждение в лог и stderr, работа продолжается; OpenKey без прав на запись открывает ключ на чтение. Compat: сообщение и конец программы, как в RapidQ.

QTREEVIEW — `TTreeView` LCL; номер пункта сквозной (AbsoluteIndex), как в RapidQ; `Tree.Item(i)` — функция ByRef, возвращает посредника QTREENODE (так же `Bar.Panel(i)` — QSTATUSPANEL). OnChange в LCL приходит не сразу, а по таймеру после смены выделения (проверено: при `ItemIndex = 2` — после DoEvents). QFILELISTBOX — `TFileListBox` LCL: папки — `[имя]`, маска `*.*` переводится в `*` (в масках LCL `*.*` — только имена с точкой). QSTATUSBAR: AutoSize выключен, высота 22 — с AutoSize LCL при показе формы создаёт окно строки состояния без родителя (ошибка 1406, проверено под Wine). Color работает у всех элементов (у TTabControl LCL он не published).

QRICHEDIT — `TRichMemo` из пакета RichMemo (на Windows — окно RichEdit). `SelAttributes` меняет у выделения только изменённое свойство (у выделения с разными шрифтами `SelAttributes.Color = …` меняет один цвет); без выделения — атрибуты точки ввода, их получит следующий вставленный текст (`AddStrings`, `SelText`). Позиции `SelStart`/`SelLength` — в символах окна RichEdit, перевод строки там — один символ, а в `Text` — два (CR LF). LoadFromFile: RTF, если файл начинается с `{\rtf`, иначе обычный текст; SaveToFile — RTF; `PlainText = 1` — всегда обычный текст. События клавиатуры и мыши — см. «События с параметрами».

Свойства в DLL ищутся по имени через RTTI LCL, поэтому новое свойство с тем же именем, что в LCL, добавляется в `rqlcl.bi` двумя строками, без правки DLL. Где имя у RapidQ другое — таблица `RqPropTable` в `dll/rqlclcore.pas`.

## Как устроено

- DLL (`stdcall`): `RqInit`, `RqDone`, `RqCreate(класс, родитель, указатель вызывающего)`, `RqSetInt` / `RqGetInt`, `RqSetStr` / `RqGetStr`, `RqSetObj` (Parent, Font), `RqGetObj` (Font), `RqSetEvent`, `RqCall` (ShowModal, Show, Close, Click…), `RqCallInt` (метод с целым параметром: AddStyle, DelStyle, FontCount, SetHandle), `RqGetHandle` (HWND, HFONT), `RqGetItemStr` / `RqSetItemStr` (строка списка по номеру: FontName, Line), `RqCallStr` (метод со строкой: AddStrings, LoadFromFile, SaveToFile), `RqGetCell` / `RqSetCell` (ячейка таблицы), `RqGetItemInt` / `RqSetItemInt` (ColWidths, RowHeights), `RqCallEx` (метод со строкой и тремя целыми: LoadFromFile таблицы, SwapCols…), `RqSetEventEx` (событие с параметрами), `RqCallInts` (метод со строкой и списком целых: рисование), `RqDoEvents`, `RqLastError`, `RqFree`. QFONT в DLL — `TFont` LCL; `RqSetObj(шрифт, "Assign", другой)` копирует значения. Свойства, которых нет в RTTI LCL (SelStart, SelText, Text у многострочных, Line…), и QRICHEDIT — в `dll/rqlclrich.pas`; QSTRINGGRID и QDIRTREE — в `dll/rqlclgrid.pas`; меню, списки, QCOOLBTN, ClientWidth/ClientHeight — в `dll/rqlclmisc.pas`; QGAUGE, QTABCONTROL, QTREEVIEW, QSTATUSBAR, QFILELISTBOX — в `dll/rqlclmore.pas`; QLISTVIEW и QFONTDIALOG — в `dll/rqlclview.pas` (SubItem(i, j) — через `RqGetCell` / `RqSetCell`: столбец — номер подпункта, строка — номер пункта). События без параметров у новых классов (OnClick, OnDblClick, OnChange, OnPopup, OnMoved) идут тем же путём, что события с параметрами (`RqSetEventEx`); `RqCallObj` — метод с объектом (AddItems пунктов меню).
- Событие: в DLL у объекта свой переходник на каждое событие; LCL вызывает его метод, он — процедуру программы с адресом объекта FreeBASIC. В `rqlcl.bi` эта процедура вызывает обработчик пользователя `Sub Xxx(ByRef Sender As QBUTTON)`.
- Строки с обеих сторон — в кодировке Windows (CP1251 у исходников RapidQ); внутри DLL — UTF-8 LCL.
- Исключения через границу DLL не идут: функция возвращает 0, текст — `RqLastError`; `rqlcl.bi` показывает его окном.
- `RqDone` вызывается деструктором модуля `rqlcl.bi` в конце программы: окна и LCL освобождаются, пока программа работает, а не при выгрузке DLL.

## Проверено

В рабочей среде (Linux, Wine 9, виртуальный дисплей): DLL собраны кросс-компилятором FPC, программы — Windows-версией fbc 1.10.1 (win32 и win64) под Wine. `selftest` для 32 и 64 бит — все проверки прошли; `demo` с исходником в CP1251 и русской локалью показывает кириллицу правильно. На настоящей Windows не запускалось. `dll/build.bat` на Windows не проверялся.

## Не сделано

- Синтаксис RapidQ (`Button1.OnClick = Button1Click` без `@`, `CREATE … END CREATE`, `TYPE … EXTENDS`, `$INCLUDE` и т. д.) переводит препроцессор `tofb/RqToFb.pas` — что сделано и что нет, в `tofb/README.md`.
- Остальные классы RapidQ (список — в проектном документе «RapidQ: не сделано»).
- QRICHEDIT LineIndex, GetLineIdx, LineFromChar, GoToLineBegin, GoToLineEnd в документации взяты из RichEdPopUp.inc (свой компонент QMAXEDIT на QRICHEDIT) — переводятся вместе с этим include, в RqLcl их нет.
- `STRING*N` в TYPE у FreeBASIC занимает N + 1 байт (проверено: `TYPE T: S AS STRING*8: N AS INTEGER` — SizeOf 16 без выравнивания 13), у RapidQ — N (глава 7: 12 байт; тест пользователя: `S AS STRING*5`, `N AS INTEGER` — SIZEOF 9). Выравнивание полей уже как у RapidQ — без промежутков (`Type … Field = 1`), а поле `STRING*N` пока на байт длиннее: WriteUDT/ReadUDT и записи для функций Windows (OSVERSIONINFO и т. п.) с таким полем получают не тот размер.
- QIMAGELIST.Handle и Clipboard.Format(i) — только чтение. StartDrag: элемент едет за мышью, пока нажата кнопка мыши, нажатие самой кнопки-элемента отменяется (ReleaseCapture); с настоящей мышью не проверялось (под Wine проверен только возврат без нажатой кнопки), как это делает RapidQ — тоже не проверено. Rotate: поворот против часовой стрелки, открывшееся место заливается цветом кисти холста — у RapidQ не проверено.
- Font, свойства-объекты кроме Parent. Boolean-свойства при чтении дают 1 / 0, как в RapidQ (о TRUE/FALSE — RAPIDQ_RULES.md).

## Лицензия LCL

LCL распространяется под LGPL с исключением (`COPYING.modifiedLGPL.txt` в исходниках Lazarus): её можно компоновать с независимыми модулями и распространять результат на своих условиях; изменения самой LCL остаются под её лицензией.
